# File and text hash calculator



Choose text or files, select a SHA-2 algorithm, and calculate. Paste an expected digest to verify a match or download the results as CSV.





## Get started



1. Choose text or select one or more files.
2. Select SHA-256, SHA-384, or SHA-512, then calculate.
3. Paste an expected hash to verify it, or download the result CSV.







## Example



### Input



```
Text: abc, UTF-8, SHA-256
```



### Expected result



```
ba7816bf8f01cfea414140de5dae2223b00361a396177a9cb410ff61f20015ad
```







## Try it



[Open full tool](<https://toolpony.com/en/tools/file-hash-calculator/>)







## Good to know



Hash verification compares bytes. A different encoding, a line ending, or even one changed byte produces a different digest.







## Limits



Up to 16 files and 64 MB combined, or one million text characters. Text uses UTF-8. Files are processed sequentially in the browser.
