# 星期幾計算器



查詢某天的星期、年內日序、ISO 週數和該星期在當年的次數。





## 開始使用



1. 按示例填寫數值，或輸入你自己的測量值。
2. 計算後可複製結果或下載明細。







## 示例



### 輸入



```
2000-01-01
```



### 預期結果



```
星期六
```

## 使用提示



計算在瀏覽器內完成。無單位標記的字段請使用一致單位。







## 計算方法



採用公曆。ISO 周從週一開始，第 1 周包含 1 月 4 日。1 月初的日期可能屬於上一年的最後一週。
