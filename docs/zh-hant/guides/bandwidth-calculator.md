# 帶寬與下載時間計算器



根據文件大小、帶寬與有效傳輸比例估算下載時間。





## 示例



### 輸入



```
1 GB，100 Mbps，有效率 100%
```



### 預期結果



```
80 秒
```







## 試一試

[打開完整工具 · 帶寬與下載時間計算器](<https://toolpony.com/zh-hant/tools/bandwidth-calculator/>)





## 計算方法



秒數 = 文件字節數 × 8 ÷ 有效每秒比特數。帶寬單位用十進制前綴，文件大小支持十進制和二進制。
