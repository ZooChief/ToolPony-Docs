# Potenzrechner



Lösen Sie eine Potenz, die Basis oder den Exponenten aus den anderen beiden Werten.





## Erste Schritte



1. Verwenden Sie das Beispiel oder geben Sie eigene Werte ein.
2. Berechnen Sie das Ergebnis und kopieren oder laden Sie die Details herunter.







## Beispiel



### Eingabe



```
Basis 2, Exponent 5
```



### Erwartetes Ergebnis



```
32
```







## Ausprobieren



[Vollständiges Werkzeug öffnen](<https://toolpony.com/de/tools/exponent-calculator/>)







## Hinweise



Die Verarbeitung erfolgt im Browser. Verwenden Sie einheitliche Einheiten.







## Berechnungsmethode



Für y = bn lösen Sie den Exponenten mit Logarithmen, wenn b und y positiv und b ≠ 1 sind.



$$
y=b^p,\qquad p=\frac{\ln y}{\ln b},\qquad b=\sqrt[p]{y}
$$
