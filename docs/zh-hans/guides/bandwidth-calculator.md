# 带宽与下载时间计算器使用指南



根据文件大小、带宽与有效传输比例估算下载时间。





## 示例



### 输入



```
1 GB，100 Mbps，有效率 100%
```



### 预期结果



```
80 秒
```







## 试一试

[打开完整工具 · 带宽与下载时间计算器](<https://toolpony.com/zh-hans/tools/bandwidth-calculator/>)





## 计算方法



传输秒数 = 文件字节数 × 8 ÷ 有效每秒比特数。1 MB/s 是每秒 1,000,000 字节，1 MiB/s 是每秒 1,048,576 字节。有效速率按输入的效率折算。





**方法来源** [NIST · Binary prefixes](<https://physics.nist.gov/cuu/Units/binary.html>)
