# GPA-Rechner



Berechnen Sie den kursgewichteten GPA, schließen Sie frühere Credits und Gruppensemester ein oder berechnen Sie den GPA, der benötigt wird, um ein Ziel zu erreichen.





## Erste Schritte



1. Verwenden Sie das Beispiel oder geben Sie eigene Werte ein.
2. Berechnen Sie das Ergebnis und kopieren oder laden Sie die Details herunter.







## Beispiel



### Eingabe



```
Mathematik, 3, A und Englisch, 3, B
```



### Erwartetes Ergebnis



```
GPA 3.5
```

## Hinweise



Die Verarbeitung erfolgt im Browser. Verwenden Sie einheitliche Einheiten.







## Berechnungsmethode



GPA ist Gesamtnotenpunkte mal Credits geteilt durch Gesamtgutschriften. Briefnoten verwenden die angezeigte 4,3-Punkte-Skala. Prozentuale Durchschnittswerte prozentuale Prozentsätze direkt. Verwenden Sie explizite Punkte für andere Schulskalen.



$$
\operatorname{GPA}=\frac{\sum_i g_i c_i}{\sum_i c_i}
$$



Geben Sie einen Kurs pro Zeile ein. In der vierten Spalte können Kurse nach Laufzeit gruppiert werden. In der fünften Spalte wird ein expliziter Bonus pro Kredit für einen Kurs hinzugefügt. Geben Sie vorherige GPA und Credits zusammen ein, wenn Sie einen vorhandenen Datensatz hinzufügen.



A+ bis F verwenden Sie die 4,3-Punkte-Mapping. P, NP, I und W werden aus der gewichteten Summe weggelassen. Verwenden Sie den Punktemodus, um einer schulspezifischen numerischen Skala zu folgen.







## Berechnungsmodus



**Kursnoten**

- Kurs, Credits, Besoldungsgruppe, fakultative Laufzeit und Bonus
- Gradformat · Briefe / Prozentsatz / Punkte
- Bisheriger GPA
- Vorherige Kredite





**Planziel GPA**

- Aktuelles GPA
- Ziel-GPA
- Ausgefüllte Kredite
- Zusätzliche Kredite
