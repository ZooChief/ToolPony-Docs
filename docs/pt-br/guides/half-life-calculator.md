# Calculadora de meia-vida



Resolva o decaimento exponencial de quaisquer três medições, ou converta entre meia-vida, vida média e constante decaimento.





## Primeiros passos



1. Use o exemplo ou insira seus próprios valores.
2. Calcule, copie o resultado ou baixe os detalhes disponíveis.







## Exemplo



### Entrada



```
100 a 10 em 50 unidades de tempo
```



### Resultado esperado



```
Meia-vida □ 15.0515
```

## Notas de uso



O cálculo é feito no seu navegador. Use unidades consistentes.







## Método de cálculo



O decaimento exponencial é N( t) = N0 · 2^ (− t/ T). T é meia- vida, a vida média é T/ ln(2) e a constante decaimento é ln(2)/ T. A conversão usa ln(2) arredondada a dez casas decimais. Use a mesma unidade de tempo para todos os campos.



$$
N(t)=N_0\,2^{-t/T},\qquad \lambda=\frac{\ln 2}{T},\qquad \tau=\frac1\lambda
$$



Escolha o desconhecido primeiro. Use unidades de tempo consistentes em todos os outros três campos. Para uma quantidade inicial de 100 e uma meia- vida de 10, a quantidade restante após 20 unidades de tempo é 25.







## Modo de cálculo



**Procurar meia- vida**

**Procurar a quantidade restante**

**Procurar a quantidade inicial**

**Procurar o tempo decorrido**
