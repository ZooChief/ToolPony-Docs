# 進制轉換與計算器



在 2–36 進制之間轉換帶符號整數，並進行精確算術、取餘和位運算。





## 開始使用



1. 按示例填寫數值，或輸入你自己的測量值。
2. 計算後可複製結果或下載明細。







## 示例



### 輸入



```
FF，從十六進制轉十進制
```



### 預期結果



```
255
```

## 使用提示



計算在瀏覽器內完成。無單位標記的字段請使用一致單位。







## 計算方法



大整數運算保留整數精度。除法向零取整，位運算按有符號 BigInt 語義。每個操作數最多 256 位。







## 計算模式



**進制轉換**

- 整數
- 輸入進制
- 輸出進制
- 最少輸出位數





**整數運算**

- 整數一
- 整數二
- 輸入進制
- 輸出進制
- 最少輸出位數
- 運算 · 加 / 減 / 乘 / 除 / 餘數 / 按位與 / 按位或 / 按位異或
