# 나이 계산기



나이, 경과 시간, 다음 생일을 계산합니다.





## 시작하기



1. 생년월일과 기준일을 입력하세요. 기준일을 비우면 기기의 오늘 날짜를 사용합니다.







## 예시



### 입력



```
생년월일 2000-01-01, 기준일 2025-02-03
```



### 예상 결과



```
25년 · 1개월 · 2일
```







## 직접 사용해 보기



[전체 도구 열기](<https://toolpony.com/ko/tools/age-calculator/>)







## 참고 사항



브라우저에서 처리합니다. 단위를 일관되게 사용하세요.







## 계산 방법



같은 날짜를 기준으로 하며 짧은 달은 말일로 맞춥니다. 2월 29일생은 평년 기준을 2월 28일이나 3월 1일로 선택하세요. 경과 시간은 하루 24시간으로 계산합니다.
