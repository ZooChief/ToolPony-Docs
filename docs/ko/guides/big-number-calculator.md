# 큰 수 계산기



정확히 큰 정수와 십진수 계수로 계산하고, 분할 및 뿌리에 대해 선택 가능한 반올림.





## 시작하기



1. 예제 값을 사용하거나 원하는 값을 입력하세요.
2. 계산한 결과를 복사하거나 세부 정보를 내려받을 수 있습니다.







## 예시



### 입력



```
9,007,199,254,740,993 + 7
```



### 예상 결과



```
9007199254741000
```

## 참고 사항



브라우저에서 처리합니다. 단위를 일관되게 사용하세요.







## 계산 방법



Addition, subtraction, 곱셈, 정수 powers 및 정수 연산은 BigInt 계수를 사용합니다. 구분은 선택한 소수 자릿수로 반올림됩니다. 사각 뿌리는 가장 가까운 곳으로 번지거나 둥글게 할 수 있습니다. 양수 및 음수 정수 지수는 결과 한도 내에서 지원됩니다.



$$
x=m\cdot 10^e,\quad x_1x_2=(m_1m_2)\cdot 10^{e_1+e_2}
$$
