# 瓷磚用量計算器



根據瓷磚尺寸、留縫和鋪貼面積估算片數、箱數與費用。





## 開始使用



1. 填寫磚長、磚寬和縫隙。負縫寬表示相鄰磚有搭接。
2. 輸入已知面積，或輸入區域的長和寬。填每箱片數可估算整箱數。
3. 需要預留切割和破損時，在「更多選項」填寫損耗率。片數按面積覆蓋估算。







## 示例



### 輸入



```
180 平方英尺、12 × 12 英寸瓷磚、¼ 英寸縫、每箱 12 片
```



### 預期結果



```
173 片，15 箱
```

## 計算方法



面積除以（磚長 + 縫寬）×（磚寬 + 縫寬）後向上取整。負縫寬表示搭接。按需加損耗，再換算成整箱。



$$
N=\left\lceil\frac{A}{(l+g)(w+g)}\right\rceil,\quad N_{\rm order}=\left\lceil N(1+a/100)\right\rceil
$$



180 平方英尺使用 12 英寸方磚並留 ¼ 英寸縫，估算需 173 片。預留 10% 後爲 191 片，每箱 12 片時向上取整爲 16 箱。



覆蓋模型用每片磚的有效長度和寬度。損耗率可預留切割、拼花和破損。最終排版請用實際房間和磚尺寸覈對。
