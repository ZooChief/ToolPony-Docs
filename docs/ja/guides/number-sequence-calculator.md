# 数列計算機



等差数列、等比数列、フィボナッチ数列の項と部分和を求め、一覧をダウンロードできます。





## 使い方



1. 例を使うか、任意の値を入力します。
2. 計算後、結果をコピーするか詳細をダウンロードできます。







## 例



### 入力



```
等差数列、初項 7、公差 −3、第 8 項
```



### 期待される結果



```
−14、和 −28
```







## 試してみる



[ツール全体を開く](<https://toolpony.com/ja/tools/number-sequence-calculator/>)







## 注意点



処理はブラウザ内で実行されます。単位をそろえて入力してください。







## 計算方法



等差・等比数列の添字は 1 から始まります。フィボナッチ数列は F₀ = 0 から始まり、正確な整数で計算します。



$$
a_n=a_1+(n-1)d,\quad g_n=g_1r^{n-1},\quad F_n=F_{n-1}+F_{n-2}
$$







## 計算モード



**等差数列**

- 初項
- 公差
- 添字





**等比数列**

- 初項
- 公比
- 添字





**フィボナッチ数列**

- 添字
