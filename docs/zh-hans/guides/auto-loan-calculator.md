# 车贷计算器



计入旧车折抵、未偿欠款、返现和税费，计算车贷月供或可承受车价。





## 开始使用



1. 输入车价，或切换到目标月供。填写首付、旧车折抵价和欠款，以及返现。
2. 输入税率和费用，选定税基抵扣与是否随贷，再导出还款表。







## 示例



### 输入



```
车价 30,000，首付 5,000，60 个月，年利率 5%
```



### 预期结果



```
税费为零时月供 471.78
```

## 计算方法



税率和抵扣规则由你输入。选择随贷时，税费计入本金。旧车净值为折抵价减去未偿债务。使用固定月利率。



$$
P=V-D-(T-O)-R+F,\quad M=\frac{Pr}{1-(1+r)^{-n}},\quad M=\frac Pn\; (r=0)
$$



V 为车价，D 为首付，T 为旧车折抵价，O 为旧车欠款，R 为返现，F 为随贷税费。P 为贷款本金，M 为月供，r 为月利率，n 为月数。
