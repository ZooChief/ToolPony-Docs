# ROI-Rechner



Berechnen Sie den Nettogewinn, die Gesamtrendite und die annualisierte Rendite mit Gebühren.





## Erste Schritte



1. Verwenden Sie das Beispiel oder geben Sie eigene Werte ein.
2. Berechnen Sie das Ergebnis und kopieren oder laden Sie die Details herunter.







## Beispiel



### Eingabe



```
1.000 investieren, nach 2 Jahren 1.210 erhalten
```



### Erwartetes Ergebnis



```
21% insgesamt; 10% annualisiert
```







## Ausprobieren



[Vollständiges Werkzeug öffnen](<https://toolpony.com/de/tools/roi-calculator/>)







## Hinweise



Die Verarbeitung erfolgt im Browser. Verwenden Sie einheitliche Einheiten.







## Berechnungsmethode



Die Gesamtrendite ist (Nettoerlös - Gesamtkosten) ÷ Gesamtkosten. Die annualisierte Rendite ergibt das gleiche Verhältnis über die angegebenen Jahre.
