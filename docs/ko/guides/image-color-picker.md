# 이미지 색상 추출



예제를 클릭하거나 이미지를 선택합니다. 포인트를 클릭하거나 픽셀 좌표를 입력하여 HEX 및 RGBA를 읽습니다. 색상을 복사하거나 샘플링 팔레트를 CSV로 내뿜습니다.





## 시작하기



1. 내장 예제를 시도하거나 이미지를 선택하십시오.
2. 포인트를 클릭하거나 X 및 Y를 입력하고 원래 픽셀을 샘플링합니다.
3. HEX를 복사하거나 최대 16개의 좌표 및 RGBA 행을 CSV로 내보내십시오.







## 예시



### 입력



```
붙박이 표본, X = 32와 Y = 32
```



### 예상 결과



```
#285eaa · RGBA 40, 94, 170, 255
```

## 참고 사항



미리보기는 샘플링이 여전히 해당 원본 픽셀을 읽는 동안 축소될 수 있습니다. 브라우저는 디코딩 중에 이미지 색상 프로필을 변환할 수 있습니다.







## 제한 사항



JPG, PNG, WebP, AVIF 또는 GIF 최대 20 MB 및 24 메가 픽셀. 브라우저의 디코딩된 픽셀을 읽습니다. 좌표는 왼쪽 상단의 (0, 0)에서 시작합니다. 팔레트는 최대 16 점을 보유합니다.
