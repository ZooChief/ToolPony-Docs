# 공약수 계산기



모든 양의 공통 요소를 나열하고 여러 정수의 가장 큰 공통 요소를 계산합니다.





## 시작하기



1. 예제 값을 사용하거나 원하는 값을 입력하세요.
2. 계산한 결과를 복사하거나 세부 정보를 내려받을 수 있습니다.







## 예시



### 입력



```
12, 18, 30
```



### 예상 결과



```
1, 2, 3, 6
```







## 직접 사용해 보기



[전체 도구 열기](<https://toolpony.com/ko/tools/common-factor-calculator/>)







## 참고 사항



브라우저에서 처리합니다. 단위를 일관되게 사용하세요.







## 계산 방법



목록의 일반적인 요소는 정확히 가장 큰 공통 쌍이자의 구분자입니다. 유클리드 알고리즘은 모든 입력의 요소를 열거하지 않고 디바이저를 찾습니다.



$$
d\mid a_1,\ldots,a_n\iff d\mid\gcd(a_1,\ldots,a_n)
$$
