# Calculadora de ecuaciones cuadráticas



Resuelva ax2 + bx + c = 0 con raíces reales o complejas, incluyendo coeficientes fraccionados.





## Primeros pasos



1. Usa el ejemplo o introduce tus propios valores.
2. Calcula, copia el resultado o descarga los detalles disponibles.







## Ejemplo



### Entrada



```
a=1, b=−5, c=6
```



### Resultado esperado



```
x₁=2, x₂=3
```

## Notas de uso



El cálculo se ejecuta en tu navegador. Usa unidades coherentes.







## Método de cálculo



Usar el b2-4ac discriminante. Un coeficiente cuadrático cero reduce la expresión a una ecuación lineal.



$$
ax^2+bx+c=0,\qquad x=\frac{-b\pm\sqrt{b^2-4ac}}{2a},\quad a\ne0
$$
