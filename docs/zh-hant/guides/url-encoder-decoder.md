# URL 編碼與解碼



編碼或解碼完整 URL、URI 組件和表單值。





## 開始使用



1. 按示例填寫數值，或輸入你自己的測量值。
2. 計算後可複製結果或下載明細。







## 示例



### 輸入



```
編碼組件：a+b & c
```



### 預期結果



```
a%2Bb%20%26%20c
```

## 使用提示



計算在瀏覽器內完成。無單位標記的字段請使用一致單位。







## 計算方法



組件編碼轉義保留分隔符。完整 URL 模式保留分隔符。表單模式用加號表示空格。
