# Descomposición en factores primos



Encontrar los factores principales, la forma exponente y el recuento de divisor de un entero positivo.





## Ejemplo



### Entrada



```
360
```



### Resultado esperado



```
2³ × 3² × 5, 24 divisores
```







## Pruébalo



[Abrir herramienta completa](<https://toolpony.com/es/tools/prime-factorization-calculator/>)







## Método de cálculo



La división de pruebas elimina factores hasta la raíz cuadrada del entero restante. Rango de entrada: 2 a 1 trillón.
