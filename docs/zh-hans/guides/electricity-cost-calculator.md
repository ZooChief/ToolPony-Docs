# 电费计算器



按设备、平均负载与电价，估算固定天数或日、周、月、年电费。





## 开始使用



1. 填设备输入功率、运行时间与电价。电器预设填入可修改的示例值。







## 示例



### 输入



```
1,000 W，每天 2 小时，30 天，每度 0.2
```



### 预期结果



```
用电 60 度，电费 12
```

## 使用提示



计算在浏览器内完成。无单位标记的字段请使用一致单位。







## 计算方法



电量等于千瓦功率乘运行小时、平均负载和设备数。电费按固定单价算。周期估算使用每月 30.44 天、每年 365.25 天。制冷量表示传热能力，算电费用电气输入功率。



$$
E_{\rm kWh}=P_{\rm kW}\,t_{\rm h}\,f\,n,\qquad C=E_{\rm kWh}\,r
$$







## 计算模式



**固定天数**

- 功率
- 功率单位 · W / kW / BTU/h / PS / TR
- 平均负载 · %
- 设备数量
- 每天运行小时 · h
- 天数
- 每度电单价





**日到年费用**

- 电器预设
- 功率
- 功率单位 · W / kW / BTU/h / PS / TR
- 平均负载 · %
- 设备数量
- 使用时长
- 使用时长单位 · 分钟/天 / 每天运行小时 / 小时/周 / 小时/月 / 天/周 / 天/月 / 天/年 / 月/年
- 每度电单价
