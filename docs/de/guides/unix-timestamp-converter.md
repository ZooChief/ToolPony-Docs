# Unix-Zeitstempel-Umrechner



Konvertieren Sie Sekunden und Millisekunden in UTC und konvertieren Sie eine ISO-Zeit mit einem expliziten Offset zurück in Unix-Zeit.





## Erste Schritte



1. Verwenden Sie das Beispiel oder geben Sie eigene Werte ein.
2. Berechnen Sie das Ergebnis und kopieren oder laden Sie die Details herunter.







## Beispiel



### Eingabe



```
0 Sekunden
```



### Erwartetes Ergebnis



```
1970-01-01T00:00:00.000Z
```

## Hinweise



Die Verarbeitung erfolgt im Browser. Verwenden Sie einheitliche Einheiten.







## Berechnungsmethode



Unix-Zeit ist seit 1970-01-01T00:00:00Z verstrichen. Conversions-Unterstützung datiert von 1900 bis 9999 mit Millisekundengenauigkeit.







## Berechnungsmodus



**Zeitstempel bis dato**

- Unix-Zeitstempel
- Einheit · Sekunden / Millisekunden





**Datum des Zeitstempels**

- ISO 8601 mit Offset
