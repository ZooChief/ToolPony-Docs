# 正態分佈 P 值計算器



計算正態分佈的左尾、右尾和雙尾 P 值，或由概率反求 Z 分數。





## 開始使用



1. 按示例填寫數值，或輸入你自己的測量值。
2. 計算後可複製結果或下載明細。







## 示例



### 輸入



```
z = 2.36
```



### 預期結果



```
雙尾約 0.018275
```

## 計算方法



正態檢驗統計量的雙尾 P 值是 |z| 處右尾概率的兩倍。尾部的選取應與備擇假設一致。



$$
p_{\mathrm{two\ tails}}=2[1-\Phi(|z|)]
$$
