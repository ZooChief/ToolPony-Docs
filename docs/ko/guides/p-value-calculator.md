# 정규분포 p값 계산기 사용 가이드



왼쪽, 오른쪽 및 양면 일반 p 값을 찾거나 선택한 확률을 반전합니다.





## 예시



### 입력



```
z = 2.36
```



### 예상 결과



```
양측 확률 ≈ 0.018275
```







## 직접 사용해 보기

[전체 도구 열기 · 정규분포 p값 계산기](<https://toolpony.com/ko/tools/p-value-calculator/>)





## 계산 방법



일반 테스트 통계의 경우 양면 p 값은 |z| 위의 꼬리의 두 배입니다. 꼬리의 정의는 대체 가설과 일치해야합니다.



$$
p_{\mathrm{two\ tails}}=2[1-\Phi(|z|)]
$$







## 계산 모드





### Z 점수를 확률로



- Z 점수







### 확률을 Z 점수로



- 확률 영역 · 왼쪽 꼬리 확률 / 오른쪽 꼬리 확률 / 중심부터 |z|까지 / −|z|와 |z| 사이 / 양쪽 꼬리 확률
- 확률
