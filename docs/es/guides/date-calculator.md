# Calculadora de fechas



Cuenta días naturales y laborables o desplaza una fecha.





## Primeros pasos



1. Introduce dos fechas y decide si incluyes la más reciente. Añade festivos en Más opciones.
2. Usa un valor negativo para retroceder. El modo laborable omite sábados, domingos y festivos indicados.







## Ejemplo



### Entrada



```
Del 2020-01-01 al 2020-02-01
```



### Resultado esperado



```
31 días naturales, 23 laborables
```

## Notas de uso



El cálculo se ejecuta en tu navegador. Usa unidades coherentes.







## Método de cálculo



Los laborables son de lunes a viernes salvo las fechas indicadas. AAAA-MM-DD se aplica una vez y MM-DD cada año. El desplazamiento incluye el extremo anterior y excluye el posterior. El resultado puede caer en día no laborable. Los meses cortos usan el último día.







## Modo de cálculo



**Entre fechas**

- Fecha inicial
- Fecha final
- Incluir la fecha final
- Festivos (AAAA-MM-DD o MM-DD)





**Sumar o restar fechas**

- Fecha inicial
- Años
- Meses
- Semanas
- Días





**Desplazar en días laborables**

- Fecha inicial
- Días laborables
- Festivos (AAAA-MM-DD o MM-DD)
