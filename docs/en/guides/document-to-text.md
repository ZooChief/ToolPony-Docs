# Document to text



Choose a DOCX, ODT or PDF from your device, or open the sample DOCX.





## Get started



1. Choose a DOCX, ODT or PDF from your device, or open the sample DOCX.
2. Paragraphs start on new lines. Table cells are separated by tabs. Copy the result or download a UTF-8 text file.







## Example



### Input



```
DOCX with a title, two text runs and a tab
```



### Expected result



```
ToolPony
ABC	123
```







## Try it



[Open full tool](<https://toolpony.com/en/tools/document-to-text/>)







## Limits



DOCX and ODT use the main body, up to 20 MiB per file and 1 MiB of extracted UTF-8 text. PDF needs selectable text. Images, page formatting and password-protected files are outside this tool’s scope.
