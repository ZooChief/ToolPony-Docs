# 圖片壓縮



選擇最多 12 張圖，設置 JPEG 或 WebP、畫質或單文件目標體積，以及可選的最長邊。逐張對比，單獨下載或打包 ZIP。





## 開始使用



1. 選擇最多 12 張圖，設置 JPEG 或 WebP。
2. 選擇畫質或每張圖的目標大小。可設最長邊，等比例縮小較大的圖。目標模式可允許進一步縮小。
3. 逐張對比原圖和結果。可以單獨下載，也可將處理成功的圖片打包。







## 示例



### 輸入



```
兩張照片，WebP，每張 100 KB，最長邊 1200 px，允許縮小
```



### 預期結果



```
將達到目標的 WebP 打包成 ZIP，每張不超過 100,000 字節。
```

## 使用提示



這裏 1 KB = 1,000 字節。目標爲大小上限，不是精確字節數。JPEG/WebP 是有損編碼，透明 PNG 可選 WebP 保留透明度。較小的原文件也可能越壓越大，結果會如實提示。







## 適用範圍



每張最多 20 MB、2400 萬像素；批次輸入和輸出各限 64 MiB。最長邊僅縮小較大圖片。JPEG 和 WebP 爲有損編碼。動圖轉爲單幀並移除原始元數據。
