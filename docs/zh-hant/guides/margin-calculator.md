# 利潤率與加價率使用指南



比較毛利率和加價率，算出最低售價或最高採購成本，用相鄰一分的報價覈對目標。





## 示例



### 輸入



```
成本 60，售價 100
```



### 預期結果



```
毛利率 40%，加價率約 66.67%
```





<a id="case-study"></a>



## 給出能達到 34% 毛利率的報價



1. 成本爲 10.00 時，理論售價是 10 ÷ 0.66，約 15.1515。定價 15.15 會低於 34% 的目標；精確到分的最低售價爲 15.16。用此售價覈算，可得毛利 5.16，實際毛利率約 34.04%。





## 按分報價達到 12% 加價率



成本 17.20，按成本加價 12%，未取整售價是 19.264。報價 19.26 時實際加價率約 11.98%，報價 19.27 才達到約 12.03%。若目標是佔售價 12% 的毛利率，最低售價則是 19.55。

## 倒推採購成本上限



售價 20.01，目標毛利率 30%，精確成本上限是 14.007。按分結算，付 14.00 能達到目標，付 14.01 時毛利率就低於 30%。

## 計算方法



毛利 = 售價 − 成本。毛利率的分母是售價，加價率的分母是成本。按分報價時，最低售價向上取整，最高採購成本向下取整。







## 計算模式





### 成本與售價



- 成本
- 售價







### 按目標毛利率定價



- 成本
- 目標毛利率 · %







### 按加價率定價



- 成本
- 目標加價率 · %







### 由售價和毛利率求成本



- 售價
- 目標毛利率 · %
