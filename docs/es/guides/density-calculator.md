# Calculadora de densidad



Resolver para la masa, el volumen o la densidad al entrar en cualquier dos valores.





## Primeros pasos



1. Usa el ejemplo o introduce tus propios valores.
2. Calcula, copia el resultado o descarga los detalles disponibles.







## Ejemplo



### Entrada



```
8 kg, 0,001 m3
```



### Resultado esperado



```
8.000 kg/m3
```

## Notas de uso



El cálculo se ejecuta en tu navegador. Usa unidades coherentes.







## Método de cálculo



Densidad = volumen de masa. La interfaz utiliza kg, m3 y kg/m3.



$$
\rho=\frac{m}{V}
$$
