# 正規分布の p 値計算機



左、右、両面の通常のp値を検索するか、選択した確率を反転します。





## 使い方



1. 例を使うか、任意の値を入力します。
2. 計算後、結果をコピーするか詳細をダウンロードできます。







## 例



### 入力



```
z = 2.36
```



### 期待される結果



```
両側確率 ≈ 0.018275
```







## 試してみる



[ツール全体を開く](<https://toolpony.com/ja/tools/p-value-calculator/>)







## 注意点



処理はブラウザ内で実行されます。単位をそろえて入力してください。







## 計算方法



通常のテスト統計では、両面p値は上尾の2倍の |z| です。 尾の定義は代替仮説と一致すべきである。



$$
p_{\mathrm{two\ tails}}=2[1-\Phi(|z|)]
$$







## 計算モード



**Z スコアから確率へ**

- Z スコア





**確率から Z スコアへ**

- 確率領域 · 左側確率 / 右側確率 / 中心から |z| まで / −|z| と |z| の間 / 両側確率
- 確率
