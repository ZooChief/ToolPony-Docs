# 二维码识别



选择、拖入或粘贴图片。独立工具页也可以开启相机。 核对识别结果后复制或下载。确认地址后再打开网页链接。





## 开始使用



1. 选择、拖入或粘贴图片。独立工具页也可以开启相机。
2. 核对识别结果后复制或下载。确认地址后再打开网页链接。

## 适用范围



每次读一个二维码。图片最大 20 MiB、2400 万像素，支持浏览器可读的 PNG、JPEG、WebP 和 SVG。相机需浏览器授权，识别成功后关闭。图片和帧留在本机。
