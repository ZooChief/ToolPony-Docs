# Anleitung: Bandbreitenrechner



Schätzen Sie die Übertragungszeit von der Dateigröße, der Verbindungsgeschwindigkeit und der Protokolleffizienz.





## Beispiel



### Eingabe



```
1 GB bei 100 Mbps, Effizienz 100%
```



### Erwartetes Ergebnis



```
80 Sekunden
```







## Ausprobieren

[Vollständiges Werkzeug öffnen · Bandbreitenrechner](<https://toolpony.com/de/tools/bandwidth-calculator/>)





## Berechnungsmethode



Übertragungszeit in Sekunden = Dateigröße in Byte × 8 ÷ effektive Bitrate. 1 MB/s entspricht 1.000.000 Byte/s, 1 MiB/s entspricht 1.048.576 Byte/s. Der Wirkungsgrad bestimmt die nutzbare Rate.





**Quellen zur Methode** [NIST · Binary prefixes](<https://physics.nist.gov/cuu/Units/binary.html>)
