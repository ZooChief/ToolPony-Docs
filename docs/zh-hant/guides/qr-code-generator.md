# 二維碼生成器



選擇掃描後要打開的類型，再填寫鏈接、文本或相應字段。 生成後可覈對編碼內容。分享可用 PNG，印刷可用 SVG。 需要時在外觀中填入深色六位 HEX。兩種導出都保留白色留邊。





## 開始使用



1. 選擇掃描後要打開的類型，再填寫鏈接、文本或相應字段。
2. 生成後可覈對編碼內容。分享可用 PNG，印刷可用 SVG。
3. 需要時在外觀中填入深色六位 HEX。兩種導出都保留白色留邊。
