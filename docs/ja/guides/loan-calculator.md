# ローン計算機



分割返済、月返済額からの期間、日付指定の繰上返済を計算し、明細を保存します。





## 使い方



1. 固定期間、目標月返済額、または日付指定の繰上返済を選択します。
2. 最初の返済月を指定します。臨時返済は 2026-06, 500 のように1行ずつ追加できます。
3. 計算して明細表を切り替え、選んだ表を保存します。







## 例



### 入力



```
元金100,000、10年、年利6%、月払い
```



### 期待される結果



```
月約1,110.21
```

## 計算方法



分割返済では名目年利を返済期間の利率に換算します。日付指定では月利を使い、予定額の後に追加返済を差し引きます。固定金利で途中の端数は丸めません。



$$
M=\frac{Pr}{1-(1+r)^{-n}},\qquad M=\frac Pn\quad(r=0)
$$



$$
n=\frac{-\ln(1-Pr/M)}{\ln(1+r)},\qquad M>Pr\quad(r>0)
$$



$$
I_k=r B_{k-1},\qquad B_k=\max(0,B_{k-1}-(M-I_k)-E_k)
$$



P は元金、r は1回分の利率、M は予定返済額、n は返済回数です。返済期間の逆算と日付指定の繰上返済では年利の百分率を1,200で割ります。B は残高、I は利息、E は元金への追加返済額です。



元金45,000、年利6.3%、毎月785なら約68.38か月です。月末請求は69回で、最後の支払額は少なくなります。明細を選んで保存します。
