# Image resizer



Set the output width or height. Keep aspect ratio enabled to preserve the original proportions. Results are exported as PNG.





## Get started



1. Choose an image.
2. Enter the width or height. Keep aspect ratio enabled to avoid stretching.
3. Resize and download the PNG result.







## Example



### Input



```
1600 × 1200 → width 800, keep aspect ratio
```



### Expected result



```
800 × 600 PNG
```







## Try it



[Open full tool](<https://toolpony.com/en/tools/image-resizer/>)







## Good to know



Changing pixel dimensions is different from lossless compression. Enlarging the image cannot recover detail that was not in the original.







## Limits



Up to 20 MB input, 24 megapixels, and 8,192 pixels per output dimension. Enlarging an image does not restore missing detail.
