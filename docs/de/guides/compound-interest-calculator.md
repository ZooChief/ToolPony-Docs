# Zinseszinsrechner



Projizieren Sie ein Gleichgewicht mit wiederkehrenden Beiträgen und Inflation oder konvertieren Sie zwischen Compoundierungshäufigkeiten.





## Erste Schritte



1. Verwenden Sie das Beispiel oder geben Sie eigene Werte ein.
2. Berechnen Sie das Ergebnis und kopieren oder laden Sie die Details herunter.







## Beispiel



### Eingabe



```
10.000 bei 5% jährlich für 10 Jahre
```



### Erwartetes Ergebnis



```
16,288.95
```







## Ausprobieren

## Hinweise



Die Verarbeitung erfolgt im Browser. Verwenden Sie einheitliche Einheiten.







## Berechnungsmethode



Effektives jährliches Wachstum ist (1+r/m)^m−1 oder exp(r)−1 mit kontinuierlicher Compoundierung.



$$
A=P(1+r/m)^{mt},\qquad \mathrm{APY}=(1+r/m)^m-1
$$







## Berechnungsmodus



**Künftiger Saldo**

- Darlehensbetrag
- Jahreszins · %
- Jahre
- Zinsintervall
- Regelmäßiger Beitrag
- Beitragsfrequenz · Jährlich / Halbjährlich / Vierteljährlich / Monatlich / Zweimal pro Monat / Alle zwei Wochen / Wöchentlich / Täglich
- Beitrag zu Beginn des Berichtszeitraums
- Jährliche Inflation · %





**Entsprechender Zinssatz**

- Jahreszins · %
- Ursprüngliche Compoundierung
- Zielcompoundierung
