# Unix タイムスタンプ変換



秒とミリ秒をUTCに変換し、明示的なオフセットを持つISO時間をUnix時間に変換します。





## 例



### 入力



```
0秒
```



### 期待される結果



```
1970-01-01T00:00:00.000Z
```







## 試してみる

[ツール全体を開く · Unix タイムスタンプ変換](<https://toolpony.com/ja/tools/unix-timestamp-converter/>)





## 計算方法



Unix時間は1970-01-01T00:00:00Z以降で、時間は延びた。 変換サポートは、1900〜9999まで、ミリ秒の精度で使用できます。







## 計算モード



**これまでのタイムスタンプ**

- Unix タイムスタンプ
- 単位 · 秒 / ミリ秒





**タイムスタンプの日付**

- ISO 8601 オフセット付き
