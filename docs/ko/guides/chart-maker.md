# 차트 만들기



헤더, 레이블 열 및 숫자 시리즈로 CSV를 붙여넣습니다. 바 또는 라인을 선택하고 차트를 업데이트하고 SVG를 다운로드하십시오.





## 시작하기



1. CSV 헤더를 입력합니다. 나머지 열에 있는 제1 열 및 숫자 시리즈에 카테고리 레이블을 넣습니다.
2. 막대 또는 줄을 선택하고 미리 보기를 업데이트합니다.
3. 차트를 SVG로 다운로드하십시오.







## 예시



### 입력



```
Month,Visits
Jan,24
Feb,38
```



### 예상 결과



```
1 월과 2 월의 두 값은 왼쪽에서 오른쪽으로 플롯되었습니다.
```

## 참고 사항



쉼표가 포함된 Quote 레이블입니다. 기간을 소수 구분 기호로 사용합니다. 음수 값은 양수 값과 동일한 척도를 사용합니다.







## 제한 사항



최대 120행과 수치 계열 6개를 지원합니다. 따옴표로 묶인 셀에는 쉼표를 넣을 수 있습니다. 각 데이터 행을 한 줄로 입력하면 입력 순서대로 그립니다.
