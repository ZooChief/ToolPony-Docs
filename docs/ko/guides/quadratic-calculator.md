# 이차방정식 근의 공식 계산기



분수 계수를 포함하여 실제 또는 복잡한 뿌리로 ax2 + bx + c = 0을 해결하십시오.





## 시작하기



1. 예제 값을 사용하거나 원하는 값을 입력하세요.
2. 계산한 결과를 복사하거나 세부 정보를 내려받을 수 있습니다.







## 예시



### 입력



```
a=1, b=−5, c=6
```



### 예상 결과



```
x₁=2, x₂=3
```







## 직접 사용해 보기



[전체 도구 열기](<https://toolpony.com/ko/tools/quadratic-calculator/>)







## 참고 사항



브라우저에서 처리합니다. 단위를 일관되게 사용하세요.







## 계산 방법



판별식 b²−4ac를 사용합니다. 이차항의 계수가 0이면 일차방정식으로 풉니다.



$$
ax^2+bx+c=0,\qquad x=\frac{-b\pm\sqrt{b^2-4ac}}{2a},\quad a\ne0
$$
