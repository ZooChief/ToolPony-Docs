# Calculadora de IMC para adultos



Calcule o IMC adulto em unidades métricas ou US, compare os intervalos de referência e veja o IMC Prime e o índice ponderal.





## Primeiros passos



1. Use o exemplo ou insira seus próprios valores.
2. Calcule, copie o resultado ou baixe os detalhes disponíveis.







## Exemplo



### Entrada



```
70 kg, 175 cm
```



### Resultado esperado



```
IMC 22,86 kg/m2
```

## Notas de uso



O cálculo é feito no seu navegador. Use unidades consistentes.







## Método de cálculo



IMC = peso (kg) ÷ altura (m)². As faixas de referência do CDC se aplicam a adultos a partir dos 20 anos. IMC Prime = IMC ÷ 25. Índice ponderal = peso (kg) ÷ altura (m)³.



$$
\operatorname{BMI}=\frac{m_{\mathrm{kg}}}{h_{\mathrm{m}}^2}
$$







## Modo de cálculo



**Sistema métrico**

- Idade
- Peso · kg
- Altura · cm





**Unidades usuais dos EUA**

- Idade
- Peso · lb
- Altura em pés · ft
- Inferimentos adicionais · in
