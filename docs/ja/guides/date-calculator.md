# 日付計算機



日数と営業日を数え、暦または営業日で日付を移動します。





## 使い方



1. 日数を数えるには日付を 2 つ入力し、遅い方の日を含めるか選びます。詳細オプションで休日を指定します。
2. 以前の日付に移動するには負の数を入力します。営業日での移動は土曜・日曜・指定の休日を飛ばします。







## 例



### 入力



```
2020-01-01 から 2020-02-01
```



### 期待される結果



```
31 日、営業日 23 日
```







## 試してみる



[ツール全体を開く](<https://toolpony.com/ja/tools/date-calculator/>)







## 注意点



処理はブラウザ内で実行されます。単位をそろえて入力してください。







## 計算方法



営業日は月〜金で、指定した休日を除きます。YYYY-MM-DD は一度、MM-DD は毎年です。営業日の移動では早い方の日を含み、遅い方を除きます。結果は週末・休日にもなります。短い月では月末に合わせます。







## 計算モード



**日付の間隔**

- 開始日
- 終了日
- 終了日を含む
- 休日（YYYY-MM-DD または MM-DD）





**日付の加減算**

- 開始日
- 年
- か月
- 週
- 日





**営業日で移動**

- 開始日
- 営業日
- 休日（YYYY-MM-DD または MM-DD）
