# 幂运算计算器



已知两个量，求幂、底数或指数。





## 开始使用



1. 按示例填写数值，或输入你自己的测量值。
2. 计算后可复制结果或下载明细。







## 示例

```

```

```

```

## 计算方法



在 y = bⁿ 中，当 b 与 y 为正且 b ≠ 1 时可用对数求指数。偶整数指数求实数底数时可能有两个解。



$$
y=b^p,\qquad p=\frac{\ln y}{\ln b},\qquad b=\sqrt[p]{y}
$$
