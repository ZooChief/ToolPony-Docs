# 最大公因數與最小公倍數



計算多組大整數的最大公因數和最小公倍數。





## 示例



### 輸入



```
12、18、24
```



### 預期結果



```
最大公因數 6，最小公倍數 72
```







## 試一試

[打開完整工具 · 最大公因數與最小公倍數](<https://toolpony.com/zh-hant/tools/gcf-lcm-calculator/>)





## 計算方法



最大公因數使用歐幾里得算法。兩個非零數的最小公倍數爲乘積的絕對值除以最大公因數。最多支持 100 個 50 位整數。
