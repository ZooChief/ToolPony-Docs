# 이미지 크기 변경



이미지를 선택하세요. 너비나 높이를 입력하고 비율을 유지하려면 가로세로 비율 유지를 선택하세요. 크기를 변경한 PNG를 다운로드하세요.





## 시작하기



1. 이미지를 선택하세요.
2. 너비나 높이를 입력하고 비율을 유지하려면 가로세로 비율 유지를 선택하세요.
3. 크기를 변경한 PNG를 다운로드하세요.







## 예시



### 입력



```
1600 × 1200, 너비 800, 비율 유지
```



### 예상 결과



```
800 × 600 PNG
```







## 직접 사용해 보기

## 제한 사항



최대 20 MB, 2,400만 화소, 한 변 8,192픽셀입니다. 이미지를 확대해도 원본에 없는 세부 정보를 복원할 수 없습니다.
