# Guía de uso · Calculadora de costo y consumo de combustible



Convertir unidades de economía de combustible, estimar el costo de combustible de un viaje, o calcular la economía de combustible medida.





## Ejemplo



### Entrada



```
300 km, 7 L/100 km, precio 1,5 por litro
```



### Resultado esperado



```
21 L; costo de combustible 31.50
```

## Método de cálculo



Combustible utilizado = distancia × L/100 km ÷ 100. Estados Unidos y millas imperiales por galón utilizan diferentes volúmenes de galón.







## Modo de cálculo





### Costo de viaje



- Distancia
- Unidad de distancia · km / mi
- Economía del combustible
- Unidad de economía de combustible · L/100 km / km/L / mpg (US) / mpg (imperial)
- Precio del combustible
- Unidad de precio del combustible · L / US gal / UK gal







### Convertir economía de combustible



- Economía del combustible
- Unidad de entrada · L/100 km / km/L / mpg (US) / mpg (imperial)
- Unidad de salida · L/100 km / km/L / mpg (US) / mpg (imperial)







### Kilometraje medido



- Distancia
- Unidad de distancia · km / mi
- Combustible utilizado
- Unidad de volumen · L / US gal / UK gal







**Fuentes del método** [NIST · Unit conversion factors](<https://www.nist.gov/pml/special-publication-811/nist-guide-si-appendix-b-conversion-factors/nist-guide-si-appendix-b8>)
