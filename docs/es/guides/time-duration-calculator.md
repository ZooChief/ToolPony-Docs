# Calculadora de duración



Calcula intervalos, combina duraciones y desplaza fechas y horas.





## Primeros pasos



1. Elige horas para un turno, fechas para varios días o expresión para operar.







## Ejemplo



### Entrada



```
De 22:30 a 06:15 del día siguiente
```



### Resultado esperado



```
07:45:00
```

## Notas de uso



El cálculo se ejecuta en tu navegador. Usa unidades coherentes.







## Método de cálculo



Un intervalo puede cruzar la medianoche. Con fechas explícitas, un día tiene 24 horas. d, h, m y s son días, horas, minutos y segundos. El signo menos afecta al grupo siguiente.



$$
T=86400d+3600h+60m+s
$$
