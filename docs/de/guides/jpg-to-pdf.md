# Bilder in PDF umwandeln



Kombinieren Sie JPG, PNG, WebP und weitere Bilder in einer PDF.





## Erste Schritte



1. Fügen Sie Bilder hinzu und legen Sie die Reihenfolge fest.
2. Wählen Sie Papierformat, Ausrichtung und Rand und speichern Sie die PDF.







## Beispiel



### Eingabe



```
Zwei Querformatbilder, A4, automatische Ausrichtung
```



### Erwartetes Ergebnis



```
Zwei A4-Seiten im Querformat
```







## Ausprobieren



[Vollständiges Werkzeug öffnen](<https://toolpony.com/de/tools/jpg-to-pdf/>)







## Grenzen



Bis zu 20 Bilder, insgesamt 30 MB und 60 Megapixel. Je Bild sind es 20 MB und 24 Megapixel. Transparenz wird weiß und bei Animationen bleibt nur das erste Bild.

[Dokumentation](https://docs.toolpony.com/de/guides/jpg-to-pdf/)
