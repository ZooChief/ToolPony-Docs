# 質因數分解計算器



求正整數的質因數、指數形式和約數個數。





## 開始使用



1. 按示例填寫數值，或輸入你自己的測量值。
2. 計算後可複製結果或下載明細。







## 示例



### 輸入



```
360
```



### 預期結果



```
2³ × 3² × 5，共 24 個約數
```

## 使用提示



計算在瀏覽器內完成。無單位標記的字段請使用一致單位。







## 計算方法



用試除法取出質因數，試除上界爲剩餘整數的平方根。輸入範圍爲 2 至 1 萬億。
