# 利润率与加价率



由成本与售价计算毛利率和加价率，或按目标毛利率定价。





## 示例



### 输入



```
成本 60，售价 100
```



### 预期结果



```
毛利率 40%，加价率约 66.67%
```







## 试一试

[打开完整工具 · 利润率与加价率](<https://toolpony.com/zh-hans/tools/margin-calculator/>)





## 计算方法



毛利率 = 毛利 ÷ 售价，加价率 = 毛利 ÷ 成本。按目标毛利率定价时，售价 = 成本 ÷（1−毛利率）。







## 计算模式



**成本与售价**

- 成本
- 售价





**按目标毛利率定价**

- 成本
- 目标毛利率 · %
