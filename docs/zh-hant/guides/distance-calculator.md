# 距離計算器



計算二維或三維兩點距離，或估算兩組地理座標的地表距離。





## 開始使用



1. 按示例填寫數值，或輸入你自己的測量值。
2. 計算後可複製結果或下載明細。







## 示例



### 輸入



```
二維：從（0, 0）到（3, 4）
```



### 預期結果



```
距離 5
```

## 使用提示



計算在瀏覽器內完成。無單位標記的字段請使用一致單位。







## 計算方法



直角座標使用歐氏距離。經緯度模式使用 WGS 84 橢球和 Lambert 近似，近對蹠點使用球面近似。結果爲地表距離估算。



$$
d=\sqrt{(x_2-x_1)^2+(y_2-y_1)^2+(z_2-z_1)^2}
$$



座標採用同一線性尺度時使用二維或三維模式。先把兩點座標換成一致單位。



地理座標中，北緯和東經爲正。測繪數據分開給出度、分、秒時選擇對應模式，結果是沿橢球面的距離估算。
