# 주사위 굴리기



사용자 지정 측면으로 하나 이상의 주사위를 굴리고 합계를 비교하고 각 롤을 봅니다.





## 시작하기



1. 예제 값을 사용하거나 원하는 값을 입력하세요.
2. 계산한 결과를 복사하거나 세부 정보를 내려받을 수 있습니다.







## 예시



### 입력



```
3 주사위, 6개의 측
```



### 예상 결과



```
세 얼굴과 그들의 합계
```







## 직접 사용해 보기



[전체 도구 열기](<https://toolpony.com/ko/tools/dice-roller/>)







## 참고 사항



브라우저에서 처리합니다. 단위를 일관되게 사용하세요.







## 계산 방법



각 다이는 독립적 인 균일 한 웹 암호화 추첨을 사용합니다. 최대 100 개의 주사위를 굴리고 각각 2 ~ 1,000 개의 측면이 있습니다.
