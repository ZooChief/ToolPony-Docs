# Kiesrechner



Berechnen Sie Volumen, Masse, Sackzahl und Kosten für Kies oder Sand.





## Erste Schritte



1. Wählen Sie Fläche, Rechteck oder Kreis und geben Sie die Schichtdicke ein.
2. Wählen Sie das Material. Weitere Optionen enthalten eigene Dichte und Sackgröße.







## Beispiel



### Eingabe



```
200 ft², 3 in Schichtdicke, Kies mit 1.680 kg/m³.
```



### Erwartetes Ergebnis



```
50 ft³ (1,42 m³), rund 2.379 kg.
```

Die Verarbeitung erfolgt im Browser. Verwenden Sie einheitliche Einheiten.







## Berechnungsmethode



Multiplizieren Sie Fläche und Schichtdicke und rechnen Sie die Zugabe hinzu. Die Masse ist Volumen mal Schüttdichte. Runden Sie beim Sackpreis auf ganze Säcke auf. Verwenden Sie nach Möglichkeit die Dichte des Lieferanten.



$$
V=Ad(1+w/100),\qquad m=\rho V,\qquad N=\left\lceil\frac{m}{m_{\rm bag}}\right\rceil\ \text{or}\ \left\lceil\frac{V}{V_{\rm bag}}\right\rceil
$$
