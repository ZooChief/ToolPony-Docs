# 手数料・歩合計算機



売上、料金、または手数料を見つけ、基本支払いと段階的な段階を算出します。





## 使い方



1. 例を使うか、任意の値を入力します。
2. 計算後、結果をコピーするか詳細をダウンロードできます。







## 例



### 入力



```
16,500対8.25%
```



### 期待される結果



```
1,361.25 委員会
```







## 試してみる



[ツール全体を開く](<https://toolpony.com/ja/tools/commission-calculator/>)







## 注意点



処理はブラウザ内で実行されます。単位をそろえて入力してください。







## 計算方法



単一金利は販売額に多額を掛け合わせる。 階層スケジュールにおいて、それぞれの閾値がその括弧の上限となる。 パーセントの階層は、その枠内の収益にのみ適用される。 固定料金は、ブラケット入力時に1回支払います。



$$
C=C_0+\sum_i s_i r_i\quad\text{(percentage tiers)}
$$







## 計算モード



**手数料を探す**

- 販売数量
- 委員会の評価 · %





**料金を確認**

- 販売数量
- 委員会の金額





**販売数量を調べる**

- 委員会の評価 · %
- 委員会の金額





**ベースおよび階層**

- 販売数量
- 基本委員会
- 基本タイプ · 固定量 / 売上のパーセント
- 上限上限、金利(%、または固定額)。 制限なく\*を使用してください。
