# Convertisseur et calculatrice de bases



Convertir des entiers signés entre les bases 2–36 et effectuer des opérations arithmétiques, résiduelles ou bitwise exactes.





## Prise en main



1. Utilisez l’exemple ou saisissez vos propres valeurs.
2. Calculez, puis copiez le résultat ou téléchargez les détails.







## Exemple



### Entrée



```
FF, base 16 à base 10
```



### Résultat attendu



```
255
```

## Notes



Le traitement se fait dans le navigateur. Utilisez des unités cohérentes.







## Méthode de calcul



BigInt préserve la précision entière. La division tronque vers zéro. Les opérations bitwise utilisent la sémantique BigInt signée. Chaque opérande est limité à 256 chiffres.
