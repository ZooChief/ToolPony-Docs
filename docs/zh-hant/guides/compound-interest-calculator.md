# 複利計算器



估算含定期投入和通脹的複利餘額，或在不同計息頻率間換算。





## 示例



### 輸入



```
10,000 按 5% 年複利，10 年
```



### 預期結果



```
16,288.95
```

## 計算方法



實際年增長率爲 (1+r/m)^m−1，連續複利爲 exp(r)−1。定期投入按選定的期初或期末開始計息。



$$
A=P(1+r/m)^{mt},\qquad \mathrm{APY}=(1+r/m)^m-1
$$







## 計算模式



**未來餘額**

- 本金
- 年利率 · %
- 年
- 計息頻率
- 每期投入
- 投入頻率 · 每年 / 每半年 / 每季度 / 每月 / 每月兩次 / 每兩週 / 每週 / 每日
- 期初投入
- 年通脹率 · %





**等效利率**

- 年利率 · %
- 原計息頻率
- 目標計息頻率
