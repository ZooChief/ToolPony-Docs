# URL 編碼與解碼



編碼或解碼完整 URL、URI 組件和表單值。





## 示例



### 輸入



```
編碼組件：a+b & c
```



### 預期結果



```
a%2Bb%20%26%20c
```







## 試一試

[打開完整工具 · URL 編碼與解碼](<https://toolpony.com/zh-hant/tools/url-encoder-decoder/>)





## 計算方法



組件編碼轉義保留分隔符。完整 URL 模式保留分隔符。表單模式用加號表示空格。
