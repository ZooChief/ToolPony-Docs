# 정규분포 p값 계산기



왼쪽, 오른쪽 및 양면 일반 p 값을 찾거나 선택한 확률을 반전합니다.





## 시작하기



1. 예제 값을 사용하거나 원하는 값을 입력하세요.
2. 계산한 결과를 복사하거나 세부 정보를 내려받을 수 있습니다.







## 예시



### 입력



```
z = 2.36
```



### 예상 결과



```
양측 확률 ≈ 0.018275
```

## 계산 방법



일반 테스트 통계의 경우 양면 p 값은 |z| 위의 꼬리의 두 배입니다. 꼬리의 정의는 대체 가설과 일치해야합니다.



$$
p_{\mathrm{two\ tails}}=2[1-\Phi(|z|)]
$$

- 확률
