# 주택담보대출 조기상환 계산기



주택담보대출의 남은 상환, 추가 납입, 일시 상환 및 두 가지 격주 일정을 비교합니다.





## 시작하기



1. 이전에 추가 상환을 했다면 명세서의 잔액과 원리금 납입액을 입력하세요. 원래 대출과 남은 기간에서 잔액을 구할 수도 있습니다.
2. 상환 계획을 고르세요. 월, 연 또는 일회성 추가 금액을 입력합니다. 기본 시작은 각각 1, 12, 1개월 차이며 추가 옵션에서 바꿀 수 있습니다.
3. 선택한 계획과 정기 상환을 비교한 다음 남은 일정 또는 비교 CSV를 내려받으세요.
4. 원금과 고정 이자의 추정값입니다. 실제 완납 금액에는 일할 이자, 수수료와 위약금이 포함될 수 있습니다. 대출기관에 확인하세요.







## 예시



### 입력



```
원래 400,000, 30년, 연 6%. 25년 남았고 월 500 추가.
```



### 예상 결과



```
207개월 남음, 절감 이자 122,306.21
```

## 계산 방법



원래 대출로 계산할 때는 이전 상환이 최초 일정대로 이루어졌다고 가정합니다. 월 이자는 잔액에 연이율을 곱하고 12로 나눕니다. 월 집계 격주 방식은 6개월마다 월 납입액 절반을 추가합니다. 연 26회 방식은 월 납입액 절반을 내며 연이율을 26으로 나눕니다.



$$
B=M\frac{1-(1+r)^{-n}}r\quad(r>0),\qquad B=Mn\quad(r=0)
$$



$$
I_k=rB_{k-1},\qquad B_k=\max(0,B_{k-1}-M+I_k-E_k)
$$



$$
E_{6j}=M/2\quad\text{(grouped)},\qquad M_{26}=M/2,\quad r_{26}=r_{\rm annual}/26
$$
