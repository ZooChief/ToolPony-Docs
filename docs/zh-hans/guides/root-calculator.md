# 方根计算器



计算平方根、立方根或任意次方根的实数主值。





## 开始使用



1. 按示例填写数值，或输入你自己的测量值。
2. 计算后可复制结果或下载明细。







## 示例



### 输入



```
144 的平方根
```



### 预期结果



```
12
```

## 使用提示



计算在浏览器内完成。无单位标记的字段请使用一致单位。







## 计算方法



n 次方根为 x 的 1/n 次幂。奇数次可处理负数，负次数表示取倒数。



$$
\sqrt[n]{x}=x^{1/n},\qquad n\ne0
$$







## 计算模式



**平方根**

- 被开方数





**立方根**

- 被开方数





**任意次方根**

- 被开方数
- 次数
