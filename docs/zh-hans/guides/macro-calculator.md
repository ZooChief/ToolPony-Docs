# 三大营养素计算器



把热量目标和营养比例换算成克数，或由克数计算热量和比例。





## 开始使用



1. 按示例填写数值，或输入你自己的测量值。
2. 计算后可复制结果或下载明细。







## 示例



### 输入



```
2,000 kcal，蛋白质 25%、碳水 45%、脂肪 30%
```



### 预期结果



```
蛋白质 125 g、碳水 225 g、脂肪约 66.67 g
```

## 使用提示



计算在浏览器内完成。无单位标记的字段请使用一致单位。







## 计算方法



按蛋白质和碳水每克 4 kcal、脂肪每克 9 kcal 换算。目标模式下三项比例合计须为 100%。







## 计算模式



**目标换算克数**

- 总热量 · kcal
- 蛋白质 · %
- 碳水化合物 · %
- 脂肪 · %





**克数换算热量**

- 蛋白质 · g
- 碳水化合物 · g
- 脂肪 · g
