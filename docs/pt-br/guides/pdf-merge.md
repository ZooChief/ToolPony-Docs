# Unir PDFs



Junte vários PDFs na ordem desejada, no seu dispositivo.





## Primeiros passos



1. Selecione pelo menos dois PDFs.
2. Ajuste a ordem com as setas e salve o PDF combinado.







## Exemplo



### Entrada



```
A.pdf (2 páginas) e B.pdf (3 páginas)
```



### Resultado esperado



```
Um PDF com A1, A2, B1, B2, B3 nessa ordem
```







## Experimente



[Abrir ferramenta completa](<https://toolpony.com/pt-br/tools/pdf-merge/>)







## Limites



Até 30 MB e 300 páginas no total. PDFs criptografados são recusados. Formulários, marcadores e assinaturas digitais podem ser perdidos.

[Documentação](https://docs.toolpony.com/pt-br/guides/pdf-merge/)
