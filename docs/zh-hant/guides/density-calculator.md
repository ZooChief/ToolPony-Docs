# 密度計算器



任填兩項求質量、體積或密度。





## 示例



### 輸入



```
8 kg，0.001 m³
```



### 預期結果



```
8,000 kg/m³
```

## 計算方法



密度 = 質量 ÷ 體積，採用 kg、m³ 和 kg/m³。



$$
\rho=\frac{m}{V}
$$
