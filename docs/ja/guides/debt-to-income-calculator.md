# 返済負担率計算機



毎月の返済額と総月収を比較してください。





## 例



### 入力



```
収入5,000、債務支払い額1,500
```



### 期待される結果



```
30%
```







## 試してみる

[ツール全体を開く · 返済負担率計算機](<https://toolpony.com/ja/tools/debt-to-income-calculator/>)





## 計算方法



債務対所得比率=月次債務支払い ÷ 月次総収入。 すべての金額に対して、同じ通貨と月次期間を使用してください。





**計算・処理の参考資料** [CFPB · Debt-to-Income Ratio](<https://www.consumerfinance.gov/ask-cfpb/what-is-a-debt-to-income-ratio-en-1791/>)
