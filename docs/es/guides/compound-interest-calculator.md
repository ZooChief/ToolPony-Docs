# Guía de uso · Calculadora de interés compuesto



Proyecte un equilibrio con las contribuciones recurrentes y la inflación, o convierta entre frecuencias agravantes.





## Ejemplo



### Entrada



```
10.000 al 5% anual durante 10 años
```



### Resultado esperado



```
16,288.95
```

## Comparar aportes durante 30 meses



1. Empieza con 10.000 y aporta 100 al mes durante dos años y seis meses. Con un 6 % nominal capitalizado mensualmente obtienes 14.842,00 aportando a fin de mes, con 13.000 aportados. A principio de mes obtienes 14.858,14. Con un 3 % de inflación anual, el primer saldo equivale hoy a 13.784,77.

## Método de cálculo



El crecimiento anual efectivo es (1+r/m)^m−1, o exp(r)−1 con compuesto continuo. Las contribuciones ganan interés desde el comienzo o fin seleccionados de cada período.



$$
A=P(1+r/m)^{mt},\qquad \mathrm{APY}=(1+r/m)^m-1
$$
