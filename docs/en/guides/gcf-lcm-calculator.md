# GCF and LCM calculator



Find greatest common factor and least common multiple for a list of large integers.





## Get started



1. Use the example values or enter your own measurements.
2. Calculate, then copy the result or download the available details.







## Example



### Input



```
12, 18, 24
```



### Expected result



```
GCF 6; LCM 72
```







## Try it



[Open full tool](<https://toolpony.com/en/tools/gcf-lcm-calculator/>)







## Good to know



The calculation runs in your browser. Use consistent units in fields with no explicit unit.







## Calculation method



Euclid’s algorithm finds GCF. LCM(a,b) = |a·b| ÷ GCF(a,b) when both are nonzero. Up to 100 integers of 50 digits each.
