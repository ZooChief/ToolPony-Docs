# 画像のサイズ変更



画像を選びます。 幅または高さを入力し、形を保つには縦横比を固定します。 サイズを変更して PNG を保存します。





## 使い方



1. 画像を選びます。
2. 幅または高さを入力し、形を保つには縦横比を固定します。
3. サイズを変更して PNG を保存します。







## 例



### 入力



```
1600 × 1200、幅 800、縦横比を固定
```



### 期待される結果



```
800 × 600 PNG
```







## 試してみる



[ツール全体を開く](<https://toolpony.com/ja/tools/image-resizer/>)







## 制限



最大 20 MB、2400 万画素、一辺 8192 px です。拡大しても元の画像にない細部は復元できません。

[ドキュメント](https://docs.toolpony.com/ja/guides/image-resizer/)
