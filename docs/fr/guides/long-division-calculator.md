# Calculatrice de division posée



Diviser les entiers ou les décimales et inspecter le quotient, le reste, la valeur décimale et chaque étape de division longue.





## Prise en main



1. Utilisez l’exemple ou saisissez vos propres valeurs.
2. Calculez, puis copiez le résultat ou téléchargez les détails.







## Exemple



### Entrée



```
12,345 ÷ 67
```



### Résultat attendu



```
184 autres 17
```

## Notes



Le traitement se fait dans le navigateur. Utilisez des unités cohérentes.







## Méthode de calcul



Le quotient entier tronque vers zéro, et le reste signé satisfait le dividende = quotient × diviseur + reste. Le tableau d'étape utilise des grandeurs absolues.



$$
a=bq+r,\quad q=\operatorname{trunc}(a/b),\quad |r|<|b|
$$
