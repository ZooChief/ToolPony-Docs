# PDF 合并



添加两个或更多 PDF，调整文件顺序后合并为一个文档。每份文件的页面按你选定的顺序依次复制。





## 开始使用



1. 选择至少两个 PDF 文件。
2. 使用上移、下移按钮调整文件顺序。
3. 合并并下载文档。







## 示例



### 输入



```
A.pdf（2 页）+ B.pdf（3 页）
```



### 预期结果



```
5 页 PDF，顺序为 A1、A2、B1、B2、B3
```

## 使用提示



页面按文件顺序复制。不支持加密文件；表单、书签、数字签名等文档级功能可能无法在页面复制后保留。







## 适用范围



输入总计最多 30 MB、300 页。不支持加密 PDF；数字签名、表单、书签等文档级功能可能无法在页面复制后保留。
