# 二維碼生成器使用指南



選擇掃描後要打開的類型，再填寫鏈接、文本或相應字段。 輸入時會自動更新二維碼。Wi-Fi、名片等類型可覈對編碼內容，再下載 PNG 或 SVG。 可選取深色，也可輸入六位 HEX 色值。兩種導出都保留白色留邊。





## 開始使用



1. 選擇掃描後要打開的類型，再填寫鏈接、文本或相應字段。
2. 輸入時會自動更新二維碼。Wi-Fi、名片等類型可覈對編碼內容，再下載 PNG 或 SVG。
3. 可選取深色，也可輸入六位 HEX 色值。兩種導出都保留白色留邊。







## 示例



### 輸入



```
https://example.com/ · M · 512 px
```



### 預期結果



```
PNG · 512 × 512 px → https://example.com/
```

## 適用範圍
