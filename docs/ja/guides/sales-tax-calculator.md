# 売上税・付加価値税計算機



売上税および付加価値税(VAT)を独自の税率で追加または削除してください。





## 使い方



1. 例を使うか、任意の値を入力します。
2. 計算後、結果をコピーするか詳細をダウンロードできます。







## 例



### 入力



```
純価格 100、付加価値税 20%
```



### 期待される結果



```
売上総額120、税額20
```







## 試してみる



[ツール全体を開く](<https://toolpony.com/ja/tools/sales-tax-calculator/>)







## 注意点



処理はブラウザ内で実行されます。単位をそろえて入力してください。







## 計算方法



総価格=純価格×(1 +レート)。 税率はユーザーによって提供されます。
