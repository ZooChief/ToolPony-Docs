# Creador de gráficos



Paste CSV con un encabezado, una columna de etiquetas y serie numérica. Escoge barras o líneas, actualiza el gráfico y descarga SVG.





## Primeros pasos



1. Introduzca un encabezado CSV. Ponga etiquetas de categoría en la primera columna y serie numérica en las columnas restantes.
2. Elija barras o líneas y actualice la vista previa.
3. Descargue el gráfico como SVG.







## Ejemplo



### Entrada



```
Month,Visits
Jan,24
Feb,38
```



### Resultado esperado



```
Dos valores en Jan y Feb, trazado de izquierda a derecha.
```

## Notas de uso



Etiquetas de citas que contienen comas. Use un período como el separador decimal. Los valores negativos utilizan la misma escala que los valores positivos.







## Límites



Hasta 120 filas y seis series numéricas. Una célula citada puede contener una coma. Cada fila se queda en una línea. Los valores se parcelan en el orden introducido.
