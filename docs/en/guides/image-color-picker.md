# Image color picker



Click the example or choose an image. Click a point or enter its pixel coordinates to read HEX and RGBA. Copy a color or export the sampled palette as CSV.





## Get started



1. Try the built-in example or choose an image.
2. Click a point, or enter X and Y and sample that original pixel.
3. Copy HEX or export up to sixteen coordinate and RGBA rows as CSV.







## Example



### Input



```
Built-in sample, X = 32 and Y = 32
```



### Expected result



```
#285eaa · RGBA 40, 94, 170, 255
```







## Try it



[Open full tool](<https://toolpony.com/en/tools/image-color-picker/>)







## Good to know



The preview can be downscaled while sampling still reads the corresponding original pixel. The browser can convert image color profiles during decoding.







## Limits



JPG, PNG, WebP, AVIF or GIF up to 20 MB and 24 megapixels. Reads the browser’s decoded pixels. Coordinates start at (0, 0) at the top left. A palette holds up to 16 points.
