# 거듭제곱 계산기



다른 두 값에서 권력, 기초 또는 지수를 위해 해결하십시오.





## 예시



### 입력



```
베이스 2, 지수 5
```



### 예상 결과



```
32
```







## 직접 사용해 보기

[전체 도구 열기 · 거듭제곱 계산기](<https://toolpony.com/ko/tools/exponent-calculator/>)





## 계산 방법



y = bⁿ에서 b와 y가 양수이고 b ≠ 1이면 로그로 지수를 구합니다. 지수가 0이 아닌 짝수 정수일 때 실수 밑을 구하면 해가 두 개일 수 있습니다.



$$
y=b^p,\qquad p=\frac{\ln y}{\ln b},\qquad b=\sqrt[p]{y}
$$







## 계산 모드



**힘**

- 밑
- 지수





**밑**

- 지수
- 전력 값





**지수**

- 밑
- 전력 값
