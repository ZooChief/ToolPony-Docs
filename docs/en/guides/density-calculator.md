# Density calculator



Solve for mass, volume or density by entering any two values.





## Example



### Input



```
8 kg, 0.001 m³
```



### Expected result



```
8,000 kg/m³
```







## Try it

[Open full tool · Density calculator](<https://toolpony.com/en/tools/density-calculator/>)





## Calculation method



Density = mass ÷ volume. The interface uses kg, m³ and kg/m³.



$$
\rho=\frac{m}{V}
$$
