# 글자 수 및 단어 수 세기



텍스트를 입력하거나 붙여넣거나, 텍스트 또는 선택 가능한 문자가 있는 PDF를 가져오세요. 한 단어부터 세 단어까지의 표현과 비율을 확인하고 CSV로 내보내세요. DOCX와 ODT도 가져올 수 있습니다. 문서 본문을 집계합니다. SRT와 WebVTT를 가져오면 시각과 서식을 제외하고 대사만 셉니다.





## 시작하기



1. 텍스트를 입력하거나 붙여넣거나, 텍스트 또는 선택 가능한 문자가 있는 PDF를 가져오세요.
2. 한 단어부터 세 단어까지의 표현과 비율을 확인하고 CSV로 내보내세요.
3. DOCX와 ODT도 가져올 수 있습니다. 문서 본문을 집계합니다.
4. SRT와 WebVTT를 가져오면 시각과 서식을 제외하고 대사만 셉니다.







## 예시



### 입력



```
파란 하늘 파란 하늘
```



### 예상 결과



```
4단어, 고유 단어 2개
```

## 제한 사항



텍스트는 UTF-8 기준 최대 1 MiB입니다. 브라우저의 언어 규칙으로 단어를 나눕니다. 구문은 문장 부호와 줄바꿈을 넘지 않으며 분모는 같은 길이의 전체 표현 수입니다.
