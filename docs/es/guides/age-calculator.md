# Calculadora de edad



Calcula la edad, el tiempo transcurrido y el próximo cumpleaños.





## Primeros pasos



1. Introduce la fecha de nacimiento y la de referencia. Si la dejas vacía, se usa la fecha del dispositivo.







## Ejemplo



### Entrada



```
Nacimiento 2000-01-01, referencia 2025-02-03
```



### Resultado esperado



```
25 años · 1 mes · 2 días
```







## Pruébalo



[Abrir herramienta completa](<https://toolpony.com/es/tools/age-calculator/>)







## Notas de uso



El cálculo se ejecuta en tu navegador. Usa unidades coherentes.







## Método de cálculo



Los meses se alinean por día o fin de mes. Para un nacimiento el 29 de febrero, elige el 28 de febrero o el 1 de marzo en años comunes. El tiempo usa días de 24 horas.
