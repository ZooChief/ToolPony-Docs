# 油耗與油費計算器



換算油耗單位、估算行程油費，或按加油量計算實測油耗。





## 開始使用



1. 按示例填寫數值，或輸入你自己的測量值。
2. 計算後可複製結果或下載明細。







## 示例



### 輸入



```
行程 300 km，油耗 7 L/100 km，每升 1.5
```



### 預期結果



```
用油 21 升，油費 31.50
```

## 使用提示



計算在瀏覽器內完成。無單位標記的字段請使用一致單位。







## 計算方法



用油量 = 距離 × 百公里油耗 ÷ 100。美製和英制每加侖英里使用不同的加侖體積，油價由用戶輸入。







## 計算模式



**行程油費**

- 距離 · km
- 油耗
- 油耗單位 · L/100 km / km/L / mpg (US) / mpg（英制）
- 每升價格





**換算油耗**

- 油耗
- 輸入單位 · L/100 km / km/L / mpg (US) / mpg（英制）





**實測油耗**

- 距離 · km
- 用油量 · L
