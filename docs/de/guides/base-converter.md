# Zahlensystem-Umrechner und Rechner



Konvertieren Sie signierte ganze Zahlen zwischen den Basen 2–36 und führen Sie genaue arithmetische, restliche oder bitweise Operationen aus.





## Erste Schritte



1. Verwenden Sie das Beispiel oder geben Sie eigene Werte ein.
2. Berechnen Sie das Ergebnis und kopieren oder laden Sie die Details herunter.







## Beispiel



### Eingabe



```
FF, Basis 16 zu Basis 10
```



### Erwartetes Ergebnis



```
255
```

## Hinweise



Die Verarbeitung erfolgt im Browser. Verwenden Sie einheitliche Einheiten.







## Berechnungsmethode



BigInt behält die Ganzzahlpräzision bei. Division kürzt gegen Null. Bitweise Operationen verwenden signierte BigInt-Semantik. Jeder Operande ist auf 256 Stellen begrenzt.
