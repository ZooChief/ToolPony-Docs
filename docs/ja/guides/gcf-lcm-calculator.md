# 最大公約数・最小公倍数の計算



大きな整数のリストに対して、最も一般的な要素と最小の倍数を見つけましょう。





## 使い方



1. 例を使うか、任意の値を入力します。
2. 計算後、結果をコピーするか詳細をダウンロードできます。







## 例



### 入力



```
12, 18, 24
```



### 期待される結果



```
GCF 6;LCM 72
```







## 試してみる



[ツール全体を開く](<https://toolpony.com/ja/tools/gcf-lcm-calculator/>)







## 注意点



処理はブラウザ内で実行されます。単位をそろえて入力してください。







## 計算方法



ユークリッドのアルゴリズムはGCFを発見する。 LCM(a,b) = |a·b| ÷ GCF(a,b) がいずれもゼロでない場合。 それぞれ50桁の最大100個の整数。
