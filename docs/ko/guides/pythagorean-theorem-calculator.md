# 피타고라스 정리 계산기



두 변의 길이 또는 제곱으로 a² + b² = c²를 풉니다.





## 시작하기



1. 서로 다른 두 변의 길이나 제곱을 입력하세요.







## 예시



### 입력



```
a² = 7, c² = 32
```



### 예상 결과



```
b² = 32 − 7 = 25이므로 b = 5입니다.
```

## 계산 방법



빗변은 두 직각변의 제곱을 더합니다. 직각변은 빗변의 제곱에서 다른 직각변의 제곱을 뺍니다. 길이는 양수여야 합니다.



$$
c=\sqrt{a^2+b^2},\quad a=\sqrt{c^2-b^2},\quad b=\sqrt{c^2-a^2}
$$
