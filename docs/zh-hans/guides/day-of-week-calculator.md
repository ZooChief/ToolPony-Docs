# 星期几计算器



查询某天的星期、年内日序、ISO 周数和该星期在当年的次数。





## 示例



### 输入



```
2000-01-01
```



### 预期结果



```
星期六
```







## 试一试

[打开完整工具 · 星期几计算器](<https://toolpony.com/zh-hans/tools/day-of-week-calculator/>)





## 计算方法



采用公历。ISO 周从周一开始，第 1 周包含 1 月 4 日。1 月初的日期可能属于上一年的最后一周。
