# Root calculator



Calculate the principal real square, cube, or nth root.





## Get started



1. Use the example values or enter your own measurements.
2. Calculate, then copy the result or download the available details.







## Example



### Input



```
Square root of 144
```



### Expected result



```
12
```







## Try it



[Open full tool](<https://toolpony.com/en/tools/root-calculator/>)







## Good to know



The calculation runs in your browser. Use consistent units in fields with no explicit unit.







## Calculation method



The nth root is x raised to 1/n. Odd integer degrees accept negative radicands. A negative degree takes the reciprocal.



$$
\sqrt[n]{x}=x^{1/n},\qquad n\ne0
$$







## Calculation mode



**Square root**

- Radicand





**Cube root**

**Nth root**
