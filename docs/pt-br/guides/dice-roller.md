# Rolador de dados



Role um ou mais dados com lados personalizados, compare totais e veja cada rolo.





## Primeiros passos



1. Use o exemplo ou insira seus próprios valores.
2. Calcule, copie o resultado ou baixe os detalhes disponíveis.







## Exemplo



### Entrada



```
3 dados, 6 lados
```



### Resultado esperado



```
Três rostos e sua soma
```







## Experimente



[Abrir ferramenta completa](<https://toolpony.com/pt-br/tools/dice-roller/>)







## Notas de uso



O cálculo é feito no seu navegador. Use unidades consistentes.







## Método de cálculo



Cada dado usa um desenho Web Crypto uniforme independente. Role até 100 dados, com 2 a 1.000 lados cada.

[Documentação](https://docs.toolpony.com/pt-br/guides/dice-roller/)
