# Quadratic formula calculator



Solve ax² + bx + c = 0 with real or complex roots, including fractional coefficients.





## Get started



1. Use the example values or enter your own measurements.
2. Calculate, then copy the result or download the available details.







## Example



### Input



```
a=1, b=−5, c=6
```



### Expected result



```
x₁=2, x₂=3
```

## Good to know



The calculation runs in your browser. Use consistent units in fields with no explicit unit.







## Calculation method



Use the discriminant b²−4ac. A zero quadratic coefficient reduces the expression to a linear equation.



$$
ax^2+bx+c=0,\qquad x=\frac{-b\pm\sqrt{b^2-4ac}}{2a},\quad a\ne0
$$
