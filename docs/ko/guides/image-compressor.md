# 이미지 압축



기기에서 이미지 1~12장을 선택하고 JPEG 또는 WebP를 고르세요. 품질 또는 파일당 목표 크기를 설정하세요. 필요하면 긴 변의 최대 길이를 지정하세요. 각 이미지의 전후를 비교하고 개별 파일 또는 ZIP을 다운로드하세요.





## 시작하기



1. 기기에서 이미지 1~12장을 선택하고 JPEG 또는 WebP를 고르세요.
2. 품질 또는 파일당 목표 크기를 설정하세요. 필요하면 긴 변의 최대 길이를 지정하세요.
3. 각 이미지의 전후를 비교하고 개별 파일 또는 ZIP을 다운로드하세요.







## 예시



### 입력



```
사진 2장, WebP, 파일당 100 KB, 긴 변 1200 px, 축소 허용
```



### 예상 결과



```
조건을 충족하는 각 이미지를 100,000바이트 이하의 WebP로 변환하고 ZIP으로 저장합니다.
```

## 제한 사항



이미지당 최대 20 MB, 2,400만 화소입니다. 묶음 입력과 출력은 각각 64 MiB까지입니다. 긴 변 제한은 이미지를 확대하지 않습니다. JPEG와 WebP는 손실 압축이며 애니메이션은 정지 이미지로 변환되고 원본 메타데이터는 제거됩니다.
