# 반감기 계산기



세 가지 측정에서 기하 급수적 인 붕괴를 해결하거나 반감기, 즉 수명과 부패 상수 사이에서 변환하십시오.





## 시작하기



1. 예제 값을 사용하거나 원하는 값을 입력하세요.
2. 계산한 결과를 복사하거나 세부 정보를 내려받을 수 있습니다.







## 예시



### 입력



```
50 시간 단위에 있는 100에서 10
```



### 예상 결과



```
반감기 ≈ 15.0515
```

## 참고 사항



브라우저에서 처리합니다. 단위를 일관되게 사용하세요.







## 계산 방법



지수 붕괴는 N(t) = N₀ · 2^(−t/T)로 나타냅니다. T는 반감기, 평균 수명은 T/ln(2), 붕괴 상수는 ln(2)/T입니다. 변환에는 소수점 이하 10자리로 반올림한 ln(2)를 사용합니다. 시간 단위는 통일하세요.



$$
N(t)=N_0\,2^{-t/T},\qquad \lambda=\frac{\ln 2}{T},\qquad \tau=\frac1\lambda
$$



먼저 알 수없는 것을 선택하십시오. 다른 세 필드에 걸쳐 일관된 시간 단위를 사용합니다. 초기 금액 인 100 및 반감기 10의 경우 20 시간 단위의 나머지 금액은 25입니다.







## 계산 모드



**반감기 찾기**

- 남은 수량
- 초기 수량
- 경과된 시간





**남은 수량 찾기**

- 초기 수량
- 경과된 시간
- 반감기





**초기 수량 찾기**

- 남은 수량
- 경과된 시간
- 반감기





**경과 시간 찾기**

- 남은 수량
- 초기 수량
- 반감기
