# Base64 kodieren und dekodieren



Verschlüsseln Sie UTF-8-Text als Standard- oder URL-sichere Base64 und validieren Sie decodierten Text.





## Erste Schritte



1. Verwenden Sie das Beispiel oder geben Sie eigene Werte ein.
2. Berechnen Sie das Ergebnis und kopieren oder laden Sie die Details herunter.







## Beispiel



### Eingabe



```
hello kodieren
```



### Erwartetes Ergebnis



```
aGVsbG8=
```







## Ausprobieren



[Vollständiges Werkzeug öffnen](<https://toolpony.com/de/tools/base64-encoder-decoder/>)







## Hinweise



Die Verarbeitung erfolgt im Browser. Verwenden Sie einheitliche Einheiten.







## Berechnungsmethode



Text wird als UTF-8 konvertiert. URL-sicherer Modus verwendet "-" und "\_" und lässt Padding in der Ausgabe aus. Bis zu 500.000 Eingabezeichen.

[Dokumentation](https://docs.toolpony.com/de/guides/base64-encoder-decoder/)
