# Wort- und Zeichenzähler



Geben Sie Text ein oder importieren Sie Text oder ein PDF mit auswählbarem Text. Wählen Sie ein bis drei Wörter pro Phrase, prüfen Sie die Anteile und laden Sie CSV herunter. Auch DOCX und ODT lassen sich importieren. Gezählt wird der Haupttext. Beim Import von SRT und WebVTT wird der Dialog ohne Zeitcodes und Formatierung gezählt.





## Erste Schritte



1. Geben Sie Text ein oder importieren Sie Text oder ein PDF mit auswählbarem Text.
2. Wählen Sie ein bis drei Wörter pro Phrase, prüfen Sie die Anteile und laden Sie CSV herunter.
3. Auch DOCX und ODT lassen sich importieren. Gezählt wird der Haupttext.
4. Beim Import von SRT und WebVTT wird der Dialog ohne Zeitcodes und Formatierung gezählt.







## Beispiel



### Eingabe



```
Blauer Himmel blauer Himmel
```



### Erwartetes Ergebnis



```
4 Wörter, 2 verschiedene Wörter
```

## Grenzen



Bis zu 1 MiB Text in UTF-8. Die Worttrennung folgt den Sprachregeln des Browsers. Phrasen enden an Satzzeichen oder Zeilenumbrüchen. Der Nenner umfasst alle Phrasen der gewählten Länge.

[Dokumentation](https://docs.toolpony.com/de/guides/word-counter/)
