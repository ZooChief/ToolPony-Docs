# 投資収益率（ROI）計算機



純利益、総リターン、および年換算で手数料を算出する。





## 使い方



1. 例を使うか、任意の値を入力します。
2. 計算後、結果をコピーするか詳細をダウンロードできます。







## 例



### 入力



```
1,000 を投資し、2 年後に 1,210 を受け取る
```



### 期待される結果



```
合計21%、年率10%
```







## 試してみる



[ツール全体を開く](<https://toolpony.com/ja/tools/roi-calculator/>)







## 注意点



処理はブラウザ内で実行されます。単位をそろえて入力してください。







## 計算方法



総リターンは(純収益−総コスト)です。÷ 総コスト。 年換算されたリターン化合物は、指定された年数における同倍率である。
