# Lanceur de dés



Rouler un ou plusieurs dés avec les côtés personnalisés, comparer les totaux et voir chaque rouleau.





## Prise en main



1. Utilisez l’exemple ou saisissez vos propres valeurs.
2. Calculez, puis copiez le résultat ou téléchargez les détails.







## Exemple



### Entrée



```
3 dés, 6 côtés
```



### Résultat attendu



```
Trois visages et leur somme
```







## Essayer



[Ouvrir l’outil complet](<https://toolpony.com/fr/tools/dice-roller/>)







## Notes



Le traitement se fait dans le navigateur. Utilisez des unités cohérentes.







## Méthode de calcul



Chaque matrice utilise un tirage Web Crypto uniforme indépendant. Rouler jusqu'à 100 dés, avec 2 à 1000 côtés chacun.
