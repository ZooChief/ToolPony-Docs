# Guide pratique · Décomposition en facteurs premiers



Trouvez les facteurs principaux, la forme de l'exposant et le nombre de diviseurs d'un entier positif.





## Exemple



### Entrée



```
360
```



### Résultat attendu



```
2³ × 3² × 5, 24 diviseurs
```







## Essayer

[Ouvrir l’outil complet · Décomposition en facteurs premiers](<https://toolpony.com/fr/tools/prime-factorization-calculator/>)





## Méthode de calcul



La division d'essai élimine les facteurs jusqu'à la racine carrée de l'entier restant. Plage d'entrée: 2 à 1 billion.
