# 파일 및 텍스트 해시 계산기



텍스트 또는 파일을 선택하고 SHA-2 알고리즘을 선택하고 계산합니다. 예상 다이제스트를 붙여 일치를 확인하거나 결과를 CSV로 다운로드하십시오.





## 시작하기



1. 텍스트를 선택하거나 하나 이상의 파일을 선택합니다.
2. SHA-256, SHA-384 또는 SHA-512를 선택한 다음 계산합니다.
3. 예상 해시를 붙여서 확인하거나 결과 CSV를 다운로드합니다.







## 예시



### 입력



```
텍스트: abc, UTF-8, SHA-256
```



### 예상 결과



```
ba7816bf8f01cfea414140de5dae2223b00361a396177a9cb410ff61f20015ad
```

## 참고 사항



해시 확인은 바이트를 비교합니다. 다른 인코딩, 줄 끝 또는 하나의 변경된 바이트는 다른 다이제스트를 생성합니다.







## 제한 사항



파일은 최대 16개, 합계 64 MB까지입니다. 텍스트는 최대 100만 자이며 UTF-8을 사용합니다. 파일은 브라우저에서 차례로 처리합니다.
