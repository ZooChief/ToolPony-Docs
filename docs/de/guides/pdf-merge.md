# PDFs zusammenführen



Fügen Sie mehrere PDFs in der gewählten Reihenfolge auf Ihrem Gerät zusammen.





## Erste Schritte



1. Wählen Sie mindestens zwei PDFs aus.
2. Ändern Sie die Reihenfolge mit den Pfeiltasten und speichern Sie die zusammengeführte Datei.







## Beispiel



### Eingabe



```
A.pdf (2 Seiten) und B.pdf (3 Seiten)
```



### Erwartetes Ergebnis



```
Eine PDF mit A1, A2, B1, B2, B3 in dieser Reihenfolge
```







## Ausprobieren



[Vollständiges Werkzeug öffnen](<https://toolpony.com/de/tools/pdf-merge/>)







## Grenzen



Insgesamt höchstens 30 MB und 300 Seiten. Verschlüsselte PDFs werden abgelehnt. Formulare, Lesezeichen und digitale Signaturen können verloren gehen.

[Dokumentation](https://docs.toolpony.com/de/guides/pdf-merge/)
