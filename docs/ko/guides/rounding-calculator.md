# 반올림 계산기



소수점 자릿수 또는 9개의 라운딩 모드가 있는 이진 분수로 정확한 소수를 둥글게 합니다.





## 시작하기



1. 예제 값을 사용하거나 원하는 값을 입력하세요.
2. 계산한 결과를 복사하거나 세부 정보를 내려받을 수 있습니다.







## 예시



### 입력



```
−2.5, 그들, 반에서 조차
```



### 예상 결과



```
−2
```







## 직접 사용해 보기



[전체 도구 열기](<https://toolpony.com/ko/tools/rounding-calculator/>)







## 참고 사항



브라우저에서 처리합니다. 단위를 일관되게 사용하세요.







## 계산 방법



정확한 decimal 나머지를 반 단계와 비교합니다. 넥타이의 경우 방향 또는 패리티 규칙을 선택합니다. 가장 가까운 것은 0에서 멀리 떨어져있는 관계를 사용합니다.



$$
x=qs+r,\qquad 0\le r<s,\qquad r=\tfrac{s}{2}\text{ at a tie}
$$



자릿수가 2이면 소수 둘째 자리, 0이면 일의 자리, −2이면 백의 자리로 반올림합니다. 분수 간격을 지정하면 1/4이나 1/16 등의 배수로 반올림합니다.



반에서 짝수 짝수 것은 정확한 넥타이에서만 선택합니다. 예를 들어, −2.5는 −2로 이동하고 −3.5는 −4로 이동합니다. 천장은 항상 긍정적 인 무한대로 움직입니다.
