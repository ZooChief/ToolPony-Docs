# Tip calculator



Split a bill and tip among people, with the tip based on the amount before or after tax.





## Get started



1. Use the example values or enter your own measurements.
2. Calculate, then copy the result or download the available details.







## Example



### Input



```
80 bill, 20% tip, 4 people
```



### Expected result



```
96 total, 24 per person
```







## Try it



[Open full tool](<https://toolpony.com/en/tools/tip-calculator/>)







## Good to know



The calculation runs in your browser. Use consistent units in fields with no explicit unit.







## Calculation method



Tip = selected bill amount × tip percentage. Per-person total equals bill, tax and tip divided by the number of people.
