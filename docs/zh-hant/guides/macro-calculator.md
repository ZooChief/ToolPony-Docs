# 三大營養素計算器



把熱量目標和營養比例換算成克數，或由克數計算熱量和比例。





## 示例



### 輸入



```
2,000 kcal，蛋白質 25%、碳水 45%、脂肪 30%
```



### 預期結果



```
蛋白質 125 g、碳水 225 g、脂肪約 66.67 g
```







## 試一試

[打開完整工具 · 三大營養素計算器](<https://toolpony.com/zh-hant/tools/macro-calculator/>)





## 計算方法



按蛋白質和碳水每克 4 kcal、脂肪每克 9 kcal 換算。目標模式下三項比例合計須爲 100%。







## 計算模式



**目標換算克數**

- 總熱量 · kcal
- 蛋白質 · %
- 碳水化合物 · %
- 脂肪 · %





**克數換算熱量**

- 蛋白質 · g
- 碳水化合物 · g
- 脂肪 · g
