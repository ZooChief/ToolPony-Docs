# Farbpipette für Bilder



Klicken Sie auf das Beispiel oder wählen Sie ein Bild. Klicken Sie auf einen Punkt oder geben Sie die Pixelkoordinaten ein, um HEX und RGBA zu lesen. Kopieren Sie eine Farbe oder exportieren Sie die gesampelte Palette als CSV.





## Erste Schritte



1. Versuchen Sie das eingebaute Beispiel oder wählen Sie ein Bild aus.
2. Klicken Sie auf einen Punkt oder geben Sie X und Y ein und probieren Sie das ursprüngliche Pixel aus.
3. Kopieren Sie HEX oder exportieren Sie bis zu sechzehn Koordinaten und RGBA-Zeilen als CSV.







## Beispiel



### Eingabe



```
Einbauprobe, X = 32 und Y = 32
```



### Erwartetes Ergebnis



```
#285eaa · RGBA 40, 94, 170, 255
```

## Hinweise



Die Vorschau kann herunterskaliert werden, während das Sampling noch das entsprechende Originalpixel liest. Der Browser kann Bildfarbprofile während der Decodierung konvertieren.







## Grenzen



JPG, PNG, WebP, AVIF oder GIF bis zu 20 MB und 24 Megapixel. Lesen Sie die decodierten Pixel des Browsers. Koordinaten beginnen bei (0, 0) oben links. Eine Palette enthält bis zu 16 Punkte.
