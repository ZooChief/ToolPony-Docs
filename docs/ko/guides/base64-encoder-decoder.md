# Base64 인코딩 및 디코딩



UTF-8 텍스트를 표준 또는 URL-safe Base64로 인코딩하고 디코딩된 텍스트를 확인합니다.





## 시작하기



1. 예제 값을 사용하거나 원하는 값을 입력하세요.
2. 계산한 결과를 복사하거나 세부 정보를 내려받을 수 있습니다.







## 예시



### 입력



```
hello 인코딩
```



### 예상 결과



```
aGVsbG8=
```







## 직접 사용해 보기



[전체 도구 열기](<https://toolpony.com/ko/tools/base64-encoder-decoder/>)







## 참고 사항



브라우저에서 처리합니다. 단위를 일관되게 사용하세요.







## 계산 방법



텍스트는 UTF-8로 변환됩니다. URL-safe 모드는 "-" 및 "\_"을 사용하고 출력에서 패딩을 생략합니다. 최대 500,000개의 입력 문자.

[문서](https://docs.toolpony.com/ko/guides/base64-encoder-decoder/)
