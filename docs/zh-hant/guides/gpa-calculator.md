# GPA 績點計算器



按課程學分加權計算績點，計入既往成績或按學期統計，也可倒算目標績點。





## 開始使用



1. 按示例填寫數值，或輸入你自己的測量值。
2. 計算後可複製結果或下載明細。







## 示例



### 輸入



```
數學 3 學分 A，英語 3 學分 B
```



### 預期結果



```
GPA 3.5
```

## 計算方法



GPA 是課程績點乘學分之和除以總學分。字母採用 4.3 分制。百分制模式直接計算加權百分數。其他校規可直接輸入績點。



$$
\operatorname{GPA}=\frac{\sum_i g_i c_i}{\sum_i c_i}
$$



每行填寫一門課。第四列可指定學期，第五列可爲該課程的每學分績點加分。計入既往成績時同時填寫既往績點和學分。



A+ 至 F 採用 4.3 分制。P、NP、I、W 不計入加權總和。學校另有分制時選擇績點數值模式。







## 計算模式



**課程成績**

- 每行：課程、學分、成績，可選學期與加分
- 成績格式 · 字母 / 百分制 / 績點數值
- 此前績點
- 此前學分





**規劃目標績點**

- 當前績點
- 目標績點
- 已修學分
- 待修學分
