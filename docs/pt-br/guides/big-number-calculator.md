# Calculadora de números grandes



Calcular com números inteiros grandes e coeficientes decimais exatos, com arredondamento selecionável para divisão e raízes.





## Primeiros passos



1. Use o exemplo ou insira seus próprios valores.
2. Calcule, copie o resultado ou baixe os detalhes disponíveis.







## Exemplo



### Entrada



```
9,007,199,254,740,993 + 7
```



### Resultado esperado



```
9007199254741000
```

## Notas de uso



O cálculo é feito no seu navegador. Use unidades consistentes.







## Método de cálculo



Adição, subtração, multiplicação, potências inteiras e operações inteiras usam coeficientes BigInt. As rodadas de divisão para as casas decimais selecionadas. As raízes quadradas podem truncar ou arredondar para as mais próximas. Os expoentes inteiros positivos e negativos são suportados dentro do limite do resultado.



$$
x=m\cdot 10^e,\quad x_1x_2=(m_1m_2)\cdot 10^{e_1+e_2}
$$
