# 행렬 계산기



덧셈, 곱들기, 전환, 반전, 해결, 또는 순위 및 결정 요인을 찾습니다. 결과를 TSV로 복사하거나 CSV를 다운로드하십시오.





## 시작하기



1. 예제 값을 사용하거나 원하는 값을 입력하세요.
2. 계산한 결과를 복사하거나 세부 정보를 내려받을 수 있습니다.







## 예시



### 입력



```
A = [2, 4; 1, 3], B = [1, −2; 4, 5]
```



### 예상 결과



```
A + B = [3, 2; 5, 8]
```

## 계산 방법



각 행을 새 줄 또는 세미콜론과 분리합니다. 값은 공백 또는 쉼표로 구분할 수 있습니다. 중첩된 JSON 배열이 허용됩니다. Square-matrix 메서드는 축소된 선회와 함께 Gaussian 제거를 사용합니다.



$$
(AB)_{ij}=\sum_{k=1}^{n}A_{ik}B_{kj},\qquad A^{-1}A=I
$$



$$
[A\mid B]\longrightarrow[I\mid X]\quad\Rightarrow\quad AX=B
$$
