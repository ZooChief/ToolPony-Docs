# Margem de lucro e markup



Encontrar margem bruta e marcação a partir de custo e preço, ou preço de um produto a uma margem alvo.





## Primeiros passos



1. Use o exemplo ou insira seus próprios valores.
2. Calcule, copie o resultado ou baixe os detalhes disponíveis.







## Exemplo



### Entrada



```
Custo 60, preço 100
```



### Resultado esperado



```
Margem de 40%; 66,67% de marcação
```







## Experimente



[Abrir ferramenta completa](<https://toolpony.com/pt-br/tools/margin-calculator/>)







## Notas de uso



O cálculo é feito no seu navegador. Use unidades consistentes.







## Método de cálculo



Margem = lucro ÷ preço de venda. Markup = lucro ÷ custo. Para atingir a margem desejada, use preço de venda = custo ÷ (1−margem).







## Modo de cálculo



**Custo e preço**

- Custo
- Preço de venda





**Preço a uma margem-alvo**

- Custo
- Margem-alvo · %
