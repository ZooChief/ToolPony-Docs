# 冪運算計算器



已知兩個量，求冪、底數或指數。





## 開始使用



1. 按示例填寫數值，或輸入你自己的測量值。
2. 計算後可複製結果或下載明細。







## 示例



### 輸入



```
底數 2，指數 5
```



### 預期結果



```
32
```

## 計算方法



在 y = bⁿ 中，當 b 與 y 爲正且 b ≠ 1 時可用對數求指數。偶整數指數求實數底數時可能有兩個解。



$$
y=b^p,\qquad p=\frac{\ln y}{\ln b},\qquad b=\sqrt[p]{y}
$$







## 計算模式



**求冪**

- 底數
- 指數





**求底數**

- 指數
- 冪的結果





**求指數**

- 底數
- 冪的結果
