# Gewinnmarge und Aufschlag



Finden Sie die Bruttomarge und den Aufschlag aus Kosten und Preis oder bepreisen Sie ein Produkt mit einer Zielmarge.





## Erste Schritte



1. Verwenden Sie das Beispiel oder geben Sie eigene Werte ein.
2. Berechnen Sie das Ergebnis und kopieren oder laden Sie die Details herunter.







## Beispiel



### Eingabe



```
Kosten 60, Preis 100
```



### Erwartetes Ergebnis



```
40% Marge; 66,67% Markup
```







## Ausprobieren



[Vollständiges Werkzeug öffnen](<https://toolpony.com/de/tools/margin-calculator/>)







## Hinweise



Die Verarbeitung erfolgt im Browser. Verwenden Sie einheitliche Einheiten.







## Berechnungsmethode



Margin = Gewinn ÷ Verkaufspreis. Markup = Gewinn ÷ Kosten. Eine Zielmarge erfordert Verkaufspreis = Kosten ÷ (1-Marge).







## Berechnungsmodus



**Kosten und Preis**

- Kosten
- Verkaufspreis





**Preis bei einer Zielmarge**

- Kosten
- Zielmarge · %
