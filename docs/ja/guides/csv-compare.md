# CSV 比較



新旧の表を貼り付けるか読み込みます。先頭行をヘッダーにして、区切り文字とキー列を選びます。 比較して変更を絞り込みます。表計算にはCSV、元のテキストを保つ完全な結果にはJSONを使います。





## 使い方



1. 新旧の表を貼り付けるか読み込みます。先頭行をヘッダーにして、区切り文字とキー列を選びます。
2. 比較して変更を絞り込みます。表計算にはCSV、元のテキストを保つ完全な結果にはJSONを使います。







## 例



### 入力



```
ID,Name,Qty
001,Oak,2
002,Pine,1
004,Ash,3

Qty,ID,Name
4,001,Oak
1,003,Fir
3,004,Ash
```



### 期待される結果



```
追加 1 · 削除 1 · 変更 1
```







## 試してみる



[ツール全体を開く](<https://toolpony.com/ja/tools/csv-compare/>)







## 制限



各表はUTF-8で1 MiB、データ5,000行、80列までです。先頭の0を含めて文字列を完全一致で比較し、重複キーと空キーを分けて表示します。番号はヘッダーから数えたレコード順です。
