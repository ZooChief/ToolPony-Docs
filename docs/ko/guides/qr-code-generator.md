# QR 코드 생성기



스캔할 유형을 고르고 링크나 텍스트, 필요한 항목을 입력하세요. 생성한 내용을 확인하고 공유용 PNG나 인쇄용 SVG를 다운로드하세요. 필요하면 모양에서 어두운 6자리 HEX 색상을 지정하세요. 두 형식 모두 흰 여백을 유지합니다.





## 시작하기



1. 스캔할 유형을 고르고 링크나 텍스트, 필요한 항목을 입력하세요.
2. 생성한 내용을 확인하고 공유용 PNG나 인쇄용 SVG를 다운로드하세요.
3. 필요하면 모양에서 어두운 6자리 HEX 색상을 지정하세요. 두 형식 모두 흰 여백을 유지합니다.







## 예시



### 입력



```
https://example.com/
```



### 예상 결과



```
https://example.com/
```

## 제한 사항



정적 QR은 입력값을 담습니다. UTF-8 최대 2,048바이트이며 정정 수준이 높으면 용량이 줄어듭니다. 흰 테두리는 네 모듈의 여백을 확보합니다. Wi-Fi QR에 입력한 암호가 포함됩니다.
