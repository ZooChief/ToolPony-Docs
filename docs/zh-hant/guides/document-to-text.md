# 文檔轉純文本



從設備選擇 DOCX、ODT 或 PDF，或打開 DOCX 示例。





## 開始使用



1. 從設備選擇 DOCX、ODT 或 PDF，或打開 DOCX 示例。
2. 段落另起一行，表格單元格用製表符分隔。可複製結果或下載 UTF-8 文本。







## 示例



### 輸入



```
含標題、兩段行內文字和一個製表符的 DOCX
```



### 預期結果



```
ToolPony
ABC	123
```

## 適用範圍



DOCX 和 ODT 僅讀取正文，文件最多 20 MiB，提取的 UTF-8 文本最多 1 MiB。PDF 須含可選文字。圖片、頁面排版和受密碼保護的文件不在處理範圍內。
