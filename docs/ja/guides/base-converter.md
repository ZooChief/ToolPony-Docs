# 進数変換・計算機



2〜36塩基間で符号付き整数を変換し、正確な算術演算、残り演算、またはビットワイズ演算を実行します。





## 使い方



1. 例を使うか、任意の値を入力します。
2. 計算後、結果をコピーするか詳細をダウンロードできます。







## 例



### 入力



```
FF、ベース16からベース10
```



### 期待される結果



```
255
```







## 試してみる



[ツール全体を開く](<https://toolpony.com/ja/tools/base-converter/>)







## 注意点



処理はブラウザ内で実行されます。単位をそろえて入力してください。







## 計算方法



BigIntは整数の精度を保持しています。 分断はゼロに向かって傾いている。 ビットワイズ演算では、署名されたBigIntセマンティクスを使用します。 各通信番号は256桁に制限されています。







## 計算モード



**変換ベース**

- 整数
- 入力ベース
- 出力ベース
- 最小出力桁





**整数算術**

- 最初の整数
- 第二整数
- 入力ベース
- 出力ベース
- 最小出力桁
- 演算 · 追加 / 控除 / 多量に / 分割 / 余り / AND / OR / XOR
