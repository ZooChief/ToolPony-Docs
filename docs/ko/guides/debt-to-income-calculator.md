# 총부채상환비율 계산기



반복되는 월별 부채 지불을 총 월 소득과 비교하십시오.





## 예시



### 입력



```
소득 5,000, 부채 지불 1,500
```



### 예상 결과



```
30%
```







## 직접 사용해 보기

[전체 도구 열기 · 총부채상환비율 계산기](<https://toolpony.com/ko/tools/debt-to-income-calculator/>)





## 계산 방법



부채 대 소득 비율 = 월별 부채 지불 ÷ 총 월 소득. 모든 금액에 대해 동일한 통화와 월별 기간을 사용하십시오.





**계산 및 처리 방식의 출처** [CFPB · Debt-to-Income Ratio](<https://www.consumerfinance.gov/ask-cfpb/what-is-a-debt-to-income-ratio-en-1791/>)
