# PDF 拆分



通過縮略圖選頁，或輸入 1-3, 5 等頁碼範圍。可生成一份 PDF，或按範圍、逐頁、固定頁數和體積上限分組。輸出遵循選頁順序。





## 開始使用



1. 選擇未加密的 PDF。
2. 在縮略圖選頁，或輸入 1-3, 5 等頁碼範圍。每個範圍按升序填寫，頁碼不能重複。
3. 合成一份 PDF，或按範圍、逐頁、固定頁數或文件大小上限分組，下載 PDF 或 ZIP。







## 示例



### 輸入



```
一份 5 頁 PDF；輸入：5, 1-3
```



### 預期結果



```
一份 PDF，頁面順序爲原文件的 5、1、2、3 頁。
```

## 使用提示



示例中若每組爲 2 頁，則得到 \[5, 1\] 和 \[2, 3\]。大小上限按實際生成的 PDF 計算，單位爲十進制 kB 或 MB。複製時不重新壓縮；單頁超限時可調高上限。







## 適用範圍



最大 30 MB、300 頁。ZIP 內 PDF 合計最多 64 MB。大小限制以生成的實際 PDF 爲準，不重新壓縮；單頁超限時可調高上限。頁碼不能重複，不支持加密 PDF。表單、書籤和數字簽名可能丟失。
