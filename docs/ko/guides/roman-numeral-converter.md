# 로마 숫자 변환기



날짜 또는 구분된 목록을 포함하여 어느 방향으로든 로마 숫자와 정수를 변환합니다.





## 시작하기



1. 예제 값을 사용하거나 원하는 값을 입력하세요.
2. 계산한 결과를 복사하거나 세부 정보를 내려받을 수 있습니다.







## 예시



### 입력



```
MCMXCIX
```



### 예상 결과



```
1999
```

## 계산 방법



변환기는 IV 및 CM과 같은 표준 빼기 쌍을 사용합니다. 오버라인은 그룹을 1,000개씩 곱합니다. 각 overlined 편지의 앞에 밑줄을 입력하거나 overline 자체를 붙여 넣습니다. 값은 1–3,999,999로 제한됩니다. 날짜 형태는 각 필드를 변환하고 분리기를 보존합니다.







## 계산 모드



**단일 값**

- 정수 또는 로마 숫자





**날짜 또는 목록**

- 가치 또는 날짜
