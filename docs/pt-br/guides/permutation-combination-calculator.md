# Guia de uso · Calculadora de permutações e combinações



Calcular seleções ordenadas e não ordenadas com ou sem repetição.





## Exemplo



### Entrada



```
n=10, r=3, sem repetição
```



### Resultado esperado



```
720 permutações; 120 combinações
```







## Experimente

[Abrir ferramenta completa · Calculadora de permutações e combinações](<https://toolpony.com/pt-br/tools/permutation-combination-calculator/>)





## Método de cálculo



Sem repetição, nPr = n!/(n−r)! e nCr = nPr/r!. Com repetição, as escolhas ordenadas são nr e as escolhas não ordenadas são C(n+r−1,r).
