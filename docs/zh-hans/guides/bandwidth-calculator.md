# 带宽与下载时间计算器



根据文件大小、带宽与有效传输比例估算下载时间。





## 示例



### 输入



```
1 GB，100 Mbps，有效率 100%
```



### 预期结果



```
80 秒
```







## 试一试



[打开完整工具](<https://toolpony.com/zh-hans/tools/bandwidth-calculator/>)







## 计算方法



秒数 = 文件字节数 × 8 ÷ 有效每秒比特数。带宽单位用十进制前缀，文件大小支持十进制和二进制。
