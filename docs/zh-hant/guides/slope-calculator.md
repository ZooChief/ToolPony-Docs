# 斜率計算器



通過兩點求斜率和截距，或求給定距離上的兩個端點。





## 開始使用



1. 按示例填寫數值，或輸入你自己的測量值。
2. 計算後可複製結果或下載明細。

### 輸入



```
從（0, 0）到（3, 4）
```

## 計算方法



斜率等於垂直變化量除以水平變化量。垂直線的斜率未定義。給定距離和方向時，起點兩側各有一個端點。



$$
m=\frac{y_2-y_1}{x_2-x_1},\qquad \theta=\arctan(m),\qquad y=mx+b
$$



兩點模式分別顯示水平變化和垂直變化。正負號表示移動方向。垂直線的 x 座標爲常數。



一條直線與一個距離會在起點兩側各確定一個點。端點表會保留兩個解。
