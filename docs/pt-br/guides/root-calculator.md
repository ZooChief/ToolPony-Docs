# Calculadora de raízes



Calcular o quadrado real principal, cubo, ou raiz nth.





## Primeiros passos



1. Use o exemplo ou insira seus próprios valores.
2. Calcule, copie o resultado ou baixe os detalhes disponíveis.







## Exemplo



### Entrada



```
Raiz quadrada de 144
```



### Resultado esperado



```
12
```

## Notas de uso



O cálculo é feito no seu navegador. Use unidades consistentes.







## Método de cálculo



A raiz nth é x elevada a 1/n. Os graus inteiros ímpares aceitam radicandos negativos. Um grau negativo toma o recíproco.



$$
\sqrt[n]{x}=x^{1/n},\qquad n\ne0
$$







## Modo de cálculo



**Raiz quadrada**

- Radicando





**Raiz cúbica**

- Radicando





**Raiz enésima**

- Radicando
- Grau
