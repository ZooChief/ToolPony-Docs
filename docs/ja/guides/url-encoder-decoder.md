# URL のエンコード・デコード



完全なURL、URIコンポーネント、およびフォーム値をエンコードまたはデコードします。





## 使い方



1. 例を使うか、任意の値を入力します。
2. 計算後、結果をコピーするか詳細をダウンロードできます。







## 例



### 入力



```
エンコードコンポーネント: A+b および c
```



### 期待される結果



```
a%2Bb%20%26%20c
```







## 試してみる



[ツール全体を開く](<https://toolpony.com/ja/tools/url-encoder-decoder/>)







## 注意点



処理はブラウザ内で実行されます。単位をそろえて入力してください。







## 計算方法



コンポーネントのエンコードは、予約された区切り文字をエスケープします。 フルURLエンコーディングは区切り文字を保持します。 フォームエンコーディングは、スペースにプラスを使用します。

[ドキュメント](https://docs.toolpony.com/ja/guides/url-encoder-decoder/)
