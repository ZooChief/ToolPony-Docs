# Calculadora de metabolismo basal e calorias



Estimar energia de repouso e gasto energético diário em unidades métricas ou US com três equações.





## Primeiros passos



1. Use o exemplo ou insira seus próprios valores.
2. Calcule, copie o resultado ou baixe os detalhes disponíveis.







## Exemplo



### Entrada



```
Equação masculina, 30 anos, 70 kg, 175 cm, Mifflin–St Jeor
```



### Resultado esperado



```
1.648,75 kcal/dia em repouso
```







## Experimente



[Abrir ferramenta completa](<https://toolpony.com/pt-br/tools/bmr-calculator/>)







## Notas de uso



O cálculo é feito no seu navegador. Use unidades consistentes.







## Método de cálculo



A energia de repouso é estimada com Mifflin–St Jeor, revisada Harris–Benedict ou Katch–McArdle. O gasto diário multiplica a estimativa pelo seu fator de atividade.







## Modo de cálculo



**Sistema métrico**

- Idade
- Grupo de equações · Masculino / Mulheres
- Peso · kg
- Altura · cm
- Equação · Mifflin–St Jeor / Revisão de Harris–Benedict / Katch–McArdle
- Gordura corporal para Katch–McArdle · %
- Factor de actividade
- Unidade energética · kcal/day / kJ/day





**Unidades usuais dos EUA**

- Idade
- Grupo de equações · Masculino / Mulheres
- Peso · lb
- Altura em pés · ft
- Inferimentos adicionais · in
- Equação · Mifflin–St Jeor / Revisão de Harris–Benedict / Katch–McArdle
- Gordura corporal para Katch–McArdle · %
- Factor de actividade
- Unidade energética · kcal/day / kJ/day
