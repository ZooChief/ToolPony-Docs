# Rechner für gemeinsame Teiler



Listen Sie alle positiven gemeinsamen Faktoren auf und berechnen Sie den größten gemeinsamen Faktor mehrerer Ganzzahlen.





## Erste Schritte



1. Verwenden Sie das Beispiel oder geben Sie eigene Werte ein.
2. Berechnen Sie das Ergebnis und kopieren oder laden Sie die Details herunter.







## Beispiel



### Eingabe



```
12, 18, 30
```



### Erwartetes Ergebnis



```
1, 2, 3, 6
```

## Hinweise



Die Verarbeitung erfolgt im Browser. Verwenden Sie einheitliche Einheiten.







## Berechnungsmethode



Die gemeinsamen Faktoren einer Liste sind genau die Teiler ihres größten gemeinsamen Teilers. Der euklidische Algorithmus findet diesen Teiler, ohne die Faktoren jedes Inputs aufzuzählen.



$$
d\mid a_1,\ldots,a_n\iff d\mid\gcd(a_1,\ldots,a_n)
$$
