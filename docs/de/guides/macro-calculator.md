# Makronährstoffrechner



Konvertieren Sie ein Kalorienziel und Nährstoffverhältnisse in Gramm oder berechnen Sie Energie und Proportionen aus Gramm.





## Erste Schritte



1. Verwenden Sie das Beispiel oder geben Sie eigene Werte ein.
2. Berechnen Sie das Ergebnis und kopieren oder laden Sie die Details herunter.







## Beispiel



### Eingabe



```
2.000 kcal: 25% Protein, 45% Kohlenhydrate, 30% Fett
```



### Erwartetes Ergebnis



```
125 g Protein, 225 g Kohlenhydrate, 66,67 g Fett
```







## Ausprobieren



[Vollständiges Werkzeug öffnen](<https://toolpony.com/de/tools/macro-calculator/>)







## Hinweise



Die Verarbeitung erfolgt im Browser. Verwenden Sie einheitliche Einheiten.







## Berechnungsmethode



Die Rechnung verwendet 4 kcal/g für Eiweiß und Kohlenhydrate und 9 kcal/g für Fett. Im Zielmodus müssen die Anteile zusammen 100 % ergeben.







## Berechnungsmodus



**Zielwert für Gramm**

- Gesamtenergie · kcal
- Eiweiß · %
- Kohlenhydrate · %
- Fett · %





**Gramm zu Energie**

- Eiweiß · g
- Kohlenhydrate · g
- Fett · g
