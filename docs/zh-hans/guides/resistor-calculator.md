# 电阻色环与串并联计算器



读 3 至 6 道色环，计算串并联等效电阻与圆线电阻。





## 开始使用



1. 选择色环数或电路连接方式。容差环通常和其他色环有较大间距。
2. 圆形导体填写直径和长度。材料预设会填入可编辑的电导率。







## 示例



### 输入



```
4 色环：绿、红、红、金
```



### 预期结果



```
5,200 Ω ±5%
```

## 使用提示



计算在浏览器内完成。无单位标记的字段请使用一致单位。







## 计算方法



依次读有效数字、倍率、容差和可选温度系数。三环电阻按 20% 容差。均匀圆形导体用 R = L/(σA)。特殊标记请核对器件资料。



$$
R_{\rm series}=\sum_i R_i,\quad R_{\rm parallel}=\left(\sum_i 1/R_i\right)^{-1},\quad R_{\rm wire}=\frac{L}{\sigma\pi(d/2)^2}
$$



$$
R_{\rm band}=D\,10^m,\qquad R_{\min,\max}=R_{\rm band}(1\mp t/100)
$$
