# Conversor de números romanos



Converter numerais romanos e inteiros em qualquer direção, incluindo datas ou listas delimitadas.





## Primeiros passos



1. Use o exemplo ou insira seus próprios valores.
2. Calcule, copie o resultado ou baixe os detalhes disponíveis.







## Exemplo



### Entrada



```
MCMXCIX
```



### Resultado esperado



```
1999
```

## Notas de uso



O cálculo é feito no seu navegador. Use unidades consistentes.







## Método de cálculo



O conversor usa pares subtrativos padrão, como IV e CM. Uma linha overline multiplica um grupo por 1.000. Digite um sublinhado antes de cada letra overlined, ou cole a linha overline em si. Os valores são limitados a 1–3,999,999. O modo Data converte cada campo e preserva separadores.







## Modo de cálculo



**Valor único**

- Inteiro ou numeral romano





**Data ou lista**

- Valores ou data
