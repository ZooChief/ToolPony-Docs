# 燃料費・燃費計算機



燃費単位を換算し、旅行時の燃料費を推定するか、または燃費を測定します。





## 使い方



1. 例を使うか、任意の値を入力します。
2. 計算後、結果をコピーするか詳細をダウンロードできます。







## 例



### 入力



```
走行距離 300 km、燃費 7 L/100 km、燃料単価 1.5/L
```



### 期待される結果



```
21リットル;燃料費31.50
```







## 試してみる



[ツール全体を開く](<https://toolpony.com/ja/tools/fuel-cost-calculator/>)







## 注意点



処理はブラウザ内で実行されます。単位をそろえて入力してください。







## 計算方法



燃料使用量 (L) = 走行距離 (km) × 燃費 (L/100 km) ÷ 100。米国ガロンと英ガロンは容量が異なります。燃料単価は入力値を使用します。







## 計算モード



**旅行費用**

- 距離 · km
- 燃料経済
- 燃料経済ユニット · L/100km / km/L / mpg(米国) / mpg(帝国主義的)
- 1リットルあたりの価格





**燃費を変換**

- 燃料経済
- 入力ユニット · L/100km / km/L / mpg(米国) / mpg(帝国主義的)





**測定された走行距離**

- 距離 · km
- 使用済み燃料 · L
