# 帯域幅計算機



ファイルサイズ、リンク速度、プロトコル効率から転送時間を推定します。





## 例



### 入力



```
100Mbpsで1GB、高効率100%
```



### 期待される結果



```
80秒
```







## 試してみる

[ツール全体を開く · 帯域幅計算機](<https://toolpony.com/ja/tools/bandwidth-calculator/>)





## 計算方法



所要時間 (秒) = ファイルのバイト数 × 8 ÷ 実効速度 (bit/s)。通信速度の接頭辞は 10 進です。ファイルサイズは 10 進と 2 進の接頭辞に対応します。
