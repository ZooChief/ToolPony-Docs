# Calculadora de notación científica



Convertir entre notación científica, ingeniería, E y decimales, o calcular con valores escalados.





## Primeros pasos



1. Usa el ejemplo o introduce tus propios valores.
2. Calcula, copia el resultado o descarga los detalles disponibles.







## Ejemplo



### Entrada



```
1568938
```



### Resultado esperado



```

```

## Método de cálculo



La notación científica utiliza un dígito líder. La notación de ingeniería utiliza un exponente divisible por tres. La adición, la resta y la multiplicación usan coeficientes decimales exactos antes de redondear a la precisión seleccionada.



$$
x=a\times10^n,\qquad 1\le |a|<10\quad(x\ne0)
$$



Entrar 1568938, 1,568938e6, o 1,568938 × 10^6. Representan el mismo valor. La notación de ingeniería utiliza un poder de diez divisible por tres.



El modo aritmético mantiene coeficientes decimales exactos para la adición, la resta y la multiplicación. Potencias no enteros y raíces cuadradas utilizan la aproximación de punto flotante.
