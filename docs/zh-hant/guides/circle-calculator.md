# 圓形計算器



由任一已知量計算半徑、直徑、周長與面積，並計算弧長、扇形面積和絃長。





## 開始使用



1. 按示例填寫數值，或輸入你自己的測量值。
2. 計算後可複製結果或下載明細。







## 示例



### 輸入



```
半徑 2，圓心角 90°
```



### 預期結果



```
周長約 12.5664，弧長約 3.1416
```

## 使用提示



計算在瀏覽器內完成。無單位標記的字段請使用一致單位。







## 計算方法



周長 = 2πr，面積 = πr²。弧長和扇形面積按圓心角佔 360° 的比例計算。



$$
A=\pi r^2,\qquad C=2\pi r
$$
