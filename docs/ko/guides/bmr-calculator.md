# 기초대사량·칼로리 계산기



3개의 방정식을 가진 미터법 또는 미국 단위에 있는 휴식 에너지 그리고 매일 에너지 지출을 견적하십시오.





## 시작하기



1. 예제 값을 사용하거나 원하는 값을 입력하세요.
2. 계산한 결과를 복사하거나 세부 정보를 내려받을 수 있습니다.







## 예시



### 입력



```
남성 방정식, 30 년, 70 kg, 175 cm, Mifflin-St Jeor
```



### 예상 결과



```
1,648.75 kcal/day 휴식시
```







## 직접 사용해 보기



[전체 도구 열기](<https://toolpony.com/ko/tools/bmr-calculator/>)







## 참고 사항



브라우저에서 처리합니다. 단위를 일관되게 사용하세요.







## 계산 방법



휴식 에너지는 Mifflin-St Jeor, 개정 된 Harris-Benedict 또는 Katch-McArdle로 추정됩니다. 일일 지출은 활동 요인에 의한 추정치를 곱합니다.







## 계산 모드



**미터법**

- 나이
- 방정식 그룹 · 남성 / 여성
- 무게 · kg
- 높이 · cm
- 방정식 · Mifflin-St Jeor는 / 해리스-베네딕트 개정 / Katch-McArdle의
- Katch-McArdle의 경우 체지방 · %
- 활동 계수
- 에너지 단위 · kcal/day / kJ/day





**미국 관용 단위**

- 나이
- 방정식 그룹 · 남성 / 여성
- 무게 · lb
- 발에 있는 고도 · ft
- 추가 인치 · in
- 방정식 · Mifflin-St Jeor는 / 해리스-베네딕트 개정 / Katch-McArdle의
- Katch-McArdle의 경우 체지방 · %
- 활동 계수
- 에너지 단위 · kcal/day / kJ/day
