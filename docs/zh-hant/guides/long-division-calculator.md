# 長除法計算器



支持整數與小數除法，查看商、餘數、小數結果以及長除法步驟。





## 開始使用



1. 按示例填寫數值，或輸入你自己的測量值。
2. 計算後可複製結果或下載明細。







## 示例



### 輸入



```
12,345 ÷ 67
```



### 預期結果



```
商 184，餘數 17
```

## 計算方法



被除數和除數按同一 10 的冪放大。整數商向零取整，帶符號餘數滿足被除數 = 商 × 除數 + 餘數。步驟表使用絕對值。



$$
a=bq+r,\quad q=\operatorname{trunc}(a/b),\quad |r|<|b|
$$
