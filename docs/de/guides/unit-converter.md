# Einheitenumrechner



Konvertieren Sie Länge, Masse, Fläche, Volumen, Temperatur, Geschwindigkeit, Energie, Daten und andere Einheiten.





## Erste Schritte



1. Verwenden Sie das Beispiel oder geben Sie eigene Werte ein.
2. Berechnen Sie das Ergebnis und kopieren oder laden Sie die Details herunter.







## Beispiel



### Eingabe



```
1 m in ft umrechnen
```



### Erwartetes Ergebnis



```
≈3.28084 ft
```

Die Verarbeitung erfolgt im Browser. Verwenden Sie einheitliche Einheiten.







## Berechnungsmethode



Jede Gruppe konvertiert über eine Standard-Basiseinheit. US- und imperiale Volumeneinheiten sind getrennt, Dezimal- und Binärspeichereinheiten behalten ihre jeweiligen Basen bei.
