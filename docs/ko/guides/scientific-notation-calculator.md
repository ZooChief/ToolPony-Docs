# 과학적 표기법 계산기



과학, 공학, E 및 소수 표기법 간에 변환하거나, 축소된 값으로 계산한다.





## 시작하기



1. 예제 값을 사용하거나 원하는 값을 입력하세요.
2. 계산한 결과를 복사하거나 세부 정보를 내려받을 수 있습니다.







## 예시



### 입력



```
1568938
```



### 예상 결과



```
1.568938 × 10^6
```

## 계산 방법



과학적 표는 하나의 주요 숫자를 사용합니다. 엔지니어링 메모는 3으로 나눌 수있는 지수를 사용합니다. 덧셈, 뺄셈 및 곱셈은 선택한 정밀도로 반올림하기 전에 정확한 십진수 계수를 사용합니다.



$$
x=a\times10^n,\qquad 1\le |a|<10\quad(x\ne0)
$$



1568938, 1.568938e6, 1.568938 × 10^6은 같은 값입니다. 공학 표기법은 10의 지수를 3의 배수로 표시합니다.



산술 모드는 덧셈, 뺄셈 및 곱셈에 대해 정확한 십진수 계수를 유지합니다. 비 정수 힘과 제곱 뿌리는 부동 소수점 근사치를 사용합니다.
