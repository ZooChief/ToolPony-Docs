# 최대공약수·최소공배수 계산기



큰 정수 목록에 대한 가장 큰 공통 요소 및 최소 공통 배수를 찾습니다.





## 시작하기



1. 예제 값을 사용하거나 원하는 값을 입력하세요.
2. 계산한 결과를 복사하거나 세부 정보를 내려받을 수 있습니다.







## 예시



### 입력



```
12, 18, 24
```



### 예상 결과



```
GCF 6; LCM 72
```







## 직접 사용해 보기



[전체 도구 열기](<https://toolpony.com/ko/tools/gcf-lcm-calculator/>)







## 참고 사항



브라우저에서 처리합니다. 단위를 일관되게 사용하세요.







## 계산 방법



유클리드 알고리즘으로 최대공약수(GCF)를 구합니다. 두 수가 모두 0이 아니면 LCM(a,b) = |a·b| ÷ GCF(a,b)입니다. 각 50자리 이내의 정수를 최대 100개 입력할 수 있습니다.
