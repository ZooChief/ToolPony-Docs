# 小費計算器



分攤賬單與小費，可按稅前或含稅金額計算小費。





## 示例



### 輸入



```
賬單 80，小費 20%，4 人
```



### 預期結果



```
合計 96，每人 24
```







## 試一試

[打開完整工具 · 小費計算器](<https://toolpony.com/zh-hant/tools/tip-calculator/>)





## 計算方法



小費 = 所選金額 × 小費比例。每人金額爲賬單、稅費與小費之和除以人數。
