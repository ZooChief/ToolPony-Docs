# 概率计算器



计算事件概率，按两个已知量反求独立事件概率，或计算正态区间概率。





## 开始使用



1. 按示例填写数值，或输入你自己的测量值。
2. 计算后可复制结果或下载明细。







## 示例



### 输入



```
独立事件 A = 0.31，B = 0.56
```



### 预期结果



```
至少一个发生：0.6964
```

## 计算方法



独立事件满足 P(A∩B)=P(A)P(B)。相关事件需直接输入交集。重复试验的全部成功概率为各次概率之积，至少一次成功使用补集计算。



$$
P(A\cup B)=P(A)+P(B)-P(A\cap B)
$$



$$
P(A\cap B)=P(A)P(B)\quad\text{(independent)}
$$







## 计算模式



**两个独立事件**

- A 的概率
- B 的概率





**已知交集**

- A 的概率
- B 的概率
- 两个事件均发生





**反求独立事件**

- 第一已知量 · A 的概率 / B 的概率 / A 不发生 / B 不发生 / 两个事件均发生 / 至少一个事件发生 / 恰好一个事件发生 / 两个事件均不发生
- 第一概率
- 第二已知量 · A 的概率 / B 的概率 / A 不发生 / B 不发生 / 两个事件均发生 / 至少一个事件发生 / 恰好一个事件发生 / 两个事件均不发生
- 第二概率





**重复独立试验**

- A 的概率
- A 的试验次数
- B 的概率
- B 的试验次数





**正态分布区间**

- 均值
- 标准差
- 下界
- 上界
