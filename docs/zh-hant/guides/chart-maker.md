# 圖表生成器使用指南



粘貼包含表頭、標籤列與數值列的 CSV。選擇柱狀圖或折線圖，可將實時預覽下載爲 SVG。





## 開始使用



1. 輸入 CSV 表頭，第一列寫類別標籤，後面各列寫數值系列。
2. 選擇柱狀圖或折線圖，修改數據即可看到變化。
3. 下載 SVG 圖表。







## 示例



### 輸入



```
月份,訪問量
一月,24
二月,38
```



### 預期結果



```
從左到右繪製一月 24、二月 38。
```

## 使用提示



標籤內的逗號需要用雙引號包住。小數點用句點，負值與正值使用同一座標尺度。







## 適用範圍



最多 120 行數據和六列數值。雙引號內可包含逗號，單元格不跨行。按輸入順序繪製。
