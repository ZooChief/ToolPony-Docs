# Calculadora de MCD y mcm



Encontrar el mayor factor común y menos común múltiple para una lista de enteros grandes.





## Primeros pasos



1. Usa el ejemplo o introduce tus propios valores.
2. Calcula, copia el resultado o descarga los detalles disponibles.







## Ejemplo



### Entrada



```
12, 18, 24
```



### Resultado esperado



```
GCF 6; LCM 72
```

## Método de cálculo



El algoritmo de Euclid encuentra GCF. LCM(a,b) = prehensia·b sufrimiento ÷ GCF(a,b) cuando ambos no son cero. Hasta 100 enteros de 50 dígitos cada uno.
