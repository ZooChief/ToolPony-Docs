# 文件與文本哈希



選擇文本或文件，再選 SHA-2 算法並計算。粘貼預期哈希檢查是否一致，或下載 CSV。





## 開始使用



1. 選擇文本模式或選擇一個或多個文件。
2. 選擇 SHA-256、SHA-384 或 SHA-512 並計算。
3. 粘貼預期哈希進行校驗，或下載結果 CSV。







## 示例



### 輸入



```
文本 abc，UTF-8，SHA-256
```



### 預期結果



```
ba7816bf8f01cfea414140de5dae2223b00361a396177a9cb410ff61f20015ad
```

## 使用提示



哈希比較使用字節。編碼、換行方式或單個字節變化都會產生不同的哈希。







## 適用範圍



最多 16 個文件且總計不超過 64 MB，文本上限一百萬字符。文本按 UTF-8 編碼，文件在瀏覽器中順序處理。
