# Redimensionner une image



Choisissez une image. Saisissez la largeur ou la hauteur. Conservez les proportions pour éviter toute déformation. Redimensionnez et téléchargez le PNG.





## Prise en main



1. Choisissez une image.
2. Saisissez la largeur ou la hauteur. Conservez les proportions pour éviter toute déformation.
3. Redimensionnez et téléchargez le PNG.







## Exemple



### Entrée



```
1600 × 1200, largeur 800, proportions conservées
```



### Résultat attendu



```
PNG 800 × 600
```







## Essayer



[Ouvrir l’outil complet](<https://toolpony.com/fr/tools/image-resizer/>)







## Limites



Limite de 20 Mo, 24 mégapixels et 8 192 pixels par côté. Agrandir une image ne restitue aucun détail absent.

[Documentation](https://docs.toolpony.com/fr/guides/image-resizer/)
