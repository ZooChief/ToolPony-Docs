# Dokument in Text umwandeln



Wähle eine DOCX-, ODT- oder PDF-Datei vom Gerät oder öffne das DOCX-Beispiel.





## Erste Schritte



1. Wähle eine DOCX-, ODT- oder PDF-Datei vom Gerät oder öffne das DOCX-Beispiel.
2. Absätze beginnen auf neuen Zeilen. Tabulatoren trennen Tabellenzellen. Kopiere das Ergebnis oder lade eine UTF-8-Datei herunter.







## Beispiel



### Eingabe



```
DOCX mit Titel, zwei Textabschnitten und einem Tabulator
```



### Erwartetes Ergebnis



```
ToolPony
ABC	123
```







## Ausprobieren



[Vollständiges Werkzeug öffnen](<https://toolpony.com/de/tools/document-to-text/>)







## Grenzen



Aus DOCX und ODT wird der Haupttext gelesen. Pro Datei sind bis zu 20 MiB und bis zu 1 MiB UTF-8-Text möglich. PDF braucht auswählbaren Text. Bilder, Seitenlayout und passwortgeschützte Dateien bleiben außen vor.
