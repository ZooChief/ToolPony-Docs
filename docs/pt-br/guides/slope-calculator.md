# Calculadora de inclinação



Encontre uma inclinação e intercepte a partir de dois pontos, ou encontre ambos os objetivos a uma determinada distância.





## Primeiros passos



1. Use o exemplo ou insira seus próprios valores.
2. Calcule, copie o resultado ou baixe os detalhes disponíveis.







## Exemplo



### Entrada



```
(0, 0) a (3, 4)
```



### Resultado esperado



```
Deslize 4/3 e distância 5
```

## Notas de uso



O cálculo é feito no seu navegador. Use unidades consistentes.







## Método de cálculo



O declive é o aumento dividido pela execução. Uma linha vertical tem uma inclinação indefinida. Uma distância e direção conhecidas determinam dois extremos em lados opostos do ponto de partida.



$$
m=\frac{y_2-y_1}{x_2-x_1},\qquad \theta=\arctan(m),\qquad y=mx+b
$$



O modo de dois pontos relata as alterações verticais e horizontais separadamente. Use o sinal de cada alteração para indicar em que direção o ponto se moveu. Uma linha vertical tem uma coordenada X constante.



Uma linha e uma distância determinam um ponto em cada lado do ponto de partida. Use a tabela de endpoint para manter ambas as soluções.
