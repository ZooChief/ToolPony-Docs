# 质因数分解计算器



求正整数的质因数、指数形式和约数个数。





## 示例



### 输入



```
360
```



### 预期结果



```
2³ × 3² × 5，共 24 个约数
```







## 试一试

[打开完整工具 · 质因数分解计算器](<https://toolpony.com/zh-hans/tools/prime-factorization-calculator/>)





## 计算方法



用试除法取出质因数，试除上界为剩余整数的平方根。输入范围为 2 至 1 万亿。
