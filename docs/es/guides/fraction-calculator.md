# Calculadora de fracciones



Usar aritmética exacta para añadir, restar, multiplicar, dividir o simplificar las fracciones y los números mixtos.





## Primeros pasos



1. Usa el ejemplo o introduce tus propios valores.
2. Calcula, copia el resultado o descarga los detalles disponibles.







## Ejemplo



### Entrada



```
1 1/2 + 2/3
```



### Resultado esperado



```
13/6
```

## Método de cálculo



Los decimales se leen como fracciones exactas. Aritmetic utiliza BigInt y se reduce por el divisor común más grande. El resultado decimal es aproximado.



$$
\frac{a}{b}+\frac{c}{d}=\frac{ad+bc}{bd},\qquad b,d\ne0
$$
