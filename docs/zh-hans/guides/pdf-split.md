# PDF 拆分



通过缩略图选页，或输入 1-3, 5 等页码范围。可生成一份 PDF，或按范围、逐页、固定页数和体积上限分组。输出遵循选页顺序。





## 开始使用



1. 选择未加密的 PDF。
2. 在缩略图选页，或输入 1-3, 5 等页码范围。每个范围按升序填写，页码不能重复。
3. 合成一份 PDF，或按范围、逐页、固定页数或文件大小上限分组，下载 PDF 或 ZIP。







## 示例



### 输入



```
一份 5 页 PDF；输入：5, 1-3
```



### 预期结果



```
一份 PDF，页面顺序为原文件的 5、1、2、3 页。
```

## 使用提示



示例中若每组为 2 页，则得到 \[5, 1\] 和 \[2, 3\]。大小上限按实际生成的 PDF 计算，单位为十进制 kB 或 MB。复制时不重新压缩；单页超限时可调高上限。







## 适用范围



最大 30 MB、300 页。ZIP 内 PDF 合计最多 64 MB。大小限制以生成的实际 PDF 为准，不重新压缩；单页超限时可调高上限。页码不能重复，不支持加密 PDF。表单、书签和数字签名可能丢失。
