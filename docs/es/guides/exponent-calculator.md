# Calculadora de potencias



Resolver para un poder, la base, o el exponente de los otros dos valores.





## Primeros pasos



1. Usa el ejemplo o introduce tus propios valores.
2. Calcula, copia el resultado o descarga los detalles disponibles.







## Ejemplo



### Entrada



```
Base 2, exponente 5
```



### Resultado esperado



```
32
```

## Método de cálculo



Para y = bn, resolver el exponente con logaritmos cuando b y y son positivos y b ل 1. Solving para una base real con un exponente no cero incluso entero puede producir dos raíces.



$$
y=b^p,\qquad p=\frac{\ln y}{\ln b},\qquad b=\sqrt[p]{y}
$$
