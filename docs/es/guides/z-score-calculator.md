# Guía de uso · Calculadora de puntuación Z



Normalizar un valor y convertir entre Z-scores, probabilidades normales y intervalos.





## Ejemplo



### Entrada



```
Valor 18, media 23, desviación 4
```



### Resultado esperado



```
z = −1.25
```







## Pruébalo

[Abrir herramienta completa · Calculadora de puntuación Z](<https://toolpony.com/es/tools/z-score-calculator/>)





## Método de cálculo



La puntuación estándar es (x − μ)/σ. La cola izquierda es el CDF normal en z. Para las regiones simétricas el inverso devuelve el límite no negativo.



$$
z=\frac{x-\mu}{\sigma},\qquad P(a<Z<b)=\Phi(b)-\Phi(a)
$$
