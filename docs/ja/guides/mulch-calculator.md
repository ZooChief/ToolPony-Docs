# マルチ材計算機



1 つ以上の区画に必要なマルチ材の体積、袋数、費用を見積もります。





## 使い方



1. 合計面積を入力するか、6, 2, m のように 1 行に 1 つの長方形を入力します。行ごとに単位を変えられます。
2. 厚さと、ばら売りまたは袋売りの単位を選びます。袋容量を指定する場合は詳細オプションを使います。







## 例



### 入力



```
200 ft²、厚さ 2 in、2 ft³ の袋、単価 5。
```



### 期待される結果



```
33.3 ft³、17 袋、費用 85。
```







## 試してみる



[ツール全体を開く](<https://toolpony.com/ja/tools/mulch-calculator/>)







## 注意点



処理はブラウザ内で実行されます。単位をそろえて入力してください。







## 計算方法



重ならない区画の面積を合計し、厚さと予備率を適用します。袋容量で割って切り上げます。ばら売りの費用は体積から求めます。



$$
A=\sum_i l_iw_i,\quad V=Ad(1+a/100),\quad N=\left\lceil\frac{V}{V_{\rm bag}}\right\rceil
$$







## 計算モード



**面積が既知**

- 面積
- 面積の単位 · cm² / m² / in² / ft² / yd² / エーカー / ハ
- 敷く厚さ
- 厚さの単位 · mm / cm / m / で / フィート / yd
- 単価
- 価格の単位
- 1 袋の容量
- 袋容量の単位 · ft³ / yd³ / m³ / L
- 予備率 · %





**複数の長方形**

- 各行に長さ、幅、単位
- 敷く厚さ
- 厚さの単位 · mm / cm / m / で / フィート / yd
- 単価
- 価格の単位
- 1 袋の容量
- 袋容量の単位 · ft³ / yd³ / m³ / L
- 予備率 · %
