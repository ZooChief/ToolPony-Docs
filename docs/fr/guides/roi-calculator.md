# Calculatrice de retour sur investissement



Calculer le bénéfice net, le rendement total et le rendement annualisé avec les frais.





## Prise en main



1. Utilisez l’exemple ou saisissez vos propres valeurs.
2. Calculez, puis copiez le résultat ou téléchargez les détails.







## Exemple



### Entrée



```
Investir 1 000 et recevoir 1 210 après 2 ans
```



### Résultat attendu



```
21 % total; 10 % annualisé
```







## Essayer



[Ouvrir l’outil complet](<https://toolpony.com/fr/tools/roi-calculator/>)







## Notes



Le traitement se fait dans le navigateur. Utilisez des unités cohérentes.







## Méthode de calcul



Le rendement total est (produit net − coût total) ÷ coût total. Le rendement annualisé se compose du même rapport au cours des années spécifiées.
