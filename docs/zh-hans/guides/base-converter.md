# 进制转换与计算器



在 2–36 进制之间转换带符号整数，并进行精确算术、取余和位运算。





## 开始使用



1. 按示例填写数值，或输入你自己的测量值。
2. 计算后可复制结果或下载明细。







## 示例



### 输入



```
FF，从十六进制转十进制
```



### 预期结果



```
255
```

## 使用提示



计算在浏览器内完成。无单位标记的字段请使用一致单位。







## 计算方法



大整数运算保留整数精度。除法向零取整，位运算按有符号 BigInt 语义。每个操作数最多 256 位。







## 计算模式

- 输出进制
- 最少输出位数
