# 文件与文本哈希



选择文本或文件，再选 SHA-2 算法并计算。粘贴预期哈希检查是否一致，或下载 CSV。





## 开始使用



1. 选择文本模式或选择一个或多个文件。
2. 选择 SHA-256、SHA-384 或 SHA-512 并计算。
3. 粘贴预期哈希进行校验，或下载结果 CSV。







## 示例



### 输入



```
文本 abc，UTF-8，SHA-256
```



### 预期结果



```
ba7816bf8f01cfea414140de5dae2223b00361a396177a9cb410ff61f20015ad
```

## 使用提示



哈希比较使用字节。编码、换行方式或单个字节变化都会产生不同的哈希。







## 适用范围



最多 16 个文件且总计不超过 64 MB，文本上限一百万字符。文本按 UTF-8 编码，文件在浏览器中顺序处理。
