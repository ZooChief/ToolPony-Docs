# 科学计算器



计算包含幂、阶乘、三角函数、根式和对数的数学表达式。





## 开始使用



1. 按示例填写数值，或输入你自己的测量值。
2. 计算后可复制结果或下载明细。







## 示例



### 输入



```
sqrt(81) + 2^3 × sin(30)，角度制
```



### 预期结果



```
13
```

## 使用提示



计算在浏览器内完成。无单位标记的字段请使用一致单位。







## 计算方法



按括号、后缀、乘方、乘除、加减的优先级计算。乘方从右结合，百分号表示除以 100。结果采用浮点运算。
