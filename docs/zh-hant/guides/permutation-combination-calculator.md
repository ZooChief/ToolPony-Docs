# 排列組合計算器使用指南



精確計算有序與無序選擇，支持可重複和不重複兩種方式。





## 示例



### 輸入



```
n=10，r=3，不重複
```



### 預期結果



```
排列 720，組合 120
```

[打開完整工具 · 排列組合計算器](<https://toolpony.com/zh-hant/tools/permutation-combination-calculator/>)





## 計算方法



不重複時 nPr = n!/(n−r)!，nCr = nPr/r!。可重複時有序方案爲 nʳ，無序方案爲 C(n+r−1,r)。
