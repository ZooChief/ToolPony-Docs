# Calculadora de costo y consumo de combustible



Convertir unidades de economía de combustible, estimar el costo de combustible de un viaje, o calcular la economía de combustible medida.





## Primeros pasos



1. Usa el ejemplo o introduce tus propios valores.
2. Calcula, copia el resultado o descarga los detalles disponibles.







## Ejemplo



### Entrada



```
300 km, 7 L/100 km, precio 1,5 por litro
```



### Resultado esperado



```
21 L; costo de combustible 31.50
```

## Notas de uso



El cálculo se ejecuta en tu navegador. Usa unidades coherentes.







## Método de cálculo



Combustible utilizado = distancia × L/100 km ÷ 100. Estados Unidos y millas imperiales por galón utilizan diferentes volúmenes de galón.







## Modo de cálculo



**Costo de viaje**

- Distancia · km
- Economía del combustible
- Unidad de economía de combustible · L/100 km / km/L / mpg (US) / mpg (imperial)
- Precio por litro





**Convertir economía de combustible**

- Economía del combustible
- Unidad de entrada · L/100 km / km/L / mpg (US) / mpg (imperial)





**Kilometraje medido**

- Distancia · km
- Combustible utilizado · L
