# 基础代谢与热量计算器



使用三种公式估算静息能量消耗与每日总能量消耗，支持公制和美制。





## 开始使用



1. 按示例填写数值，或输入你自己的测量值。
2. 计算后可复制结果或下载明细。







## 示例



### 输入



```
男性公式，30 岁，70 kg，175 cm，Mifflin–St Jeor
```



### 预期结果



```
静息约 1,648.75 kcal/天
```

## 使用提示



计算在浏览器内完成。无单位标记的字段请使用一致单位。







## 计算方法



静息消耗使用 Mifflin–St Jeor、修订版 Harris–Benedict 或 Katch–McArdle 估算。每日总消耗为估算值乘以活动系数。







## 计算模式



**公制**

- 年龄
- 公式分组 · 男性 / 女性
- 体重 · kg
- 身高 · cm
- 计算公式 · Mifflin–St Jeor / 修订版 Harris–Benedict / Katch–McArdle
- Katch–McArdle 的体脂率 · %
- 活动系数
- 能量单位 · kcal/天 / kJ/天





**美制**

- 年龄
- 公式分组 · 男性 / 女性
- 体重 · lb
- 身高英尺部分 · ft
- 额外英寸 · in
- 计算公式 · Mifflin–St Jeor / 修订版 Harris–Benedict / Katch–McArdle
- Katch–McArdle 的体脂率 · %
- 活动系数
- 能量单位 · kcal/天 / kJ/天
