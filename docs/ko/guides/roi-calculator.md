# 투자수익률(ROI) 계산기



순이익, 총 수익 및 연간 수익을 수수료로 계산합니다.





## 예시



### 입력



```
1,000을 투자하여 2년 뒤에 1,210을 받습니다
```



### 예상 결과



```
총 21%; 연간 10%
```







## 직접 사용해 보기

[전체 도구 열기 · 투자수익률(ROI) 계산기](<https://toolpony.com/ko/tools/roi-calculator/>)





## 계산 방법



총 수익은 (순 수익 - 총 비용) ÷ 총 비용입니다. 연간 반환 화합물 지정된 년 동안 동일한 비율.
