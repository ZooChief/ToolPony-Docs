# Calculadora de equações quadráticas



Resolver ax2 + bx + c = 0 com raízes reais ou complexas, incluindo coeficientes fracionários.





## Primeiros passos



1. Use o exemplo ou insira seus próprios valores.
2. Calcule, copie o resultado ou baixe os detalhes disponíveis.







## Exemplo



### Entrada



```
a=1, b=−5, c=6
```



### Resultado esperado



```
x₁=2, x₂=3
```

## Notas de uso



O cálculo é feito no seu navegador. Use unidades consistentes.







## Método de cálculo



Use o discriminante b2−4ac. Um coeficiente quadrático zero reduz a expressão para uma equação linear.



$$
ax^2+bx+c=0,\qquad x=\frac{-b\pm\sqrt{b^2-4ac}}{2a},\quad a\ne0
$$
