# Calculadora do teorema de Pitágoras



Resolva a² + b² = c² a partir dos comprimentos ou quadrados de dois lados.





## Primeiros passos



1. Insira os comprimentos ou quadrados de dois lados diferentes.







## Exemplo



### Entrada



```
a² = 7, c² = 32
```



### Resultado esperado



```
b² = 32 − 7 = 25, portanto b = 5.
```

## Método de cálculo



Some os quadrados dos catetos para a hipotenusa. Para um cateto, subtraia o quadrado do outro do quadrado da hipotenusa. Os comprimentos são positivos.



$$
c=\sqrt{a^2+b^2},\quad a=\sqrt{c^2-b^2},\quad b=\sqrt{c^2-a^2}
$$
