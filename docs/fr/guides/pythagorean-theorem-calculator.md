# Calculateur du théorème de Pythagore



Résolvez a² + b² = c² à partir des longueurs ou des carrés de deux côtés.





## Prise en main



1. Saisissez les longueurs ou les carrés de deux côtés différents.







## Exemple



### Entrée



```
a² = 7, c² = 32
```



### Résultat attendu



```
b² = 32 − 7 = 25, donc b = 5.
```

## Notes



Le traitement se fait dans le navigateur. Utilisez des unités cohérentes.







## Méthode de calcul



Additionnez les carrés des deux côtés pour l’hypoténuse. Pour un côté, soustrayez le carré de l’autre de celui de l’hypoténuse. Les longueurs sont positives.



$$
c=\sqrt{a^2+b^2},\quad a=\sqrt{c^2-b^2},\quad b=\sqrt{c^2-a^2}
$$
