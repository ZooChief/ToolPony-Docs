# 公因數計算器



列出多個整數的全部正公因數，並求最大公因數。





## 開始使用



1. 按示例填寫數值，或輸入你自己的測量值。
2. 計算後可複製結果或下載明細。







## 示例



### 輸入



```
12、18、30
```



### 預期結果



```
1、2、3、6
```

## 計算方法



多個整數的公因數是它們最大公因數的全部因數。歐幾里得算法無需枚舉各個整數的因數。



$$
d\mid a_1,\ldots,a_n\iff d\mid\gcd(a_1,\ldots,a_n)
$$
