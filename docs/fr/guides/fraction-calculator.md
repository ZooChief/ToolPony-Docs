# Guide pratique · Calculatrice de fractions



Utilisez l'arithmétique exacte pour ajouter, soustraire, multiplier, diviser ou simplifier les fractions et les nombres mixtes.





## Exemple



### Entrée



```
1 1/2 + 2/3
```



### Résultat attendu



```
13/6
```

## Méthode de calcul



Les décimaux sont lus comme fractions exactes. Arithmetic utilise BigInt et réduit par le plus grand diviseur commun. Le résultat décimal est approximatif.



$$
\frac{a}{b}+\frac{c}{d}=\frac{ad+bc}{bd},\qquad b,d\ne0
$$
