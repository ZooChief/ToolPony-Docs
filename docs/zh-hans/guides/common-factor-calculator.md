# 公因数计算器



列出多个整数的全部正公因数，并求最大公因数。





## 开始使用



1. 按示例填写数值，或输入你自己的测量值。
2. 计算后可复制结果或下载明细。







## 示例



### 输入



```
12、18、30
```



### 预期结果



```
1、2、3、6
```

## 计算方法



多个整数的公因数是它们最大公因数的全部因数。欧几里得算法无需枚举各个整数的因数。



$$
d\mid a_1,\ldots,a_n\iff d\mid\gcd(a_1,\ldots,a_n)
$$
