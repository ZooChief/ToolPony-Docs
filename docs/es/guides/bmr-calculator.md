# Calculadora de metabolismo basal y calorías



Estimar el gasto energético y energético diario en unidades métricas o estadounidenses con tres ecuaciones.





## Primeros pasos



1. Usa el ejemplo o introduce tus propios valores.
2. Calcula, copia el resultado o descarga los detalles disponibles.







## Ejemplo



### Entrada



```
Ecuación masculina, 30 años, 70 kg, 175 cm, Mifflin-St Jeor
```



### Resultado esperado



```
1,648,75 kcal/día en reposo
```







## Pruébalo



[Abrir herramienta completa](<https://toolpony.com/es/tools/bmr-calculator/>)







## Notas de uso



El cálculo se ejecuta en tu navegador. Usa unidades coherentes.







## Método de cálculo



La energía de reposo se calcula con Mifflin-St Jeor, Harris-Benedict revisado o Katch-McArdle. El gasto diario multiplica la estimación por su factor de actividad.







## Modo de cálculo



**Sistema métrico**

- Edad
- Grupo de Ecuador · Hombre / Mujer
- Peso · kg
- Altura · cm
- Ecuación · Mifflin-St Jeor / Harris–Benedicto revisado / Katch-McArdle
- Grasa corporal para Katch-McArdle · %
- Factor de actividad
- Unidad de energía · kcal/day / kJ/day





**Unidades estadounidenses**

- Edad
- Grupo de Ecuador · Hombre / Mujer
- Peso · lb
- Altura en los pies · ft
- pulgadas adicionales · in
- Ecuación · Mifflin-St Jeor / Harris–Benedicto revisado / Katch-McArdle
- Grasa corporal para Katch-McArdle · %
- Factor de actividad
- Unidad de energía · kcal/day / kJ/day
