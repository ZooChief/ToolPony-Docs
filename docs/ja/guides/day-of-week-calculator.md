# 曜日計算機



曜日、年内の日番号、ISO 週番号、年間の出現回数を調べます。





## 使い方



1. 例を使うか、任意の値を入力します。
2. 計算後、結果をコピーするか詳細をダウンロードできます。







## 例



### 入力



```
2000-01-01
```



### 期待される結果



```
土曜日
```







## 試してみる



[ツール全体を開く](<https://toolpony.com/ja/tools/day-of-week-calculator/>)







## 注意点



処理はブラウザ内で実行されます。単位をそろえて入力してください。







## 計算方法



グレゴリオ暦を使います。ISO 週は月曜始まりで、1 月 4 日を含む週が第 1 週です。1 月初旬が前年の最終週になることがあります。
