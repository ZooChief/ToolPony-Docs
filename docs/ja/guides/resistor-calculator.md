# 抵抗値・カラーコード計算機



3〜6 本の色帯、直列・並列の合成抵抗、丸線の抵抗値を計算します。





## 使い方



1. 帯の本数または接続方式を選びます。許容差の帯は他の帯から離れていることがあります。
2. 丸線の場合は直径と長さを入力します。材質のプリセットで導電率を入力し、必要に応じて変更できます。







## 例



### 入力



```
4 本帯：緑、赤、赤、金
```



### 期待される結果



```
5,200 Ω ±5%
```







## 試してみる



[ツール全体を開く](<https://toolpony.com/ja/tools/resistor-calculator/>)







## 注意点



処理はブラウザ内で実行されます。単位をそろえて入力してください。







## 計算方法



有効数字、乗数、許容差、必要なら温度係数の順に読みます。3 本帯は許容差 20% です。一様な丸線は R = L/(σA) です。特殊な表示は部品仕様書を確認してください。



$$
R_{\rm series}=\sum_i R_i,\quad R_{\rm parallel}=\left(\sum_i 1/R_i\right)^{-1},\quad R_{\rm wire}=\frac{L}{\sigma\pi(d/2)^2}
$$



$$
R_{\rm band}=D\,10^m,\qquad R_{\min,\max}=R_{\rm band}(1\mp t/100)
$$
