# 密度計算器



任填兩項求質量、體積或密度。





## 開始使用



1. 按示例填寫數值，或輸入你自己的測量值。
2. 計算後可複製結果或下載明細。







## 示例



### 輸入



```
8 kg，0.001 m³
```



### 預期結果



```
8,000 kg/m³
```

## 使用提示



計算在瀏覽器內完成。無單位標記的字段請使用一致單位。







## 計算方法



密度 = 質量 ÷ 體積，採用 kg、m³ 和 kg/m³。



$$
\rho=\frac{m}{V}
$$
