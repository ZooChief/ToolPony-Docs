# 带宽与下载时间计算器



根据文件大小、带宽与有效传输比例估算下载时间。





## 开始使用



1. 按示例填写数值，或输入你自己的测量值。
2. 计算后可复制结果或下载明细。







## 示例



### 输入



```
1 GB，100 Mbps，有效率 100%
```



### 预期结果



```
80 秒
```

## 使用提示



计算在浏览器内完成。无单位标记的字段请使用一致单位。







## 计算方法



秒数 = 文件字节数 × 8 ÷ 有效每秒比特数。带宽单位用十进制前缀，文件大小支持十进制和二进制。
