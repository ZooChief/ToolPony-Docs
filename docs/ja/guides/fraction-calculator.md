# 分数計算機



正確な算術を使用して、分数と混合数を追加、引き算、乗算、分割または単純化します。





## 使い方



1. 例を使うか、任意の値を入力します。
2. 計算後、結果をコピーするか詳細をダウンロードできます。







## 例



### 入力



```
1 1/2 + 2/3
```



### 期待される結果



```
13/6
```







## 試してみる



[ツール全体を開く](<https://toolpony.com/ja/tools/fraction-calculator/>)







## 注意点



処理はブラウザ内で実行されます。単位をそろえて入力してください。







## 計算方法



十数文字は正確な分数として読み取らされます。 算術はBigIntを使用し、最大の共通分化器によって低減する。 十数度の結果は概算です。



$$
\frac{a}{b}+\frac{c}{d}=\frac{ad+bc}{bd},\qquad b,d\ne0
$$







## 計算モード



**等差数列**

- 最初の数字
- 演算 · 追加 / 控除 / 多量に / 分割
- 第二番





**簡素化または変換**

- 番号





**小数点までの分数**

- フラクションまたはミックスドナンバー
- 十年の場所
