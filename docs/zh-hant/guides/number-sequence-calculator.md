# 數列計算器



求等差、等比和斐波那契數列的指定項、部分和，並下載各項。





## 開始使用



1. 按示例填寫數值，或輸入你自己的測量值。
2. 計算後可複製結果或下載明細。







## 示例



### 輸入



```
等差數列，首項 7，公差 −3，第 8 項
```



### 預期結果



```
第 8 項爲 −14，前 8 項和爲 −28
```

## 使用提示



計算在瀏覽器內完成。無單位標記的字段請使用一致單位。







## 計算方法



等差和等比數列從 1 開始編號。斐波那契數列從 F₀ = 0 開始，使用精確整數。



$$
a_n=a_1+(n-1)d,\quad g_n=g_1r^{n-1},\quad F_n=F_{n-1}+F_{n-2}
$$







## 計算模式



**等差數列**

- 首項
- 公差
- 序號





**等比數列**

- 首項
- 公比
- 序號





**斐波那契數列**

- 序號
