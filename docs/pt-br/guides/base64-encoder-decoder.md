# Codificar e decodificar Base64



Codifique o texto UTF-8 como base64 padrão ou seguro para URL e valide o texto decodificado.





## Primeiros passos



1. Use o exemplo ou insira seus próprios valores.
2. Calcule, copie o resultado ou baixe os detalhes disponíveis.







## Exemplo



### Entrada



```
Codificar hello
```



### Resultado esperado



```
aGVsbG8=
```







## Experimente



[Abrir ferramenta completa](<https://toolpony.com/pt-br/tools/base64-encoder-decoder/>)







## Notas de uso



O cálculo é feito no seu navegador. Use unidades consistentes.







## Método de cálculo



O texto é convertido como UTF-8. O modo seguro de URL usa "-" e "\_" e omite o preenchimento na saída. Até 500.000 caracteres de entrada.

[Documentação](https://docs.toolpony.com/pt-br/guides/base64-encoder-decoder/)
