# Calculadora de largura de banda



Estimar o tempo de transferência do tamanho do arquivo, velocidade da ligação e eficiência do protocolo.





## Primeiros passos



1. Use o exemplo ou insira seus próprios valores.
2. Calcule, copie o resultado ou baixe os detalhes disponíveis.







## Exemplo



### Entrada



```
1 GB a 100 Mbps, eficiência 100%
```



### Resultado esperado



```
80 segundos
```







## Experimente



[Abrir ferramenta completa](<https://toolpony.com/pt-br/tools/bandwidth-calculator/>)







## Notas de uso



O cálculo é feito no seu navegador. Use unidades consistentes.







## Método de cálculo



Tempo em segundos = bytes de arquivo × 8 □ bits efetivos por segundo. Prefixos de rede são decimais. Tamanho do arquivo suporta prefixos decimais e binários.
