# Provisionsrechner



Finden Sie Verkäufe, Raten oder Provisionen und berechnen Sie dann eine Basiszahlung plus progressive Stufen.





## Erste Schritte



1. Verwenden Sie das Beispiel oder geben Sie eigene Werte ein.
2. Berechnen Sie das Ergebnis und kopieren oder laden Sie die Details herunter.







## Beispiel



### Eingabe



```
16.500 bei 8,25%
```



### Erwartetes Ergebnis



```
1.361.25 Provisionen
```

## Hinweise



Die Verarbeitung erfolgt im Browser. Verwenden Sie einheitliche Einheiten.







## Berechnungsmethode



Ein einheitlicher Satz multipliziert den Verkaufsbetrag. In einem Stufenplan ist jeder Schwellenwert die Obergrenze für diese Klammer. Prozentsätze gelten nur für Einnahmen in der Klammer. Feste Stufen zahlen einmal, wenn die Klammer eingegeben wird.



$$
C=C_0+\sum_i s_i r_i\quad\text{(percentage tiers)}
$$







## Berechnungsmodus



**Finde Kommission**

- Verkaufsbetrag
- Kommissionssatz · %





**Find-Rate**

- Verkaufsbetrag
- Kommissionsbetrag





**Verkaufsbetrag ermitteln**

- Kommissionssatz · %
- Kommissionsbetrag





**Basis und Ebenen**

- Verkaufsbetrag
- Basisprovision
- Basistyp · Festbetrag / Prozentsatz der Verkäufe
- Tierobergrenze, Rate (% oder fester Betrag). \* für kein Limit verwenden.
