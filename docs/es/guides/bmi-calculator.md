# Calculadora de IMC para adultos



Calcular el IMC adulto en unidades métricas o estadounidenses, comparar rangos de referencia, y ver el índice BMI Prime y ponderal.





## Ejemplo



### Entrada



```
70 kg, 175 cm
```



### Resultado esperado



```
IMC ♥22,86 kg/m2
```







## Pruébalo

[Abrir herramienta completa · Calculadora de IMC para adultos](<https://toolpony.com/es/tools/bmi-calculator/>)





## Método de cálculo



IMC = peso (kg) ÷ altura (m)². Los rangos de referencia corresponden a las categorías de los CDC para adultos a partir de los 20 años. IMC Prime = IMC ÷ 25. Índice ponderal = peso (kg) ÷ altura (m)³.



$$
\operatorname{BMI}=\frac{m_{\mathrm{kg}}}{h_{\mathrm{m}}^2}
$$







## Modo de cálculo



**Sistema métrico**

- Edad
- Peso · kg
- Altura · cm





**Unidades estadounidenses**

- Edad
- Peso · lb
- Altura en los pies · ft
- pulgadas adicionales · in







**Fuentes del método** [CDC · Adult BMI Categories](<https://www.cdc.gov/bmi/adult-calculator/bmi-categories.html>)
