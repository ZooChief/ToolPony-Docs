# Calculadora de números grandes



Calcular con enteros muy grandes y coeficientes decimales, con redondeo seleccionable para división y raíces.





## Primeros pasos



1. Usa el ejemplo o introduce tus propios valores.
2. Calcula, copia el resultado o descarga los detalles disponibles.







## Ejemplo



### Entrada



```
9,007,199,254,740,993 + 7
```



### Resultado esperado



```
9007199254741000
```

## Notas de uso



El cálculo se ejecuta en tu navegador. Usa unidades coherentes.







## Método de cálculo



La adición, la resta, la multiplicación, los poderes enteros y las operaciones enteros utilizan los coeficientes BigInt. La división ronda a los lugares decimales seleccionados. Las raíces cuadradas pueden truncar o redondear a más cercano. Los exponentes de entero positivo y negativo se soportan dentro del límite de resultados.



$$
x=m\cdot 10^e,\quad x_1x_2=(m_1m_2)\cdot 10^{e_1+e_2}
$$
