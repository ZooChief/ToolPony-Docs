# Calculadora da relação dívida-renda



Compare seus pagamentos de dívida mensais recorrentes com o rendimento mensal bruto.





## Primeiros passos



1. Use o exemplo ou insira seus próprios valores.
2. Calcule, copie o resultado ou baixe os detalhes disponíveis.







## Exemplo



### Entrada



```
Rendimento 5.000, pagamentos da dívida 1.500
```



### Resultado esperado



```
30%
```







## Experimente



[Abrir ferramenta completa](<https://toolpony.com/pt-br/tools/debt-to-income-calculator/>)







## Notas de uso



O cálculo é feito no seu navegador. Use unidades consistentes.







## Método de cálculo



Razão dívida/rendimento = pagamentos mensais da dívida □ Rendimento mensal bruto. Use a mesma moeda e um período mensal para todos os montantes.
