# 随机数生成器



在闭区间内生成随机整数，支持去重和排序。





## 开始使用



1. 按示例填写数值，或输入你自己的测量值。
2. 计算后可复制结果或下载明细。







## 示例



### 输入



```
最小 1，最大 10，生成 5 个
```



### 预期结果



```
5 个 1 至 10 的随机整数
```







## 试一试

## 使用提示



计算在浏览器内完成。无单位标记的字段请使用一致单位。







## 计算方法



随机值来自 Web Crypto，采用拒绝采样避免取模偏差。最多生成 1,000 个数，区间范围为 −10 亿至 10 亿。
