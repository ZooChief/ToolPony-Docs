# Unix 時間戳轉換



將秒或毫秒時間戳換算爲 UTC，或將帶時區偏移的 ISO 時間轉回 Unix 時間。





## 開始使用



1. 按示例填寫數值，或輸入你自己的測量值。
2. 計算後可複製結果或下載明細。







## 示例



### 輸入



```
0 秒
```



### 預期結果



```
1970-01-01T00:00:00.000Z
```

## 使用提示



計算在瀏覽器內完成。無單位標記的字段請使用一致單位。







## 計算方法



Unix 時間以 1970-01-01T00:00:00Z 爲起點，支持 1900–9999 年，精確到毫秒。







## 計算模式



**時間戳轉日期**

- Unix 時間戳
- 單位 · 秒 / 毫秒





**日期轉時間戳**

- 帶時區偏移的 ISO 8601
