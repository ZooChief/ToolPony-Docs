# 画像圧縮



端末から画像を 1〜12 枚選び、JPEG または WebP を指定します。 画質またはファイルごとの目標サイズを設定します。必要なら長辺の上限を指定します。 各画像の前後を確認し、個別または ZIP で保存します。





## 使い方



1. 端末から画像を 1〜12 枚選び、JPEG または WebP を指定します。
2. 画質またはファイルごとの目標サイズを設定します。必要なら長辺の上限を指定します。
3. 各画像の前後を確認し、個別または ZIP で保存します。







## 例



### 入力



```
写真 2 枚、WebP、各 100 KB、長辺 1200 px、縮小を許可
```



### 期待される結果



```
条件を満たした各画像を 100,000 バイト以下の WebP に変換し、ZIP にまとめます。
```

## 制限



1 枚 20 MB・2400 万画素まで。バッチ入出力は各 64 MiB まで。長辺の上限で画像を拡大することはありません。JPEG と WebP は非可逆圧縮です。アニメーションは静止画になり、元のメタデータは削除されます。
