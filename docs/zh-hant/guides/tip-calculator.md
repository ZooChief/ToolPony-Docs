# 小費計算器



分攤賬單與小費，可按稅前或含稅金額計算小費。





## 開始使用



1. 按示例填寫數值，或輸入你自己的測量值。
2. 計算後可複製結果或下載明細。







## 示例



### 輸入



```
賬單 80，小費 20%，4 人
```



### 預期結果



```
合計 96，每人 24
```

## 使用提示



計算在瀏覽器內完成。無單位標記的字段請使用一致單位。







## 計算方法



小費 = 所選金額 × 小費比例。每人金額爲賬單、稅費與小費之和除以人數。
