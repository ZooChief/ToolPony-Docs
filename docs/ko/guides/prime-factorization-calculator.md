# 소인수분해 계산기



양수, 지수 양식 및 양수 정수의 구분자 수를 찾습니다.





## 시작하기



1. 예제 값을 사용하거나 원하는 값을 입력하세요.
2. 계산한 결과를 복사하거나 세부 정보를 내려받을 수 있습니다.







## 예시



### 입력



```
360
```



### 예상 결과



```
2³ × 3² × 5, 약수 24개
```







## 직접 사용해 보기



[전체 도구 열기](<https://toolpony.com/ko/tools/prime-factorization-calculator/>)







## 참고 사항



브라우저에서 처리합니다. 단위를 일관되게 사용하세요.







## 계산 방법



시험 분할은 나머지 정수의 제곱근까지 요소를 제거합니다. 입력 범위: 2 ~ 1 조.
