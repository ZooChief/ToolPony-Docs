# 油耗与油费计算器



换算油耗单位、估算行程油费，或按加油量计算实测油耗。





## 开始使用



1. 按示例填写数值，或输入你自己的测量值。
2. 计算后可复制结果或下载明细。







## 示例



### 输入



```
行程 300 km，油耗 7 L/100 km，每升 1.5
```



### 预期结果



```
用油 21 升，油费 31.50
```







## 试一试



[打开完整工具](<https://toolpony.com/zh-hans/tools/fuel-cost-calculator/>)







## 使用提示



计算在浏览器内完成。无单位标记的字段请使用一致单位。







## 计算方法



用油量 = 距离 × 百公里油耗 ÷ 100。美制和英制每加仑英里使用不同的加仑体积，油价由用户输入。







## 计算模式



**行程油费**

- 距离 · km
- 油耗
- 油耗单位 · L/100 km / km/L / mpg (US) / mpg（英制）
- 每升价格





**换算油耗**

- 油耗
- 输入单位 · L/100 km / km/L / mpg (US) / mpg（英制）





**实测油耗**

- 距离 · km
- 用油量 · L
