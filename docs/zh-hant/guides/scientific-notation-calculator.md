# 科學記數法計算器



在科學、工程、E 記數法與十進制之間轉換，或對這些數值進行運算。





## 開始使用



1. 按示例填寫數值，或輸入你自己的測量值。
2. 計算後可複製結果或下載明細。







## 示例



### 輸入



```
1568938
```



### 預期結果



```
1.568938 × 10^6
```

## 計算方法



科學記數法保留一個前導數字。工程記數法的指數是 3 的倍數。加減乘先以十進制係數精確運算，再按指定精度舍入。



$$
x=a\times10^n,\qquad 1\le |a|<10\quad(x\ne0)
$$



1568938、1.568938e6 和 1.568938 × 10^6 表示同一個數。工程記數法的 10 的指數是 3 的倍數。



運算模式的加、減、乘使用精確十進制係數。非整數冪和平方根採用浮點近似。
