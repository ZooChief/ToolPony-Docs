# 요일 계산기



요일, 연중 일수, ISO 주 번호와 해당 요일 횟수를 확인합니다.





## 시작하기



1. 예제 값을 사용하거나 원하는 값을 입력하세요.
2. 계산한 결과를 복사하거나 세부 정보를 내려받을 수 있습니다.







## 예시



### 입력



```
2000-01-01
```



### 예상 결과



```
토요일
```







## 직접 사용해 보기



[전체 도구 열기](<https://toolpony.com/ko/tools/day-of-week-calculator/>)







## 참고 사항



브라우저에서 처리합니다. 단위를 일관되게 사용하세요.







## 계산 방법



그레고리력을 사용합니다. ISO 주는 월요일부터 시작하고 1월 4일이 있는 주가 첫째 주입니다. 1월 초가 전년도 마지막 주에 속할 수 있습니다.
