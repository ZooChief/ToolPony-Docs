# 住宅ローン繰上返済計算機



住宅ローンの残りの返済、繰上返済、一括精算、2種類の隔週返済を比較します。





## 使い方



1. 以前に追加返済をした場合は明細の残元金と元利返済額を使います。当初ローンと残期間から残高を求めることもできます。
2. 返済方法を選びます。追加額は毎月、年1回、または1回分を指定します。開始月はそれぞれ1、12、1月目で、詳細設定で変更できます。
3. 選択した計画と通常返済を比較し、残りの明細または比較CSVを保存します。
4. 元金と固定利息の試算です。実際の完済額には日割利息や手数料、違約金が含まれる場合があります。金融機関に確認してください。







## 例



### 入力



```
当初400,000、30年、年利6%。残り25年、毎月500を追加。
```



### 期待される結果



```
207か月で完済、利息を122,306.21軽減
```

## 計算方法



元のローンから求める場合は、過去の支払いが当初予定どおりと仮定します。月利息は残高に年利を掛けて12で割ります。月次集約の隔週方式は6か月ごとに月返済額の半額を追加します。年26回方式は月返済額の半額を払い、年利を26で割ります。



$$
B=M\frac{1-(1+r)^{-n}}r\quad(r>0),\qquad B=Mn\quad(r=0)
$$



$$
I_k=rB_{k-1},\qquad B_k=\max(0,B_{k-1}-M+I_k-E_k)
$$



$$
E_{6j}=M/2\quad\text{(grouped)},\qquad M_{26}=M/2,\quad r_{26}=r_{\rm annual}/26
$$
