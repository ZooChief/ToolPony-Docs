# Lanzador de dados



Enrolle uno o más dados con los lados personalizados, compare los totales y vea cada rollo.





## Primeros pasos



1. Usa el ejemplo o introduce tus propios valores.
2. Calcula, copia el resultado o descarga los detalles disponibles.







## Ejemplo



### Entrada



```
3 dados, 6 lados
```



### Resultado esperado



```
Tres caras y su suma
```







## Pruébalo



[Abrir herramienta completa](<https://toolpony.com/es/tools/dice-roller/>)







## Notas de uso



El cálculo se ejecuta en tu navegador. Usa unidades coherentes.







## Método de cálculo



Cada die utiliza un uniforme independiente Web Crypto. Roll hasta 100 dados, con 2 a 1.000 lados cada uno.

[Documentación](https://docs.toolpony.com/es/guides/dice-roller/)
