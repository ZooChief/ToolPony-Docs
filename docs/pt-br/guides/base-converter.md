# Conversor e calculadora de bases



Converta inteiros assinados entre as bases 2–36 e execute operações aritméticas exatas, remanescentes ou bitwise.





## Exemplo



### Entrada



```
FF, base 16 à base 10
```



### Resultado esperado



```
255
```







## Experimente

[Abrir ferramenta completa · Conversor e calculadora de bases](<https://toolpony.com/pt-br/tools/base-converter/>)





## Método de cálculo



O BigInt preserva a precisão inteira. A divisão trunca para zero. As operações Bitwise usam a semântica do BigInt assinada. Cada operando é limitado a 256 dígitos.







## Modo de cálculo



**Converter base**

- Inteiro
- Base de entrada
- Base de saída
- Digitos de saída mínimos





**Aritmética integral**

- Primeiro inteiro
- Segundo inteiro
- Base de entrada
- Base de saída
- Digitos de saída mínimos
- Operação · Adicionar / Subtrair / Multiplicar / Dividir / Resto / AND / OR / XOR
