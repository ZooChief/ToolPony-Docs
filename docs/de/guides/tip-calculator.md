# Trinkgeldrechner



Teilen Sie eine Rechnung und ein Trinkgeld unter den Menschen, wobei das Trinkgeld auf dem Betrag vor oder nach der Steuer basiert.





## Erste Schritte



1. Verwenden Sie das Beispiel oder geben Sie eigene Werte ein.
2. Berechnen Sie das Ergebnis und kopieren oder laden Sie die Details herunter.







## Beispiel



### Eingabe



```
80 Bill, 20% Trinkgeld, 4 Personen
```



### Erwartetes Ergebnis



```
Gesamt 96, pro Person 24
```







## Ausprobieren



[Vollständiges Werkzeug öffnen](<https://toolpony.com/de/tools/tip-calculator/>)







## Hinweise



Die Verarbeitung erfolgt im Browser. Verwenden Sie einheitliche Einheiten.







## Berechnungsmethode



Tipp = ausgewählter Rechnungsbetrag × Trinkgeldprozentsatz. Pro Person entspricht Gesamtrechnung, Steuern und Trinkgeld geteilt durch die Anzahl der Personen.
