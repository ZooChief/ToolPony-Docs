# 質因數分解計算器



求正整數的質因數、指數形式和約數個數。





## 示例



### 輸入



```
360
```



### 預期結果



```
2³ × 3² × 5，共 24 個約數
```







## 試一試

[打開完整工具 · 質因數分解計算器](<https://toolpony.com/zh-hant/tools/prime-factorization-calculator/>)





## 計算方法



用試除法取出質因數，試除上界爲剩餘整數的平方根。輸入範圍爲 2 至 1 萬億。
