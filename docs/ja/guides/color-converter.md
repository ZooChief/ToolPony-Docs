# 色変換



HEX、RGB、HSL を相互変換し、透明度を保ったまま色を確認できます。





## 使い方



1. 例を使うか、任意の値を入力します。
2. 計算後、結果をコピーするか詳細をダウンロードできます。







## 例



### 入力



```
rgb(102, 51, 153)
```



### 期待される結果



```
#663399、hsl(270 50% 40%)
```







## 試してみる



[ツール全体を開く](<https://toolpony.com/ja/tools/color-converter/>)







## 注意点



処理はブラウザ内で実行されます。単位をそろえて入力してください。







## 計算方法



HEX は各チャンネルを 8 ビットで表します。RGB は数値または割合、HSL は色相を度、彩度と明度を割合で指定します。HEX 出力は各チャンネルを最も近いバイト値に丸めます。
