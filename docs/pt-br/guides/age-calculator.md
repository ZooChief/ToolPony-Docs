# Calculadora de idade



Calcule idade, tempo decorrido e o próximo aniversário.





## Primeiros passos



1. Informe o nascimento e a data de referência. Em branco, usa a data de hoje do dispositivo.







## Exemplo



### Entrada



```
Nascimento 2000-01-01, referência 2025-02-03
```



### Resultado esperado



```
25 anos · 1 mês · 2 dias
```







## Experimente



[Abrir ferramenta completa](<https://toolpony.com/pt-br/tools/age-calculator/>)







## Notas de uso



O cálculo é feito no seu navegador. Use unidades consistentes.







## Método de cálculo



Os meses seguem o mesmo dia ou o último dia do mês. Para nascimento em 29 de fevereiro, escolha 28 de fevereiro ou 1º de março em anos comuns. O tempo usa dias de 24 horas.
