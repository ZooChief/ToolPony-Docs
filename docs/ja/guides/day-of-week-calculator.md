# 曜日計算機の使い方



曜日、年内の日番号、ISO 週番号、年間の出現回数を調べます。





## 例



### 入力



```
2000-01-01
```



### 期待される結果



```
土曜日
```







## 試してみる

[ツール全体を開く · 曜日計算機](<https://toolpony.com/ja/tools/day-of-week-calculator/>)





## 計算方法



グレゴリオ暦を使います。ISO 週は月曜始まりで、1 月 4 日を含む週が第 1 週です。1 月初旬が前年の最終週になることがあります。
