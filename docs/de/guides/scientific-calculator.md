# Anleitung: Wissenschaftlicher Taschenrechner



Ausdrücke mit Potenzen, Fakultäten, trigonometrischen Funktionen, Wurzeln und Logarithmen berechnen.





## Beispiel



### Eingabe



```
sqrt(81) + 2^3 × sin(30), Grad
```



### Erwartetes Ergebnis



```
13
```

## Diagonale berechnen



1. Für eine 12 × 5 cm große Platte ergibt √(12² + 5²) eine Diagonale von 13 cm. Markieren Sie einen Teilausdruck und drücken Sie x², um nur diesen zu quadrieren.
2. Direkt danach liefert asin(5/Ans) im Modus DEG den Winkel gegenüber der 5-cm-Seite, etwa 22,62°.

## Berechnungsmethode



Zuerst kommen Klammern, dann nachgestellte Operatoren, Potenzen, Punkt- und Strichrechnung. Potenzen binden von rechts. Prozent teilt durch 100. Die Rechnung verwendet Gleitkommazahlen.
