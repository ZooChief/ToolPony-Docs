# 단리 계산기



간단한이자를 계산하거나 다른 입력에서 원리, 이자율 또는 용어를 해결합니다.





## 시작하기



1. 예제 값을 사용하거나 원하는 값을 입력하세요.
2. 계산한 결과를 복사하거나 세부 정보를 내려받을 수 있습니다.







## 예시



### 입력



```
원금 1,000, 연이율 5%, 기간 2년
```



### 예상 결과



```
100 이자; 1,100 총
```







## 직접 사용해 보기



[전체 도구 열기](<https://toolpony.com/ko/tools/simple-interest-calculator/>)







## 참고 사항



브라우저에서 처리합니다. 단위를 일관되게 사용하세요.







## 계산 방법



이자는 주 × 주기율 × 기간 수와 같습니다. 곱하기 전에 해당 용어를 요율과 동일한 단위로 변환합니다. 최종 잔액은 원리에 관심을 더합니다.



$$
I=Prt,\qquad A=P+I
$$



용어 단위를 인용된 비율 기간에 일치시킵니다. 예를 들어, 24 개월 동안 적용되는 연간 5 %는 2 개의 연간 기간을 사용합니다.



끝 균형이 알려질 때 역 모드를 사용합니다. 제로 비율 또는 제로 용어는 역 문제를 고유하지 않습니다.

**관심과 최종 균형**

- 원금
- 이자율 · %
- 요금 기간 · 년 당 / 월 당
- 년
- 개월





**원금 찾기**

- 요금 기간 · 년 당 / 월 당

**이자율 찾기**

- 요금 기간 · 년 당 / 월 당





**용어 찾기**
