# 감가상각 계산기 사용 가이드



연간 직선, 감소 균형 또는 금액의 숫자 일정을 구축하십시오.





## 예시



### 입력



```
17,500 비용, 2,500 인양, 6 년, 직선
```



### 예상 결과



```
연간 2,500
```







## 직접 사용해 보기

[전체 도구 열기 · 감가상각 계산기](<https://toolpony.com/ko/tools/depreciation-calculator/>)





## 계산 방법



직선은 유용한 생활로 감가상각 비용을 나눕니다. 균형 감소는 책 가치를 여는 데 요인/생명을 적용하고 인양을 중단합니다. Sum-of-years의 숫자는 남은 연도의 가중치에 의해 할당됩니다. 금액은 연간 반올림됩니다.



$$
D_{\mathrm{SL}}=\frac{C-S}{n},\quad D_{k,\mathrm{SYD}}=(C-S)\frac{n-k+1}{n(n+1)/2}
$$







## 계산 모드





### 직선



- 자산 비용
- 인양 가치
- 유용한 삶
- 반올림 · 소수점 두 자리 / 전체 금액







### 균형 감소



- 자산 비용
- 인양 가치
- 유용한 삶
- 감가상각 요인
- 반올림 · 소수점 두 자리 / 전체 금액







### Sum-of-years' 자릿수



- 자산 비용
- 인양 가치
- 유용한 삶
- 반올림 · 소수점 두 자리 / 전체 금액
