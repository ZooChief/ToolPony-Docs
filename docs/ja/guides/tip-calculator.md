# チップ計算機



税金の前後金額をもとに、請求書とチップを人間で分割する。





## 使い方



1. 例を使うか、任意の値を入力します。
2. 計算後、結果をコピーするか詳細をダウンロードできます。







## 例



### 入力



```
80件、20%のチップ、4名
```



### 期待される結果



```
合計 96、1 人あたり 24
```







## 試してみる



[ツール全体を開く](<https://toolpony.com/ja/tools/tip-calculator/>)







## 注意点



処理はブラウザ内で実行されます。単位をそろえて入力してください。







## 計算方法



ヒント = 選択された請求額 × チップパーセンテージ。 一人当たりの合計は、請求額、税金、およびチップを人数で割る。
