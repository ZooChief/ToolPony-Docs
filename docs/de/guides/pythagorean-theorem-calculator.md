# Satz-des-Pythagoras-Rechner



Löse a² + b² = c² aus zwei Seitenlängen oder deren Quadraten.





## Erste Schritte



1. Gib Längen oder Quadrate für zwei verschiedene Seiten ein.







## Beispiel



### Eingabe



```
a² = 7, c² = 32
```



### Erwartetes Ergebnis



```
b² = 32 − 7 = 25, also b = 5.
```

## Berechnungsmethode



Addiere für die Hypotenuse die Kathetenquadrate. Ziehe für eine Kathete das andere Kathetenquadrat vom Hypotenusenquadrat ab. Längen sind positiv.



$$
c=\sqrt{a^2+b^2},\quad a=\sqrt{c^2-b^2},\quad b=\sqrt{c^2-a^2}
$$
