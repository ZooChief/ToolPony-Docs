# 圖片尺寸調整



設置輸出寬度或高度，開啓保持寬高比以避免拉伸。調整後的圖片以 PNG 格式導出。





## 開始使用



1. 選擇圖片。
2. 輸入寬度或高度，開啓保持寬高比以避免拉伸。
3. 調整尺寸並下載 PNG 結果。







## 示例



### 輸入



```
1600 × 1200 → 寬度設爲 800，保持寬高比
```



### 預期結果



```
800 × 600 PNG
```

## 使用提示



改變像素尺寸與無損壓縮不同。放大圖片無法找回原圖中不存在的細節。







## 適用範圍



輸入最大 20 MB，像素總數最多 2400 萬，輸出每邊最多 8,192 像素。放大圖片不能恢復原本缺失的細節。
