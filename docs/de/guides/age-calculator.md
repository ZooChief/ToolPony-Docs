# Altersrechner



Berechnen Sie Alter, vergangene Zeit und den nächsten Geburtstag.





## Erste Schritte



1. Geben Sie Geburtstag und Stichtag ein. Ein leeres Feld verwendet das heutige Gerätedatum.







## Beispiel



### Eingabe



```
Geburt 2000-01-01, Stichtag 2025-02-03
```



### Erwartetes Ergebnis



```
25 Jahre · 1 Monat · 2 Tage
```







## Ausprobieren



[Vollständiges Werkzeug öffnen](<https://toolpony.com/de/tools/age-calculator/>)







## Hinweise



Die Verarbeitung erfolgt im Browser. Verwenden Sie einheitliche Einheiten.







## Berechnungsmethode



Monate enden am gleichen Tag oder am Monatsende. Für den 29. Februar wählen Sie in Gemeinjahren den 28. Februar oder den 1. März. Zeitangaben verwenden Tage mit 24 Stunden.
