# Calculadora de frações



Use aritmética exata para adicionar, subtrair, multiplicar, dividir ou simplificar frações e números mistos.





## Primeiros passos



1. Use o exemplo ou insira seus próprios valores.
2. Calcule, copie o resultado ou baixe os detalhes disponíveis.







## Exemplo



### Entrada



```
1 1/2 + 2/3
```



### Resultado esperado



```
13/6
```

## Notas de uso



O cálculo é feito no seu navegador. Use unidades consistentes.







## Método de cálculo



As decimais são lidas como frações exatas. Aritmética usa BigInt e reduz pelo maior divisor comum. O resultado decimal é aproximado.



$$
\frac{a}{b}+\frac{c}{d}=\frac{ad+bc}{bd},\qquad b,d\ne0
$$
