# 体积计算器



根据尺寸计算水箱容量、管壁材料体积或实心几何体的体积，以升或立方单位显示结果。





## 示例



### 输入



```
球半径 2 米
```



### 预期结果



```
约 33.5103 立方米
```





<a id="case-study"></a>



## 按水位线估算圆柱水箱能装多少水



1. 量水箱内径和水位线以下的有效深度。以内径 1 米、水深 1.2 米为例，点「运行示例」会选择圆柱模式，填入半径 0.5 米，输出单位设为升。
2. 容量为 π × 0.5² × 1.2 立方米，约 942.48 升。直径如果直接填进半径栏，平方项会让结果放大到四倍。
3. 把水位线下移 0.2 米，将高度改为 1 米再计算，容量约为 785.40 升。与第一次相比，少装的约 157.08 升就是两条水位线之间的容积。

## 计算方法



棱柱体积等于底面积乘垂直高度，圆锥和棱锥再除以三。空心管扣除内圆柱。球冠可填写任意两个尺寸。



$$
V_{\mathrm{cone}}=\tfrac13\pi r^2h,\qquad V_{\mathrm{sphere}}=\tfrac43\pi r^3
$$
