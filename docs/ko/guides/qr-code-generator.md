# QR 코드 생성기 사용 가이드



스캔할 유형을 고르고 링크나 텍스트, 필요한 항목을 입력하세요. 입력하면 코드가 갱신됩니다. Wi-Fi나 연락처는 인코딩된 내용을 확인한 뒤 PNG 또는 SVG로 저장할 수 있습니다. 어두운 색을 선택하거나 여섯 자리 HEX 값을 입력하세요. 두 형식 모두 흰 여백을 유지합니다.





## 시작하기



1. 스캔할 유형을 고르고 링크나 텍스트, 필요한 항목을 입력하세요.
2. 입력하면 코드가 갱신됩니다. Wi-Fi나 연락처는 인코딩된 내용을 확인한 뒤 PNG 또는 SVG로 저장할 수 있습니다.
3. 어두운 색을 선택하거나 여섯 자리 HEX 값을 입력하세요. 두 형식 모두 흰 여백을 유지합니다.







## 예시



### 입력



```
https://example.com/ · M · 512 px
```



### 예상 결과



```
PNG · 512 × 512 px → https://example.com/
```

## 제한 사항



정적 QR은 입력값을 담습니다. UTF-8 최대 2,048바이트이며 정정 수준이 높으면 용량이 줄어듭니다. 흰 테두리는 네 모듈의 여백을 확보합니다. Wi-Fi QR에 입력한 암호가 포함됩니다.
