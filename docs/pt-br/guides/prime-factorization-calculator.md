# Fatoração em números primos



Encontre fatores primos, forma expoente e a contagem divisora de um inteiro positivo.





## Primeiros passos



1. Use o exemplo ou insira seus próprios valores.
2. Calcule, copie o resultado ou baixe os detalhes disponíveis.







## Exemplo



### Entrada



```
360
```



### Resultado esperado



```
2³ × 3² × 5, 24 divisores
```







## Experimente



[Abrir ferramenta completa](<https://toolpony.com/pt-br/tools/prime-factorization-calculator/>)







## Notas de uso



O cálculo é feito no seu navegador. Use unidades consistentes.







## Método de cálculo



A divisão de testes remove os fatores até a raiz quadrada do inteiro restante. Intervalo de entrada: 2 a 1 trilhão.
