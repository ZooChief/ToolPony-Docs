# 순열과 조합 계산기



반복 유무에 관계없이 정확한 주문 및 주문되지 않은 선택을 계산합니다.





## 예시



### 입력



```
n=10, r=3, 반복 없이
```



### 예상 결과



```
720 순열; 120 조합
```







## 직접 사용해 보기

[전체 도구 열기 · 순열과 조합 계산기](<https://toolpony.com/ko/tools/permutation-combination-calculator/>)





## 계산 방법



반복 없이, nPr = n!/ (n−r)! 그리고 nCr = nPr/r!. 반복으로, 순서된 선택은 nr이고 순서 없는 선택은 C (n+r-1,r)입니다.
