# Primfaktorzerlegung



Finden Sie Primfaktoren, Exponentenform und die Teilerzahl einer positiven Ganzzahl.





## Erste Schritte



1. Verwenden Sie das Beispiel oder geben Sie eigene Werte ein.
2. Berechnen Sie das Ergebnis und kopieren oder laden Sie die Details herunter.







## Beispiel



### Eingabe



```
360
```



### Erwartetes Ergebnis



```
2³ × 3² × 5, 24 Teiler
```

## Berechnungsmethode



Die Probedivision entfernt Faktoren bis zur Quadratwurzel der verbleibenden ganzen Zahl. Der Eingabebereich reicht von 2 bis 10¹².
