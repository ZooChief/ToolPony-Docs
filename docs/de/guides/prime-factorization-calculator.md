# Primfaktorzerlegung



Finden Sie Primfaktoren, Exponentenform und die Teilerzahl einer positiven Ganzzahl.





## Beispiel



### Eingabe



```
360
```



### Erwartetes Ergebnis



```
2³ × 3² × 5, 24 Teiler
```







## Ausprobieren

[Vollständiges Werkzeug öffnen · Primfaktorzerlegung](<https://toolpony.com/de/tools/prime-factorization-calculator/>)





## Berechnungsmethode



Die Probedivision entfernt Faktoren bis zur Quadratwurzel der verbleibenden ganzen Zahl. Der Eingabebereich reicht von 2 bis 10¹².
