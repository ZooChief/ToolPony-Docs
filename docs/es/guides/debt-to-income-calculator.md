# Guía de uso · Calculadora de relación deuda-ingresos



Compare sus pagos mensuales recurrentes de deuda con ingresos mensuales brutos.





## Ejemplo



### Entrada



```
Ingresos 5.000, pagos de deuda 1.500
```



### Resultado esperado



```
30%
```







## Pruébalo

[Abrir herramienta completa · Calculadora de relación deuda-ingresos](<https://toolpony.com/es/tools/debt-to-income-calculator/>)





## Método de cálculo



Tasa de deuda a ingresos = pagos mensuales de deuda ÷ ingreso mensual bruto. Use la misma moneda y un período mensual para todas las cantidades.





**Fuentes del método** [CFPB · Debt-to-Income Ratio](<https://www.consumerfinance.gov/ask-cfpb/what-is-a-debt-to-income-ratio-en-1791/>)
