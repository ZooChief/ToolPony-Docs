# Calculadora de círculos



Localizar raio, diâmetro, circunferência e área de qualquer medida conhecida. Calcular arcos, setores e acordes.





## Primeiros passos



1. Use o exemplo ou insira seus próprios valores.
2. Calcule, copie o resultado ou baixe os detalhes disponíveis.







## Exemplo



### Entrada



```
Raio 2; ângulo central 90°
```



### Resultado esperado



```
Circunferência *12.5664; arco *3.1416
```

## Notas de uso



O cálculo é feito no seu navegador. Use unidades consistentes.







## Método de cálculo



Circunferência = 2πr. Área = πr2. Comprimento do arco e escala da área do setor com o ângulo central dividido por 360°.



$$
A=\pi r^2,\qquad C=2\pi r
$$
