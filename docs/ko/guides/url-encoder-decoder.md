# URL 인코딩 및 디코딩



전체 URL, URI 구성 요소 및 양식 값을 인코딩하거나 디코딩합니다.





## 시작하기



1. 예제 값을 사용하거나 원하는 값을 입력하세요.
2. 계산한 결과를 복사하거나 세부 정보를 내려받을 수 있습니다.







## 예시



### 입력



```
구성 요소 인코딩: a+b & c
```



### 예상 결과



```
a%2Bb%20%26%20c
```







## 직접 사용해 보기



[전체 도구 열기](<https://toolpony.com/ko/tools/url-encoder-decoder/>)







## 참고 사항



브라우저에서 처리합니다. 단위를 일관되게 사용하세요.







## 계산 방법



구성 요소 인코딩은 예약된 구분 기호를 탈출합니다. 전체 URL 인코딩은 구분 기호를 보존합니다. 양식 인코딩 사용 및 공백에 대한.

[문서](https://docs.toolpony.com/ko/guides/url-encoder-decoder/)
