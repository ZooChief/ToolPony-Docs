# 分數計算器



精確計算分數和帶分數的加減乘除、約分及小數轉換。





## 開始使用



1. 按示例填寫數值，或輸入你自己的測量值。
2. 計算後可複製結果或下載明細。







## 示例



### 輸入



```
1 1/2 + 2/3
```



### 預期結果



```
13/6
```

## 使用提示



計算在瀏覽器內完成。無單位標記的字段請使用一致單位。







## 計算方法



小數按十進制精確轉換爲分數。運算使用大整數並按最大公因數約分。小數展示爲近似值。



$$
\frac{a}{b}+\frac{c}{d}=\frac{ad+bc}{bd},\qquad b,d\ne0
$$







## 計算模式



**分數運算**

- 第一個數
- 運算 · 加 / 減 / 乘 / 除
- 第二個數





**約分或轉換**

- 數值





**分數轉小數**

- 分數或帶分數
- 小數位數
