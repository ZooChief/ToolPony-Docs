# Generador de números aleatorios



Genera enteros enteros en un rango inclusivo, con una singularidad opcional y clasificación.





## Primeros pasos



1. Usa el ejemplo o introduce tus propios valores.
2. Calcula, copia el resultado o descarga los detalles disponibles.







## Ejemplo



### Entrada



```
Mínimo 1, máximo 10, cantidad 5
```



### Resultado esperado



```
Cinco enteros aleatorios del 1 al 10
```







## Pruébalo



[Abrir herramienta completa](<https://toolpony.com/es/tools/random-number-generator/>)







## Notas de uso



El cálculo se ejecuta en tu navegador. Usa unidades coherentes.







## Método de cálculo



Los números aleatorios proceden de Web Crypto. El muestreo por rechazo evita el sesgo de módulo. Genera hasta 1.000 enteros entre −1.000.000.000 y 1.000.000.000.
