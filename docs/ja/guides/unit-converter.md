# 単位変換



長さ、質量、面積、体積、温度、速度、エネルギー、データなど、さまざまな単位を変換する。





## 使い方



1. 例を使うか、任意の値を入力します。
2. 計算後、結果をコピーするか詳細をダウンロードできます。







## 例



### 入力



```
1 m を ft に変換
```



### 期待される結果



```
≈3.28084フィート
```







## 試してみる



[ツール全体を開く](<https://toolpony.com/ja/tools/unit-converter/>)







## 注意点



処理はブラウザ内で実行されます。単位をそろえて入力してください。







## 計算方法



各グループは標準ベース単位を通じて変換します。 米国および帝国の体積単位は別々である。 数式およびバイナリストレージユニットはそれぞれのベースを保持しています。
