# Guia de uso · Calculadora de imposto sobre vendas e IVA



Adicione ou remova o imposto de vendas e o IVA usando sua própria taxa.





## Exemplo



### Entrada



```
Preço líquido 100, IVA 20%
```



### Resultado esperado



```
Total 120, imposto 20
```





<a id="case-study"></a>



## Descobrir a alíquota de um recibo



1. O recibo mostra 200,00 sem imposto e 217,00 pagos. Divida a diferença de 17,00 pelo preço sem imposto para obter 8,5%. Aplique a alíquota a 200 para conferir o total.

## Método de cálculo



Preço bruto = preço líquido × (1 + taxa). As taxas de imposto são fornecidas pelo usuário.
