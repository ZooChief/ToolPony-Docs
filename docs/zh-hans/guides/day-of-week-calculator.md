# 星期几计算器



查询某天的星期、年内日序、ISO 周数和该星期在当年的次数。





## 开始使用



1. 按示例填写数值，或输入你自己的测量值。
2. 计算后可复制结果或下载明细。







## 示例



### 输入



```
2000-01-01
```



### 预期结果



```
星期六
```

## 使用提示



计算在浏览器内完成。无单位标记的字段请使用一致单位。







## 计算方法



采用公历。ISO 周从周一开始，第 1 周包含 1 月 4 日。1 月初的日期可能属于上一年的最后一周。
