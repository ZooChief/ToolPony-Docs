# 판매 수수료 계산기



판매, 요금 또는 커미션을 찾은 다음 기본 지불과 점진적 계층을 계산합니다.





## 시작하기



1. 예제 값을 사용하거나 원하는 값을 입력하세요.
2. 계산한 결과를 복사하거나 세부 정보를 내려받을 수 있습니다.







## 예시



### 입력



```
16,500 에 8.25%
```



### 예상 결과



```
1,361.25 위원회
```







## 직접 사용해 보기



[전체 도구 열기](<https://toolpony.com/ko/tools/commission-calculator/>)







## 참고 사항



브라우저에서 처리합니다. 단위를 일관되게 사용하세요.







## 계산 방법



단일 비율은 판매 금액을 곱합니다. 계층 일정에서 각 임계값은 해당 브래킷의 상한선입니다. 퍼센트 계층은 대괄호의 수익에만 적용됩니다. 고정 계층은 브래킷이 입력될 때 한 번 지불합니다.



$$
C=C_0+\sum_i s_i r_i\quad\text{(percentage tiers)}
$$







## 계산 모드



**커미션 찾기**

- 판매 금액
- 위원회 비율 · %





**요금 찾기**

- 판매 금액
- 위원회 금액





**판매 금액 찾기**

- 위원회 비율 · %
- 위원회 금액





**기본 및 계층**

- 판매 금액
- 기본위원회
- 기본 유형 · 고정 금액 / 매출의 퍼센트
- 계층 상한, 비율(% 또는 고정 금액). 제한 없음에 \*를 사용하십시오.
