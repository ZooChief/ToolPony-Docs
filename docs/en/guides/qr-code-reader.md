# QR code reader



Choose, drop or paste an image. You can also turn on the camera in the standalone tool. Review the decoded text, then copy or download it. Open a web link only after checking the address.





## Get started



1. Choose, drop or paste an image. You can also turn on the camera in the standalone tool.
2. Review the decoded text, then copy or download it. Open a web link only after checking the address.







## Example



### Input



```
Read sample
```



### Expected result



```
https://example.com/qr-sample
```







## Try it



[Open full tool](<https://toolpony.com/en/tools/qr-code-reader/>)







## Limits



One QR code per scan. Images up to 20 MiB and 24 megapixels, including supported PNG, JPEG, WebP and SVG. The camera needs browser permission and stops after a successful read. Images and frames stay on your device.

[Documentation](https://docs.toolpony.com/en/guides/qr-code-reader/)
