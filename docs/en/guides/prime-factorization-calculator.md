# Prime factorization calculator



Find prime factors, exponent form and the divisor count of a positive integer.





## Get started



1. Use the example values or enter your own measurements.
2. Calculate, then copy the result or download the available details.







## Example



### Input



```
360
```



### Expected result



```
2³ × 3² × 5, 24 divisors
```







## Try it



[Open full tool](<https://toolpony.com/en/tools/prime-factorization-calculator/>)







## Good to know



The calculation runs in your browser. Use consistent units in fields with no explicit unit.







## Calculation method



Trial division removes factors up to the square root of the remaining integer. Input range: 2 to 1 trillion.
