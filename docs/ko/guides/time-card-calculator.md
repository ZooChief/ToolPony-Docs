# 근무시간표 계산기



한 주 근무와 휴식을 기록하고 반올림, 임금 규칙, CSV를 사용하세요.





## 시작하기



1. 08:30, 8.30, 8:30 AM처럼 입력하세요. 휴식은 00:30처럼 시간과 분을 입력하세요.
2. 반올림과 선택 임금 규칙을 지정한 뒤 CSV를 받거나 인쇄하세요. 브라우저에 초안을 저장할 수도 있습니다.







## 예시



### 입력



```
08:30–17:00, 휴식 00:30
```



### 예상 결과



```
08:00:00
```

## 계산 방법



휴식을 뺀 순 근무 시간을 반올림합니다. 종료가 시작보다 빠르면 다음 날입니다. 일일·주간 한도와 요율은 직접 정합니다.



$$
t_i=(e_i-s_i)\bmod 1440-b_i,\qquad t'_i=q\,\operatorname{round}(t_i/q)\quad(q>0)
$$



$$
P=(t_{\rm base}+m\,t_{\rm overtime})r/60
$$
