# Rechner für einfache Zinsen



Berechnen Sie einfache Zinsen oder lösen Sie nach Kapital, Zinssatz oder Begriff aus den anderen Inputs.





## Erste Schritte



1. Verwenden Sie das Beispiel oder geben Sie eigene Werte ein.
2. Berechnen Sie das Ergebnis und kopieren oder laden Sie die Details herunter.







## Beispiel



### Eingabe



```
1.000 bei 5 % für 2 Jahre
```



### Erwartetes Ergebnis



```
100 Zinsen; 1.100 insgesamt
```

## Berechnungsmethode



Die Zinsen sind gleich dem Kapital × dem periodischen Zinssatz × der Anzahl der Perioden. Umrechnen des Terms in dieselbe Einheit wie der Zinssatz vor der Multiplikation. Der Endsaldo addiert den Zins zum Kapital.



$$
I=Prt,\qquad A=P+I
$$



Vergleichen Sie den Begriff Einheit mit der angegebenen Zinsperiode, z. B. 5 % pro Jahr, die für 24 Monate angewendet werden, verwenden Sie 2 Jahreszeiträume.



Wenn der Endsaldo bekannt ist, kann eine Nullrate oder ein Nullterm dazu führen, dass das inverse Problem nicht einzigartig ist.
