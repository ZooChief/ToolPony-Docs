# 质因数分解计算器



求正整数的质因数、指数形式和约数个数。





## 开始使用



1. 按示例填写数值，或输入你自己的测量值。
2. 计算后可复制结果或下载明细。







## 示例



### 输入



```
360
```



### 预期结果



```
2³ × 3² × 5，共 24 个约数
```

## 使用提示



计算在浏览器内完成。无单位标记的字段请使用一致单位。







## 计算方法



用试除法取出质因数，试除上界为剩余整数的平方根。输入范围为 2 至 1 万亿。
