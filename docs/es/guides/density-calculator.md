# Calculadora de densidad



Resolver para la masa, el volumen o la densidad al entrar en cualquier dos valores.





## Ejemplo



### Entrada



```
8 kg, 0,001 m3
```



### Resultado esperado



```
8.000 kg/m3
```







## Pruébalo

[Abrir herramienta completa · Calculadora de densidad](<https://toolpony.com/es/tools/density-calculator/>)





## Método de cálculo



Densidad = volumen de masa. La interfaz utiliza kg, m3 y kg/m3.



$$
\rho=\frac{m}{V}
$$
