# Sales tax and VAT calculator



Add or remove sales tax and VAT using your own rate.





## Get started



1. Use the example values or enter your own measurements.
2. Calculate, then copy the result or download the available details.







## Example



### Input



```
Net price 100, VAT 20%
```



### Expected result



```
Gross 120, tax 20
```







## Try it



[Open full tool](<https://toolpony.com/en/tools/sales-tax-calculator/>)







## Good to know



The calculation runs in your browser. Use consistent units in fields with no explicit unit.







## Calculation method



Gross price = net price × (1 + rate). Tax rates are supplied by the user.
