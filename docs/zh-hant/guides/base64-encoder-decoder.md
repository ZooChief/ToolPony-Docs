# Base64 編碼與解碼



將 UTF-8 文本編碼爲標準或 URL 安全 Base64，並校驗解碼文本。





## 開始使用



1. 按示例填寫數值，或輸入你自己的測量值。
2. 計算後可複製結果或下載明細。







## 示例



### 輸入



```
編碼 hello
```



### 預期結果



```
aGVsbG8=
```

## 使用提示



計算在瀏覽器內完成。無單位標記的字段請使用一致單位。







## 計算方法



文本以 UTF-8 轉換。URL 安全模式採用 “-” 和 “\_”，輸出省略填充。輸入上限爲 50 萬字符。
