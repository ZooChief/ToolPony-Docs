# 이미지를 PDF로 변환



JPG, PNG, WebP 등 여러 이미지를 PDF 한 개로 만듭니다.





## 시작하기



1. 이미지를 추가하고 페이지 순서를 정합니다.
2. 용지 크기, 방향, 여백을 선택한 뒤 PDF를 저장합니다.







## 예시



### 입력



```
가로 사진 2장, A4, 자동 방향
```



### 예상 결과



```
가로 A4 2페이지
```







## 직접 사용해 보기



[전체 도구 열기](<https://toolpony.com/ko/tools/jpg-to-pdf/>)







## 제한 사항



최대 20장, 입력 합계 30 MB와 6천만 화소입니다. 이미지 한 장은 20 MB와 2,400만 화소까지 가능합니다. 투명 부분은 흰색이며 애니메이션은 첫 프레임만 사용합니다.

[문서](https://docs.toolpony.com/ko/guides/jpg-to-pdf/)
