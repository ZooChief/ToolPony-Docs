# Calculadora de porcentajes



Resolver porcentaje, parte, entero, aumento, disminución, cambio inverso, diferencia y error.





## Primeros pasos



1. Por una parte como el 15% de 240, elija el porcentaje de un valor. Si la parte es 36 y conoce el total o la tasa, elija el modo inverso correspondiente.
2. Elija el cambio porcentual para un valor antiguo y nuevo ordenado. Use la diferencia porcentual para dos valores positivos sin base.
3. Introduzca 15 para 15%. Compare el resultado contra los ejemplos trabajados a continuación.







## Ejemplo



### Entrada



```
15% de 240
```



### Resultado esperado



```
36
```

## Método de cálculo



Porcentaje = parte ÷ entera × 100. El cambio utiliza el valor original absoluto como su denominador. La diferencia simétrica utiliza la media de los valores absolutos.



$$
x=yp/100,\quad p=100x/y,\quad y=100x/p
$$



$$
\Delta\%=100\frac{x_1-x_0}{|x_0|},\quad D\%=200\frac{|x_1-x_0|}{|x_1|+|x_0|}
$$



80 → 100 es un cambio del 25% porque 80 es el valor inicial. La diferencia porcentual entre los mismos números es de aproximadamente 22.22% porque el denominador es su promedio, 90.



Después de un aumento del 20% a 120, el cambio inverso da 100. Un cambio de −100% no se puede revertir. El cambio de una base cero no tiene resultado porcentual.



Para un valor medido de 90 y referencia de 96, el error absoluto por ciento es de 6.25%. El resultado firmado con esa referencia positiva es −6.25%.
