# Encoder et décoder une URL



Encoder ou décoder des URL complètes, des composants URI et des valeurs de formulaire.





## Prise en main



1. Utilisez l’exemple ou saisissez vos propres valeurs.
2. Calculez, puis copiez le résultat ou téléchargez les détails.







## Exemple



### Entrée



```
Encoder le composant : a+b & c
```



### Résultat attendu



```
a%2Bb%20%26%20c
```







## Essayer



[Ouvrir l’outil complet](<https://toolpony.com/fr/tools/url-encoder-decoder/>)







## Notes



Le traitement se fait dans le navigateur. Utilisez des unités cohérentes.







## Méthode de calcul



L'encodage des composants évite les séparateurs réservés. L'encodage complet des URLs préserve les séparateurs.
