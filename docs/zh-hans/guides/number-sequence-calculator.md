# 数列计算器



求等差、等比和斐波那契数列的指定项、部分和，并下载各项。





## 开始使用



1. 按示例填写数值，或输入你自己的测量值。
2. 计算后可复制结果或下载明细。







## 示例



### 输入



```
等差数列，首项 7，公差 −3，第 8 项
```



### 预期结果



```
第 8 项为 −14，前 8 项和为 −28
```

## 使用提示



计算在浏览器内完成。无单位标记的字段请使用一致单位。







## 计算方法



等差和等比数列从 1 开始编号。斐波那契数列从 F₀ = 0 开始，使用精确整数。



$$
a_n=a_1+(n-1)d,\quad g_n=g_1r^{n-1},\quad F_n=F_{n-1}+F_{n-2}
$$







## 计算模式



**等差数列**

- 首项
- 公差
- 序号





**等比数列**

- 首项
- 公比
- 序号





**斐波那契数列**

- 序号
