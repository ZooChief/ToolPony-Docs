# Codificar e decodificar URL



Codifique ou descodificar URLs completas, componentes URI e valores de formulário.





## Primeiros passos



1. Use o exemplo ou insira seus próprios valores.
2. Calcule, copie o resultado ou baixe os detalhes disponíveis.







## Exemplo



### Entrada



```
Codificar componente: a+b & c
```



### Resultado esperado



```
a%2Bb%20%26%20c
```







## Experimente



[Abrir ferramenta completa](<https://toolpony.com/pt-br/tools/url-encoder-decoder/>)







## Notas de uso



O cálculo é feito no seu navegador. Use unidades consistentes.







## Método de cálculo



A codificação de componentes escapa aos separadores reservados. A codificação de URL completa preserva os separadores. A codificação de formulários usa mais para espaços.
