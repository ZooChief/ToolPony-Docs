# Calculatrice d’équations du second degré



Résolvez ax2 + bx + c = 0 avec des racines réelles ou complexes, y compris des coefficients fractionnaires.





## Prise en main



1. Utilisez l’exemple ou saisissez vos propres valeurs.
2. Calculez, puis copiez le résultat ou téléchargez les détails.







## Exemple



### Entrée



```
a=1, b=−5, c=6
```



### Résultat attendu



```
x₁=2, x₂=3
```

## Notes



Le traitement se fait dans le navigateur. Utilisez des unités cohérentes.







## Méthode de calcul



Utilisez le discriminant b2−4ac. Un coefficient quadratique zéro réduit l'expression à une équation linéaire.



$$
ax^2+bx+c=0,\qquad x=\frac{-b\pm\sqrt{b^2-4ac}}{2a},\quad a\ne0
$$
