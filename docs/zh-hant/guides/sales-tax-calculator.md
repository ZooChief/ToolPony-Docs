# 銷售稅與增值稅計算器



按自定義稅率計算含稅價、未稅價與稅額。





## 示例



### 輸入



```
未稅價 100，增值稅 20%
```



### 預期結果



```
含稅價 120，稅額 20
```

## 計算方法



含稅價 = 未稅價 ×（1 + 稅率）。稅率由用戶填寫。
