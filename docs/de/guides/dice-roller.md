# Würfelsimulator



Rollen Sie einen oder mehrere Würfel mit benutzerdefinierten Seiten, vergleichen Sie die Summen und sehen Sie jede Rolle.





## Erste Schritte



1. Verwenden Sie das Beispiel oder geben Sie eigene Werte ein.
2. Berechnen Sie das Ergebnis und kopieren oder laden Sie die Details herunter.







## Beispiel



### Eingabe



```
3 Würfel, 6 Seiten
```



### Erwartetes Ergebnis



```
Drei Gesichter und ihre Summe
```







## Ausprobieren



[Vollständiges Werkzeug öffnen](<https://toolpony.com/de/tools/dice-roller/>)







## Hinweise



Die Verarbeitung erfolgt im Browser. Verwenden Sie einheitliche Einheiten.







## Berechnungsmethode



Jeder Würfel verwendet einen unabhängigen einheitlichen Web Crypto Draw. Rollen Sie bis zu 100 Würfel mit jeweils 2 bis 1.000 Seiten.

[Dokumentation](https://docs.toolpony.com/de/guides/dice-roller/)
