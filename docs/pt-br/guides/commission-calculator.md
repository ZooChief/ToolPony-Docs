# Calculadora de comissões



Encontre vendas, taxa, ou comissão, em seguida, calcular um pagamento base mais níveis progressivos.





## Primeiros passos



1. Use o exemplo ou insira seus próprios valores.
2. Calcule, copie o resultado ou baixe os detalhes disponíveis.







## Exemplo



### Entrada



```
16,500 a 8,25%
```



### Resultado esperado



```
1.361.25 comissão
```

## Notas de uso



O cálculo é feito no seu navegador. Use unidades consistentes.







## Método de cálculo



Uma taxa única multiplica o montante de vendas. Em um esquema de níveis, cada limiar é o limite superior para esse nível. Níveis percentuais se aplicam apenas à receita entre os níveis. Níveis fixos pagam uma vez quando o nível é inserido.



$$
C=C_0+\sum_i s_i r_i\quad\text{(percentage tiers)}
$$







## Modo de cálculo



**Procurar comissão**

- Montante das vendas
- Taxa da Comissão · %





**Taxa de procura**

- Montante das vendas
- Montante da Comissão





**Procurar o valor das vendas**

- Taxa da Comissão · %
- Montante da Comissão





**Base e níveis**

- Montante das vendas
- Comissão de base
- Tipo de base · Montante fixo / Percentagem de vendas
- Limite superior de nível, taxa (% ou montante fixo). Use \* para nenhum limite.
