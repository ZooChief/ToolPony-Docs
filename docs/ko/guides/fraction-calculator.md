# 분수 계산기



정확한 산술을 사용하여 분수와 혼합 숫자를 추가, 빼기, 곱하거나 나누거나 단순화합니다.





## 시작하기



1. 예제 값을 사용하거나 원하는 값을 입력하세요.
2. 계산한 결과를 복사하거나 세부 정보를 내려받을 수 있습니다.







## 예시



### 입력



```
1 1/2 + 2/3
```



### 예상 결과



```
13/6
```

## 계산 방법



십진수는 정확한 분수로 읽습니다. 산리스메틱은 BigInt를 사용하고 가장 큰 일반적인 쌍으로 줄입니다. 소수 결과는 대략입니다.



$$
\frac{a}{b}+\frac{c}{d}=\frac{ad+bc}{bd},\qquad b,d\ne0
$$
