# 表面積計算器



支持球、圓錐、圓柱、長方體、膠囊體、球冠、橢球、棱錐和空心管等，可混用尺寸單位。





## 開始使用



1. 按示例填寫數值，或輸入你自己的測量值。
2. 計算後可複製結果或下載明細。







## 示例



### 輸入



```
球半徑 2 米
```



### 預期結果



```
約 50.2655 平方米
```

## 使用提示



計算在瀏覽器內完成。無單位標記的字段請使用一致單位。







## 計算方法



總表面積包含端面。適用的立體會分別列出側面積和端面面積。橢球表面積爲近似值。



$$
A_{\mathrm{cylinder}}=2\pi r^2+2\pi rh,\qquad A_{\mathrm{sphere}}=4\pi r^2
$$
