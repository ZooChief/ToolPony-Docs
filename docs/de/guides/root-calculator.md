# Wurzelrechner



Berechnen Sie die reelle Quadrat-, Würfel- oder n-te Wurzel.





## Beispiel



### Eingabe



```
Quadratwurzel von 144
```



### Erwartetes Ergebnis



```
12
```







## Ausprobieren

[Vollständiges Werkzeug öffnen · Wurzelrechner](<https://toolpony.com/de/tools/root-calculator/>)





## Berechnungsmethode



Die n-te Wurzel ist x auf 1/n erhöht. Ungerade ganzzahlige Grade akzeptieren negative Radicanden. Ein negativer Grad nimmt den Kehrwert.



$$
\sqrt[n]{x}=x^{1/n},\qquad n\ne0
$$







## Berechnungsmodus



**Quadratwurzel**

- Radikand





**Kubikwurzel**

- Radikand





**n-te Wurzel**

- Radikand
- Höhe
