# 내부수익률(IRR) 계산기



불규칙한 연간 흐름 또는 터미널 값 및 정기 예금 또는 인출에서 연간 유효 비율을 찾으십시오.





## 시작하기



1. 예제 값을 사용하거나 원하는 값을 입력하세요.
2. 계산한 결과를 복사하거나 세부 정보를 내려받을 수 있습니다.







## 예시



### 입력



```
55,000 지출 14,000, 18,000, 22,000, 26,000 유입
```



### 예상 결과



```
IRR ≈ 15.093%
```

## 계산 방법



내부수익률(IRR)은 순현재가치를 0으로 만드는 할인율입니다. 고정 현금 흐름 모드에서는 납입 빈도와 기간 시작 또는 종료 시점을 선택합니다. 시작 시점의 납입액을 최종 시점에도 포함할지 지정할 수 있습니다. 탐색 범위는 −99.9999%부터 10,000%까지입니다.



$$
0=\sum_{i=0}^n\frac{F_i}{(1+r)^{t_i}}
$$







## 계산 모드



**불규칙한 연간 흐름**

- 초기 투자액
- 후속 연간 현금 흐름





**조정 흐름 및 종료 균형**

- 초기 투자액
- 전체 년
- 추가 개월
- 균형 종료
- 지불 금액
- 지불 유형 · 출금 / 보증금
- 연간 지불 · 1 / 2 / 4 / 12 / 24 / 26 / 52
- 지불 타이밍 · 기간 종료 / 기간의 시작
- 시작 모드에 터미널 지불 포함
