# Chart maker



Paste CSV with a header, a label column and numeric series. Pick bars or lines, update the chart and download SVG.





## Get started



1. Enter a CSV header. Put category labels in the first column and numeric series in the remaining columns.
2. Choose bars or lines and update the preview.
3. Download the chart as an SVG.







## Example



### Input



```
Month,Visits
Jan,24
Feb,38
```



### Expected result



```
Two values at Jan and Feb, plotted from left to right.
```







## Try it



[Open full tool](<https://toolpony.com/en/tools/chart-maker/>)







## Good to know



Quote labels containing commas. Use a period as the decimal separator. Negative values use the same scale as positive values.







## Limits



Up to 120 rows and six numeric series. A quoted cell may contain a comma. Each row stays on one line. Values are plotted in the order entered.
