# Calculatrice de cercle



Trouvez le rayon, le diamètre, la circonférence et la surface d'une mesure connue. Calculez les arcs, les secteurs et les accords.





## Prise en main



1. Utilisez l’exemple ou saisissez vos propres valeurs.
2. Calculez, puis copiez le résultat ou téléchargez les détails.







## Exemple



### Entrée



```
Rayon 2; angle central 90°
```



### Résultat attendu



```
Circonférence 12,5664; arc 3.1416
```

## Notes



Le traitement se fait dans le navigateur. Utilisez des unités cohérentes.







## Méthode de calcul



Circonférence = 2πr. Superficie = πr2. Longueur de l'arc et échelle de secteur avec l'angle central divisé par 360°.



$$
A=\pi r^2,\qquad C=2\pi r
$$
