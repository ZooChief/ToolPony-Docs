# 債務收入比計算器



比較每月固定債務還款與稅前月收入。





## 開始使用



1. 按示例填寫數值，或輸入你自己的測量值。
2. 計算後可複製結果或下載明細。







## 示例



### 輸入



```
稅前月收入 5,000，月債務還款 1,500
```



### 預期結果



```
30%
```

## 使用提示



計算在瀏覽器內完成。無單位標記的字段請使用一致單位。







## 計算方法



債務收入比 = 月債務還款額 ÷ 稅前月收入。所有金額請用同一幣種和月度口徑。
