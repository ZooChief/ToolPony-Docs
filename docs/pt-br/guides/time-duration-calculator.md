# Calculadora de duração



Calcule intervalos, combine durações e desloque datas e horários.





## Primeiros passos



1. Escolha horários para um turno, datas para vários dias ou expressão para calcular.







## Exemplo



### Entrada



```
Das 22:30 às 06:15 do dia seguinte
```



### Resultado esperado



```
07:45:00
```

## Notas de uso



O cálculo é feito no seu navegador. Use unidades consistentes.







## Método de cálculo



Um intervalo pode cruzar a meia-noite. Com datas, cada dia tem 24 horas. d, h, m e s são dias, horas, minutos e segundos. O sinal de menos vale para o grupo seguinte.



$$
T=86400d+3600h+60m+s
$$
