# Ratio calculator



Solve a missing term in a proportion, simplify a ratio, or scale both terms.





## Example



### Input



```
3:4 = x:20
```



### Expected result



```
x=15
```







## Try it

[Open full tool · Ratio calculator](<https://toolpony.com/en/tools/ratio-calculator/>)





## Calculation method



A:B = C:D implies A×D = B×C, with nonzero denominators. Simplification accepts decimal and fractional quantities.







## Calculation mode



**Solve a proportion**

- A
- B
- C
- D





**Simplify or scale**

- First term
- Second term
- Scale factor





**Enlarge or reduce a ratio**

- First term
- Second term
- Direction · Reduce / Enlarge
- Factor
