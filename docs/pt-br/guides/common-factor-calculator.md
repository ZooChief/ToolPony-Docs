# Calculadora de divisores comuns



Listar todos os fatores comuns positivos e calcular o maior fator comum de múltiplos inteiros.





## Primeiros passos



1. Use o exemplo ou insira seus próprios valores.
2. Calcule, copie o resultado ou baixe os detalhes disponíveis.







## Exemplo



### Entrada



```
12, 18, 30
```



### Resultado esperado



```
1, 2, 3, 6
```

## Método de cálculo



Os fatores comuns de uma lista são exatamente os divisores de seu maior divisor comum. O algoritmo Euclidiano encontra esse divisor sem enumerar todos os fatores de entrada.



$$
d\mid a_1,\ldots,a_n\iff d\mid\gcd(a_1,\ldots,a_n)
$$
