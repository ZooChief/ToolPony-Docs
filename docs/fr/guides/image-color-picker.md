# Pipette de couleurs d’image



Cliquez sur l'exemple ou choisissez une image. Cliquez sur un point ou entrez ses coordonnées de pixel pour lire HEX et RGBA. Copiez une couleur ou exportez la palette échantillonnée en CSV.





## Prise en main



1. Essayez l'exemple intégré ou choisissez une image.
2. Cliquez sur un point, ou entrez X et Y et échantillonnez ce pixel original.
3. Copier HEX ou exporter jusqu'à seize lignes de coordonnées et RGBA comme CSV.







## Exemple



### Entrée



```
Échantillon intégré, X = 32 et Y = 32
```



### Résultat attendu



```
#285eaa · RGBA 40, 94, 170, 255
```







## Essayer



[Ouvrir l’outil complet](<https://toolpony.com/fr/tools/image-color-picker/>)







## Notes



L'aperçu peut être réduit pendant que l'échantillonnage lit toujours le pixel d'origine correspondant. Le navigateur peut convertir des profils de couleur d'image pendant le décodage.







## Limites



JPG, PNG, WebP, AVIF ou GIF jusqu'à 20 Mo et 24 mégapixels. Lisez les pixels décodés du navigateur. Les coordonnées commencent à (0, 0) en haut à gauche. Une palette peut contenir jusqu'à 16 points.

[Documentation](https://docs.toolpony.com/fr/guides/image-color-picker/)
