# Calculadora de permutaciones y combinaciones



Computa selecciones exactas ordenadas y sin orden con o sin repetición.





## Primeros pasos



1. Usa el ejemplo o introduce tus propios valores.
2. Calcula, copia el resultado o descarga los detalles disponibles.







## Ejemplo



### Entrada



```
n=10, r=3, sin repetición
```



### Resultado esperado



```
720 permutaciones; 120 combinaciones
```

## Notas de uso



El cálculo se ejecuta en tu navegador. Usa unidades coherentes.







## Método de cálculo



Sin repetición, nPr = n!/(n−r)! y nCr = nPr/r!. Con la repetición, las opciones ordenadas son nr y las opciones no ordenadas son C(n+r−1,r).
