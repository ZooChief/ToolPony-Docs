# 因数计算器



列出全部正因数、因数对与质因数分解。





## 开始使用



1. 按示例填写数值，或输入你自己的测量值。
2. 计算后可复制结果或下载明细。







## 示例



### 输入



```
120
```



### 预期结果



```
共有 16 个正因数，包括 1 和 120
```

## 计算方法



因数能将原数整除。每个较小的因数 d 对应 n/d，因此查到 √n 即可找全。



$$
d\mid n\iff n\bmod d=0,\qquad n=d\cdot(n/d)
$$
