# サイコロ



カスタムサイドで1つ以上のダイスをロールし、合計を比較して各ロールを表示します。





## 使い方



1. 例を使うか、任意の値を入力します。
2. 計算後、結果をコピーするか詳細をダウンロードできます。







## 例



### 入力



```
3ディシ、6面
```



### 期待される結果



```
三つの顔とその額
```







## 試してみる



[ツール全体を開く](<https://toolpony.com/ja/tools/dice-roller/>)







## 注意点



処理はブラウザ内で実行されます。単位をそろえて入力してください。







## 計算方法



各ダイは独立した統一版のWeb Crypto抽選を使用しています。 最大100ダイスをそれぞれ2～1,000面ずつ展開。

[ドキュメント](https://docs.toolpony.com/ja/guides/dice-roller/)
