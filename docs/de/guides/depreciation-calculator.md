# Abschreibungsrechner



Bauen Sie einen jährlichen linearen, rückläufigen Gleichgewichts- oder Jahressummenplan auf.





## Erste Schritte



1. Verwenden Sie das Beispiel oder geben Sie eigene Werte ein.
2. Berechnen Sie das Ergebnis und kopieren oder laden Sie die Details herunter.







## Beispiel



### Eingabe



```
17.500 Kosten, 2.500 Rettung, 6 Jahre, geradlinig
```



### Erwartetes Ergebnis



```
2.500 pro Jahr
```

Die Verarbeitung erfolgt im Browser. Verwenden Sie einheitliche Einheiten.







## Berechnungsmethode



Geradlinig dividiert die abschreibungsfähigen Kosten durch die Nutzungsdauer. Der sinkende Saldo wendet Faktor/Lebensdauer auf den Anfangsbuchwert an und stoppt bei der Bergung. Die Summe der Jahresziffern wird durch die Gewichtung der verbleibenden Jahre zugewiesen. Die Beträge werden pro Jahr gerundet.



$$
D_{\mathrm{SL}}=\frac{C-S}{n},\quad D_{k,\mathrm{SYD}}=(C-S)\frac{n-k+1}{n(n+1)/2}
$$







## Berechnungsmodus



**Geradeauslinie**

- Anlagekosten
- Wert der Bergung
- Nutzungsdauer
- Rundung · Zwei Dezimalstellen / Gesamtbetrag





**Sinkende Bilanz**

- Anlagekosten
- Wert der Bergung
- Nutzungsdauer
- Abschreibungsfaktor
- Rundung · Zwei Dezimalstellen / Gesamtbetrag





**Jahressummenstellen**

- Anlagekosten
- Wert der Bergung
- Nutzungsdauer
- Rundung · Zwei Dezimalstellen / Gesamtbetrag
