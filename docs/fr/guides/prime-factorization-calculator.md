# Décomposition en facteurs premiers



Trouvez les facteurs principaux, la forme de l'exposant et le nombre de diviseurs d'un entier positif.





## Prise en main



1. Utilisez l’exemple ou saisissez vos propres valeurs.
2. Calculez, puis copiez le résultat ou téléchargez les détails.







## Exemple



### Entrée



```
360
```



### Résultat attendu



```
2³ × 3² × 5, 24 diviseurs
```

## Notes



Le traitement se fait dans le navigateur. Utilisez des unités cohérentes.







## Méthode de calcul



La division d'essai élimine les facteurs jusqu'à la racine carrée de l'entier restant. Plage d'entrée: 2 à 1 billion.
