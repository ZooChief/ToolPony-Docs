# 排列組合計算器



精確計算有序與無序選擇，支持可重複和不重複兩種方式。





## 開始使用



1. 按示例填寫數值，或輸入你自己的測量值。
2. 計算後可複製結果或下載明細。







## 示例



### 輸入



```
n=10，r=3，不重複
```



### 預期結果



```
排列 720，組合 120
```

計算在瀏覽器內完成。無單位標記的字段請使用一致單位。







## 計算方法



不重複時 nPr = n!/(n−r)!，nCr = nPr/r!。可重複時有序方案爲 nʳ，無序方案爲 C(n+r−1,r)。
