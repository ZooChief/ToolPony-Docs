# 주택담보대출 계산기



고정 금리 모기지를 계약금, 반복 비용, 추가 지불 및 격주 지불과 비교하십시오.





## 시작하기



1. 예제 값을 사용하거나 원하는 값을 입력하세요.
2. 계산한 결과를 복사하거나 세부 정보를 내려받을 수 있습니다.







## 예시



### 입력



```
홈 400,000; 아래로 20%; 30 년; 6%
```



### 예상 결과



```
≈1,918.56 월간 원금 및이자
```

## 참고 사항



브라우저에서 처리합니다. 단위를 일관되게 사용하세요.







## 계산 방법



월 이자 = 남은 원금 × 연이율 ÷ 12입니다. 비용에는 입력한 연간 금액과 증가율을 적용합니다. 이 모델에서는 잔여 원금이 최초 주택 가격의 80%에 도달하면 PMI를 중단할 수 있습니다. 격주 방식은 연이율을 26으로 나누고 2주마다 월 상환액의 절반을 납입하는 경우를 비교합니다.



$$
I_k=r B_{k-1},\qquad B_k=B_{k-1}-(M_k-I_k)
$$
