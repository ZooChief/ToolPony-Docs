# 割引計算機



割引を積み重ね、固定クーポンを差し引いて、割引価格に消費税を適用してください。





## 使い方



1. 例を使うか、任意の値を入力します。
2. 計算後、結果をコピーするか詳細をダウンロードできます。







## 例



### 入力



```
20%オフと10%オフの100
```



### 期待される結果



```
72;複合割引 28%
```







## 試してみる



[ツール全体を開く](<https://toolpony.com/ja/tools/discount-calculator/>)







## 注意点



処理はブラウザ内で実行されます。単位をそろえて入力してください。







## 計算方法



パーセンテージ割引を順に適用し、次に固定クーポンを適用してから、課税してください。 0%から100%まで最大10の金利。



20% と 10% の割引を続けて適用すると、価格は元の 0.8 × 0.9 倍です。割引率を順に入力し、必要に応じてクーポンや税を追加します。



販売価格や保存した金額を把握した場合は、逆モードを使用してください。 逆モードでは、税引き前の1つの割引が適用されます。







## 計算モード



**割引を適用してください**

- 元の価格
- 割引率
- 固定クーポン
- 税率 · %





**オリジナル価格を探す**

- 割引後の価格
- 割引タイプ · パーセンテージ / 固定量
- 割引





**料金と貯蓄を見つける**

- 元の価格
- 既知の金額 · 割引価格 / 節約
- 金額





**節約から価格を見つけましょう**

- 保存された金額
- 割引率 · %
