# 複利計算機



繰り返しの寄与とインフレとのバランスを図ること、または複利周波数を変換すること。





## 使い方



1. 例を使うか、任意の値を入力します。
2. 計算後、結果をコピーするか詳細をダウンロードできます。







## 例



### 入力



```
元金 10,000、年利 5%、10 年間
```



### 期待される結果



```
16,288.95
```







## 試してみる



[ツール全体を開く](<https://toolpony.com/ja/tools/compound-interest-calculator/>)







## 注意点



処理はブラウザ内で実行されます。単位をそろえて入力してください。







## 計算方法



持続的な複結合による有効な年間成長率は(1+r/m)^m−1、またはexp(r)−1である。 寄付金は、各期間の選択された開始または終了から利息を獲得します。



$$
A=P(1+r/m)^{mt},\qquad \mathrm{APY}=(1+r/m)^m-1
$$







## 計算モード



**将来の均衡**

- 元金
- 年利 · %
- 年
- 複利頻度
- 定期的貢献
- 貢献頻度 · 年1回 / 半年ごと / 四半期ごと / 毎月 / 月2回 / 2週間ごと / 毎週 / 毎日
- 期間開始時に貢献してください
- 年間インフレ · %





**同等金利**

- 年利 · %
- オリジナルコンパウンディング
- ターゲット複合化
