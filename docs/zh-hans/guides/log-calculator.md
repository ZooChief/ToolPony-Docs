# 对数计算器



计算对数值、底数或真数，底数可为数值或 e。





## 开始使用



1. 按示例填写数值，或输入你自己的测量值。
2. 计算后可复制结果或下载明细。







## 示例



### 输入



```
底数 3，真数 81
```



### 预期结果



```
4
```

## 使用提示



计算在浏览器内完成。无单位标记的字段请使用一致单位。







## 计算方法



log₍b₎(x) 是满足 bʸ = x 的指数 y。换底公式为 ln(x) 除以 ln(b)。



$$
\log_b(x)=\frac{\ln x}{\ln b},\qquad b>0,\quad b\ne1,\quad x>0
$$







## 计算模式



**求对数**

- 底数（数值或 e）
- 真数





**求底数**

- 真数
- 对数值





**求真数**

- 底数（数值或 e）
- 对数值
