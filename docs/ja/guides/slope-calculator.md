# 傾き計算機



2つの点からスロープとインターセプトを見つけたり、それぞれの距離で両方のエンドポイントを検索したりできます。





## 使い方



1. 例を使うか、任意の値を入力します。
2. 計算後、結果をコピーするか詳細をダウンロードできます。







## 例



### 入力



```
(0、0)から(3、4)
```



### 期待される結果



```
4月3日と距離5
```

[ツール全体を開く](<https://toolpony.com/ja/tools/slope-calculator/>)







## 注意点



処理はブラウザ内で実行されます。単位をそろえて入力してください。







## 計算方法



傾斜は上昇を走行によって分けている。 垂直線には未定義の傾きがある。 既知の距離と方向が、出発点の反対側にある2つのエンドポイントを決定する。



$$
m=\frac{y_2-y_1}{x_2-x_1},\qquad \theta=\arctan(m),\qquad y=mx+b
$$



2点モードは、垂直方向と水平方向の変更を個別に報告する。 それぞれの変化のサインを使って、ポイントがどの方向に動いたかを判断してください。 垂直線は一定のx座標を持つ。



ラインと距離が、スタート地点の両側の点を決定する。 エンドポイントテーブルを使用して、両方のソリューションを維持できます。







## 計算モード



**2ポイント**

- X1
- Y1
- X2
- Y2





**ポイントと方向**

- X1
- Y1
- 距離
- 方向の指定方法 · 傾き / 度数の角度
- 方向値
