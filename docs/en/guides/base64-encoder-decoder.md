# Base64 encode and decode



Encode UTF-8 text as standard or URL-safe Base64 and validate decoded text.





## Get started



1. Use the example values or enter your own measurements.
2. Calculate, then copy the result or download the available details.







## Example



### Input



```
Encode hello
```



### Expected result



```
aGVsbG8=
```







## Try it



[Open full tool](<https://toolpony.com/en/tools/base64-encoder-decoder/>)







## Good to know



The calculation runs in your browser. Use consistent units in fields with no explicit unit.







## Calculation method



Text is converted as UTF-8. URL-safe mode uses "-" and "\_" and omits padding in output. Up to 500,000 input characters.

[Documentation](https://docs.toolpony.com/en/guides/base64-encoder-decoder/)
