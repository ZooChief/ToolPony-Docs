# Z 分數計算器



標準化觀測值，並在 Z 分數、正態概率和區間之間換算。





## 開始使用



1. 按示例填寫數值，或輸入你自己的測量值。
2. 計算後可複製結果或下載明細。







## 示例



### 輸入



```
觀測值 18，均值 23，標準差 4
```



### 預期結果



```
z = −1.25
```

## 計算方法



標準分數等於（x − μ）除以 σ。左尾爲 z 處的正態分佈函數。對稱區域反查時返回非負邊界。



$$
z=\frac{x-\mu}{\sigma},\qquad P(a<Z<b)=\Phi(b)-\Phi(a)
$$
