# 三平方の定理計算機



二辺の長さまたは二乗から a² + b² = c² を解きます。





## 使い方



1. 異なる二辺の長さまたはその二乗を入力してください。







## 例



### 入力



```
a² = 7、c² = 32
```



### 期待される結果



```
b² = 32 − 7 = 25 なので b = 5 です。
```

## 注意点



処理はブラウザ内で実行されます。単位をそろえて入力してください。







## 計算方法



斜辺を求めるときは直角を挟む二辺の二乗を足します。一辺を求めるときは斜辺の二乗から他方の辺の二乗を引きます。辺の長さは正です。



$$
c=\sqrt{a^2+b^2},\quad a=\sqrt{c^2-b^2},\quad b=\sqrt{c^2-a^2}
$$
