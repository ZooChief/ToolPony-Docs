# Fraction calculator guide



Use exact arithmetic to add, subtract, multiply, divide or simplify fractions and mixed numbers.





## Example



### Input



```
1 1/2 + 2/3
```



### Expected result



```
13/6
```







## Try it

[Open full tool · Fraction calculator](<https://toolpony.com/en/tools/fraction-calculator/>)





## Calculation method



Decimals are read as exact fractions. Arithmetic uses BigInt and reduces by the greatest common divisor. The decimal result is approximate.



$$
\frac{a}{b}+\frac{c}{d}=\frac{ad+bc}{bd},\qquad b,d\ne0
$$







## Calculation mode





### Arithmetic



- First number
- Operation · Add / Subtract / Multiply / Divide
- Second number







### Simplify or convert



- Number







### Fraction to decimal



- Fraction or mixed number
- Decimal places
