# Rechner für Permutationen und Kombinationen



Berechnen Sie exakt geordnete und ungeordnete Auswahlen mit oder ohne Wiederholung.





## Erste Schritte



1. Verwenden Sie das Beispiel oder geben Sie eigene Werte ein.
2. Berechnen Sie das Ergebnis und kopieren oder laden Sie die Details herunter.







## Beispiel



### Eingabe



```
n = 10, r = 3, ohne Wiederholung
```



### Erwartetes Ergebnis



```
720 Permutationen; 120 Kombinationen
```

## Hinweise



Die Verarbeitung erfolgt im Browser. Verwenden Sie einheitliche Einheiten.







## Berechnungsmethode



Ohne Wiederholung sind nPr = n!/(n-r)! und nCr = nPr/r!. Bei Wiederholung sind geordnete Entscheidungen nr und ungeordnete Entscheidungen C(n+r-1,r).
