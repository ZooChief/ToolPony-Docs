# CSV 비교



이전 표와 새 표를 붙여넣거나 가져오세요. 첫 행은 머리글로 두고 구분자와 키 열을 고르세요. 표를 비교하고 변경을 필터링하세요. 스프레드시트에는 CSV, 원문을 보존하는 전체 보고서에는 JSON을 사용합니다.





## 시작하기



1. 이전 표와 새 표를 붙여넣거나 가져오세요. 첫 행은 머리글로 두고 구분자와 키 열을 고르세요.
2. 표를 비교하고 변경을 필터링하세요. 스프레드시트에는 CSV, 원문을 보존하는 전체 보고서에는 JSON을 사용합니다.







## 예시



### 입력



```
ID,Name,Qty
001,Oak,2
002,Pine,1
004,Ash,3

Qty,ID,Name
4,001,Oak
1,003,Fir
3,004,Ash
```



### 예상 결과



```
추가 1 · 누락 1 · 변경 1
```

## 열 순서가 바뀐 두 재고 목록 대조하기



1. 재고 예제를 불러와 ID를 키로 선택합니다. 이전 파일의 열은 ID, Name, Qty 순서이고 새 파일은 Qty부터 시작합니다. 두 파일을 비교하세요.
2. 001(Oak)의 수량은 2에서 4로 바뀌고 002는 삭제, 003은 추가, 004는 그대로입니다. 열 순서가 달라도 변경, 삭제, 추가가 각각 1건입니다.
3. 새 파일에서 001만 1로 바꾸고 다시 비교하면 추가 2건, 삭제 2건, 변경 0건입니다. 같은 품목의 수량을 비교하려면 원본 내보내기에서 앞자리 0을 보존하세요.

## 제한 사항



표당 UTF-8 1 MiB, 데이터 행 5,000개 및 열 80개까지 지원합니다. 앞자리 0을 포함해 텍스트를 그대로 비교합니다. 중복 키와 빈 키는 따로 표시하며 머리글부터 레코드 번호를 셉니다.



재고를 비교할 때는 고정된 SKU를 키로 쓰세요. 이전 파일의 0012가 새 파일에서 12로 바뀌면 삭제 1건과 추가 1건으로 표시됩니다. 같은 상품의 수량 변경을 비교하려면 두 파일 모두 앞자리 0을 유지하세요.
