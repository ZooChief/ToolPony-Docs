# 순열과 조합 계산기



반복 유무에 관계없이 정확한 주문 및 주문되지 않은 선택을 계산합니다.





## 시작하기



1. 예제 값을 사용하거나 원하는 값을 입력하세요.
2. 계산한 결과를 복사하거나 세부 정보를 내려받을 수 있습니다.







## 예시



### 입력



```
n=10, r=3, 반복 없이
```



### 예상 결과



```
720 순열; 120 조합
```

브라우저에서 처리합니다. 단위를 일관되게 사용하세요.







## 계산 방법



반복 없이, nPr = n!/ (n−r)! 그리고 nCr = nPr/r!. 반복으로, 순서된 선택은 nr이고 순서 없는 선택은 C (n+r-1,r)입니다.
