# 体積計算機



球体、円錐形、タンク、カプセル、キャップ、楕円体、ピラミッド、および混合寸法の中空チューブを解く。





## 使い方



1. 例を使うか、任意の値を入力します。
2. 計算後、結果をコピーするか詳細をダウンロードできます。







## 例



### 入力



```
半径2mの球体
```



### 期待される結果



```
≈33.5103 m³
```







## 試してみる



[ツール全体を開く](<https://toolpony.com/ja/tools/volume-calculator/>)







## 注意点



処理はブラウザ内で実行されます。単位をそろえて入力してください。







## 計算方法



プリズムの体積は、その基部面積が垂直な高さのときである。 円錐形またはピラミッド型は、その製品を3つに分ける。 中空管が内円筒を引き算する。 球形キャップは任意の2次元を許容する。



$$
V_{\mathrm{cone}}=\tfrac13\pi r^2h,\qquad V_{\mathrm{sphere}}=\tfrac43\pi r^3
$$
