# PDF を JPG・PNG に変換



指定した PDF ページを最大 300 DPI の画像に変換します。





## 使い方



1. PDF を選び、サムネイルかページ番号で範囲を指定します。
2. JPG または PNG と解像度を選び、画像または ZIP を保存します。







## 例



### 入力



```
612 × 792 pt の 1 ページ、PNG、144 DPI
```



### 期待される結果



```
1224 × 1584 ピクセルの PNG
```







## 試してみる



[ツール全体を開く](<https://toolpony.com/ja/tools/pdf-to-jpg/>)







## 制限



入力は 30 MB・300 ページまで。1 回に 40 ページ・6000 万画素まで、1 ページは 2400 万画素・一辺 8192 ピクセルまで。ZIP 内の画像は 64 MB まで。白い背景で変換し、暗号化 PDF は対象外です。

[ドキュメント](https://docs.toolpony.com/ja/guides/pdf-to-jpg/)
