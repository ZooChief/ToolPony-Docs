# 부피 계산기



치수로 탱크의 용량과 입체의 부피를 구합니다. 속이 빈 관은 안쪽과 바깥쪽 반지름을 입력해 관 벽의 부피를 계산합니다. 리터나 세제곱 단위를 선택하세요.





## 예시



### 입력



```
반경 2개 m를 가진 구체
```



### 예상 결과



```
≈33.5103 m³
```





<a id="case-study"></a>



## 원통형 탱크의 수위선까지 담기는 물의 양 계산하기



1. 탱크 안지름과 수위선까지의 깊이를 잽니다. 안지름 1 m, 깊이 1.2 m 예제를 계산하면 원기둥 모드의 반지름이 0.5 m, 출력 단위가 L로 설정됩니다.
2. 용량은 π × 0.5² × 1.2 m³, 약 942.48 L입니다. 반지름 칸에 지름을 입력하면 제곱 항 때문에 결과가 4배가 됩니다.
3. 수위선을 0.2 m 낮춰 깊이를 1 m로 바꾸면 약 785.40 L입니다. 두 수위선 사이의 용량은 그 차이인 약 157.08 L입니다.

## 계산 방법



프리즘의 부피는 기본 면적 시간 수직 높이입니다. 원뿔 또는 피라미드는 해당 제품을 세 개로 나눕니다. 중공 튜브는 내부 실린더를 뺍니다. 구형 캡은 두 가지 차원을 허용합니다.



$$
V_{\mathrm{cone}}=\tfrac13\pi r^2h,\qquad V_{\mathrm{sphere}}=\tfrac43\pi r^3
$$
