# 電費計算器



按設備、平均負載與電價，估算固定天數或日、周、月、年電費。





## 開始使用



1. 填設備輸入功率、運行時間與電價。電器預設填入可修改的示例值。







## 示例



### 輸入



```
1,000 W，每天 2 小時，30 天，每度 0.2
```



### 預期結果



```
用電 60 度，電費 12
```

## 使用提示



計算在瀏覽器內完成。無單位標記的字段請使用一致單位。







## 計算方法



電量等於千瓦功率乘運行小時、平均負載和設備數。電費按固定單價算。週期估算使用每月 30.44 天、每年 365.25 天。製冷量表示傳熱能力，算電費用電氣輸入功率。



$$
E_{\rm kWh}=P_{\rm kW}\,t_{\rm h}\,f\,n,\qquad C=E_{\rm kWh}\,r
$$







## 計算模式



**固定天數**

- 功率
- 功率單位 · W / kW / BTU/h / PS / TR
- 平均負載 · %
- 設備數量
- 每天運行小時 · h
- 天數
- 每度電單價





**日到年費用**

- 電器預設
- 功率
- 功率單位 · W / kW / BTU/h / PS / TR
- 平均負載 · %
- 設備數量
- 使用時長
- 使用時長單位 · 分鐘/天 / 每天運行小時 / 小時/周 / 小時/月 / 天/周 / 天/月 / 天/年 / 月/年
- 每度電單價
