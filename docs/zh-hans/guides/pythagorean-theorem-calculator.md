# 勾股定理计算器



输入任意两边的长度或平方，解出 a² + b² = c²。





## 开始使用



1. 请输入两条不同边的长度或平方。







## 示例



### 输入



```
a² = 7，c² = 32
```



### 预期结果



```
b² = 32 − 7 = 25，因此 b = 5。
```

## 计算方法



求斜边时将两直角边的平方相加。求直角边时用斜边平方减去另一条直角边平方。边长须为正。



$$
c=\sqrt{a^2+b^2},\quad a=\sqrt{c^2-b^2},\quad b=\sqrt{c^2-a^2}
$$
