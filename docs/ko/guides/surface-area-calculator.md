# 겉넓이 계산기 사용 가이드



입체의 표면적을 계산합니다. 탱크나 관처럼 평평한 단면이 있는 입체는 덮을 면을 골라 면적을 비교할 수 있습니다.





## 예시



### 입력



```
반경 2개 m를 가진 구체
```



### 예상 결과



```
≈50.2655 m²
```





<a id="case-study"></a>



## 뚜껑 없는 수조의 안감



1. 안쪽 길이 120 cm, 너비 0.8 m, 깊이 450 mm를 입력합니다. 옆면과 한쪽 단면을 선택해 네 벽과 바닥을 덮습니다.
2. 벽은 1.80 m², 바닥은 0.96 m²로 이음매와 손실을 제외한 합계는 2.76 m²입니다. 모든 면을 선택하면 뚜껑을 더해 3.72 m²가 됩니다.

## 계산 방법



닫힌 표면에는 모든 단면이 포함됩니다. 단면적은 각각의 치수로 구하며 타원체의 표면적은 대칭 타원 적분으로 수치 계산합니다.



$$
A_{\mathrm{cylinder}}=2\pi r^2+2\pi rh,\qquad A_{\mathrm{sphere}}=4\pi r^2
$$
