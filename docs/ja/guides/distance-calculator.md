# 距離計算機



2 次元・3 次元の 2 点間の距離を求めるか、緯度と経度から地表に沿った距離を推定します。





## 使い方



1. 例を使うか、任意の値を入力します。
2. 計算後、結果をコピーするか詳細をダウンロードできます。







## 例



### 入力



```
2D:(0)、0)から(3、4)
```



### 期待される結果



```
距離5
```

## 注意点



処理はブラウザ内で実行されます。単位をそろえて入力してください。







## 計算方法



カルテシア距離はユークリディアンの標準を使用している。 地理的モードでは、WGS 84楕円体とランバートの近似値を使用します。 ほぼ反ポダル点は球形近似を使用する。 これは表面的な推定値です。



$$
d=\sqrt{(x_2-x_1)^2+(y_2-y_1)^2+(z_2-z_1)^2}
$$



既に線形スケールを共有する座標には、2Dまたは3Dモードを使用してください。 両方のポイントを最初に同じ単位に変換します。



地理的座標については、北と東は陽性である。 アンケートで別々の角フィールドが与えられる場合は、1秒程度のモードを使用してください。 結果は楕円表面の経路を推定する。
