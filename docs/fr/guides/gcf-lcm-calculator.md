# Calculatrice de PGCD et PPCM



Trouver le facteur le plus commun et le moins commun multiple pour une liste de grands entiers.





## Prise en main



1. Utilisez l’exemple ou saisissez vos propres valeurs.
2. Calculez, puis copiez le résultat ou téléchargez les détails.







## Exemple



### Entrée



```
12, 18, 24
```



### Résultat attendu



```
GCF 6; LCM 72
```







## Essayer



[Ouvrir l’outil complet](<https://toolpony.com/fr/tools/gcf-lcm-calculator/>)







## Notes



Le traitement se fait dans le navigateur. Utilisez des unités cohérentes.







## Méthode de calcul



L'algorithme d'Euclide trouve GCF. LCM(a,b) =====a.b=== GCF(a,b) lorsque les deux ne sont pas zéro. Jusqu'à 100 entiers de 50 chiffres chacun.
