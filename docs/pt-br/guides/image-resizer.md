# Redimensionar imagens



Escolha uma imagem. Informe a largura ou a altura. Mantenha a proporção para evitar distorção. Redimensione e baixe o PNG.





## Primeiros passos



1. Escolha uma imagem.
2. Informe a largura ou a altura. Mantenha a proporção para evitar distorção.
3. Redimensione e baixe o PNG.







## Exemplo



### Entrada



```
1600 × 1200, largura 800, manter proporção
```



### Resultado esperado



```
PNG de 800 × 600
```







## Experimente



[Abrir ferramenta completa](<https://toolpony.com/pt-br/tools/image-resizer/>)







## Limites



Até 20 MB, 24 megapixels e 8.192 pixels por lado. Ampliar a imagem não recupera detalhes ausentes.

[Documentação](https://docs.toolpony.com/pt-br/guides/image-resizer/)
