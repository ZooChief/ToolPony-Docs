# Halbwertszeit-Rechner



Lösen Sie den exponentiellen Zerfall aus drei beliebigen Messungen oder konvertieren Sie zwischen Halbwertszeit, mittlerer Lebensdauer und Zerfallskonstante.





## Erste Schritte



1. Verwenden Sie das Beispiel oder geben Sie eigene Werte ein.
2. Berechnen Sie das Ergebnis und kopieren oder laden Sie die Details herunter.







## Beispiel



### Eingabe



```
100 bis 10 in 50 Zeiteinheiten
```



### Erwartetes Ergebnis



```
Halbwertszeit ≈ 15.0515
```

## Hinweise



Die Verarbeitung erfolgt im Browser. Verwenden Sie einheitliche Einheiten.







## Berechnungsmethode



Exponentieller Zerfall ist N(t) = N0 · 2^(-t/T). T ist Halbwertszeit, mittlere Lebensdauer ist T/ln(2) und die Zerfallskonstante ist ln(2)/T. Die Umrechnung verwendet ln(2) auf zehn Dezimalstellen gerundet. Verwenden Sie die gleiche Zeiteinheit für alle Felder.



$$
N(t)=N_0\,2^{-t/T},\qquad \lambda=\frac{\ln 2}{T},\qquad \tau=\frac1\lambda
$$



Wähle zuerst die gesuchte Größe und verwende in den anderen drei Feldern dieselbe Zeiteinheit. Bei einem Anfangswert von 100 und einer Halbwertszeit von 10 bleiben nach 20 Zeiteinheiten 25 übrig.







## Berechnungsmodus



**Halbwertszeit finden**

- Verbleibende Menge
- Ursprüngliche Menge
- Verstrichene Zeit





**Restmenge finden**

- Ursprüngliche Menge
- Verstrichene Zeit
- Halbwertszeit





**Anfangsmenge finden**

- Verbleibende Menge
- Verstrichene Zeit
- Halbwertszeit





**Fällige Zeit finden**

- Verbleibende Menge
- Ursprüngliche Menge
- Halbwertszeit





**Umrechnungs-Zerfallsmaßnahmen**

- Bekannte Messungen · Halbwertszeit / Mittlere Lebensdauer / Abnahmekonstante
- Wert
