# 直角三角形計算機



高さ、面積、周長など二つの値から直角を挟む辺、斜辺、角度を求めます。





## 使い方



1. 長さ、面積、周長のいずれかを含む二つの値を入力してください。
2. 二つの解では直角を挟む二辺と鋭角のラベルが入れ替わります。







## 例



### 入力



```
c = 5、h = 2.4
```



### 期待される結果



```
直角を挟む辺は 3 と 4、面積は 6、周長は 12。a はどちらの辺でも構いません。
```

## 注意点



処理はブラウザ内で実行されます。単位をそろえて入力してください。







## 計算方法



c は斜辺、h は斜辺への垂線の長さです。長さの単位を統一し、面積にはその平方単位を使います。



$$
c^2=a^2+b^2,\quad h=ab/c,\quad S=ab/2,\quad P=a+b+c
$$



$$
a,b=\frac{\sqrt{c^2+2ch}\;\pm\;\sqrt{c^2-2ch}}{2}
$$
