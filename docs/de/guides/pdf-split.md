# PDF aufteilen



Wählen Sie Seiten und speichern Sie sie als PDF oder ZIP.





## Erste Schritte



1. Wählen Sie eine unverschlüsselte PDF.
2. Wählen Sie Miniaturen oder geben Sie Seitenbereiche wie 5, 1-3 ein.
3. Wählen Sie eine PDF, eine Datei je Bereich oder eine je Seite.
4. Teilen Sie auch nach Seitenanzahl oder Dateigröße. Das Limit gilt für die geschriebenen PDFs. Die Inhalte werden nicht neu komprimiert.







## Beispiel



### Eingabe



```
PDF mit 5 Seiten, Auswahl 5, 1-3
```



### Erwartetes Ergebnis



```
Eine PDF mit Seiten 5, 1, 2 und 3 in dieser Reihenfolge
```







## Ausprobieren



[Vollständiges Werkzeug öffnen](<https://toolpony.com/de/tools/pdf-split/>)







## Grenzen



Bis zu 30 MB und 300 Seiten. Jede Seite darf nur einmal vorkommen. Die PDF-Dateien im ZIP dürfen zusammen 64 MB nicht überschreiten. Formulare, Lesezeichen und Signaturen können verloren gehen.
