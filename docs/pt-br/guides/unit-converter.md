# Conversor de unidades



Converter comprimento, massa, área, volume, temperatura, velocidade, energia, dados e outras unidades.





## Primeiros passos



1. Use o exemplo ou insira seus próprios valores.
2. Calcule, copie o resultado ou baixe os detalhes disponíveis.







## Exemplo



### Entrada



```
Converter 1 m em ft
```



### Resultado esperado



```
□3,28084 pés
```

## Notas de uso



O cálculo é feito no seu navegador. Use unidades consistentes.







## Método de cálculo



Cada grupo converte através de uma unidade de base padrão. U.S. e unidades de volume imperiais são separadas. unidades de armazenamento decimais e binárias manter suas respectivas bases.
