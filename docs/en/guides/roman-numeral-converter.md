# Roman numeral converter



Convert Roman numerals and integers in either direction, including dates or delimited lists.





## Get started



1. Use the example values or enter your own measurements.
2. Calculate, then copy the result or download the available details.







## Example



### Input



```
MCMXCIX
```



### Expected result



```
1999
```







## Try it



[Open full tool](<https://toolpony.com/en/tools/roman-numeral-converter/>)







## Good to know



The calculation runs in your browser. Use consistent units in fields with no explicit unit.







## Calculation method



The converter uses standard subtractive pairs such as IV and CM. An overline multiplies a group by 1,000. Enter an underscore before each overlined letter, or paste the overline itself. Values are limited to 1–3,999,999. Date mode converts each field and preserves separators.







## Calculation mode



**Single value**

- Integer or Roman numeral





**Date or list**

- Values or date
