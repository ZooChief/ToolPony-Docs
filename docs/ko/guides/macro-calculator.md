# 다량 영양소 계산기 사용 가이드



칼로리 목표와 영양소 비율을 그램으로 변환하거나 그램에서 에너지와 비율을 계산합니다.





## 예시



### 입력



```
2,000 kcal: 25% 단백질, 45% 탄수화물, 30% 지방
```



### 예상 결과



```
125 g 단백질, 225 g 탄수화물, 66.67 g 지방
```





<a id="case-study"></a>



## 레시피를 3회분으로 나누기



1. 전체 레시피에 단백질 30 g, 탄수화물 60 g, 지방 10 g을 입력하세요. 일반 4/4/9 계수로 450 kcal입니다. 3등분하면 1회 150 kcal이며 각 영양소는 10 g, 20 g, 약 3.33 g입니다.
2. 포장 식품 표시는 식이섬유나 당알코올에 별도 환산 계수를 사용할 수 있어 같은 그램 수라도 열량이 달라질 수 있습니다.



[예제 실행](<https://toolpony.com/ko/tools/macro-calculator/#example-three-servings>)

## 계산 방법



일반 에너지 환산 계수는 단백질과 탄수화물 4 kcal/g, 지방 9 kcal/g입니다. 비율 하나를 비우면 100%까지 자동으로 채웁니다. 균등하게 나눌 때 각 영양소와 열량을 같은 제공 횟수로 나눕니다.







## 계산 모드





### 열량에서 그램으로



- 총열량 · kcal
- 단백질 · %
- 탄수화물 · %
- 지방 · %
- 나머지를 채울 항목 · 빈 항목에서 결정 / 수동 / 단백질 / 탄수화물 / 지방
- 제공량 수







### 그램에서 열량으로



- 단백질 · g
- 탄수화물 · g
- 지방 · g
- 제공량 수
