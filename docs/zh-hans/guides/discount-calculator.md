# 折扣计算器



叠加多个折扣、减去固定优惠券，并对折后价格计税。





## 开始使用



1. 按示例填写数值，或输入你自己的测量值。
2. 计算后可复制结果或下载明细。







## 示例



### 输入



```
原价 100，先减 20% 再减 10%
```



### 预期结果



```
折后 72，相当于减 28%
```

## 使用提示



计算在浏览器内完成。无单位标记的字段请使用一致单位。







## 计算方法



依次应用百分比折扣，再减固定优惠，最后计税。最多 10 个 0% 至 100% 的折扣率。



连续打八折和九折，剩下原价的 0.8 × 0.9。按顺序填写折扣率，再按需添加优惠券或税。



已知折后价或节省金额时可用反推模式。反推采用单个税前折扣。







## 计算模式



**应用折扣**

- 原价
- 减免百分比列表
- 固定优惠金额
- 税率 · %





**反推原价**

- 折后价
- 折扣类型 · 百分比 / 固定金额
- 折扣





**求折扣率与节省金额**

- 原价
- 已知金额 · 折后价 / 节省金额
- 金额





**由节省金额求价格**

- 节省金额
- 折扣率 · %
