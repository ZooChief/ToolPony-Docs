# Convertir PDF a JPG o PNG



Convierte páginas de PDF a imágenes de hasta 300 DPI.





## Primeros pasos



1. Elige un PDF y selecciona las páginas por miniatura o número.
2. Elige JPG o PNG y la resolución. Guarda una imagen o un ZIP.







## Ejemplo



### Entrada



```
Una página de 612 × 792 pt, PNG, 144 DPI
```



### Resultado esperado



```
Un PNG de 1224 × 1584 píxeles
```







## Pruébalo



[Abrir herramienta completa](<https://toolpony.com/es/tools/pdf-to-jpg/>)







## Límites



Entrada de hasta 30 MB y 300 páginas. Máximo de 40 páginas y 60 megapíxeles por exportación, con 24 megapíxeles y 8192 píxeles por lado en cada página. Las imágenes del ZIP se limitan a 64 MB. El fondo es blanco. Se rechazan los PDF cifrados.

[Documentación](https://docs.toolpony.com/es/guides/pdf-to-jpg/)
