# JPG to PDF



Add up to 20 pictures, arrange their order, and choose paper size, orientation and margins. Each image becomes one PDF page. Download the combined document.





## Get started



1. Add pictures from your device.
2. Use the arrows to set page order. Choose A4, US Letter, or image-sized pages.
3. Create and download the PDF.







## Example



### Input



```
A landscape JPG, then a portrait PNG → A4, automatic orientation
```



### Expected result



```
Two PDF pages in that order; the first landscape, the second portrait.
```







## Try it



[Open full tool](<https://toolpony.com/en/tools/jpg-to-pdf/>)







## Good to know



Each picture occupies one centered page without stretching. Transparent areas become white. Browser decoding applies image orientation; JPEG images are encoded again. Image-sized pages use one PDF point per image pixel and ignore margin/orientation choices. Files are not uploaded.







## Limits



30 MB total input, 20 MB per image, 24 megapixels per image and 60 megapixels combined. Encoded images are limited to 64 MB. Supports browser-decodable JPG, PNG, WebP, AVIF and GIF; animation becomes one frame. Transparency is flattened onto white, JPEG is re-encoded and metadata is removed.
