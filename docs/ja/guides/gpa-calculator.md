# GPA 計算機



コース加重GPAを計算する、過去の単位やグループ学期を含める、または目標に到達するために必要なGPAを計算する。





## 使い方



1. 例を使うか、任意の値を入力します。
2. 計算後、結果をコピーするか詳細をダウンロードできます。







## 例



### 入力



```
数学、3、A、英語、3、B
```



### 期待される結果



```
GPA 3.5
```







## 試してみる



[ツール全体を開く](<https://toolpony.com/ja/tools/gpa-calculator/>)







## 注意点



処理はブラウザ内で実行されます。単位をそろえて入力してください。







## 計算方法



GPAは、総成績点の単位単位を合計単位で割ったものです。 文字の成績は、表示された4.3点スケールを使用します。 パーセンテージモードは直接パーセンテージを平均します。 他の学校の体重計には明示的なポイントを使用してください。



$$
\operatorname{GPA}=\frac{\sum_i g_i c_i}{\sum_i c_i}
$$



1行につき1つのコースを入力してください。 第四列は、コースを学期ごとにグループ化できます。 第五に、コースに明示的な1クレジット単位ボーナスが追加されます。 既存のレコードを追加する際に、以前のGPAとクレジットを一緒に入力してください。



A+ は F を介して 4.3 点のマッピングを使用します。 P、NP、I、およびWは重み付けされた合計から省略される。 ポイントモードを使用して、学校固有の数値スケールに従います。







## 計算モード



**コースの成績**

- コース、単位、成績、任意科目およびボーナス
- グレード形式 · 手紙 / パーセンテージ / ポイント
- 既存の GPA
- 過去のクレジット





**計画目標GPA**

- 現在のGPA
- ターゲットGPA
- クレジットの完了
- 追加クレジット
