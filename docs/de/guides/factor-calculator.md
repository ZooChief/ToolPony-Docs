# Teilerrechner



Listen Sie jeden positiven Teiler, alle Faktorpaare und die Primfaktorisierung auf.





## Erste Schritte



1. Verwenden Sie das Beispiel oder geben Sie eigene Werte ein.
2. Berechnen Sie das Ergebnis und kopieren oder laden Sie die Details herunter.







## Beispiel



### Eingabe



```
120
```



### Erwartetes Ergebnis



```
16 positive Teiler, darunter 1 und 120
```







## Ausprobieren



[Vollständiges Werkzeug öffnen](<https://toolpony.com/de/tools/factor-calculator/>)







## Hinweise



Die Verarbeitung erfolgt im Browser. Verwenden Sie einheitliche Einheiten.







## Berechnungsmethode



Jeder kleine Teiler d paart sich mit n/d, so dass die Suche nach √n jedes Paar findet.



$$
d\mid n\iff n\bmod d=0,\qquad n=d\cdot(n/d)
$$
