# 복리 계산기 사용 가이드



반복되는 기여와 인플레이션으로 균형을 투사하거나 복리 주파수 간에 변환하십시오.





## 예시



### 입력



```
10 년 동안 매년 5 %에서 10,000
```



### 예상 결과



```
16,288.95
```





<a id="case-study"></a>



## 30개월 적립 시점 비교



1. 원금 10,000에 2년 6개월 동안 매월 100을 적립합니다. 연 6% 월복리에서 월말 납입 잔액은 14,842.00이고 총 납입액은 13,000입니다. 월초로 옮기면 14,858.14입니다. 연 물가상승률이 3%라면 월말 납입 잔액의 현재 구매력은 13,784.77입니다.

## 계산 방법



실효 연간 성장률은 (1+r/m)^m−1이며 연속 복리에서는 exp(r)−1입니다. 추가 납입금에는 각 기간의 시작 또는 종료 중 선택한 시점부터 이자가 붙습니다.



$$
A=P(1+r/m)^{mt},\qquad \mathrm{APY}=(1+r/m)^m-1
$$
