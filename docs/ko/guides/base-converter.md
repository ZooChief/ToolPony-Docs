# 진법 변환 및 계산기



데이터베이스(2–36) 사이에 서명된 정수를 변환하고 정확한 산술, 나머지 또는 비트별 연산을 수행합니다.





## 예시



### 입력



```
FF, 기초 16에 기초 10
```



### 예상 결과



```
255
```







## 직접 사용해 보기

[전체 도구 열기 · 진법 변환 및 계산기](<https://toolpony.com/ko/tools/base-converter/>)





## 계산 방법



BigInt는 정수 정밀도를 유지합니다. 나눗셈은 0 방향으로 버립니다. 비트 연산에는 부호 있는 BigInt 규칙을 사용합니다. 각 피연산자는 최대 256자리입니다.







## 계산 모드



**Convert 기초**

- 정수
- 입력 기초
- 출력 기초
- 최소 출력 자릿수





**정수 산술**

- 첫 번째 정수
- 두 번째 정수
- 입력 기초
- 출력 기초
- 최소 출력 자릿수
- 연산 · 추가 / 뺄셈 / Multiply / Divide는 / 나머지 / AND / OR / XOR
