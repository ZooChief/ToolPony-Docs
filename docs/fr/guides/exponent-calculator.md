# Calculatrice de puissances



Résolvez pour une puissance, la base ou l'exposant des deux autres valeurs.





## Exemple



### Entrée



```
Base 2, exposant 5
```



### Résultat attendu



```
32
```







## Essayer

[Ouvrir l’outil complet · Calculatrice de puissances](<https://toolpony.com/fr/tools/exponent-calculator/>)





## Méthode de calcul



Pour y = bn, résolvez l'exposant avec des logarithmes lorsque b et y sont positifs et b 1. Résoudre pour une base réelle avec un exposant non zéro même entier peut produire deux racines.



$$
y=b^p,\qquad p=\frac{\ln y}{\ln b},\qquad b=\sqrt[p]{y}
$$







## Mode de calcul



**Puissance**

- Base
- Exposant





**Base**

**Exposant**

- Base
- Valeur de puissance
