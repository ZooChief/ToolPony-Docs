# 単位変換の使い方



長さ、質量、面積、体積、温度、速度、エネルギー、データなど、さまざまな単位を変換する。





## 例



### 入力



```
1 m を ft に変換
```



### 期待される結果



```
≈3.28084フィート
```





<a id="case-study"></a>



## 温度変化を確かめる



1. 20 °C から 10 °C に下がったときは温度差を選び、−10 °C を入力します。変化量は −18 °F、10 °C 自体の温度は 50 °F です。





## 1 TB のドライブを GiB で見る



1 TB は 1,000,000,000,000 バイトです。1 GiB の 1,073,741,824 バイトで割ると、フォーマット前の容量は約 931.32 GiB です。画面と CSV で全桁を確認できます。



[入力例を実行](<https://toolpony.com/ja/tools/unit-converter/#example-drive-capacity>)







## 3/8 インチの継手



3/8 インチと入力すると 9.525 mm です。帯分数も使え、1 3/8 インチは 34.925 mm です。



[入力例を実行](<https://toolpony.com/ja/tools/unit-converter/#example-fractional-inch>)

## 計算方法



定義された換算比は分数で厳密に計算します。循環小数は丸めた値と元の分数を併記します。ラジアンと他の角度単位の換算には π の近似値を使います。
