# 거리 계산기



2차원 또는 3차원에서 두 점 사이의 거리를 구하거나 위도와 경도로 지표면 거리를 추정합니다.





## 시작하기



1. 예제 값을 사용하거나 원하는 값을 입력하세요.
2. 계산한 결과를 복사하거나 세부 정보를 내려받을 수 있습니다.







## 예시



### 입력



```
2D: (0, 0)에 (3, 4)
```



### 예상 결과



```
거리 5
```







## 직접 사용해 보기



[전체 도구 열기](<https://toolpony.com/ko/tools/distance-calculator/>)







## 참고 사항



브라우저에서 처리합니다. 단위를 일관되게 사용하세요.







## 계산 방법



데카르트 거리는 유클리드 규범을 사용합니다. 지리적 모드는 WGS 84 타원과 램버트의 근사치를 사용합니다. 거의 antipodal 점은 둥근 근사치를 사용합니다. 이것은 표면 추정치입니다.



$$
d=\sqrt{(x_2-x_1)^2+(y_2-y_1)^2+(z_2-z_1)^2}
$$



이미 선형 스케일을 공유하는 좌표에 대해 2D 또는 3D 모드를 사용합니다. 두 점을 먼저 동일한 유닛으로 변환합니다.



지리적 좌표의 경우 북쪽과 동쪽은 긍정적입니다. 설문조사에서 별도의 각진 필드를 제공하는 경우 정도-분-초 모드를 사용합니다. 결과는 타원 표면 경로를 추정합니다.







## 계산 모드



**2D**

- X1
- Y1
- X2
- Y2





**3D**

- X1
- Y1
- Z1
- X2
- Y2
- Z2





**위도와 경도**

- 첫 번째 위도 · °
- 첫 번째 경도 · °
- 제2위위 · °
- 두 번째 경도 · °





**학위, 분 및 초**

- 첫 위도도
- 첫 위도 분
- 첫 위도 초
- 제1위도 반구 · N / S
- 첫 경도 정도
- 첫 경도 분
- 첫 경도 초
- 첫 번째 경도 반구 · E / W
- 제2위도
- 두 번째 위도 시간
- 두 번째 위도 초
- 제2위도 반구 · N / S
- 두 번째 경도도
- 두 번째 경도 분
- 두 번째 경도 초
- 제2의 경도 반구 · E / W
