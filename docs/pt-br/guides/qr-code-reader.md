# Leitor de QR Code



Escolha, solte ou cole uma imagem. Na ferramenta independente você também pode ligar a câmera. Confira o texto e copie ou baixe. Verifique o endereço antes de abrir um link.





## Primeiros passos



1. Escolha, solte ou cole uma imagem. Na ferramenta independente você também pode ligar a câmera.
2. Confira o texto e copie ou baixe. Verifique o endereço antes de abrir um link.







## Exemplo



### Entrada



```
Ler exemplo
```



### Resultado esperado



```
https://example.com/qr-sample
```

## Limites



Um QR Code por leitura. Imagens de até 20 MiB e 24 megapixels, incluindo PNG, JPEG, WebP e SVG compatíveis. A câmera requer permissão e para após ler. As imagens ficam no seu dispositivo.

[Documentação](https://docs.toolpony.com/pt-br/guides/qr-code-reader/)
