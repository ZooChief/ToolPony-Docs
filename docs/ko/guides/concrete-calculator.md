# 콘크리트 물량 계산기



슬래브, 발판, 튜브, 연석 및 계단에 대한 콘크리트 부피, 무게 및 전체 가방을 추정합니다.





## 시작하기



1. 각 측정에 대해 일치하는 모양과 설정 단위를 선택하십시오. 튜브는 외부 및 내부 직경을 사용합니다.
2. 계단의 경우 상승 횟수와 상단 플랫폼의 길이를 별도로 입력하십시오. 다른 모양에 대해 동일한 조각의 수를 사용하십시오.
3. 알려진 경우 기본 밀도를 재료 레이블의 값으로 바꿉니다. 주문에 전체 가방 테이블을 사용하십시오.







## 예시



### 입력



```
7 ft × 3 ft × 5에서 석판, 양 2
```



### 예상 결과



```
17.5 ft³, 밀도 133 lb/ft³에서 2,327.50 lb
```

## 계산 방법



볼륨은 단면적 시간 길이와 같습니다. 기본값은 파운드의 경우 133lb/ft3, 킬로그램의 경우 2,130kg/m3를 사용합니다. 사용자 정의 밀도는 하나의 값에서 두 결과를 변환합니다. 전체 가방에 주문을 반올림하기 전에 수당을 추가하십시오.



$$
V_{\rm slab}=lwhq,\quad V_{\rm tube}=\pi hq(d_o^2-d_i^2)/4
$$



$$
V_{\rm stairs}=brn\left[p+u(n-1)/2\right],\qquad m=V\rho
$$



계단 공식에서 b는 너비, r 상승, u 수평 실행, n 상승 수, 상단 플랫폼의 깊이 p입니다. 솔리드 볼륨에는 n−1 트레드와 상단 플랫폼이 포함됩니다.



7 ft × 3 ft × 5 in 슬래브 2개의 밀도가 133 lb/ft³이면 무게는 2,327.50 lb입니다. 60 lb 포대 38.79개에 해당하며 여유분을 더하기 전 주문 표에서는 39개로 올림합니다.
