# 멀칭재 계산기



한 구역 또는 여러 구역의 멀칭재 부피, 포대 수, 비용을 계산합니다.





## 시작하기



1. 총면적 또는 한 줄당 사각형 하나를 6, 2, m처럼 입력하세요. 줄마다 다른 단위를 쓸 수 있습니다.
2. 깊이와 벌크 또는 포대 가격 단위를 선택하세요. 사용자 지정 포대의 용량은 추가 옵션에 입력하세요.







## 예시



### 입력



```
200 ft², 깊이 2 in, 2 ft³ 포대, 단가 5.
```



### 예상 결과



```
33.3 ft³, 17포대, 총비용 85.
```

## 계산 방법



겹치지 않는 구역의 면적을 합한 뒤 깊이와 여유분을 적용합니다. 포대 용량으로 나눠 올림합니다. 벌크 가격은 계산된 부피를 사용합니다.



$$
A=\sum_i l_iw_i,\quad V=Ad(1+a/100),\quad N=\left\lceil\frac{V}{V_{\rm bag}}\right\rceil
$$
