# 内部収益率（IRR）計算機



不規則な年間流量、または終端値、定期預金または出金から年間有効レートを確認してください。





## 使い方



1. 例を使うか、任意の値を入力します。
2. 計算後、結果をコピーするか詳細をダウンロードできます。







## 例



### 入力



```
初期投資 55,000、各期の収入 14,000、18,000、22,000、26,000
```



### 期待される結果



```
IRR ≈ 15.093%
```

## 計算方法



IRRは、正味現在価値をゼロにするレートです。 固定モードのキャッシュフローは、選択した支払い頻度と開始または終了時刻を使用します。 期間の開始支払いも端末境界でカウントされるかどうかを選択してください。 検索率は−99.9999%から10,000%までです。



$$
0=\sum_{i=0}^n\frac{F_i}{(1+r)^{t_i}}
$$







## 計算モード



**不規則な年間流量**

- 初期投資額
- その後の年間キャッシュフロー





**フローとエンディングバランスの固定**

- 初期投資額
- 年月はずっと
- 追加月数
- エンディングバランス
- 支払い額
- 支払いタイプ · 退会 / 入金
- 年間支払い額 · 1 / 2 / 4 / 12 / 24 / 26 / 52
- 支払いのタイミング · 期間の終了 / 期間の始まり
- 端末決済を開始モードに含めてください
