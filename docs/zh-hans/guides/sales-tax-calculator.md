# 销售税与增值税计算器使用指南



按自定义税率计算含税价、未税价与税额。





## 示例



### 输入



```
未税价 100，增值税 20%
```



### 预期结果



```
含税价 120，税额 20
```





<a id="case-study"></a>



## 从小票反推税率



1. 小票上未税价为 200.00，实付 217.00。两者相差 17.00，用未税价作分母可得 8.5%。点「用此税率核算」即可用 200 算回 217。

## 计算方法



含税价 = 未税价 ×（1 + 税率）。税率由用户填写。
