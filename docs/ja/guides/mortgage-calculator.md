# 住宅ローン計算機



固定金利の住宅ローンと頭金、定期費用、追加支払い、隔週返済額を比較してください。





## 使い方



1. 例を使うか、任意の値を入力します。
2. 計算後、結果をコピーするか詳細をダウンロードできます。







## 例



### 入力



```
物件価格 400,000、頭金 20%、期間 30 年、年利 6%
```



### 期待される結果



```
月額元本および利息 ≈1,918.56
```







## 試してみる



[ツール全体を開く](<https://toolpony.com/ja/tools/mortgage-calculator/>)







## 注意点



処理はブラウザ内で実行されます。単位をそろえて入力してください。







## 計算方法



毎月の利息は残元金 × 年利 ÷ 12 です。費用は年額と増加率の入力に従います。このモデルでは残元金が購入時の住宅価格の 80% に達した時点で PMI を終了できます。隔週払いでは年利を 26 で割り、2 週間ごとに月々の返済額の半分を支払う場合と比較します。



$$
I_k=r B_{k-1},\qquad B_k=B_{k-1}-(M_k-I_k)
$$
