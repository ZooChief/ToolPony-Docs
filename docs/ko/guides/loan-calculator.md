# 대출 계산기



분할 상환, 월 상환액에 따른 기간, 날짜별 추가 상환을 계산하고 전체 일정을 내보냅니다.





## 시작하기



1. 고정 기간, 목표 월 상환액 또는 날짜별 추가 상환을 선택하세요.
2. 첫 상환 월을 입력하세요. 일회성 상환은 2026-06, 500처럼 한 줄에 하나씩 추가합니다.
3. 계산 후 내역 표를 전환하고 선택한 표를 내려받으세요.







## 예시



### 입력



```
원금 100,000, 10년, 연 6%, 매월 납입
```



### 예상 결과



```
월 약 1,110.21
```

## 계산 방법



분할 상환은 명목 연이율을 회차 이율로 변환합니다. 날짜별 모드는 월 이자를 적용하고 정기 납입 후 원금에서 추가금을 차감합니다. 고정 금리로 계산하며 중간 값은 반올림하지 않습니다.



$$
M=\frac{Pr}{1-(1+r)^{-n}},\qquad M=\frac Pn\quad(r=0)
$$



$$
n=\frac{-\ln(1-Pr/M)}{\ln(1+r)},\qquad M>Pr\quad(r>0)
$$



$$
I_k=r B_{k-1},\qquad B_k=\max(0,B_{k-1}-(M-I_k)-E_k)
$$



P는 원금, r은 회차 이율, M은 정기 납입액, n은 상환 횟수입니다. 기간 역산과 날짜별 추가 상환에서는 연이율의 백분율을 1,200으로 나눕니다. B는 잔액, I는 이자, E는 원금에서 차감하는 추가금입니다.



원금 45,000, 연 6.3%, 월 785이면 약 68.38개월입니다. 월말 청구는 69회이며 마지막 금액은 더 작습니다. 일정을 선택한 뒤 내려받으세요.
