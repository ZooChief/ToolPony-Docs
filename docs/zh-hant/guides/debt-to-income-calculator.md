# 債務收入比計算器



比較每月固定債務還款與稅前月收入。





## 示例



### 輸入



```
稅前月收入 5,000，月債務還款 1,500
```



### 預期結果



```
30%
```







## 試一試



[打開完整工具](<https://toolpony.com/zh-hant/tools/debt-to-income-calculator/>)







## 計算方法



債務收入比 = 月債務還款額 ÷ 稅前月收入。所有金額請用同一幣種和月度口徑。
