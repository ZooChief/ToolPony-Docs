# CSV 比較



新旧の表を貼り付けるか読み込みます。先頭行をヘッダーにして、区切り文字とキー列を選びます。 比較して変更を絞り込みます。表計算にはCSV、元のテキストを保つ完全な結果にはJSONを使います。





## 使い方



1. 新旧の表を貼り付けるか読み込みます。先頭行をヘッダーにして、区切り文字とキー列を選びます。
2. 比較して変更を絞り込みます。表計算にはCSV、元のテキストを保つ完全な結果にはJSONを使います。







## 例



### 入力



```
ID,Name,Qty
001,Oak,2
002,Pine,1
004,Ash,3

Qty,ID,Name
4,001,Oak
1,003,Fir
3,004,Ash
```



### 期待される結果



```
追加 1 · 削除 1 · 変更 1
```





<a id="case-study"></a>



## 列の順序が変わった 2 つの在庫表を照合する



1. 在庫の例を読み込み、ID をキーに選びます。旧ファイルは ID、Name、Qty の順、新ファイルは Qty が先頭です。2 つを比較します。
2. ID 001（Oak）の数量は 2 から 4 に変わり、002 は削除、003 は追加、004 は同じです。列の順序が違っても変更・削除・追加が各 1 件になります。
3. 新ファイルの 001 だけを 1 に変えると、追加 2 件、削除 2 件、変更 0 件になります。同じ商品の数量を比較するには、出力元で先頭のゼロを保持してください。

## 制限



各表はUTF-8で1 MiB、データ5,000行、80列までです。先頭の0を含めて文字列を完全一致で比較し、重複キーと空キーを分けて表示します。番号はヘッダーから数えたレコード順です。



在庫表では変わらない SKU をキーにします。旧ファイルの 0012 が新ファイルで 12 になると、削除と追加が各 1 件になります。数量の差を同じ商品の変更として比較するには、両方のファイルで先頭のゼロを保持してください。
