# 密码生成器



在本地生成密码，支持字符集、自定义排除与字符不重复。





## 开始使用



1. 按示例填写数值，或输入你自己的测量值。
2. 计算后可复制结果或下载明细。







## 示例



### 输入



```
20 位，启用四个字符组
```



### 预期结果



```
生成一条随机密码
```

## 使用提示



计算在浏览器内完成。无单位标记的字段请使用一致单位。







## 计算方法



使用 Web Crypto 随机取样。要求包含每个启用的字符组时，先分别抽取，再随机打乱位置。密码仅显示在当前页面。
