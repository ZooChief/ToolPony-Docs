# Codificar y decodificar URL



codificar o decodificar URLs completas, componentes URI y valores de forma.





## Primeros pasos



1. Usa el ejemplo o introduce tus propios valores.
2. Calcula, copia el resultado o descarga los detalles disponibles.







## Ejemplo



### Entrada



```
Componente de código: a+b & c
```



### Resultado esperado



```
a%2Bb%20%26%20c
```
