# 日期計算器



統計日曆天數與工作日，或按年月週日、工作日增減日期。





## 開始使用



1. 統計時填兩個日期，選擇是否包含較晚日期。節假日在更多選項填寫。
2. 要向前移日期，輸入負數。按工作日增減時跳過週六、週日和填寫的節假日。







## 示例



### 輸入



```
2020-01-01 至 2020-02-01
```



### 預期結果



```
31 個日曆日、23 個工作日
```

計算在瀏覽器內完成。無單位標記的字段請使用一致單位。







## 計算方法



工作日爲週一至週五，並排除你填寫的日期。YYYY-MM-DD 僅一次，MM-DD 每年重複。按工作日增減時計入較早日期、排除較晚日期，結果可落在週末或節假日。月份增減遇短月取月末。







## 計算模式



**日期間隔**

- 起始日期
- 結束日期
- 包含結束日期
- 節假日（YYYY-MM-DD 或 MM-DD）





**日期加減**

- 起始日期
- 年
- 月
- 週數
- 天





**按工作日增減**

- 起始日期
- 工作日
- 節假日（YYYY-MM-DD 或 MM-DD）
