# Rechner für Kraftstoffkosten und Verbrauch



Konvertieren Sie Kraftstoffverbrauchseinheiten, schätzen Sie die Kraftstoffkosten einer Reise oder berechnen Sie den gemessenen Kraftstoffverbrauch.





## Erste Schritte



1. Verwenden Sie das Beispiel oder geben Sie eigene Werte ein.
2. Berechnen Sie das Ergebnis und kopieren oder laden Sie die Details herunter.







## Beispiel



### Eingabe



```
300 km, 7 L/100 km, Preis 1,5 pro Liter
```



### Erwartetes Ergebnis



```
21 L; Kraftstoffkosten 31,50
```







## Ausprobieren



[Vollständiges Werkzeug öffnen](<https://toolpony.com/de/tools/fuel-cost-calculator/>)







## Hinweise



Die Verarbeitung erfolgt im Browser. Verwenden Sie einheitliche Einheiten.







## Berechnungsmethode



Verwendeter Kraftstoff = Entfernung × L/100 km ÷ 100. US-amerikanische und imperiale Meilen pro Gallone verwenden unterschiedliche Gallonenvolumina. Die Kraftstoffpreise werden vom Benutzer geliefert.







## Berechnungsmodus



**Reisekosten**

- Entfernung · km
- Kraftstoffverbrauch
- Kraftstoffverbrauchseinheit · L/100 km / km/L / mpg (US) / mpg (imperial)
- Preis pro Liter





**Konvertierungskraftstoffverbrauch**

- Kraftstoffverbrauch
- Eingabeeinheit · L/100 km / km/L / mpg (US) / mpg (imperial)





**Gemessene Kilometerleistung**

- Entfernung · km
- Kraftstoffverbrauch · L
