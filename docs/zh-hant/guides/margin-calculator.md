# 利潤率與加價率



由成本與售價計算毛利率和加價率，或按目標毛利率定價。





## 開始使用



1. 按示例填寫數值，或輸入你自己的測量值。
2. 計算後可複製結果或下載明細。







## 示例



### 輸入



```
成本 60，售價 100
```



### 預期結果



```
毛利率 40%，加價率約 66.67%
```







## 試一試



[打開完整工具](<https://toolpony.com/zh-hant/tools/margin-calculator/>)







## 使用提示



計算在瀏覽器內完成。無單位標記的字段請使用一致單位。







## 計算方法



毛利率 = 毛利 ÷ 售價，加價率 = 毛利 ÷ 成本。按目標毛利率定價時，售價 = 成本 ÷（1−毛利率）。







## 計算模式



**成本與售價**

- 成本
- 售價





**按目標毛利率定價**

- 成本
- 目標毛利率 · %
