# Calculadora de gorjetas



Dividir uma conta e gorjeta entre as pessoas, com a dica com base no valor antes ou depois de impostos.





## Primeiros passos



1. Use o exemplo ou insira seus próprios valores.
2. Calcule, copie o resultado ou baixe os detalhes disponíveis.







## Exemplo



### Entrada



```
80 notas, 20% gorjeta, 4 pessoas
```



### Resultado esperado



```
96 no total, 24 por pessoa
```







## Experimente



[Abrir ferramenta completa](<https://toolpony.com/pt-br/tools/tip-calculator/>)







## Notas de uso



O cálculo é feito no seu navegador. Use unidades consistentes.







## Método de cálculo



Dica = quantidade de fatura selecionada × porcentagem de gorjeta. Por pessoa total é igual a conta, imposto e dica dividido pelo número de pessoas.
