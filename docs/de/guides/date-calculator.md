# Datumsrechner



Zählen Sie Kalender- und Arbeitstage oder verschieben Sie ein Datum um Kalendereinheiten oder Arbeitstage.





## Erste Schritte



1. Geben Sie zwei Daten ein und wählen Sie, ob das spätere Datum mitzählt. Feiertage stehen unter Weitere Optionen.
2. Geben Sie zum Zurückrechnen eine negative Zahl ein. Arbeitstage überspringen Samstage, Sonntage und Ihre Feiertage.







## Beispiel



### Eingabe



```
2020-01-01 bis 2020-02-01
```



### Erwartetes Ergebnis



```
31 Kalendertage, 23 Arbeitstage
```

## Hinweise



Die Verarbeitung erfolgt im Browser. Verwenden Sie einheitliche Einheiten.







## Berechnungsmethode



Arbeitstage sind Montag bis Freitag ohne Ihre Feiertage. YYYY-MM-DD gilt einmal, MM-DD jährlich. Beim Verschieben zählt das frühere Datum, das spätere ist ausgeschlossen. Das Ergebnis kann am Wochenende oder Feiertag liegen. Kürzere Monate enden am Monatsende.







## Berechnungsmodus



**Zwischen Daten**

- Startdatum
- Enddatum
- Enddatum mitzählen
- Feiertage (YYYY-MM-DD oder MM-DD)





**Datum verschieben**

- Startdatum
- Jahre
- Monate
- Wochen
- Tage





**Um Arbeitstage verschieben**

- Startdatum
- Arbeitstage
- Feiertage (YYYY-MM-DD oder MM-DD)
