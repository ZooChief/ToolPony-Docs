# Calculatrice de permutations et combinaisons



Calculez les sélections ordonnées et non ordonnées avec ou sans répétition.





## Prise en main



1. Utilisez l’exemple ou saisissez vos propres valeurs.
2. Calculez, puis copiez le résultat ou téléchargez les détails.







## Exemple



### Entrée



```
n=10, r=3, sans répétition
```



### Résultat attendu



```
720 permutations; 120 combinaisons
```







## Essayer



[Ouvrir l’outil complet](<https://toolpony.com/fr/tools/permutation-combination-calculator/>)







## Notes



Le traitement se fait dans le navigateur. Utilisez des unités cohérentes.







## Méthode de calcul



Sans répétition, nPr = n!/(n−r)! et nCr = nPr/r!. Avec répétition, les choix ordonnés sont nr et les choix non ordonnés sont C(n+r−1,r).
