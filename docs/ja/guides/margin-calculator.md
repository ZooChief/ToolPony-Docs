# 利益率と値入率



コストと価格から粗利益率とマークアップを見つけ、ターゲットマージンで製品の価格を算出してください。





## 使い方



1. 例を使うか、任意の値を入力します。
2. 計算後、結果をコピーするか詳細をダウンロードできます。







## 例



### 入力



```
料金60、価格100
```



### 期待される結果



```
40%のマージン;66.67%のマークアップ
```







## 試してみる



[ツール全体を開く](<https://toolpony.com/ja/tools/margin-calculator/>)







## 注意点



処理はブラウザ内で実行されます。単位をそろえて入力してください。







## 計算方法



利益率=利益 ÷ 販売価格。 マークアップ=利益 ÷ コスト。 目標マージンには販売価格=原価(1−マージン)が必要である。







## 計算モード



**コストと価格**

- コスト
- 販売価格





**目標マージンでの価格**

- コスト
- 目標マージン · %
