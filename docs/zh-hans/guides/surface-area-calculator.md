# 表面积计算器



支持球、圆锥、圆柱、长方体、胶囊体、球冠、椭球、棱锥和空心管等，可混用尺寸单位。





## 开始使用



1. 按示例填写数值，或输入你自己的测量值。
2. 计算后可复制结果或下载明细。







## 示例



### 输入



```
球半径 2 米
```



### 预期结果



```
约 50.2655 平方米
```

## 使用提示



计算在浏览器内完成。无单位标记的字段请使用一致单位。







## 计算方法



总表面积包含端面。适用的立体会分别列出侧面积和端面面积。椭球表面积为近似值。



$$
A_{\mathrm{cylinder}}=2\pi r^2+2\pi rh,\qquad A_{\mathrm{sphere}}=4\pi r^2
$$
