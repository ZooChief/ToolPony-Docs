# 年齡計算器



計算週歲、出生至今的時長和下次生日。





## 開始使用



1. 填出生日期和計算日期。計算日期留空時用設備上的今天。







## 示例



### 輸入



```
出生 2000-01-01，計算日期 2025-02-03
```



### 預期結果



```
25 歲 1 個月 2 天
```

## 使用提示



計算在瀏覽器內完成。無單位標記的字段請使用一致單位。







## 計算方法



月份對齊同一日，短月取月末。2 月 29 日出生可選在平年 2 月 28 日或 3 月 1 日過週年。總時長按每個日曆日 24 小時換算。
