# 단위 변환기



길이, 질량, 면적, 부피, 온도, 속도, 에너지, 데이터 및 기타 단위를 변환합니다.





## 시작하기



1. 예제 값을 사용하거나 원하는 값을 입력하세요.
2. 계산한 결과를 복사하거나 세부 정보를 내려받을 수 있습니다.







## 예시



### 입력



```
1 m를 ft로 변환
```



### 예상 결과



```
≈3.28084 ft
```

## 계산 방법



각 그룹은 표준 기본 단위를 통해 변환합니다. 미국과 제국 부피 단위는 분리됩니다. Decimal 및 바이너리 스토리지 유닛은 각각의 기초를 유지합니다.
