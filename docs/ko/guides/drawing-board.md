# 그림판



브러시 또는 지우개로 캔버스에 그려보세요. 색상 및 크기, 언도 또는 다시 실행 스트로크를 설정 한 다음 투명한 PNG를 다운로드하십시오.





## 시작하기



1. 브러시 또는 지우개를 선택하고 크기를 설정합니다.
2. 마우스, 손가락 또는 펜으로 캔버스에 그립니다.
3. 뇌졸중을 취소하거나 다시 실행 하 고 투명한 PNG를 수출.







## 직접 사용해 보기



[전체 도구 열기](<https://toolpony.com/ko/tools/drawing-board/>)







## 참고 사항



캔버스를 지우는 것은 사용 가능한 기록 내에서 취소 할 수 있습니다. 탭을 닫기 전에 PNG를 가져옵니다.







## 제한 사항



캔버스는 1080 × 640 픽셀입니다. 도면은 이 탭에 유지됩니다. Ctrl/Cmd+Z 및 Ctrl/Cmd+Shift+Z를 실행 취소 및 다시 실행 취소합니다.
