# Base converter and calculator



Convert signed integers between bases 2–36 and perform exact arithmetic, remainder or bitwise operations.





## Get started



1. Use the example values or enter your own measurements.
2. Calculate, then copy the result or download the available details.







## Example



### Input



```
FF, base 16 to base 10
```



### Expected result



```
255
```

## Good to know



The calculation runs in your browser. Use consistent units in fields with no explicit unit.







## Calculation method



BigInt preserves integer precision. Division truncates toward zero. Bitwise operations use signed BigInt semantics. Each operand is limited to 256 digits.
