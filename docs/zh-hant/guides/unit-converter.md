# 單位換算使用指南



換算長度、質量、面積、體積、溫度、速度、能量、數字存儲等單位。





## 示例



### 輸入



```
1 米轉英尺
```



### 預期結果



```
約 3.28084 英尺
```





<a id="case-study"></a>



## 覈對一次降溫



1. 溫度從 20 °C 降到 10 °C。選擇「溫差」並輸入 −10 °C，變化量爲 −18 °F。切回「溫度」，10 °C 的讀數對應 50 °F。





## 1 TB 硬盤有多少 GiB



標稱 1 TB 的硬盤有 1,000,000,000,000 字節。每 GiB 有 1,073,741,824 字節，格式化前容量約爲 931.32 GiB。頁面和導出的 CSV 保留完整小數。



[運行示例](<https://toolpony.com/zh-hant/tools/unit-converter/#example-drive-capacity>)







## 3/8 英寸的接頭



在英寸欄輸入 3/8，讀數是 9.525 mm。也可以輸入帶分數，例如 1 3/8 in 等於 34.925 mm。



[運行示例](<https://toolpony.com/zh-hant/tools/unit-converter/#example-fractional-inch>)

## 計算方法



已定義的換算比例按精確分數計算。遇到循環小數，同時顯示近似讀數與原分數。弧度與其他角度單位互轉時使用 π 的近似值。







## 計算模式





### 長度



- 數值
- 原單位
- 目標單位







### 質量



- 數值
- 原單位
- 目標單位







### 面積



- 數值
- 原單位
- 目標單位







### 體積



- 數值
- 原單位
- 目標單位







### 溫度



- 數值
- 原單位 · °C / °F / K
- 目標單位 · °C / °F / K
- 溫差







### 速度



- 數值
- 原單位 · m/s / km/h / mph / ft/s / 節
- 目標單位 · m/s / km/h / mph / ft/s / 節







### 壓力



- 數值
- 原單位 · Pa / kPa / MPa / bar / atm / Torr / psi
- 目標單位 · Pa / kPa / MPa / bar / atm / Torr / psi







### 能量



- 數值
- 原單位
- 目標單位







### 功率



- 數值
- 原單位 · W / mW / kW / MW / 英制機械馬力 / 公制馬力
- 目標單位 · W / mW / kW / MW / 英制機械馬力 / 公制馬力







### 力



- 數值
- 原單位 · N / kN / dyn / kgf / lbf
- 目標單位 · N / kN / dyn / kgf / lbf







### 時間



- 數值
- 原單位 · ns / μs / ms / s / min / h / d / wk
- 目標單位 · ns / μs / ms / s / min / h / d / wk







### 數字存儲



- 數值
- 原單位
- 目標單位







### 角度



- 數值
- 原單位 · ° / rad / grad / turn / arcmin / arcsec
- 目標單位 · ° / rad / grad / turn / arcmin / arcsec







### 頻率



- 數值
- 原單位 · Hz / kHz / MHz / GHz / rpm
- 目標單位 · Hz / kHz / MHz / GHz / rpm
