# Big number calculator



Calculate with exact large integers and decimal coefficients, with selectable rounding for division and roots.





## Get started



1. Use the example values or enter your own measurements.
2. Calculate, then copy the result or download the available details.







## Example



### Input



```
9,007,199,254,740,993 + 7
```



### Expected result



```
9007199254741000
```







## Try it



[Open full tool](<https://toolpony.com/en/tools/big-number-calculator/>)







## Good to know



The calculation runs in your browser. Use consistent units in fields with no explicit unit.







## Calculation method



Addition, subtraction, multiplication, integer powers and integer operations use BigInt coefficients. Division rounds to the selected decimal places. Square roots can truncate or round to nearest. Positive and negative integer exponents are supported within the result limit.



$$
x=m\cdot 10^e,\quad x_1x_2=(m_1m_2)\cdot 10^{e_1+e_2}
$$
