# 저항 색띠 및 합성 저항 계산기



3~6개 색띠를 읽고 직렬·병렬 합성 저항과 원형 전선 저항을 계산합니다.





## 시작하기



1. 띠 수 또는 연결 방식을 선택하세요. 허용 오차 띠는 다른 띠와 떨어져 있는 경우가 많습니다.
2. 원형 도체의 지름과 길이를 입력하세요. 재질 프리셋이 입력한 전도도는 수정할 수 있습니다.







## 예시



### 입력



```
4색 띠: 초록, 빨강, 빨강, 금
```



### 예상 결과



```
5,200 Ω ±5%
```







## 직접 사용해 보기



[전체 도구 열기](<https://toolpony.com/ko/tools/resistor-calculator/>)







## 참고 사항



브라우저에서 처리합니다. 단위를 일관되게 사용하세요.







## 계산 방법



유효 숫자, 승수, 허용 오차, 온도 계수 순서로 읽으세요. 3색 띠 허용 오차는 20%입니다. 균일한 원형 도체는 R = L/(σA)입니다. 특수 표기는 부품 사양서를 확인하세요.



$$
R_{\rm series}=\sum_i R_i,\quad R_{\rm parallel}=\left(\sum_i 1/R_i\right)^{-1},\quad R_{\rm wire}=\frac{L}{\sigma\pi(d/2)^2}
$$



$$
R_{\rm band}=D\,10^m,\qquad R_{\min,\max}=R_{\rm band}(1\mp t/100)
$$







## 계산 모드



**4색 띠**

- 첫째 자리
- 둘째 자리
- 승수
- 허용 오차





**3색 띠**

- 첫째 자리
- 둘째 자리
- 승수





**5색 띠**

- 첫째 자리
- 둘째 자리
- 셋째 자리
- 승수
- 허용 오차





**6색 띠**

- 첫째 자리
- 둘째 자리
- 셋째 자리
- 승수
- 허용 오차
- 온도 계수





**병렬**

- 저항값(Ω)

- 저항값(Ω)
