# 销售税与增值税计算器



按自定义税率计算含税价、未税价与税额。





## 开始使用



1. 按示例填写数值，或输入你自己的测量值。
2. 计算后可复制结果或下载明细。







## 示例



### 输入



```
未税价 100，增值税 20%
```



### 预期结果



```
含税价 120，税额 20
```







## 试一试

## 使用提示



计算在浏览器内完成。无单位标记的字段请使用一致单位。







## 计算方法



含税价 = 未税价 ×（1 + 税率）。税率由用户填写。
