# Conversor de color



Convierte HEX, RGB y HSL, conserva la transparencia y previsualiza el color.





## Primeros pasos



1. Usa el ejemplo o introduce tus propios valores.
2. Calcula, copia el resultado o descarga los detalles disponibles.







## Ejemplo



### Entrada



```
rgb(102, 51, 153)
```



### Resultado esperado



```
#663399, hsl(270 50% 40%)
```

[Abrir herramienta completa](<https://toolpony.com/es/tools/color-converter/>)







## Notas de uso



El cálculo se ejecuta en tu navegador. Usa unidades coherentes.







## Método de cálculo



HEX usa canales de 8 bits. RGB admite números o porcentajes. HSL usa grados para el tono y porcentajes para la saturación y la luminosidad. La salida HEX redondea cada canal al byte más cercano.
