# Rabattrechner



Stack-Rabatte, subtrahieren einen festen Coupon und wenden die Umsatzsteuer auf den ermäßigten Preis an.





## Erste Schritte



1. Verwenden Sie das Beispiel oder geben Sie eigene Werte ein.
2. Berechnen Sie das Ergebnis und kopieren oder laden Sie die Details herunter.







## Beispiel



### Eingabe



```
100 mit 20% und 10% off
```



### Erwartetes Ergebnis



```
72; kombinierter Rabatt 28%
```







## Ausprobieren



[Vollständiges Werkzeug öffnen](<https://toolpony.com/de/tools/discount-calculator/>)







## Hinweise



Die Verarbeitung erfolgt im Browser. Verwenden Sie einheitliche Einheiten.







## Berechnungsmethode



Wenden Sie prozentuale Rabatte an, dann den festen Coupon, dann Steuern. bis zu 10 Sätze von 0% bis 100%.



Zwei aufeinanderfolgende Rabatte von 20% und 10% lassen 0,8 × 0,9 des ursprünglichen Preises übrig. Geben Sie beide Sätze in der Reihenfolge ein und fügen Sie dann gegebenenfalls einen Coupon oder eine Steuer hinzu.



Verwenden Sie einen umgekehrten Modus, wenn Sie den Verkaufspreis oder den gesparten Betrag kennen.







## Berechnungsmodus



**Ermäßigungen anwenden**

- Ursprünglicher Preis
- Abzinsungssätze
- Festverzinsung
- Steuersatz · %





**Originalpreis finden**

- Preis nach Abschlag
- Discount-Typ · Prozentsatz / Festbetrag
- Abzinsung





**Find Rate und Einsparungen**

- Ursprünglicher Preis
- Bekannter Betrag · Abgezinster Preis / Einsparungen
- Betrag





**Finden Sie Preise aus Einsparungen**

- Gesparter Betrag
- Abzinsungssatz · %
