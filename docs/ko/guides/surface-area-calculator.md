# 겉넓이 계산기



구체, 콘, 탱크, 캡슐, 모자, 타원, 피라미드 및 혼합 차원을 가진 중공 관을 해결합니다.





## 시작하기



1. 예제 값을 사용하거나 원하는 값을 입력하세요.
2. 계산한 결과를 복사하거나 세부 정보를 내려받을 수 있습니다.







## 예시



### 입력



```
반경 2개 m를 가진 구체
```



### 예상 결과



```
≈50.2655 m²
```







## 직접 사용해 보기



[전체 도구 열기](<https://toolpony.com/ko/tools/surface-area-calculator/>)







## 참고 사항



브라우저에서 처리합니다. 단위를 일관되게 사용하세요.







## 계산 방법



전체 표면적은 끝면을 포함한다. 해당되는 경우 측면 및 최종면 영역이 별도로 나열됩니다. Ellipsoid 지역은 대략적입니다.



$$
A_{\mathrm{cylinder}}=2\pi r^2+2\pi rh,\qquad A_{\mathrm{sphere}}=4\pi r^2
$$
