# Calculadora de ancho de banda



Tiempo estimado de transferencia del tamaño del archivo, velocidad de enlace y eficiencia del protocolo.





## Primeros pasos



1. Usa el ejemplo o introduce tus propios valores.
2. Calcula, copia el resultado o descarga los detalles disponibles.







## Ejemplo



### Entrada



```
1 GB a 100 Mbps, eficiencia 100%
```



### Resultado esperado



```
80 segundos
```







## Pruébalo



[Abrir herramienta completa](<https://toolpony.com/es/tools/bandwidth-calculator/>)







## Notas de uso



El cálculo se ejecuta en tu navegador. Usa unidades coherentes.







## Método de cálculo



Tiempo en segundos = bytes de archivo × 8 ÷ bits efectivos por segundo. Los prefijos de la red son decimales. El tamaño de archivo soporta prefijos decimales y binarios.
