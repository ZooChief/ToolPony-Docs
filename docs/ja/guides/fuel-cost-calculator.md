# 燃料費・燃費計算機の使い方



燃費単位を換算し、旅行時の燃料費を推定するか、または燃費を測定します。





## 例



### 入力



```
走行距離 300 km、燃費 7 L/100 km、燃料単価 1.5/L
```



### 期待される結果



```
21リットル;燃料費31.50
```





<a id="case-study"></a>



## 英国の燃費を換算する



1. 英国のレビューの 35 mpg は英ガロンの値です。英 mpg を入力単位にすると約 8.07 L/100 km、米国式で約 29.14 mpg です。出力単位を切り替えて比較できます。



[入力例を実行](<https://toolpony.com/ja/tools/fuel-cost-calculator/#example-uk-mileage>)





## 試してみる

[ツール全体を開く · 燃料費・燃費計算機](<https://toolpony.com/ja/tools/fuel-cost-calculator/>)





## 計算方法



燃料使用量 (L) = 走行距離 (km) × 燃費 (L/100 km) ÷ 100。米国ガロンと英ガロンは容量が異なります。燃料単価は入力値を使用します。







## 計算モード





### 旅行費用



- 距離
- 距離の単位 · km / mi
- 燃料経済
- 燃料経済ユニット · L/100km / km/L / mpg(米国) / mpg(帝国主義的)
- 給油価格
- 給油価格の単位 · L / US gal / UK gal







### 燃費を変換



- 燃料経済
- 入力ユニット · L/100km / km/L / mpg(米国) / mpg(帝国主義的)
- 出力単位 · L/100km / km/L / mpg(米国) / mpg(帝国主義的)







### 測定された走行距離



- 距離
- 距離の単位 · km / mi
- 使用済み燃料
- 体積の単位 · L / US gal / UK gal
