# Calculadora de área superficial



Resolver esferas, conos, tanques, cápsulas, caps, ellipsoides, pirámides y tubos huecos con dimensiones mixtas.





## Primeros pasos



1. Usa el ejemplo o introduce tus propios valores.
2. Calcula, copia el resultado o descarga los detalles disponibles.







## Ejemplo



### Entrada



```
Esfera con radio 2 m
```



### Resultado esperado



```
≈50.2655 m²
```

## Notas de uso



El cálculo se ejecuta en tu navegador. Usa unidades coherentes.







## Método de cálculo



El área total de superficie incluye las caras finales. Cuando sea aplicable, las áreas laterales y de la cara final se enumeran por separado.



$$
A_{\mathrm{cylinder}}=2\pi r^2+2\pi rh,\qquad A_{\mathrm{sphere}}=4\pi r^2
$$
