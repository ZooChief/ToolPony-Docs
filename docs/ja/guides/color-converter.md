# 色変換



HEX、RGB、HSL を相互変換し、透明度を保ったまま色を確認できます。





## 例



### 入力



```
rgb(102, 51, 153)
```



### 期待される結果



```
#663399、hsl(270 50% 40%)
```







## 試してみる

[ツール全体を開く · 色変換](<https://toolpony.com/ja/tools/color-converter/>)





## 計算方法



HEX は各チャンネルを 8 ビットで表します。RGB は数値または割合、HSL は色相を度、彩度と明度を割合で指定します。HEX 出力は各チャンネルを最も近いバイト値に丸めます。





**計算・処理の参考資料** [W3C · CSS Color 4](<https://www.w3.org/TR/css-color-4/>)
