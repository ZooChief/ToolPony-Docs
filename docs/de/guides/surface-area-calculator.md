# Oberflächenrechner



Lösekugeln, Kegel, Behälter, Kapseln, Kappen, Ellipsoide, Pyramiden und Hohlrohre mit gemischten Abmessungen.





## Erste Schritte



1. Verwenden Sie das Beispiel oder geben Sie eigene Werte ein.
2. Berechnen Sie das Ergebnis und kopieren oder laden Sie die Details herunter.







## Beispiel



### Eingabe



```
Kugel mit Radius von 2 m
```



### Erwartetes Ergebnis



```
≈50.2655 m²
```







## Ausprobieren



[Vollständiges Werkzeug öffnen](<https://toolpony.com/de/tools/surface-area-calculator/>)







## Hinweise



Die Verarbeitung erfolgt im Browser. Verwenden Sie einheitliche Einheiten.







## Berechnungsmethode



Die Gesamtfläche umfasst die Endflächen; gegebenenfalls werden die Seitenflächen und die Endflächen getrennt aufgeführt; die Ellipsenfläche ist ungefähr.



$$
A_{\mathrm{cylinder}}=2\pi r^2+2\pi rh,\qquad A_{\mathrm{sphere}}=4\pi r^2
$$
