# Générateur de nombres aléatoires



Générer des entiers aléatoires dans une gamme inclusive, avec une singularité et un tri optionnels.





## Prise en main



1. Utilisez l’exemple ou saisissez vos propres valeurs.
2. Calculez, puis copiez le résultat ou téléchargez les détails.







## Exemple



### Entrée



```
Minimum 1, maximum 10, nombre 5
```



### Résultat attendu



```
Cinq entiers aléatoires de 1 à 10
```







## Essayer



[Ouvrir l’outil complet](<https://toolpony.com/fr/tools/random-number-generator/>)







## Notes



Le traitement se fait dans le navigateur. Utilisez des unités cohérentes.







## Méthode de calcul



Les nombres aléatoires proviennent de Web Crypto. L’échantillonnage par rejet évite le biais modulo. Générez jusqu’à 1 000 entiers entre −1 000 000 000 et 1 000 000 000.
