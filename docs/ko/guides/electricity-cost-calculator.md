# 전기 요금 계산기



기기, 부하, 단가로 지정 기간 또는 일·주·월·연간 전력과 요금을 추정합니다.





## 시작하기



1. 기기의 입력 전력, 사용 시간, 요율을 입력하세요. 프리셋 예시는 수정할 수 있습니다.







## 예시



### 입력



```
1,000 W, 하루 2시간, 30일, kWh당 0.2
```



### 예상 결과



```
60 kWh, 요금 12
```







## 직접 사용해 보기



[전체 도구 열기](<https://toolpony.com/ko/tools/electricity-cost-calculator/>)







## 참고 사항



브라우저에서 처리합니다. 단위를 일관되게 사용하세요.







## 계산 방법



전력 사용량은 kW, 작동 시간, 평균 부하, 기기 수의 곱입니다. 단일 요율을 쓰고 월 30.44일, 연 365.25일로 추정합니다. 냉방 용량은 이동한 열량이므로 요금에는 전기 입력을 사용하세요.



$$
E_{\rm kWh}=P_{\rm kW}\,t_{\rm h}\,f\,n,\qquad C=E_{\rm kWh}\,r
$$







## 계산 모드



**일수 지정**

- 전력
- 전력 단위 · W / kW / BTU/h / PS / TR
- 평균 부하 · %
- 기기 수
- 하루 작동 시간 · h
- 일수
- kWh당 요금





**일·주·월·연간 추정**

- 가전 프리셋
- 전력
- 전력 단위 · W / kW / BTU/h / PS / TR
- 평균 부하 · %
- 기기 수
- 사용 시간
- 사용 시간 단위 · 분/일 / 하루 작동 시간 / 시간/주 / 시간/월 / 일/주 / 일/월 / 일/년 / 개월/년
- kWh당 요금
