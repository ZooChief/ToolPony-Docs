# Documento para texto



Escolha um DOCX, ODT ou PDF do dispositivo, ou abra o DOCX de exemplo.





## Primeiros passos



1. Escolha um DOCX, ODT ou PDF do dispositivo, ou abra o DOCX de exemplo.
2. Cada parágrafo começa em uma nova linha. Tabulações separam as células. Copie o resultado ou baixe o texto em UTF-8.







## Exemplo



### Entrada



```
DOCX com um título, dois trechos de texto e uma tabulação
```



### Resultado esperado



```
ToolPony
ABC	123
```







## Experimente



[Abrir ferramenta completa](<https://toolpony.com/pt-br/tools/document-to-text/>)







## Limites



DOCX e ODT usam o corpo principal, com até 20 MiB por arquivo e 1 MiB de texto UTF-8 extraído. O PDF precisa de texto selecionável. Imagens, formatação da página e arquivos protegidos por senha ficam fora do escopo.

[Documentação](https://docs.toolpony.com/pt-br/guides/document-to-text/)
