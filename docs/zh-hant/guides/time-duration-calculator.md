# 時長計算器



計算時刻或日期時間的間隔、加減時長，也可移動日期時間。





## 開始使用



1. 單班用時刻間隔，多天用日期時間間隔，混合加減可用表達式。







## 示例



### 輸入



```
22:30 至 06:15，跨日
```



### 預期結果



```
07:45:00
```

## 使用提示



計算在瀏覽器內完成。無單位標記的字段請使用一致單位。







## 計算方法



時刻間隔可以跨午夜。填寫日期時，每日按 24 小時。表達式用 d、h、m、s 表示天、小時、分鐘和秒，減號作用於後面一整組時間量。



$$
T=86400d+3600h+60m+s
$$
