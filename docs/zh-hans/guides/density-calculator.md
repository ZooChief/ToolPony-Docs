# 密度计算器



任填两项求质量、体积或密度。





## 开始使用



1. 按示例填写数值，或输入你自己的测量值。
2. 计算后可复制结果或下载明细。







## 示例



### 输入



```
8 kg，0.001 m³
```



### 预期结果



```
8,000 kg/m³
```







## 试一试

## 使用提示



计算在浏览器内完成。无单位标记的字段请使用一致单位。







## 计算方法



密度 = 质量 ÷ 体积，采用 kg、m³ 和 kg/m³。



$$
\rho=\frac{m}{V}
$$
