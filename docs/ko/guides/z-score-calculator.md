# Z 점수 계산기



값을 표준화하고 Z 점수, 정규 확률, 구간을 서로 변환합니다.





## 시작하기



1. 예제 값을 사용하거나 원하는 값을 입력하세요.
2. 계산한 결과를 복사하거나 세부 정보를 내려받을 수 있습니다.







## 예시



### 입력



```
관측값 18, 평균 23, 표준편차 4
```



### 예상 결과



```
z = −1.25
```

## 계산 방법



표준 점수는 (x − μ)/σ입니다. 왼쪽 꼬리 확률은 z에서의 정규 누적분포함수입니다. 대칭 구간을 역산할 때는 음이 아닌 경계를 반환합니다.



$$
z=\frac{x-\mu}{\sigma},\qquad P(a<Z<b)=\Phi(b)-\Phi(a)
$$

- 확률
