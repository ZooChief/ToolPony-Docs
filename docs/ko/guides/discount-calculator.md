# 할인 계산기



할인을 쌓고 고정 쿠폰을 뺍니다. 할인 된 가격에 판매 세를 적용하십시오.





## 시작하기



1. 예제 값을 사용하거나 원하는 값을 입력하세요.
2. 계산한 결과를 복사하거나 세부 정보를 내려받을 수 있습니다.







## 예시



### 입력



```
100 with 20% and 10% off
```



### 예상 결과



```
72; 결합 된 할인 28 %
```







## 직접 사용해 보기



[전체 도구 열기](<https://toolpony.com/ko/tools/discount-calculator/>)







## 참고 사항



브라우저에서 처리합니다. 단위를 일관되게 사용하세요.







## 계산 방법



순서대로 백분율 할인을 적용한 다음 고정 쿠폰, 다음 세금. 0%에서 100%까지 10까지.



20 %와 10 %의 두 가지 연속 할인은 원래 가격의 0.8 × 0.9를 남깁니다. 두 요금을 모두 순서대로 입력한 다음 해당되는 경우 쿠폰 또는 세금을 추가합니다.



판매 가격 또는 저장된 금액을 알 때 역 모드를 사용하십시오. 역 모드는 세금 전에 하나의 할인을 처리합니다.







## 계산 모드



**할인 적용**

- 원래 가격
- 할인 비율
- 쿠폰 수정
- 세율 · %





**원래 가격 찾기**

- 할인 후 가격
- 할인 유형 · 백분율 / 고정 금액
- 할인





**요금 및 저축 찾기**

- 원래 가격
- 알려진 금액 · 할인된 가격 / 저축
- 금액





**저축에서 가격 찾기**

- 저장 금액
- 할인율 · %
