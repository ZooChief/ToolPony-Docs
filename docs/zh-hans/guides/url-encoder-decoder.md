# URL 编码与解码



编码或解码完整 URL、URI 组件和表单值。





## 示例



### 输入



```
编码组件：a+b & c
```



### 预期结果



```
a%2Bb%20%26%20c
```







## 试一试

[打开完整工具 · URL 编码与解码](<https://toolpony.com/zh-hans/tools/url-encoder-decoder/>)





## 计算方法



组件编码转义保留分隔符。完整 URL 模式保留分隔符。表单模式用加号表示空格。
