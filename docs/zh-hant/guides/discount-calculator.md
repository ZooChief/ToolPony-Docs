# 折扣計算器



疊加多個折扣、減去固定優惠券，並對摺後價格計稅。





## 開始使用



1. 按示例填寫數值，或輸入你自己的測量值。
2. 計算後可複製結果或下載明細。







## 示例



### 輸入



```
原價 100，先減 20% 再減 10%
```



### 預期結果



```
折後 72，相當於減 28%
```

## 使用提示



計算在瀏覽器內完成。無單位標記的字段請使用一致單位。







## 計算方法



依次應用百分比折扣，再減固定優惠，最後計稅。最多 10 個 0% 至 100% 的折扣率。



連續打八折和九折，剩下原價的 0.8 × 0.9。按順序填寫折扣率，再按需添加優惠券或稅。



已知折後價或節省金額時可用反推模式。反推採用單個稅前折扣。







## 計算模式



**應用折扣**

- 原價
- 減免百分比列表
- 固定優惠金額
- 稅率 · %





**反推原價**

- 折後價
- 折扣類型 · 百分比 / 固定金額
- 折扣





**求折扣率與節省金額**

- 原價
- 已知金額 · 折後價 / 節省金額
- 金額





**由節省金額求價格**

- 節省金額
- 折扣率 · %
