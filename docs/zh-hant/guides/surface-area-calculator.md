# 表面積計算器使用指南



計算立體表面積。水箱、管壁等帶平面的幾何體可選擇要覆蓋的面，分別查看側面積與端面面積。





## 示例



### 輸入



```
球半徑 2 米
```



### 預期結果



```
約 50.2655 平方米
```





<a id="case-study"></a>



## 計算無蓋水箱的內襯



1. 水箱內長 120 cm、寬 0.8 m、深 450 mm。內襯要鋪四壁和底面，選擇「側面和一個端面」。
2. 四壁共 1.80 m²，底面 0.96 m²，合計 2.76 m²，未計接縫餘量與損耗。切換到「全部面」會加上蓋板，總面積變成 3.72 m²。

## 計算方法



完整表面包括全部端面。端面按自身尺寸單獨計算。橢球表面積使用對稱橢圓積分數值求解。



$$
A_{\mathrm{cylinder}}=2\pi r^2+2\pi rh,\qquad A_{\mathrm{sphere}}=4\pi r^2
$$
