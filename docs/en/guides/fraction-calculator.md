# Fraction calculator



Use exact arithmetic to add, subtract, multiply, divide or simplify fractions and mixed numbers.





## Get started



1. Use the example values or enter your own measurements.
2. Calculate, then copy the result or download the available details.







## Example



### Input



```
1 1/2 + 2/3
```



### Expected result



```
13/6
```







## Try it



[Open full tool](<https://toolpony.com/en/tools/fraction-calculator/>)







## Good to know



The calculation runs in your browser. Use consistent units in fields with no explicit unit.







## Calculation method



Decimals are read as exact fractions. Arithmetic uses BigInt and reduces by the greatest common divisor. The decimal result is approximate.



$$
\frac{a}{b}+\frac{c}{d}=\frac{ad+bc}{bd},\qquad b,d\ne0
$$
