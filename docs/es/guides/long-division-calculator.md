# Calculadora de división larga



Divide números enteros o decimales e inspeccione el cociente, el resto, el valor decimal, y cada paso de división larga.





## Primeros pasos



1. Usa el ejemplo o introduce tus propios valores.
2. Calcula, copia el resultado o descarga los detalles disponibles.







## Ejemplo



### Entrada



```
12,345 ÷ 67
```



### Resultado esperado



```
184 restantes 17
```

## Método de cálculo



Escala ambas entradas por el mismo poder de diez. El cociente entero trunca hacia cero, y el resto firmado satisfies dividendo = quotient × divisor + resto. La tabla paso utiliza magnitudes absolutas.



$$
a=bq+r,\quad q=\operatorname{trunc}(a/b),\quad |r|<|b|
$$
