# Base64 kodieren und dekodieren



Verschlüsseln Sie UTF-8-Text als Standard- oder URL-sichere Base64 und validieren Sie decodierten Text.





## Beispiel



### Eingabe



```
hello kodieren
```



### Erwartetes Ergebnis



```
aGVsbG8=
```







## Ausprobieren

[Vollständiges Werkzeug öffnen · Base64 kodieren und dekodieren](<https://toolpony.com/de/tools/base64-encoder-decoder/>)





## Berechnungsmethode



Text wird als UTF-8 konvertiert. URL-sicherer Modus verwendet "-" und "\_" und lässt Padding in der Ausgabe aus. Bis zu 500.000 Eingabezeichen.





**Quellen zur Methode** [IETF · RFC 4648 (Base64)](<https://www.rfc-editor.org/rfc/rfc4648>)
