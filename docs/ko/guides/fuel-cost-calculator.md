# 연료비·연비 계산기



연비 단위를 전환하거나, 여행의 연료 비용을 추정하거나, 측정 된 연비를 계산합니다.





## 시작하기



1. 예제 값을 사용하거나 원하는 값을 입력하세요.
2. 계산한 결과를 복사하거나 세부 정보를 내려받을 수 있습니다.







## 예시



### 입력



```
300 km, 7 L/100 km의 리터 당 1.5의 가격
```



### 예상 결과



```
21 L; 연료 비용 31.50
```







## 직접 사용해 보기



[전체 도구 열기](<https://toolpony.com/ko/tools/fuel-cost-calculator/>)







## 참고 사항



브라우저에서 처리합니다. 단위를 일관되게 사용하세요.







## 계산 방법



연료 사용량(L) = 거리(km) × 연비(L/100 km) ÷ 100. 미국 갤런과 영국 갤런은 부피가 다릅니다. 연료 가격은 직접 입력합니다.







## 계산 모드



**여행 비용**

- 거리 · km
- 연비
- 연비 단위 · L/100 km / km/L / mpg (미국) / mpg (제국)
- 리터당 가격





**재생유**

- 연비
- 입력 단위 · L/100 km / km/L / mpg (미국) / mpg (제국)





**측정 마일리지**

- 거리 · km
- 사용 된 연료 · L
