# 거듭제곱근 계산기 사용 가이드



주 실제 제곱, 큐브 또는 n제곱을 계산합니다.





## 예시



### 입력



```
제곱근 144
```



### 예상 결과



```
12
```







## 직접 사용해 보기

[전체 도구 열기 · 거듭제곱근 계산기](<https://toolpony.com/ko/tools/root-calculator/>)





## 계산 방법



n번째 루트는 x를 1/n으로 끌어 올렸습니다. 이상한 정수 정도는 음수 radicands를 허용합니다. 음수 정도는 상호를 취합니다.



$$
\sqrt[n]{x}=x^{1/n},\qquad n\ne0
$$







## 계산 모드





### 제곱근



- 근호 안의 수







### 세제곱근



- 근호 안의 수







### n제곱근



- 근호 안의 수
- 학위
