# 자동차 대출 계산기



보상 판매, 잔여 채무, 리베이트와 세금을 반영해 월 상환액 또는 최대 차량 가격을 계산하세요.





## 시작하기



1. 차량 가격을 입력하거나 목표 월 상환액으로 전환하세요. 선납금, 보상 판매 가치와 채무, 리베이트를 추가하세요.
2. 세율과 수수료, 과세표준 공제와 할부 포함 여부를 선택한 뒤 상환 일정을 내보내세요.







## 예시



### 입력



```
차량 30,000, 선납금 5,000, 60개월, 연 5%
```



### 예상 결과



```
세금과 수수료 제외 월 471.78
```

## 계산 방법



세율과 과세표준에서 공제할 항목을 선택하세요. 할부에 포함한 세금과 수수료는 원금에 더합니다. 보상 판매 순액은 차량 가치에서 잔여 채무를 뺀 금액입니다. 고정 월 이율을 사용합니다.



$$
P=V-D-(T-O)-R+F,\quad M=\frac{Pr}{1-(1+r)^{-n}},\quad M=\frac Pn\; (r=0)
$$



V는 차량 가격, D는 선납금, T는 보상 판매 가치, O는 기존 차량 채무, R은 리베이트, F는 할부에 포함한 세금과 수수료입니다. P는 원금, M은 월 상환액, r은 월 이율, n은 개월 수입니다.
