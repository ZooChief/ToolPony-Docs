# べき乗計算機



力、基盤、あるいは他の二つの値から指数を解く。





## 使い方



1. 例を使うか、任意の値を入力します。
2. 計算後、結果をコピーするか詳細をダウンロードできます。







## 例



### 入力



```
ベース2、被余率5
```



### 期待される結果



```
32
```







## 試してみる



[ツール全体を開く](<https://toolpony.com/ja/tools/exponent-calculator/>)







## 注意点



処理はブラウザ内で実行されます。単位をそろえて入力してください。







## 計算方法



y = bⁿ で b と y が正、b ≠ 1 の場合、対数で指数を求めます。0 でない偶整数の指数から実数の底を求めると、2 つの解が得られる場合があります。



$$
y=b^p,\qquad p=\frac{\ln y}{\ln b},\qquad b=\sqrt[p]{y}
$$

**指数**
