# 砂石用量計算器



估算碎石或砂的體積、重量、整袋數和費用。





## 開始使用



1. 選擇已知面積、長方形或圓形，再填寫鋪設厚度。
2. 選擇材料。可在更多選項填寫自定義密度或每袋容量。







## 示例



### 輸入



```
200 ft²、厚 3 in，碎石密度 1,680 kg/m³。
```



### 預期結果



```
50 ft³（1.42 m³），約 2,379 kg。
```

計算在瀏覽器內完成。無單位標記的字段請使用一致單位。







## 計算方法



面積乘鋪設厚度，再加損耗預留。重量等於體積乘散裝密度。按袋計價時先向上取整袋數。已知供應商給出的散裝密度時，優先使用該值。



$$
V=Ad(1+w/100),\qquad m=\rho V,\qquad N=\left\lceil\frac{m}{m_{\rm bag}}\right\rceil\ \text{or}\ \left\lceil\frac{V}{V_{\rm bag}}\right\rceil
$$
