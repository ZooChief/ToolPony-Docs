# Marge bénéficiaire et majoration



Trouvez la marge brute et le balisage à partir du coût et du prix, ou le prix d'un produit à une marge cible.





## Prise en main



1. Utilisez l’exemple ou saisissez vos propres valeurs.
2. Calculez, puis copiez le résultat ou téléchargez les détails.







## Exemple



### Entrée



```
Coût 60, prix 100
```



### Résultat attendu



```
Marge de 40 %; majoration de 66,67 %
```







## Essayer



[Ouvrir l’outil complet](<https://toolpony.com/fr/tools/margin-calculator/>)







## Notes



Le traitement se fait dans le navigateur. Utilisez des unités cohérentes.







## Méthode de calcul



Marge = profit ÷ prix de vente. Markup = bénéfice ÷ coût. Une marge cible exige le prix de vente = coût ÷ (1 -margin).







## Mode de calcul



**Coût et prix**

- Coût
- Prix de vente





**Prix à une marge cible**

- Coût
- Marge cible · %
