# 총부채상환비율 계산기



반복되는 월별 부채 지불을 총 월 소득과 비교하십시오.





## 시작하기



1. 예제 값을 사용하거나 원하는 값을 입력하세요.
2. 계산한 결과를 복사하거나 세부 정보를 내려받을 수 있습니다.







## 예시



### 입력



```
소득 5,000, 부채 지불 1,500
```



### 예상 결과



```
30%
```







## 직접 사용해 보기



[전체 도구 열기](<https://toolpony.com/ko/tools/debt-to-income-calculator/>)







## 참고 사항



브라우저에서 처리합니다. 단위를 일관되게 사용하세요.







## 계산 방법



부채 대 소득 비율 = 월별 부채 지불 ÷ 총 월 소득. 모든 금액에 대해 동일한 통화와 월별 기간을 사용하십시오.
