# Unicode-Konverter



Konvertieren Sie Text in Unicode-Codepunkte, UTF-8 hexadezimale Bytes oder UTF-16 entkommt und dekodieren Sie sie zurück in Text.





## Erste Schritte



1. Verwenden Sie das Beispiel oder geben Sie eigene Werte ein.
2. Berechnen Sie das Ergebnis und kopieren oder laden Sie die Details herunter.







## Beispiel



### Eingabe



```
🐴
```



### Erwartetes Ergebnis



```
U+1F434 oder F0 9F 90 B4
```







## Ausprobieren



[Vollständiges Werkzeug öffnen](<https://toolpony.com/de/tools/unicode-converter/>)







## Hinweise



Die Verarbeitung erfolgt im Browser. Verwenden Sie einheitliche Einheiten.







## Berechnungsmethode



Der Code-Point-Modus behandelt ein Zusatzzeichen als einen Skalar. UTF-16 verwendet zwei Codeeinheiten für ein solches Zeichen. Ungültige Ersatzsequenzen und ungültige UTF-8-Bytes werden abgelehnt.







## Berechnungsmodus



**Codetext**

- Eingabe
- Kodierung · Unicode-Codepunkte / UTF-8-Bytes in Hexadezimal / JavaScript-UTF-16-Escapes





**Dekodierungstext**

- Eingabe
- Kodierung · Unicode-Codepunkte / UTF-8-Bytes in Hexadezimal / JavaScript-UTF-16-Escapes
