# 대역폭 계산기



파일 크기, 링크 속도 및 프로토콜 효율성에서 전송 시간을 추정합니다.





## 시작하기



1. 예제 값을 사용하거나 원하는 값을 입력하세요.
2. 계산한 결과를 복사하거나 세부 정보를 내려받을 수 있습니다.







## 예시



### 입력



```
100 Mbps에 1개 GB, 효율성 100%년
```



### 예상 결과



```
80 초
```







## 직접 사용해 보기



[전체 도구 열기](<https://toolpony.com/ko/tools/bandwidth-calculator/>)







## 참고 사항



브라우저에서 처리합니다. 단위를 일관되게 사용하세요.







## 계산 방법



시간 in seconds = file bytes × 8 ÷ 초당 유효 비트. 네트워크 접두사는 소수입니다. 파일 크기는 소수 및 이진 접두사를 지원합니다.
