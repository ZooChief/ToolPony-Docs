# Convertir imágenes a PDF



Combina imágenes JPG, PNG, WebP y de otros formatos en un PDF.





## Primeros pasos



1. Añade las imágenes y ordénalas.
2. Elige el tamaño de papel, la orientación y el margen, y guarda el PDF.







## Ejemplo



### Entrada



```
Dos imágenes horizontales, A4, orientación automática
```



### Resultado esperado



```
Dos páginas A4 en horizontal
```







## Pruébalo



[Abrir herramienta completa](<https://toolpony.com/es/tools/jpg-to-pdf/>)







## Límites



Hasta 20 imágenes, 30 MB y 60 megapíxeles en total. Cada imagen admite 20 MB y 24 megapíxeles. La transparencia se vuelve blanca y solo se usa el primer fotograma de una animación.

[Documentación](https://docs.toolpony.com/es/guides/jpg-to-pdf/)
