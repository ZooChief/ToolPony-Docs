# 比例計算器



求比例中的未知項、化簡比例，或按倍數縮放兩項。





## 示例



### 輸入



```
3:4 = x:20
```



### 預期結果



```
x=15
```







## 試一試

[打開完整工具 · 比例計算器](<https://toolpony.com/zh-hant/tools/ratio-calculator/>)





## 計算方法



A:B = C:D 等價於 A×D = B×C，分母應非零。化簡支持小數和分數。







## 計算模式



**求未知項**

- A
- B
- C
- D





**化簡或縮放**

- 第一項
- 第二項
- 縮放倍數





**按倍數放大或縮小**

- 第一項
- 第二項
- 方向 · 縮小 / 放大
- 倍數
