# 最大公因数与最小公倍数使用指南



计算多组大整数的最大公因数和最小公倍数。





## 示例



### 输入



```
12、18、24
```



### 预期结果



```
最大公因数 6，最小公倍数 72
```







## 试一试

[打开完整工具 · 最大公因数与最小公倍数](<https://toolpony.com/zh-hans/tools/gcf-lcm-calculator/>)





## 计算方法



最大公因数使用欧几里得算法。两个非零数的最小公倍数为乘积的绝对值除以最大公因数。最多支持 100 个 50 位整数。
