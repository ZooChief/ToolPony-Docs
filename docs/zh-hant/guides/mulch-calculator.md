# 覆蓋料用量計算器



估算一塊或多塊區域的覆蓋料體積、整袋數及費用。





## 開始使用



1. 填寫總面積，或每行填寫一個長方形，例如 6, 2, m。各行可使用不同單位。
2. 設定厚度，選擇散裝或袋裝計價。自定義袋裝的容量在更多選項填寫。







## 示例



### 輸入



```
200 ft²、厚 2 in，每袋 2 ft³、單價 5。
```



### 預期結果



```
33.3 ft³，17 袋，費用 85。
```

## 使用提示



計算在瀏覽器內完成。無單位標記的字段請使用一致單位。







## 計算方法



合計互不重疊的區域面積，乘以鋪設厚度並加上損耗預留。體積除以每袋容量後向上取整。散裝費用按計算體積計價。



$$
A=\sum_i l_iw_i,\quad V=Ad(1+a/100),\quad N=\left\lceil\frac{V}{V_{\rm bag}}\right\rceil
$$







## 計算模式



**已知面積**

- 面積
- 面積單位 · cm² / m² / in² / ft² / yd² / acre / ha
- 鋪設厚度
- 厚度單位 · mm / cm / m / in / ft / yd
- 單價
- 計價單位
- 每袋容量
- 每袋容量單位 · ft³ / yd³ / m³ / L
- 損耗預留 · %





**多個長方形**

- 每行填寫長、寬、單位
