# 복리 계산기



반복되는 기여와 인플레이션으로 균형을 투사하거나 복리 주파수 간에 변환하십시오.





## 시작하기



1. 예제 값을 사용하거나 원하는 값을 입력하세요.
2. 계산한 결과를 복사하거나 세부 정보를 내려받을 수 있습니다.







## 예시



### 입력



```
10 년 동안 매년 5 %에서 10,000
```



### 예상 결과



```
16,288.95
```

## 계산 방법



실효 연간 성장률은 (1+r/m)^m−1이며 연속 복리에서는 exp(r)−1입니다. 추가 납입금에는 각 기간의 시작 또는 종료 중 선택한 시점부터 이자가 붙습니다.



$$
A=P(1+r/m)^{mt},\qquad \mathrm{APY}=(1+r/m)^m-1
$$
