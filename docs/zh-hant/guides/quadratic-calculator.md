# 二次方程計算器



求 ax² + bx + c = 0 的實根或復根，支持分數係數。





## 開始使用



1. 按示例填寫數值，或輸入你自己的測量值。
2. 計算後可複製結果或下載明細。







## 示例



### 輸入



```
a=1，b=−5，c=6
```



### 預期結果



```
x₁=2，x₂=3
```

## 使用提示



計算在瀏覽器內完成。無單位標記的字段請使用一致單位。







## 計算方法



判別式爲 b²−4ac。二次項係數爲零時按一次方程處理。



$$
ax^2+bx+c=0,\qquad x=\frac{-b\pm\sqrt{b^2-4ac}}{2a},\quad a\ne0
$$
