# 混凝土用量计算器



估算板、基础、圆管、路缘沟和台阶所需的混凝土体积、重量和整袋数。





## 开始使用



1. 选择实际形状，并为各尺寸设置单位。圆管模式使用内外直径。
2. 楼梯模式分别输入台阶级数和顶部平台进深。其余模式填写相同构件的数量。
3. 已知包装上的材料密度时可替换默认值。采购时看整袋数表。







## 示例



### 输入



```
7 英尺 × 3 英尺 × 5 英寸的板，数量 2
```



### 预期结果



```
17.5 立方英尺，按 133 磅/立方英尺计为 2,327.50 磅
```

## 计算方法



体积为截面积乘长度。默认按 133 磅/立方英尺算磅数，按 2,130 公斤/立方米算公斤数。自定义密度时两项结果按同一密度换算。采购先加损耗预留，再向上取整。



$$
V_{\rm slab}=lwhq,\quad V_{\rm tube}=\pi hq(d_o^2-d_i^2)/4
$$



$$
V_{\rm stairs}=brn\left[p+u(n-1)/2\right],\qquad m=V\rho
$$



楼梯公式中，b 为宽度，r 为每级高度，u 为每级水平进深，n 为台阶级数，p 为顶部平台进深。实体体积包含 n−1 段踏步和顶层平台。



两块 7 英尺 × 3 英尺 × 5 英寸的板，按 133 磅/立方英尺计需 2327.50 磅，折合 38.79 袋 60 磅装。未预留损耗时，采购表向上取整为 39 袋。
