# Conversor Unicode



Converter texto para pontos de código Unicode, bytes hexadecimais UTF-8 ou UTF-16 escapa, e decodificá-los de volta ao texto.





## Primeiros passos



1. Use o exemplo ou insira seus próprios valores.
2. Calcule, copie o resultado ou baixe os detalhes disponíveis.







## Exemplo



### Entrada



```
🐴
```



### Resultado esperado



```
U+1F434 ou F0 9F 90 B4
```

## Notas de uso



O cálculo é feito no seu navegador. Use unidades consistentes.







## Método de cálculo



O modo de ponto de código trata um caractere suplementar como um escalar. O UTF- 16 usa duas unidades de código para tal caractere. Sequências de substituição inválidas e bytes UTF- 8 inválidos são rejeitados.







## Modo de cálculo



**Codificar texto**

- Entrada
- Codificação · Pontos de código Unicode / Bytes hexadecimais UTF-8 / Escapes UTF-16 do JavaScript





**Descodificar texto**

- Entrada
- Codificação · Pontos de código Unicode / Bytes hexadecimais UTF-8 / Escapes UTF-16 do JavaScript
