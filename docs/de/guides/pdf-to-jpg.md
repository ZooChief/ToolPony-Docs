# PDF in JPG oder PNG umwandeln



Rendern Sie ausgewählte PDF-Seiten mit bis zu 300 DPI als Bilder.





## Erste Schritte



1. Wählen Sie eine PDF und markieren Sie Seiten in der Vorschau oder über die Seitennummern.
2. Wählen Sie JPG oder PNG und die Auflösung. Speichern Sie ein Bild oder ein ZIP.







## Beispiel



### Eingabe



```
Eine Seite mit 612 × 792 pt, PNG, 144 DPI
```



### Erwartetes Ergebnis



```
Ein PNG mit 1224 × 1584 Pixeln
```







## Ausprobieren



[Vollständiges Werkzeug öffnen](<https://toolpony.com/de/tools/pdf-to-jpg/>)







## Grenzen



Eingabe bis 30 MB und 300 Seiten. Je Export höchstens 40 Seiten und 60 Megapixel, je Seite 24 Megapixel und 8192 Pixel pro Kante. ZIP-Bilder sind auf 64 MB begrenzt. Seiten haben einen weißen Hintergrund. Verschlüsselte PDFs werden abgelehnt.

[Dokumentation](https://docs.toolpony.com/de/guides/pdf-to-jpg/)
