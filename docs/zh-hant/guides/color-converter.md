# 顏色轉換器



在 HEX、RGB 和 HSL 間轉換，保留透明度並預覽顏色。





## 開始使用



1. 按示例填寫數值，或輸入你自己的測量值。
2. 計算後可複製結果或下載明細。







## 示例



### 輸入



```
rgb(102, 51, 153)
```



### 預期結果



```
#663399，hsl(270 50% 40%)
```

## 使用提示



計算在瀏覽器內完成。無單位標記的字段請使用一致單位。







## 計算方法



HEX 表示 8 位通道。RGB 可輸入數值或百分比。HSL 色相用度，飽和度與亮度用百分比。HEX 輸出將各通道舍入到最接近的字節值。
