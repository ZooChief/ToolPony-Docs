# Calculatrice du métabolisme de base et des calories



Estimer les dépenses d'énergie au repos et les dépenses quotidiennes d'énergie en unités métriques ou américaines avec trois équations.





## Prise en main



1. Utilisez l’exemple ou saisissez vos propres valeurs.
2. Calculez, puis copiez le résultat ou téléchargez les détails.







## Exemple



### Entrée



```
équation mâle, 30 ans, 70 kg, 175 cm, Mifflin–St Jeor
```



### Résultat attendu



```
1 648,75 kcal/jour de repos
```







## Essayer



[Ouvrir l’outil complet](<https://toolpony.com/fr/tools/bmr-calculator/>)







## Notes



Le traitement se fait dans le navigateur. Utilisez des unités cohérentes.







## Méthode de calcul



L'énergie de repos est estimée avec Mifflin–St Jeor, Harris–Benedict révisé ou Katch–McArdle. Les dépenses quotidiennes multiplient l'estimation par votre facteur d'activité.







## Mode de calcul



**Métrique**

- Âge
- Groupe d'équations · Hommes / Femmes
- Poids · kg
- Hauteur · cm
- Équation · Mifflin–St Jeor / Harris–Bénédict révisé / Katch–McArdle
- Graisse corporelle pour Katch–McArdle · %
- Facteur d'activité
- Unité énergie · kcal/day / kJ/day





**Unités américaines**

- Âge
- Groupe d'équations · Hommes / Femmes
- Poids · lb
- Hauteur des pieds · ft
- pouces supplémentaires · in
- Équation · Mifflin–St Jeor / Harris–Bénédict révisé / Katch–McArdle
- Graisse corporelle pour Katch–McArdle · %
- Facteur d'activité
- Unité énergie · kcal/day / kJ/day
