# Convertisseur de chiffres romains



Convertir les chiffres romains et les entiers dans l'une ou l'autre direction, y compris les dates ou les listes délimitées.





## Prise en main



1. Utilisez l’exemple ou saisissez vos propres valeurs.
2. Calculez, puis copiez le résultat ou téléchargez les détails.







## Exemple



### Entrée



```
MCMXCIX
```



### Résultat attendu



```
1999
```

## Notes



Le traitement se fait dans le navigateur. Utilisez des unités cohérentes.







## Méthode de calcul



Le convertisseur utilise des paires de soustraction standard telles que IV et CM. Un surlignement multiplie un groupe par 1 000. Saisissez un pointage avant chaque lettre surligne ou collez le surlignement lui-même. Les valeurs sont limitées à 1–3 999 999. Le mode Date convertit chaque champ et préserve les séparateurs.







## Mode de calcul



**Valeur unique**

- Nombre entier ou romain





**Date ou liste**

- Valeurs ou date
