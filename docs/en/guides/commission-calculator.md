# Commission calculator



Find sales, rate, or commission, then calculate a base payment plus progressive tiers.





## Get started



1. Use the example values or enter your own measurements.
2. Calculate, then copy the result or download the available details.







## Example



### Input



```
16,500 at 8.25%
```



### Expected result



```
1,361.25 commission
```







## Try it



[Open full tool](<https://toolpony.com/en/tools/commission-calculator/>)







## Good to know



The calculation runs in your browser. Use consistent units in fields with no explicit unit.







## Calculation method



A single rate multiplies the sales amount. In a tier schedule, each threshold is the upper limit for that bracket. Percent tiers apply only to revenue in the bracket. Fixed tiers pay once when the bracket is entered.



$$
C=C_0+\sum_i s_i r_i\quad\text{(percentage tiers)}
$$







## Calculation mode



**Find commission**

- Sales amount
- Commission rate · %





**Find rate**

- Sales amount
- Commission amount





**Find sales amount**

- Commission rate · %
- Commission amount





**Base and tiers**

- Sales amount
- Base commission
- Base type · Fixed amount / Percent of sales
- Tier upper limit, rate (%, or fixed amount). Use \* for no limit.
