# Calculadora de densidade



Resolva a massa, volume ou densidade inserindo quaisquer dois valores.





## Primeiros passos



1. Use o exemplo ou insira seus próprios valores.
2. Calcule, copie o resultado ou baixe os detalhes disponíveis.







## Exemplo



### Entrada



```
8 kg, 0,001 m3
```



### Resultado esperado



```
8.000 kg/m3
```







## Experimente



[Abrir ferramenta completa](<https://toolpony.com/pt-br/tools/density-calculator/>)







## Notas de uso



O cálculo é feito no seu navegador. Use unidades consistentes.







## Método de cálculo



Densidade = volume de massa. A interface usa kg, m3 e kg/m3.



$$
\rho=\frac{m}{V}
$$
