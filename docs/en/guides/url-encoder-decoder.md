# URL encode and decode



Encode or decode complete URLs, URI components and form values.





## Get started



1. Use the example values or enter your own measurements.
2. Calculate, then copy the result or download the available details.







## Example



### Input



```
Encode component: a+b & c
```



### Expected result



```
a%2Bb%20%26%20c
```







## Try it



[Open full tool](<https://toolpony.com/en/tools/url-encoder-decoder/>)







## Good to know



The calculation runs in your browser. Use consistent units in fields with no explicit unit.







## Calculation method



Component encoding escapes reserved separators. Full URL encoding preserves separators. Form encoding uses plus for spaces.
