# 二维码生成器使用指南



选择扫描后要打开的类型，再填写链接、文本或相应字段。 输入时会自动更新二维码。Wi-Fi、名片等类型可核对编码内容，再下载 PNG 或 SVG。 可选取深色，也可输入六位 HEX 色值。两种导出都保留白色留边。





## 开始使用



1. 选择扫描后要打开的类型，再填写链接、文本或相应字段。
2. 输入时会自动更新二维码。Wi-Fi、名片等类型可核对编码内容，再下载 PNG 或 SVG。
3. 可选取深色，也可输入六位 HEX 色值。两种导出都保留白色留边。







## 示例



### 输入



```
https://example.com/ · M · 512 px
```



### 预期结果



```
PNG · 512 × 512 px → https://example.com/
```

## 适用范围



静态码直接编码所填内容。最多 2,048 个 UTF-8 字节，纠错级别较高时容量更小。白边保留四个模块宽的识读留白。Wi-Fi 二维码包含填写的密码。
