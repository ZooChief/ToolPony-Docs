# Calculadora de divisores comunes



Enumerar todos los factores comunes positivos y calcular el mayor factor común de múltiples enteros.





## Primeros pasos



1. Usa el ejemplo o introduce tus propios valores.
2. Calcula, copia el resultado o descarga los detalles disponibles.







## Ejemplo



### Entrada



```
12, 18, 30
```



### Resultado esperado



```
1, 2, 3, 6
```

## Método de cálculo



Los factores comunes de una lista son exactamente los divisores de su mayor divisor común. El algoritmo de Euclidean encuentra que divisor sin enumerar los factores de cada entrada.



$$
d\mid a_1,\ldots,a_n\iff d\mid\gcd(a_1,\ldots,a_n)
$$
