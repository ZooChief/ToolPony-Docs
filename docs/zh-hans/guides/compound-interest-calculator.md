# 复利计算器



估算含定期投入和通胀的复利余额，或在不同计息频率间换算。





## 开始使用



1. 按示例填写数值，或输入你自己的测量值。
2. 计算后可复制结果或下载明细。







## 示例



### 输入



```
10,000 按 5% 年复利，10 年
```



### 预期结果



```
16,288.95
```

计算在浏览器内完成。无单位标记的字段请使用一致单位。







## 计算方法



实际年增长率为 (1+r/m)^m−1，连续复利为 exp(r)−1。定期投入按选定的期初或期末开始计息。



$$
A=P(1+r/m)^{mt},\qquad \mathrm{APY}=(1+r/m)^m-1
$$
