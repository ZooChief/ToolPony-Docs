# 電気料金計算機



機器、負荷、単価から指定日数または日・週・月・年の電力量と料金を推定します。





## 使い方



1. 機器の消費電力、使用時間、単価を入力します。プリセットの例は変更できます。







## 例



### 入力



```
1,000 W、1 日 2 h、30 日、0.2/kWh
```



### 期待される結果



```
60 kWh、料金 12
```







## 試してみる



[ツール全体を開く](<https://toolpony.com/ja/tools/electricity-cost-calculator/>)







## 注意点



処理はブラウザ内で実行されます。単位をそろえて入力してください。







## 計算方法



消費電力量は kW、運転時間、平均負荷、台数の積です。単一の料金単価を使い、月 30.44 日・年 365.25 日で推定します。冷房能力は熱移動量なので、料金計算には消費電力を使います。



$$
E_{\rm kWh}=P_{\rm kW}\,t_{\rm h}\,f\,n,\qquad C=E_{\rm kWh}\,r
$$







## 計算モード



**日数を指定**

- 電力
- 電力の単位 · W / kW / BTU/h / PS / TR
- 平均負荷 · %
- 台数
- 1 日の運転時間 · h
- 日数
- kWh あたりの料金





**日・週・月・年の見積もり**

- 家電のプリセット
- 電力
- 電力の単位 · W / kW / BTU/h / PS / TR
- 平均負荷 · %
- 台数
- 使用時間
- 使用時間の単位 · 分/日 / 1 日の運転時間 / 時間/週 / 時間/月 / 日/週 / 日/月 / 日/年 / 月/年
- kWh あたりの料金
