# Fuel cost and mileage calculator



Convert fuel economy units, estimate the fuel cost of a trip, or calculate measured fuel economy.





## Get started



1. Use the example values or enter your own measurements.
2. Calculate, then copy the result or download the available details.







## Example



### Input



```
300 km, 7 L/100 km, price 1.5 per liter
```



### Expected result



```
21 L; fuel cost 31.50
```







## Try it



[Open full tool](<https://toolpony.com/en/tools/fuel-cost-calculator/>)







## Good to know



The calculation runs in your browser. Use consistent units in fields with no explicit unit.







## Calculation method



Fuel used = distance × L/100 km ÷ 100. US and imperial miles per gallon use different gallon volumes. Fuel prices are user-supplied.







## Calculation mode



**Trip cost**

- Distance · km
- Fuel economy
- Fuel economy unit · L/100 km / km/L / mpg (US) / mpg (imperial)
- Price per liter





**Convert fuel economy**

- Fuel economy
- Input unit · L/100 km / km/L / mpg (US) / mpg (imperial)





**Measured mileage**

- Distance · km
- Fuel used · L
