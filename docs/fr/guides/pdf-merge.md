# Fusionner des PDF



Assemblez plusieurs PDF dans l’ordre de votre choix, sur votre appareil.





## Prise en main



1. Sélectionnez au moins deux PDF.
2. Réorganisez les fichiers avec les flèches et enregistrez le document fusionné.







## Exemple



### Entrée



```
A.pdf (2 pages) et B.pdf (3 pages)
```



### Résultat attendu



```
Un PDF dans l’ordre A1, A2, B1, B2, B3
```







## Essayer



[Ouvrir l’outil complet](<https://toolpony.com/fr/tools/pdf-merge/>)







## Limites



30 Mo et 300 pages au total. Les PDF chiffrés sont refusés. Les formulaires, signets et signatures numériques peuvent être perdus.

[Documentation](https://docs.toolpony.com/fr/guides/pdf-merge/)
