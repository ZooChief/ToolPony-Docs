# 砂石用量计算器



估算碎石或砂的体积、重量、整袋数和费用。





## 开始使用



1. 选择已知面积、长方形或圆形，再填写铺设厚度。
2. 选择材料。可在更多选项填写自定义密度或每袋容量。







## 示例



### 输入



```
200 ft²、厚 3 in，碎石密度 1,680 kg/m³。
```



### 预期结果



```
50 ft³（1.42 m³），约 2,379 kg。
```

## 使用提示



计算在浏览器内完成。无单位标记的字段请使用一致单位。







## 计算方法



面积乘铺设厚度，再加损耗预留。重量等于体积乘散装密度。按袋计价时先向上取整袋数。已知供应商给出的散装密度时，优先使用该值。



$$
V=Ad(1+w/100),\qquad m=\rho V,\qquad N=\left\lceil\frac{m}{m_{\rm bag}}\right\rceil\ \text{or}\ \left\lceil\frac{V}{V_{\rm bag}}\right\rceil
$$
