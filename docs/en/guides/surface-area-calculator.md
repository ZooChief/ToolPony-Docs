# Surface area calculator



Solve spheres, cones, tanks, capsules, caps, ellipsoids, pyramids and hollow tubes with mixed dimensions.





## Get started



1. Use the example values or enter your own measurements.
2. Calculate, then copy the result or download the available details.







## Example



### Input



```

```



### Expected result



```
≈50.2655 m²
```







## Try it



[Open full tool](<https://toolpony.com/en/tools/surface-area-calculator/>)







## Good to know



The calculation runs in your browser. Use consistent units in fields with no explicit unit.







## Calculation method



Total surface area includes end faces. Where applicable, lateral and end-face areas are listed separately. Ellipsoid area is approximate.



$$
A_{\mathrm{cylinder}}=2\pi r^2+2\pi rh,\qquad A_{\mathrm{sphere}}=4\pi r^2
$$
