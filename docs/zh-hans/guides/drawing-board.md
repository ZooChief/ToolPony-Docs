# 在线画板



用画笔或橡皮擦在画布上绘制，调整颜色与粗细，撤销或重做笔画，最后下载透明 PNG。





## 开始使用



1. 选择画笔或橡皮擦，设置粗细。
2. 使用鼠标、手指或触控笔绘制。
3. 撤销或重做笔画，然后导出透明 PNG。







## 试一试



[打开完整工具](<https://toolpony.com/zh-hans/tools/drawing-board/>)







## 使用提示



在可用的历史记录内可以撤销清空。关闭标签页前请导出 PNG。







## 适用范围



画布为 1080 × 640 像素，内容保留在当前标签页。使用 Ctrl/Cmd+Z 撤销，Ctrl/Cmd+Shift+Z 重做。
