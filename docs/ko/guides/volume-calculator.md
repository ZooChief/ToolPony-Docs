# 부피 계산기



구체, 콘, 탱크, 캡슐, 모자, 타원, 피라미드 및 혼합 차원을 가진 중공 관을 해결합니다.





## 시작하기



1. 예제 값을 사용하거나 원하는 값을 입력하세요.
2. 계산한 결과를 복사하거나 세부 정보를 내려받을 수 있습니다.







## 예시



### 입력



```
반경 2개 m를 가진 구체
```



### 예상 결과



```
≈33.5103 m³
```

## 계산 방법



프리즘의 부피는 기본 면적 시간 수직 높이입니다. 원뿔 또는 피라미드는 해당 제품을 세 개로 나눕니다. 중공 튜브는 내부 실린더를 뺍니다. 구형 캡은 두 가지 차원을 허용합니다.



$$
V_{\mathrm{cone}}=\tfrac13\pi r^2h,\qquad V_{\mathrm{sphere}}=\tfrac43\pi r^3
$$
