# Fuel cost and mileage calculator guide



Convert fuel economy units, estimate the fuel cost of a trip, or calculate measured fuel economy.





## Example



### Input



```
300 km, 7 L/100 km, price 1.5 per liter
```



### Expected result



```
21 L; fuel cost 31.50
```

## Calculation method



Fuel used = distance × L/100 km ÷ 100. US and imperial miles per gallon use different gallon volumes. Fuel prices are user-supplied.







## Calculation mode





### Trip cost



- Distance
- Distance unit · km / mi
- Fuel economy
- Fuel economy unit · L/100 km / km/L / mpg (US) / mpg (imperial)
- Pump price
- Pump price unit · L / US gal / UK gal







### Convert fuel economy



- Fuel economy
- Input unit · L/100 km / km/L / mpg (US) / mpg (imperial)
- Output unit · L/100 km / km/L / mpg (US) / mpg (imperial)







### Measured mileage



- Distance
- Distance unit · km / mi
- Fuel used
- Volume unit · L / US gal / UK gal







**Method references** [NIST · Unit conversion factors](<https://www.nist.gov/pml/special-publication-811/nist-guide-si-appendix-b-conversion-factors/nist-guide-si-appendix-b8>)
