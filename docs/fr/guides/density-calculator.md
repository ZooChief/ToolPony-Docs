# Guide pratique · Calculatrice de masse volumique



Résolvez pour la masse, le volume ou la densité en entrant deux valeurs.





## Exemple



### Entrée



```
8 kg, 0,001 m3
```



### Résultat attendu



```
8 000 kg/m3
```







## Essayer

[Ouvrir l’outil complet · Calculatrice de masse volumique](<https://toolpony.com/fr/tools/density-calculator/>)





## Méthode de calcul



La masse volumique est la masse divisée par le volume. Le calcul utilise les kilogrammes et les mètres cubes puis convertit le résultat dans l’unité choisie.



$$
\rho=\frac{m}{V}
$$
