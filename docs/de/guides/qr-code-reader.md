# QR-Code-Scanner



Wählen, ziehen oder fügen Sie ein Bild ein. Im eigenständigen Werkzeug können Sie auch die Kamera nutzen. Prüfen Sie den Text und kopieren oder speichern Sie ihn. Öffnen Sie Weblinks erst nach Prüfung der Adresse.





## Erste Schritte



1. Wählen, ziehen oder fügen Sie ein Bild ein. Im eigenständigen Werkzeug können Sie auch die Kamera nutzen.
2. Prüfen Sie den Text und kopieren oder speichern Sie ihn. Öffnen Sie Weblinks erst nach Prüfung der Adresse.







## Beispiel



### Eingabe



```
Beispiel lesen
```



### Erwartetes Ergebnis



```
https://example.com/qr-sample
```







## Ausprobieren



[Vollständiges Werkzeug öffnen](<https://toolpony.com/de/tools/qr-code-reader/>)







## Grenzen



Ein QR-Code pro Scan. Bilder bis 20 MiB und 24 Megapixel, darunter unterstützte PNG, JPEG, WebP und SVG. Die Kamera braucht Freigabe und stoppt nach dem Lesen. Bilder und Frames bleiben auf dem Gerät.

[Dokumentation](https://docs.toolpony.com/de/guides/qr-code-reader/)
