# Calculadora de relación deuda-ingresos



Compare sus pagos mensuales recurrentes de deuda con ingresos mensuales brutos.





## Primeros pasos



1. Usa el ejemplo o introduce tus propios valores.
2. Calcula, copia el resultado o descarga los detalles disponibles.







## Ejemplo



### Entrada



```
Ingresos 5.000, pagos de deuda 1.500
```



### Resultado esperado



```
30%
```







## Pruébalo



[Abrir herramienta completa](<https://toolpony.com/es/tools/debt-to-income-calculator/>)







## Notas de uso



El cálculo se ejecuta en tu navegador. Usa unidades coherentes.







## Método de cálculo



Tasa de deuda a ingresos = pagos mensuales de deuda ÷ ingreso mensual bruto. Use la misma moneda y un período mensual para todas las cantidades.
