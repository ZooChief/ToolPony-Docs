# 最大公因數與最小公倍數



計算多組大整數的最大公因數和最小公倍數。





## 開始使用



1. 按示例填寫數值，或輸入你自己的測量值。
2. 計算後可複製結果或下載明細。







## 示例



### 輸入



```
12、18、24
```



### 預期結果



```
最大公因數 6，最小公倍數 72
```

## 使用提示



計算在瀏覽器內完成。無單位標記的字段請使用一致單位。







## 計算方法



最大公因數使用歐幾里得算法。兩個非零數的最小公倍數爲乘積的絕對值除以最大公因數。最多支持 100 個 50 位整數。
