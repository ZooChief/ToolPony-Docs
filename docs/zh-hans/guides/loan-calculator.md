# 贷款计算器



计算分期、按月供反求期限、规划按日期提前还款，并导出完整明细。





## 开始使用



1. 选择固定期限、目标月供或按日期提前还款。
2. 按日期提前还款时先填首次还款月，再按行填写一次性还款，例如 2026-06, 500。
3. 计算后切换明细表，再下载当前选中的表格。







## 示例



### 输入



```
本金 100,000，期限 10 年，年利率 6%，按月
```



### 预期结果



```
月还款约 1,110.21
```

## 计算方法



分期模式将名义年利率换算到还款期。日期模式按月计息，额外金额在计划还款后抵减本金。使用固定利率，中间金额不逐期取整到分。



$$
M=\frac{Pr}{1-(1+r)^{-n}},\qquad M=\frac Pn\quad(r=0)
$$



$$
n=\frac{-\ln(1-Pr/M)}{\ln(1+r)},\qquad M>Pr\quad(r>0)
$$



$$
I_k=r B_{k-1},\qquad B_k=\max(0,B_{k-1}-(M-I_k)-E_k)
$$



P 为本金，r 为每期利率，M 为计划还款额，n 为期数。反求期限和按日期提前还款模式用年利率百分数除以 1,200 得到 r。B 为剩余本金，I 为利息，E 为冲减本金的额外金额。



本金 45,000，年利率 6.3%，月供 785，估计 68.38 个月还清。按整月账单共 69 期，最后一期金额较小。下载前可切换对应的明细。
