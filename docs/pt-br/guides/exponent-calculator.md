# Calculadora de potências



Resolva uma potência, a base, ou o expoente dos outros dois valores.





## Primeiros passos



1. Use o exemplo ou insira seus próprios valores.
2. Calcule, copie o resultado ou baixe os detalhes disponíveis.







## Exemplo



### Entrada



```
Base 2, expoente 5
```



### Resultado esperado



```
32
```

## Notas de uso



O cálculo é feito no seu navegador. Use unidades consistentes.







## Método de cálculo



Para y = bn, solucione o expoente com logaritmos quando b e y são positivos e b 1. Solucionando para uma base real com um expoente não zero mesmo inteiro pode produzir duas raízes.



$$
y=b^p,\qquad p=\frac{\ln y}{\ln b},\qquad b=\sqrt[p]{y}
$$
