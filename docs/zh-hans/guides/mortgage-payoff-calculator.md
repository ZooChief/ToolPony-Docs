# 房贷提前还款计算器



比较房贷原还款计划、额外还款、一次结清与两种双周还款，查看剩余期限和节省利息。





## 开始使用



1. 若之前做过额外还款，选账单余额模式，填入当前本金与本息月供。也可用原贷款和剩余期限推算余额。
2. 选择还款方案。可填写每月、每年或一次性的额外金额，默认分别从第 1、12、1 个月起算，起始月份可在更多选项修改。
3. 对比所选方案与原方案，再下载剩余还款表或对比 CSV。
4. 这里只估算本金与固定利息。实际结清报价可能含按日利息、费用和违约金，请向贷款机构核对。







## 示例



### 输入



```
原贷款 400,000，30 年，年利率 6%。剩 25 年，每月多还 500。
```



### 预期结果



```
207 个月还清，节省利息 122,306.21
```

## 计算方法



由原贷款推算时，假设先前每期均按计划还款。月利息是剩余本金乘以年利率再除以 12。按月汇总的双周方案每 6 个月多还半笔月供。每年 26 期方案每期还半笔月供，按年利率除以 26 计息。



$$
B=M\frac{1-(1+r)^{-n}}r\quad(r>0),\qquad B=Mn\quad(r=0)
$$



$$
I_k=rB_{k-1},\qquad B_k=\max(0,B_{k-1}-M+I_k-E_k)
$$



$$
E_{6j}=M/2\quad\text{(grouped)},\qquad M_{26}=M/2,\quad r_{26}=r_{\rm annual}/26
$$
