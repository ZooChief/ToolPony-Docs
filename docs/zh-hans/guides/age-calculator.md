# 年龄计算器



计算周岁、出生至今的时长和下次生日。





## 开始使用



1. 填出生日期和计算日期。计算日期留空时用设备上的今天。







## 示例



### 输入



```
出生 2000-01-01，计算日期 2025-02-03
```



### 预期结果



```
25 岁 1 个月 2 天
```

## 使用提示



计算在浏览器内完成。无单位标记的字段请使用一致单位。







## 计算方法



月份对齐同一日，短月取月末。2 月 29 日出生可选在平年 2 月 28 日或 3 月 1 日过周年。总时长按每个日历日 24 小时换算。
