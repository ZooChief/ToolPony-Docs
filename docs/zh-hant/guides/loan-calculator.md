# 貸款計算器



計算分期、按月供反求期限、規劃按日期提前還款，並導出完整明細。





## 開始使用



1. 選擇固定期限、目標月供或按日期提前還款。
2. 按日期提前還款時先填首次還款月，再按行填寫一次性還款，例如 2026-06, 500。
3. 計算後切換明細表，再下載當前選中的表格。







## 示例



### 輸入



```
本金 100,000，期限 10 年，年利率 6%，按月
```



### 預期結果



```
月還款約 1,110.21
```

## 計算方法



分期模式將名義年利率換算到還款期。日期模式按月計息，額外金額在計劃還款後抵減本金。使用固定利率，中間金額不逐期取整到分。



$$
M=\frac{Pr}{1-(1+r)^{-n}},\qquad M=\frac Pn\quad(r=0)
$$



$$
n=\frac{-\ln(1-Pr/M)}{\ln(1+r)},\qquad M>Pr\quad(r>0)
$$



$$
I_k=r B_{k-1},\qquad B_k=\max(0,B_{k-1}-(M-I_k)-E_k)
$$



P 爲本金，r 爲每期利率，M 爲計劃還款額，n 爲期數。反求期限和按日期提前還款模式用年利率百分數除以 1,200 得到 r。B 爲剩餘本金，I 爲利息，E 爲衝減本金的額外金額。



本金 45,000，年利率 6.3%，月供 785，估計 68.38 個月還清。按整月賬單共 69 期，最後一期金額較小。下載前可切換對應的明細。
