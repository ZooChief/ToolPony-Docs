# Unir PDF



Combina varios PDF en el orden que elijas, desde tu dispositivo.





## Primeros pasos



1. Selecciona al menos dos PDF.
2. Ajusta el orden con las flechas y guarda el PDF combinado.







## Ejemplo



### Entrada



```
A.pdf (2 páginas) y B.pdf (3 páginas)
```



### Resultado esperado



```
Un PDF con A1, A2, B1, B2, B3 en ese orden
```







## Pruébalo



[Abrir herramienta completa](<https://toolpony.com/es/tools/pdf-merge/>)







## Límites



Hasta 30 MB y 300 páginas en total. Se rechazan los PDF cifrados. Los formularios, marcadores y firmas digitales pueden perderse.

[Documentación](https://docs.toolpony.com/es/guides/pdf-merge/)
