# 佣金计算器



求销售额、佣金率或佣金，也可计算底佣叠加阶梯佣金。





## 开始使用



1. 按示例填写数值，或输入你自己的测量值。
2. 计算后可复制结果或下载明细。







## 示例



### 输入



```
销售额 16,500，佣金率 8.25%
```



### 预期结果



```
佣金 1,361.25
```

## 使用提示



计算在浏览器内完成。无单位标记的字段请使用一致单位。







## 计算方法



单一费率乘以销售额。阶梯表每行的阈值是该档上限，百分比仅作用于该档收入，固定佣金在进入该档时支付一次。



$$
C=C_0+\sum_i s_i r_i\quad\text{(percentage tiers)}
$$







## 计算模式



**求佣金**

- 销售额
- 佣金率 · %





**求费率**

- 销售额
- 佣金金额





**求销售额**

- 佣金率 · %
- 佣金金额





**底佣与阶梯**

- 销售额
- 底佣
- 底佣类型 · 固定金额 / 销售额百分比
- 每行填写档位上限和费率（% 或固定金额）。用 \* 表示不限。
