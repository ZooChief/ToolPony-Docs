# 自動車ローン計算機



下取り、残債、値引き、税金を含め、月返済額や車両価格の上限を計算します。





## 使い方



1. 車両価格を入力するか目標月返済額に切り替えます。頭金、下取り額と残債、値引きを入力します。
2. 税率と手数料、課税額の控除と借入への組み入れを選び、返済表を保存します。







## 例



### 入力



```
車両価格30,000、頭金5,000、60か月、年利5%
```



### 期待される結果



```
税・手数料なしで月471.78
```

## 注意点



処理はブラウザ内で実行されます。単位をそろえて入力してください。







## 計算方法



税率と課税額から差し引く項目を指定します。借入に含めた税や手数料は元金に加算します。下取り純額は下取り額から残債を引いた額です。固定月利で計算します。



$$
P=V-D-(T-O)-R+F,\quad M=\frac{Pr}{1-(1+r)^{-n}},\quad M=\frac Pn\; (r=0)
$$



V は車両価格、D は頭金、T は下取り額、O は下取り車の残債、R は値引き、F は借入に含む税と手数料です。P は元金、M は月返済額、r は月利、n は月数です。
