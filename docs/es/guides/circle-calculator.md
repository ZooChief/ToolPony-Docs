# Calculadora de círculos



Encontrar radio, diámetro, circunferencia y área de cualquier medida conocida. Calcular arcos, sectores y acordes.





## Primeros pasos



1. Usa el ejemplo o introduce tus propios valores.
2. Calcula, copia el resultado o descarga los detalles disponibles.







## Ejemplo



### Entrada



```
Radius 2; ángulo central 90°
```



### Resultado esperado



```
Circunferencia ♥12.5664; arc ♥3.1416
```

## Notas de uso



El cálculo se ejecuta en tu navegador. Usa unidades coherentes.







## Método de cálculo



Circumference = 2πr. Area = πr2. Longitud del arco y escala del sector con el ángulo central dividido en 360°.



$$
A=\pi r^2,\qquad C=2\pi r
$$
