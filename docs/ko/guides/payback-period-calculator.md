# 투자 회수 기간 계산기



성장 또는 불규칙한 연간 현금 흐름에서 정기적이고 할인 된 회수를 찾으십시오.





## 시작하기



1. 예제 값을 사용하거나 원하는 값을 입력하세요.
2. 계산한 결과를 복사하거나 세부 정보를 내려받을 수 있습니다.







## 예시



### 입력



```
17,500 초기, 첫 번째 유입 4,700, 성장 8%, 6% 할인
```



### 예상 결과



```
페이백 ≈ 3.379년, 할인 ≈ 3.841년
```

## 계산 방법



초기 지출부터 현금 흐름을 누적합니다. 처음으로 누적액이 0을 넘는 해에는 그해의 경과 비율을 보간합니다. 할인 현금 흐름은 k년 차 금액을 (1+r)^k로 나눕니다. 현금 흐름이 일정하면 연금 공식을 역산해 할인 회수 기간을 구합니다.



$$
C_k=\sum_{i=0}^{k}F_i,\qquad F_i^{\mathrm{PV}}=\frac{F_i}{(1+r)^i}
$$







## 계산 모드



**정기적이거나 증가하는 현금 흐름**

- 초기 투자액
- 1년차 현금흐름
- 연간 성장 또는 감소 · %
- 년
- 연간 할인율 · %





**불규칙한 연간 현금 흐름**

- 초기 투자액
- 후속 연간 현금 흐름
- 연간 할인율 · %
