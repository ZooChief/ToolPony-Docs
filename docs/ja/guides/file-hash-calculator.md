# ファイル・テキストのハッシュ計算



テキストまたはファイルを選択し、SHA-2アルゴリズムを選択して計算します。 予想されたダイジェストを貼り付けて一致確認するか、結果をCSVとしてダウンロードしてください。





## 使い方



1. テキストを選択するか、1つ以上のファイルを選択してください。
2. SHA-256、SHA-384、またはSHA-512を選択し、計算してください。
3. 予期していたハッシュを貼り付けて検証するか、結果CSVをダウンロードしてください。







## 例



### 入力



```
テキスト:abc、UTF-8、SHA-256
```



### 期待される結果



```
ba7816bf8f01cfea414140de5dae2223b00361a396177a9cb410ff61f20015ad
```

## 注意点



ハッシュ検証はバイトを比較しています。 異なる符号化、行終了、あるいは1つの変更されたバイトは、異なるダイジェストを生成する。







## 制限



ファイルは最大 16 個、合計 64 MB、テキストは最大 100 万文字です。テキストは UTF-8 として扱い、ファイルはブラウザ内で順次処理します。
