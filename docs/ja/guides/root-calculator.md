# 累乗根計算機



主な実の正方形、立方体、または9番目の根を計算します。





## 例



### 入力



```
144の平方根
```



### 期待される結果



```
12
```







## 試してみる

[ツール全体を開く · 累乗根計算機](<https://toolpony.com/ja/tools/root-calculator/>)





## 計算方法



n の根は x を 1/n に上げます。 奇数整数度は負の急進を許容する。 マイナスの度合いは相互的なものを取る。



$$
\sqrt[n]{x}=x^{1/n},\qquad n\ne0
$$







## 計算モード



**平方根**

- 根号の中の値





**立方根**

- 根号の中の値





**n 乗根**

- 根号の中の値
- 学位
