# Umrechner für römische Zahlen



Konvertieren Sie römische Ziffern und ganze Zahlen in beide Richtungen, einschließlich Datumsangaben oder begrenzter Listen.





## Erste Schritte



1. Verwenden Sie das Beispiel oder geben Sie eigene Werte ein.
2. Berechnen Sie das Ergebnis und kopieren oder laden Sie die Details herunter.







## Beispiel



### Eingabe



```
MCMXCIX
```



### Erwartetes Ergebnis



```
1999
```







## Ausprobieren



[Vollständiges Werkzeug öffnen](<https://toolpony.com/de/tools/roman-numeral-converter/>)







## Hinweise



Die Verarbeitung erfolgt im Browser. Verwenden Sie einheitliche Einheiten.







## Berechnungsmethode



Der Konverter verwendet standardmäßige subtraktive Paare wie IV und CM. Eine Overline multipliziert eine Gruppe mit 1.000. Geben Sie vor jedem überstrichenen Buchstaben einen Unterstrich ein oder fügen Sie die Overline selbst ein. Werte sind auf 1-3,999,999 begrenzt. Der Datumsmodus konvertiert jedes Feld und bewahrt Trennzeichen.







## Berechnungsmodus



**Einzelwert**

- Ganzzahl oder römische Zahl





**Datum oder Liste**

- Werte oder Datum
