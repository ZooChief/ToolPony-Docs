# Calculadora de interés compuesto



Proyecte un equilibrio con las contribuciones recurrentes y la inflación, o convierta entre frecuencias agravantes.





## Primeros pasos



1. Usa el ejemplo o introduce tus propios valores.
2. Calcula, copia el resultado o descarga los detalles disponibles.







## Ejemplo



### Entrada



```
10.000 al 5% anual durante 10 años
```



### Resultado esperado



```
16,288.95
```

## Notas de uso



El cálculo se ejecuta en tu navegador. Usa unidades coherentes.







## Método de cálculo



El crecimiento anual efectivo es (1+r/m)^m−1, o exp(r)−1 con compuesto continuo. Las contribuciones ganan interés desde el comienzo o fin seleccionados de cada período.



$$
A=P(1+r/m)^{mt},\qquad \mathrm{APY}=(1+r/m)^m-1
$$







## Modo de cálculo



**Saldo futuro**

- Principal
- Tasa anual · %

- Contribución periódica

- Contribuir al comienzo del período
- inflación anual · %





**Tasa de interés equitativa**

- Tasa anual · %
- Composición original
