# Calculatrice de remises



Incluez les rabais, soustrayez un coupon fixe et appliquez la taxe de vente au prix réduit.





## Prise en main



1. Utilisez l’exemple ou saisissez vos propres valeurs.
2. Calculez, puis copiez le résultat ou téléchargez les détails.







## Exemple



### Entrée



```
100 avec 20% et 10% de rabais
```



### Résultat attendu



```
72; rabais combiné 28%
```

[Ouvrir l’outil complet](<https://toolpony.com/fr/tools/discount-calculator/>)







## Notes



Le traitement se fait dans le navigateur. Utilisez des unités cohérentes.







## Méthode de calcul



Appliquer des réductions en pourcentage dans l'ordre, puis le coupon fixe, puis taxe. Jusqu'à 10 taux de 0% à 100%.



Deux remises successives de 20 % et 10 % laissent 0,8 × 0,9 du prix initial. Entrez les deux taux dans l'ordre, puis ajoutez un coupon ou une taxe s'il y a lieu.



Utilisez un mode inverse lorsque vous connaissez le prix de vente ou le montant économisé. Les modes inverses gèrent un rabais avant taxe.







## Mode de calcul



**Appliquer des rabais**

- Prix d'origine
- Pourcentages d'actualisation
- Coupon fixe
- Taux d’imposition · %





**Trouver le prix original**

- Prix après rabais
- Type de rabais · Pourcentage / Montant fixe
- Réduction





**Trouver le taux et l'épargne**

- Prix d'origine
- Montant connu · Prix réduit / Économies
- Montant





**Trouver les prix de l'épargne**

- Montant économisé
- Taux d’actualisation · %
