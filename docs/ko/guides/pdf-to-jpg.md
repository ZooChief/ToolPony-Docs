# PDF를 JPG·PNG로 변환



선택한 PDF 페이지를 최대 300 DPI의 이미지로 변환합니다.





## 시작하기



1. PDF를 선택하고 미리 보기나 번호로 페이지를 지정합니다.
2. JPG 또는 PNG와 해상도를 선택해 이미지나 ZIP을 저장합니다.







## 예시



### 입력



```
612 × 792 pt 페이지 한 장, PNG, 144 DPI
```



### 예상 결과



```
1224 × 1584픽셀 PNG
```







## 직접 사용해 보기



[전체 도구 열기](<https://toolpony.com/ko/tools/pdf-to-jpg/>)







## 제한 사항



입력은 최대 30 MB, 300페이지입니다. 한 번에 최대 40페이지와 6천만 화소까지 내보냅니다. 페이지당 2,400만 화소, 한 변 8,192픽셀, ZIP 이미지 합계 64 MB로 제한됩니다. 흰 배경으로 렌더링하며 암호화 PDF는 지원하지 않습니다.
