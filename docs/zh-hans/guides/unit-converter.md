# 单位换算



换算长度、质量、面积、体积、温度、速度、能量、数字存储等单位。





## 开始使用



1. 按示例填写数值，或输入你自己的测量值。
2. 计算后可复制结果或下载明细。







## 示例



### 输入



```
1 米转英尺
```



### 预期结果



```
约 3.28084 英尺
```

## 使用提示



计算在浏览器内完成。无单位标记的字段请使用一致单位。







## 计算方法



每组先换算到标准基准单位。美制和英制体积分开，十进制与二进制存储单位采用各自基数。
