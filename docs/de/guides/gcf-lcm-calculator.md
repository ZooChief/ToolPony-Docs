# ggT- und kgV-Rechner



Finden Sie den größten gemeinsamen Faktor und den kleinsten gemeinsamen Vielfachen für eine Liste großer Ganzzahlen.





## Erste Schritte



1. Verwenden Sie das Beispiel oder geben Sie eigene Werte ein.
2. Berechnen Sie das Ergebnis und kopieren oder laden Sie die Details herunter.







## Beispiel



### Eingabe



```
12, 18, 24
```



### Erwartetes Ergebnis



```
GCF 6; LCM 72
```







## Ausprobieren

## Hinweise



Die Verarbeitung erfolgt im Browser. Verwenden Sie einheitliche Einheiten.







## Berechnungsmethode



Der euklidische Algorithmus berechnet den ggT. Wenn beide Zahlen ungleich null sind, gilt kgV(a,b) = |a·b| ÷ ggT(a,b). Gib bis zu 100 ganze Zahlen mit je höchstens 50 Stellen ein.
