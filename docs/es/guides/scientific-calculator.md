# Calculadora científica



Evaluar expresiones matemáticas con poderes, factoriales, trigonometría, raíces y logaritmos.





## Primeros pasos



1. Usa el ejemplo o introduce tus propios valores.
2. Calcula, copia el resultado o descarga los detalles disponibles.







## Ejemplo



### Entrada



```
sqrt(81) + 2^3 × sin(30), grados
```



### Resultado esperado



```
13
```
