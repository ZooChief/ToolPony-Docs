# QRコード読み取り



画像を選択、ドロップ、または貼り付けます。ツール単体のページではカメラも使えます。 内容を確認し、コピーまたは保存します。アドレスを確認してからリンクを開いてください。





## 使い方



1. 画像を選択、ドロップ、または貼り付けます。ツール単体のページではカメラも使えます。
2. 内容を確認し、コピーまたは保存します。アドレスを確認してからリンクを開いてください。

## 制限



1回につきQRコード1個。PNG、JPEG、WebP、SVGなど最大20 MiB、2,400万画素です。カメラには許可が必要で、読み取ると停止します。画像やフレームは端末内に留まります。
