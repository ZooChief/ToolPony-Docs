# 分数计算器



精确计算分数和带分数的加减乘除、约分及小数转换。





## 开始使用



1. 按示例填写数值，或输入你自己的测量值。
2. 计算后可复制结果或下载明细。







## 示例



### 输入



```
1 1/2 + 2/3
```



### 预期结果



```
13/6
```

## 计算方法



小数按十进制精确转换为分数。运算使用大整数并按最大公因数约分。小数展示为近似值。



$$
\frac{a}{b}+\frac{c}{d}=\frac{ad+bc}{bd},\qquad b,d\ne0
$$







## 计算模式



**分数运算**

**约分或转换**

- 数值





**分数转小数**

- 分数或带分数
