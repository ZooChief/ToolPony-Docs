# 신뢰구간 계산기



일반적인 평균 간격 또는 비율에 대한 윌슨 간격을 추정합니다.





## 시작하기



1. 예제 값을 사용하거나 원하는 값을 입력하세요.
2. 계산한 결과를 복사하거나 세부 정보를 내려받을 수 있습니다.







## 예시



### 입력



```
n = 36, 평균 56, 표준 편차 8, 99%
```



### 예상 결과



```
56 ± 3.434
```

## 계산 방법



일반 마진은 표준 오류의 z 곱하기 표준 오류 s/√n입니다. 윌슨 점수 간격은 비율에 대한 센터와 너비를 조정하고 \[0,1\] 내에 유지됩니다.



$$
\bar{x}\pm z_{1-\alpha/2}\frac{s}{\sqrt n}
$$



$$
\frac{\widehat{p}+z^2/(2n)\pm z\sqrt{\widehat{p}(1-\widehat{p})/n+z^2/(4n^2)}}{1+z^2/n}
$$







## 계산 모드



**일반 평균 간격**

- 표본 크기
- 평균
- 표준편차
- 신뢰수준 · %





**윌슨 비율 간격**

- 표본 크기
- 성공
- 신뢰수준 · %
