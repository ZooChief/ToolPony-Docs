# Calculadora científica



Avaliar expressões matemáticas com poderes, fatorials, trigonometria, raízes e logaritmos.





## Primeiros passos



1. Use o exemplo ou insira seus próprios valores.
2. Calcule, copie o resultado ou baixe os detalhes disponíveis.







## Exemplo



### Entrada



```
sqrt( 81) + 2^3 × sin( 30), graus
```



### Resultado esperado



```
13
```
