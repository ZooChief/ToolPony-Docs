# Calculadora de datas



Conte dias corridos e úteis ou desloque uma data.





## Primeiros passos



1. Informe duas datas e escolha incluir a mais recente. Adicione feriados em Mais opções.
2. Use um valor negativo para retroceder. O modo de dias úteis ignora sábados, domingos e feriados informados.







## Exemplo



### Entrada



```
De 2020-01-01 a 2020-02-01
```



### Resultado esperado



```
31 dias corridos, 23 dias úteis
```

## Notas de uso



O cálculo é feito no seu navegador. Use unidades consistentes.







## Método de cálculo



Dias úteis vão de segunda a sexta, excluindo as datas informadas. AAAA-MM-DD vale uma vez e MM-DD vale a cada ano. O deslocamento inclui a data anterior e exclui a posterior. O resultado pode cair em dia não útil. Meses mais curtos usam o último dia.







## Modo de cálculo



**Entre datas**

- Data inicial
- Data final
- Incluir a data final
- Feriados (AAAA-MM-DD ou MM-DD)





**Somar ou subtrair datas**

- Data inicial
- Anos
- Meses
- Semanas
- Dias





**Deslocar em dias úteis**

- Data inicial
- Dias úteis
- Feriados (AAAA-MM-DD ou MM-DD)
