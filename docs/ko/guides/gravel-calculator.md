# 자갈 계산기



자갈과 모래의 부피, 무게, 포대 수, 비용을 계산합니다.





## 시작하기



1. 면적, 직사각형, 원형 중 하나를 선택하고 깊이를 입력하세요.
2. 재료를 고르세요. 추가 옵션에서 밀도나 포대 용량을 입력하세요.







## 예시



### 입력



```
200 ft², 깊이 3 in, 자갈 1,680 kg/m³.
```



### 예상 결과



```
50 ft³(1.42 m³), 약 2,379 kg.
```

## 참고 사항



브라우저에서 처리합니다. 단위를 일관되게 사용하세요.







## 계산 방법



면적과 깊이를 곱한 뒤 여유분을 더합니다. 무게는 부피와 벌크 밀도의 곱입니다. 포대 단가로 계산할 때 포대 수를 올림합니다. 공급업체의 밀도를 알고 있다면 그 값을 사용하세요.



$$
V=Ad(1+w/100),\qquad m=\rho V,\qquad N=\left\lceil\frac{m}{m_{\rm bag}}\right\rceil\ \text{or}\ \left\lceil\frac{V}{V_{\rm bag}}\right\rceil
$$
