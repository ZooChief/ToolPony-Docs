# Calculadora de comisiones



Encuentra ventas, tarifas o comisión, luego calcula un pago base más fichas progresivas.





## Primeros pasos



1. Usa el ejemplo o introduce tus propios valores.
2. Calcula, copia el resultado o descarga los detalles disponibles.







## Ejemplo



### Entrada



```
16.500 al 8,25%
```



### Resultado esperado



```
1.361.25 Comisión
```

## Notas de uso



El cálculo se ejecuta en tu navegador. Usa unidades coherentes.







## Método de cálculo



Una tarifa única multiplica la cantidad de ventas. En un horario de nivel, cada umbral es el límite superior para ese soporte. Los niveles porcentuales se aplican sólo a los ingresos en el soporte. Los niveles fijos pagan una vez que se ingresa el soporte.



$$
C=C_0+\sum_i s_i r_i\quad\text{(percentage tiers)}
$$







## Modo de cálculo



**Buscar comisión**

- Cantidad de ventas
- Tasa de la Comisión · %





**Tasa de búsqueda**

- Cantidad de ventas
- Monto de la Comisión





**Encontrar el importe de las ventas**

- Tasa de la Comisión · %
- Monto de la Comisión





**Base y niveles**

- Cantidad de ventas
- Comisión de base
- Tipo de base · Cantidad fija / Porcentaje de ventas
- Límite superior, tasa (%, o cantidad fija). Uso \* sin límite.
