# 対数計算機



対語、基本、または引数を見つけましょう。 ベースは数値またはeである可能性があります。





## 使い方



1. 例を使うか、任意の値を入力します。
2. 計算後、結果をコピーするか詳細をダウンロードできます。







## 例



### 入力



```
ベース3、引数81
```



### 期待される結果



```
4
```

## 計算方法



対数log(b)(x)は、x で満足できる係数です。 変更基数式は、ln(x) を ln(b) で分割します。



$$
\log_b(x)=\frac{\ln x}{\ln b},\qquad b>0,\quad b\ne1,\quad x>0
$$
