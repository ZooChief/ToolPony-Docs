# Dividir PDF



Selecione páginas e salve em um PDF ou ZIP.





## Primeiros passos



1. Selecione um PDF sem criptografia.
2. Escolha miniaturas ou digite páginas e intervalos como 5, 1-3.
3. Escolha um único PDF, um arquivo por intervalo ou um arquivo por página.
4. Também é possível dividir por número de páginas ou tamanho. O limite vale para os PDFs gerados, sem recompressão.







## Exemplo



### Entrada



```
PDF de 5 páginas, seleção 5, 1-3
```



### Resultado esperado



```
Um PDF com as páginas 5, 1, 2 e 3 nessa ordem
```

## Limites



Até 30 MB e 300 páginas. As páginas não podem se repetir. Os PDFs no ZIP têm limite total de 64 MB. Formulários, marcadores e assinaturas podem ser perdidos.
