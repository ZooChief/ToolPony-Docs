# Hash-Rechner für Dateien und Text



Wählen Sie Text oder Dateien aus, wählen Sie einen SHA-2-Algorithmus aus und berechnen Sie einen erwarteten Digest, um eine Übereinstimmung zu überprüfen, oder laden Sie die Ergebnisse als CSV herunter.





## Erste Schritte



1. Wählen Sie Text oder wählen Sie eine oder mehrere Dateien aus.
2. Wählen Sie SHA-256, SHA-384 oder SHA-512 und berechnen Sie dann.
3. Fügen Sie einen erwarteten Hash ein, um ihn zu überprüfen, oder laden Sie das Ergebnis CSV herunter.







## Beispiel



### Eingabe



```
Text: abc, UTF-8, SHA-256
```



### Erwartetes Ergebnis



```
ba7816bf8f01cfea414140de5dae2223b00361a396177a9cb410ff61f20015ad
```

[Vollständiges Werkzeug öffnen](<https://toolpony.com/de/tools/file-hash-calculator/>)







## Hinweise



Eine andere Codierung, eine Zeilenendung oder sogar ein geändertes Byte erzeugt einen anderen Digest.







## Grenzen



Bis zu 16 Dateien und 64 MB zusammen oder eine Million Textzeichen. Text verwendet UTF-8. Dateien werden sequentiell im Browser verarbeitet.
