# 比例計算器



求比例中的未知項、化簡比例，或按倍數縮放兩項。





## 開始使用



1. 按示例填寫數值，或輸入你自己的測量值。
2. 計算後可複製結果或下載明細。







## 示例



### 輸入



```
3:4 = x:20
```



### 預期結果



```
x=15
```

## 使用提示



計算在瀏覽器內完成。無單位標記的字段請使用一致單位。







## 計算方法



A:B = C:D 等價於 A×D = B×C，分母應非零。化簡支持小數和分數。







## 計算模式



**求未知項**

- A
- B
- C
- D





**化簡或縮放**

- 第一項
- 第二項
- 縮放倍數





**按倍數放大或縮小**

- 第一項
- 第二項
- 方向 · 縮小 / 放大
- 倍數
