# Permutation and combination calculator



Compute exact ordered and unordered selections with or without repetition.





## Get started



1. Use the example values or enter your own measurements.
2. Calculate, then copy the result or download the available details.







## Example



### Input



```
n=10, r=3, without repetition
```



### Expected result



```
720 permutations; 120 combinations
```







## Try it



[Open full tool](<https://toolpony.com/en/tools/permutation-combination-calculator/>)







## Good to know



The calculation runs in your browser. Use consistent units in fields with no explicit unit.







## Calculation method



Without repetition, nPr = n!/(n−r)! and nCr = nPr/r!. With repetition, ordered choices are nʳ and unordered choices are C(n+r−1,r).
