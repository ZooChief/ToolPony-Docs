# 팁 계산기



세금 전후 금액에 따라 팁과 함께 사람들 사이에 청구서와 팁을 나눕니다.





## 시작하기



1. 예제 값을 사용하거나 원하는 값을 입력하세요.
2. 계산한 결과를 복사하거나 세부 정보를 내려받을 수 있습니다.







## 예시



### 입력



```
80 청구서, 20% 끝, 4 사람들
```



### 예상 결과



```
합계 96, 1인당 24
```







## 직접 사용해 보기



[전체 도구 열기](<https://toolpony.com/ko/tools/tip-calculator/>)







## 참고 사항



브라우저에서 처리합니다. 단위를 일관되게 사용하세요.







## 계산 방법



팁 = 선택한 청구서 금액 × 팁 비율. 1 인당 총 청구서, 세금 및 팁은 사람들의 수로 나뉩니다.
