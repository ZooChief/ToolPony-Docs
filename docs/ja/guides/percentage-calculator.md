# パーセント計算機



パーセンテージ、パート、全体、増加、減少、逆の変化、差、誤差を解く。





## 使い方



1. 240の15%などについては、値のパーセンテージを選択してください。 部品が36で、合計またはレートがわかっている場合は、対応する逆モードを選択してください。
2. 古い値と新しい値のパーセンテージ変更を選択してください。 ベースラインなしで、2つの正の値に対してパーセンテージ差を使用してください。
3. 15%で15を入力してください。 以下の作業例との結果を比較してください。







## 例



### 入力



```
240の15%
```



### 期待される結果



```
36
```







## 試してみる



[ツール全体を開く](<https://toolpony.com/ja/tools/percentage-calculator/>)







## 注意点



処理はブラウザ内で実行されます。単位をそろえて入力してください。







## 計算方法



パーセンテージ=一部 ÷ 全体 × 100。 変更は絶対元値をその単位として使用する。 対称差は絶対値の平均を使用する。



$$
x=yp/100,\quad p=100x/y,\quad y=100x/p
$$



$$
\Delta\%=100\frac{x_1-x_0}{|x_0|},\quad D\%=200\frac{|x_1-x_0|}{|x_1|+|x_0|}
$$



80 → 100は25%の変更です。なぜなら、80がスタート値だからです。 同じ数値のパーセンテージ差は約22.22%であり、その分母が平均である90である。



20%上昇して120となった後、逆の変更で100点が与えられる。 -100% の変更は元に戻せない。 ゼロベースラインからの変更にはパーセンテージの結果がない。



90の測定値および96の参照の場合、絶対率誤差は6.25%である。 その肯定的な参照を持つ署名結果は−6.25%です。







## 計算モード



**値の割合**

- パーセンテージ · %
- 値





**パーセンテージを見つける**

- パート
- 全体





**全体を見つけてください**

- パート
- パーセンテージ · %





**パーセンテージの変更**

- 元の値
- 新しい値





**パーセンテージ差**

- 初値
- 第二値





**署名された値との違い**

- 初値
- 第二値





**変更を適用してください**

- 元の値
- 署名された変更 · %





**変化を逆転させる**

- 新しい値
- 署名された変更 · %





**パーセント誤差**

- 測定された値
- 参考値
- エラー規約 · 絶対 / 基準値に対する符号付き
