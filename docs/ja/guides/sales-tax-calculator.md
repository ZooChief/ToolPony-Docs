# 売上税・付加価値税計算機



売上税および付加価値税(VAT)を独自の税率で追加または削除してください。





## 例



### 入力



```
純価格 100、付加価値税 20%
```



### 期待される結果



```
売上総額120、税額20
```







## 試してみる

[ツール全体を開く · 売上税・付加価値税計算機](<https://toolpony.com/ja/tools/sales-tax-calculator/>)





## 計算方法



総価格=純価格×(1 +レート)。 税率はユーザーによって提供されます。
