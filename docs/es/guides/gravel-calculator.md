# Calculadora de grava



Estima el volumen, peso, número de sacos y coste de grava o arena.





## Primeros pasos



1. Elige área conocida, rectángulo o círculo e introduce el espesor.
2. Elige el material. Indica densidad o capacidad de saco en Más opciones.







## Ejemplo



### Entrada



```
200 ft², espesor de 3 in, grava de 1.680 kg/m³.
```



### Resultado esperado



```
50 ft³ (1,42 m³), unos 2.379 kg.
```

## Notas de uso



El cálculo se ejecuta en tu navegador. Usa unidades coherentes.







## Método de cálculo



Multiplica el área por el espesor y añade el margen. La masa es el volumen por la densidad aparente. Para el precio por saco, redondea al saco entero superior. Usa la densidad del proveedor si está disponible.



$$
V=Ad(1+w/100),\qquad m=\rho V,\qquad N=\left\lceil\frac{m}{m_{\rm bag}}\right\rceil\ \text{or}\ \left\lceil\frac{V}{V_{\rm bag}}\right\rceil
$$
