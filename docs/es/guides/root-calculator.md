# Guía de uso · Calculadora de raíces



Calcular el cuadrado real principal, cubo, o raíz nth.





## Ejemplo



### Entrada



```
raíz cuadrada de 144
```



### Resultado esperado



```
12
```







## Pruébalo

[Abrir herramienta completa · Calculadora de raíces](<https://toolpony.com/es/tools/root-calculator/>)





## Método de cálculo



La raíz nth es x elevada a 1/n. Los grados de enteros Odd aceptan radicands negativos. Un grado negativo toma el recíproco.



$$
\sqrt[n]{x}=x^{1/n},\qquad n\ne0
$$







## Modo de cálculo





### Raíz cuadrada



- Radicando







### Raíz cúbica



- Radicando







### Raíz enésima



- Radicando
- Grado
