# 판매세·부가가치세 계산기



자신의 요율을 사용하여 판매세 및 VAT를 추가하거나 제거하십시오.





## 예시



### 입력



```
순 가격 100, VAT 20 %
```



### 예상 결과



```
총 120, 세금 20
```







## 직접 사용해 보기

[전체 도구 열기 · 판매세·부가가치세 계산기](<https://toolpony.com/ko/tools/sales-tax-calculator/>)





## 계산 방법



총 가격 = 순 가격 × (1 + 요금). 세율은 사용자가 제공합니다.
