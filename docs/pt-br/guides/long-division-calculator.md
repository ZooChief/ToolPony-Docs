# Calculadora de divisão longa



Divida inteiros ou decimais e inspecione o quociente, o restante, o valor decimal, e cada passo de divisão longa.





## Primeiros passos



1. Use o exemplo ou insira seus próprios valores.
2. Calcule, copie o resultado ou baixe os detalhes disponíveis.







## Exemplo



### Entrada



```
12,345 ÷ 67
```



### Resultado esperado



```
184 restantes 17
```

## Notas de uso



O cálculo é feito no seu navegador. Use unidades consistentes.







## Método de cálculo



Escalar ambas as entradas pelo mesmo poder de dez. O quociente inteiro trunca para zero, e o restante assinado satisfaz dividendo = quociente × divisor + restante. A tabela de passos usa magnitudes absolutas.



$$
a=bq+r,\quad q=\operatorname{trunc}(a/b),\quad |r|<|b|
$$
