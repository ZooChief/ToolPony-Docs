# 画像を PDF に変換



JPG、PNG、WebP などの画像を 1 件の PDF にまとめます。





## 使い方



1. 画像を追加し、ページの順序を調整します。
2. 用紙サイズ、向き、余白を選び、PDF を保存します。







## 例



### 入力



```
横長の画像 2 枚、A4、自動方向
```



### 期待される結果



```
横向きの A4 が 2 ページ
```







## 試してみる



[ツール全体を開く](<https://toolpony.com/ja/tools/jpg-to-pdf/>)







## 制限



最大 20 枚、入力合計 30 MB・6000 万画素。1 枚は 20 MB・2400 万画素まで。透明部分は白になり、アニメーションは先頭フレームのみです。

[ドキュメント](https://docs.toolpony.com/ja/guides/jpg-to-pdf/)
