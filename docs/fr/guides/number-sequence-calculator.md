# Calculateur de suites



Calculez un terme et une somme partielle pour une suite arithmétique, géométrique ou de Fibonacci, puis téléchargez la liste.





## Prise en main



1. Utilisez l’exemple ou saisissez vos propres valeurs.
2. Calculez, puis copiez le résultat ou téléchargez les détails.







## Exemple



### Entrée



```
Suite arithmétique, premier terme 7, raison −3, indice 8
```



### Résultat attendu



```
−14, somme −28
```

## Notes



Le traitement se fait dans le navigateur. Utilisez des unités cohérentes.







## Méthode de calcul



Les indices des suites arithmétiques et géométriques commencent à 1. La suite de Fibonacci commence à F₀ = 0 et utilise des entiers exacts.



$$
a_n=a_1+(n-1)d,\quad g_n=g_1r^{n-1},\quad F_n=F_{n-1}+F_{n-2}
$$







## Mode de calcul



**Arithmétique**

- Premier terme
- Raison additive
- Indice





**Géométrique**

- Premier terme
- Raison multiplicative
- Indice





**Fibonacci**

- Indice
