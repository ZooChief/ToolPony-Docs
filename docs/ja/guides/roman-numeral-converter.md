# ローマ数字変換



ローマ数字と整数を、日付や制限付きリストを含めて、どちらの方向にも変換します。





## 使い方



1. 例を使うか、任意の値を入力します。
2. 計算後、結果をコピーするか詳細をダウンロードできます。







## 例



### 入力



```
MCMXCIX
```



### 期待される結果



```
1999
```







## 試してみる



[ツール全体を開く](<https://toolpony.com/ja/tools/roman-numeral-converter/>)







## 注意点



処理はブラウザ内で実行されます。単位をそろえて入力してください。







## 計算方法



コンバーターは、IVやCMなどの標準的な減算ペアを使用しています。 オーバーラインはグループを1,000人倍にする。 オーバーラインされた各文字の前にアンダースコアを入力するか、オーバーライン自体を貼り付けてください。 値は1〜3,999,999に制限されています。 日付モードは各フィールドを変換し、区切り文字を保持します。







## 計算モード



**単一値**

- 整数またはローマ語





**日付またはリスト**

- 値または日付
