# Day of the week



Find the weekday, day of year, ISO week and number of occurrences of that weekday.





## Get started



1. Use the example values or enter your own measurements.
2. Calculate, then copy the result or download the available details.







## Example



### Input



```
2000-01-01
```



### Expected result



```
Saturday
```







## Try it



[Open full tool](<https://toolpony.com/en/tools/day-of-week-calculator/>)







## Good to know



The calculation runs in your browser. Use consistent units in fields with no explicit unit.







## Calculation method



The calendar is Gregorian. ISO weeks start on Monday. Week 1 contains January 4, so early January may belong to the last ISO week of the preceding year.
