# 進制轉換與計算器使用指南



在 2–36 進制之間轉換帶符號整數，並進行精確算術、取餘和位運算。





## 示例



### 輸入



```
FF，從十六進制轉十進制
```



### 預期結果



```
255
```

## 覈對十六進制編號



1. 把 0x20\_0000\_0000\_0001 轉成十進制，末位 1 會保留在 9007199254740993 中。可以交換進制，也可以複製二進制一行，得到連續的數字。

## 計算方法



進制轉換最多支持 4,096 位二進制整數。算術和位運算每個操作數最多 256 位數字，整數除法向零取整。空格和下劃線可分隔數字。







## 計算模式





### 進制轉換



- 整數
- 輸入進制
- 輸出進制
- 最少輸出位數







### 整數運算



- 整數一
- 整數二
- 輸入進制
- 輸出進制
- 最少輸出位數
- 運算 · 加 / 減 / 乘 / 除 / 餘數 / 按位與 / 按位或 / 按位異或
