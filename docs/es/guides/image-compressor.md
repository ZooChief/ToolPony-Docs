# Comprimir imágenes



Selecciona entre una y doce imágenes y elige JPEG o WebP. Indica una calidad o un tamaño objetivo por archivo. Si hace falta, limita el lado mayor. Compara cada imagen y descarga archivos sueltos o un ZIP.





## Primeros pasos



1. Selecciona entre una y doce imágenes y elige JPEG o WebP.
2. Indica una calidad o un tamaño objetivo por archivo. Si hace falta, limita el lado mayor.
3. Compara cada imagen y descarga archivos sueltos o un ZIP.







## Ejemplo



### Entrada



```
Dos fotos, WebP, 100 KB por archivo, lado máximo de 1200 px, reducción permitida
```



### Resultado esperado



```
Los resultados que alcanzan el objetivo son WebP de hasta 100.000 bytes dentro de un ZIP.
```







## Pruébalo



[Abrir herramienta completa](<https://toolpony.com/es/tools/image-compressor/>)







## Límites



Hasta 20 MB y 24 megapíxeles por imagen, 64 MiB por lote de entrada y salida. El lado máximo no amplía imágenes. JPEG y WebP tienen pérdida. Las animaciones se convierten en imágenes fijas y se eliminan los metadatos originales.
