# Wissenschaftlicher Taschenrechner



Bewerten Sie mathematische Ausdrücke mit Potenzen, Faktorien, Trigonometrie, Wurzeln und Logarithmen.





## Erste Schritte



1. Verwenden Sie das Beispiel oder geben Sie eigene Werte ein.
2. Berechnen Sie das Ergebnis und kopieren oder laden Sie die Details herunter.







## Beispiel



### Eingabe



```
sqrt(81) + 2^3 × sin(30), Grad
```



### Erwartetes Ergebnis



```
13
```

## Berechnungsmethode



Operatoren folgen Klammern, Postfix, Exponent, Multiplikation und Additionspriorität. Potenzen assoziieren von rechts. Prozent geteilt durch 100. Ergebnisse verwenden Gleitkommaarithmetik.
