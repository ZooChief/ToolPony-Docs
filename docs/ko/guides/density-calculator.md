# 밀도 계산기



두 값을 입력하여 질량, 부피 또는 밀도를 해결합니다.





## 시작하기



1. 예제 값을 사용하거나 원하는 값을 입력하세요.
2. 계산한 결과를 복사하거나 세부 정보를 내려받을 수 있습니다.







## 예시



### 입력



```
8 kg, 0.001 m3
```



### 예상 결과



```
8,000 kg/m3
```

## 계산 방법



밀도 = 질량 ÷ 볼륨. 인터페이스는 kg, m3 및 kg/m3을 사용합니다.



$$
\rho=\frac{m}{V}
$$
