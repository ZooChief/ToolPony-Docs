# 帶寬與下載時間計算器



根據文件大小、帶寬與有效傳輸比例估算下載時間。





## 開始使用



1. 按示例填寫數值，或輸入你自己的測量值。
2. 計算後可複製結果或下載明細。







## 示例



### 輸入



```
1 GB，100 Mbps，有效率 100%
```



### 預期結果



```
80 秒
```

## 使用提示



計算在瀏覽器內完成。無單位標記的字段請使用一致單位。







## 計算方法



秒數 = 文件字節數 × 8 ÷ 有效每秒比特數。帶寬單位用十進制前綴，文件大小支持十進制和二進制。
