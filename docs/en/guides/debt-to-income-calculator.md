# Debt-to-income calculator



Compare your recurring monthly debt payments with gross monthly income.





## Get started



1. Use the example values or enter your own measurements.
2. Calculate, then copy the result or download the available details.







## Example



### Input



```
Income 5,000, debt payments 1,500
```



### Expected result



```
30%
```







## Try it



[Open full tool](<https://toolpony.com/en/tools/debt-to-income-calculator/>)







## Good to know



The calculation runs in your browser. Use consistent units in fields with no explicit unit.







## Calculation method



Debt-to-income ratio = monthly debt payments ÷ gross monthly income. Use the same currency and a monthly period for all amounts.
