# 房貸提前還款計算器



比較房貸原還款計劃、額外還款、一次結清與兩種雙週還款，查看剩餘期限和節省利息。





## 開始使用



1. 若之前做過額外還款，選賬單餘額模式，填入當前本金與本息月供。也可用原貸款和剩餘期限推算餘額。
2. 選擇還款方案。可填寫每月、每年或一次性的額外金額，默認分別從第 1、12、1 個月起算，起始月份可在更多選項修改。
3. 對比所選方案與原方案，再下載剩餘還款表或對比 CSV。
4. 這裏只估算本金與固定利息。實際結清報價可能含按日利息、費用和違約金，請向貸款機構覈對。







## 示例



### 輸入



```
原貸款 400,000，30 年，年利率 6%。剩 25 年，每月多還 500。
```



### 預期結果



```
207 個月還清，節省利息 122,306.21
```

## 計算方法



由原貸款推算時，假設先前每期均按計劃還款。月利息是剩餘本金乘以年利率再除以 12。按月彙總的雙週方案每 6 個月多還半筆月供。每年 26 期方案每期還半筆月供，按年利率除以 26 計息。



$$
B=M\frac{1-(1+r)^{-n}}r\quad(r>0),\qquad B=Mn\quad(r=0)
$$



$$
I_k=rB_{k-1},\qquad B_k=\max(0,B_{k-1}-M+I_k-E_k)
$$



$$
E_{6j}=M/2\quad\text{(grouped)},\qquad M_{26}=M/2,\quad r_{26}=r_{\rm annual}/26
$$
