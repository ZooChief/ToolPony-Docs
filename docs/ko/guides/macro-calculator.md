# 다량 영양소 계산기



칼로리 목표와 영양소 비율을 그램으로 변환하거나 그램에서 에너지와 비율을 계산합니다.





## 시작하기



1. 예제 값을 사용하거나 원하는 값을 입력하세요.
2. 계산한 결과를 복사하거나 세부 정보를 내려받을 수 있습니다.







## 예시



### 입력



```
2,000 kcal: 25% 단백질, 45% 탄수화물, 30% 지방
```



### 예상 결과



```
125 g 단백질, 225 g 탄수화물, 66.67 g 지방
```







## 직접 사용해 보기



[전체 도구 열기](<https://toolpony.com/ko/tools/macro-calculator/>)







## 참고 사항



브라우저에서 처리합니다. 단위를 일관되게 사용하세요.







## 계산 방법



단백질과 탄수화물은 4 kcal/g, 지방은 9 kcal/g으로 환산합니다. 목표 모드에서 비율의 합은 100%여야 합니다.







## 계산 모드



**그램에 목표**

- 총 에너지 · kcal
- 단백질 · %
- 탄수화물 · %
- 지방 · %





**에너지에 그램**

- 단백질 · g
- 탄수화물 · g
- 지방 · g
