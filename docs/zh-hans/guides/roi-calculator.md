# 投资回报率计算器



计入费用，计算净收益、总投资回报率和年化回报率。





## 示例



### 输入



```
投入 1,000，两年后收到 1,210
```



### 预期结果



```
总回报率 21%，年化 10%
```







## 试一试

[打开完整工具 · 投资回报率计算器](<https://toolpony.com/zh-hans/tools/roi-calculator/>)





## 计算方法



总回报率为（净回收金额 − 总投入）÷ 总投入。年化回报率把该比例按期限折算为复合年收益。
