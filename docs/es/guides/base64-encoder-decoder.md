# Codificar y decodificar Base64



codificar texto UTF-8 como estándar o seguro de URL Base64 y validar texto decodificado.





## Primeros pasos



1. Usa el ejemplo o introduce tus propios valores.
2. Calcula, copia el resultado o descarga los detalles disponibles.







## Ejemplo



### Entrada



```
Codificar hello
```



### Resultado esperado



```
aGVsbG8=
```







## Pruébalo



[Abrir herramienta completa](<https://toolpony.com/es/tools/base64-encoder-decoder/>)







## Notas de uso



El cálculo se ejecuta en tu navegador. Usa unidades coherentes.







## Método de cálculo



El texto se convierte como UTF-8. El modo URL-safe utiliza "-" y "\_" y omite el relleno en salida. Hasta 500.000 caracteres de entrada.

[Documentación](https://docs.toolpony.com/es/guides/base64-encoder-decoder/)
