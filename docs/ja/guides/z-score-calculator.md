# Z スコア計算機



値を標準化し、Z スコア、正規確率、区間を相互に換算します。





## 使い方



1. 例を使うか、任意の値を入力します。
2. 計算後、結果をコピーするか詳細をダウンロードできます。







## 例



### 入力



```
観測値 18、平均 23、標準偏差 4
```



### 期待される結果



```
z = −1.25
```







## 試してみる



[ツール全体を開く](<https://toolpony.com/ja/tools/z-score-calculator/>)







## 注意点



処理はブラウザ内で実行されます。単位をそろえて入力してください。







## 計算方法



標準得点は (x − μ)/σ です。左側確率は z における正規分布の累積確率です。対称区間の逆算では非負の境界を返します。



$$
z=\frac{x-\mu}{\sigma},\qquad P(a<Z<b)=\Phi(b)-\Phi(a)
$$







## 計算モード



**値を標準化**

- 観測値
- 平均
- 標準偏差





**Z スコアから確率へ**

- Z スコア





**確率から Z スコアへ**

- 確率領域 · 左側確率 / 右側確率 / 中心から |z| まで / −|z| と |z| の間 / 両側確率
- 確率





**2 つの Z スコア間の確率**

- 下限の Z スコア
- 上限の Z スコア
