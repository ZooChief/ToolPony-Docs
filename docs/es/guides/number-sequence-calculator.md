# Calculadora de sucesiones



Encuentre un término, suma parcial y lista descargable para secuencias aritméticas, geométricas o Fibonacci.





## Primeros pasos



1. Usa el ejemplo o introduce tus propios valores.
2. Calcula, copia el resultado o descarga los detalles disponibles.







## Ejemplo



### Entrada



```
secuencia Aritmética, primera 7, diferencia −3, índice 8
```



### Resultado esperado



```
−14, suma - 28
```

## Método de cálculo



Los índices rítmicos y geométricos comienzan en 1. Fibonacci comienza en F0 = 0. La lista Fibonacci utiliza enteros exactos.



$$
a_n=a_1+(n-1)d,\quad g_n=g_1r^{n-1},\quad F_n=F_{n-1}+F_{n-2}
$$
