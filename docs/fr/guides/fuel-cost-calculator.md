# Calculatrice de coût et de consommation de carburant



Convertir les unités d'économie de carburant, estimer le coût du carburant d'un voyage, ou calculer l'économie de carburant mesurée.





## Prise en main



1. Utilisez l’exemple ou saisissez vos propres valeurs.
2. Calculez, puis copiez le résultat ou téléchargez les détails.







## Exemple



### Entrée



```
300 km, 7 L/100 km, prix 1,5 par litre
```



### Résultat attendu



```
21 L; coût du carburant 31,50
```

## Notes



Le traitement se fait dans le navigateur. Utilisez des unités cohérentes.







## Méthode de calcul



Carburant utilisé = distance × L/100 km ÷ 100. Les milles américains et impériaux par gallon utilisent différents volumes de gallon. Les prix du carburant sont fournis par les utilisateurs.







## Mode de calcul



**Coût du voyage**

- Distance · km
- Économie de carburant
- Unité de consommation de carburant · L/100 km / km/L / MPG (É.-U.) / mpg (impérial)
- Prix par litre





**Convertir l'économie de carburant**

- Économie de carburant
- Unité d'entrée · L/100 km / km/L / MPG (É.-U.) / mpg (impérial)





**Kilométrage mesuré**

- Distance · km
- Carburant utilisé · L
