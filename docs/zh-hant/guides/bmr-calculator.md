# 基礎代謝與熱量計算器



使用三種公式估算靜息能量消耗與每日總能量消耗，支持公制和美製。





## 開始使用



1. 按示例填寫數值，或輸入你自己的測量值。
2. 計算後可複製結果或下載明細。







## 示例



### 輸入



```
男性公式，30 歲，70 kg，175 cm，Mifflin–St Jeor
```



### 預期結果



```
靜息約 1,648.75 kcal/天
```

## 使用提示



計算在瀏覽器內完成。無單位標記的字段請使用一致單位。







## 計算方法



靜息消耗使用 Mifflin–St Jeor、修訂版 Harris–Benedict 或 Katch–McArdle 估算。每日總消耗爲估算值乘以活動係數。







## 計算模式



**公制**

- 年齡
- 公式分組 · 男性 / 女性
- 體重 · kg
- 身高 · cm
- 計算公式 · Mifflin–St Jeor / 修訂版 Harris–Benedict / Katch–McArdle
- Katch–McArdle 的體脂率 · %
- 活動係數
- 能量單位 · kcal/天 / kJ/天





**美製**

- 年齡
- 公式分組 · 男性 / 女性
- 體重 · lb
- 身高英尺部分 · ft
- 額外英寸 · in
- 計算公式 · Mifflin–St Jeor / 修訂版 Harris–Benedict / Katch–McArdle
- Katch–McArdle 的體脂率 · %
- 活動係數
- 能量單位 · kcal/天 / kJ/天
