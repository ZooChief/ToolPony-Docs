# 銷售稅與增值稅計算器使用指南



按自定義稅率計算含稅價、未稅價與稅額。





## 示例



### 輸入



```
未稅價 100，增值稅 20%
```



### 預期結果



```
含稅價 120，稅額 20
```





<a id="case-study"></a>



## 從小票反推稅率



1. 小票上未稅價爲 200.00，實付 217.00。兩者相差 17.00，用未稅價作分母可得 8.5%。點「用此稅率覈算」即可用 200 算回 217。

## 計算方法



含稅價 = 未稅價 ×（1 + 稅率）。稅率由用戶填寫。
