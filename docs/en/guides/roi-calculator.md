# ROI calculator



Calculate net profit, total return and annualized return with fees.





## Get started



1. Use the example values or enter your own measurements.
2. Calculate, then copy the result or download the available details.







## Example



### Input



```
Invest 1,000, receive 1,210 after 2 years
```



### Expected result



```
21% total; 10% annualized
```







## Try it



[Open full tool](<https://toolpony.com/en/tools/roi-calculator/>)







## Good to know



The calculation runs in your browser. Use consistent units in fields with no explicit unit.







## Calculation method



Total return is (net proceeds − total cost) ÷ total cost. Annualized return compounds the same ratio over the specified years.
