# 圆形计算器



由任一已知量计算半径、直径、周长与面积，并计算弧长、扇形面积和弦长。





## 开始使用



1. 按示例填写数值，或输入你自己的测量值。
2. 计算后可复制结果或下载明细。







## 示例



### 输入



```
半径 2，圆心角 90°
```



### 预期结果



```
周长约 12.5664，弧长约 3.1416
```

## 使用提示



计算在浏览器内完成。无单位标记的字段请使用一致单位。







## 计算方法



周长 = 2πr，面积 = πr²。弧长和扇形面积按圆心角占 360° 的比例计算。



$$
A=\pi r^2,\qquad C=2\pi r
$$
