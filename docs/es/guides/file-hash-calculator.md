# Calculadora de hash de archivos y texto



Elija texto o archivos, seleccione un algoritmo SHA-2 y calcule. Pruebe un digesto esperado para verificar un partido o descargar los resultados como CSV.





## Primeros pasos



1. Elija texto o seleccione uno o más archivos.
2. Seleccione SHA-256, SHA-384, o SHA-512, luego calcule.
3. Pruebe un hash esperado para verificarlo, o descargue el resultado CSV.







## Ejemplo



### Entrada



```
Texto: abc, UTF-8, SHA-256
```



### Resultado esperado



```
ba7816bf8f01cfea414140de5dae2223b00361a396177a9cb410ff61f20015ad
```

## Notas de uso



La verificación de cenizas compara los bytes. Una codificación diferente, un final de línea, o incluso un byte cambiado produce un digestión diferente.







## Límites



Hasta 16 archivos y 64 MB combinados, o un millón de caracteres de texto. El texto utiliza UTF-8. Los archivos se procesan secuencialmente en el navegador.
