# 난수 생성기



선택적 고유성과 정렬이 포함된 포괄적인 범위에서 임의의 정수를 생성합니다.





## 시작하기



1. 예제 값을 사용하거나 원하는 값을 입력하세요.
2. 계산한 결과를 복사하거나 세부 정보를 내려받을 수 있습니다.







## 예시



### 입력



```
최솟값 1, 최댓값 10, 개수 5
```



### 예상 결과



```
1부터 10까지의 정수 난수 5개
```







## 직접 사용해 보기



[전체 도구 열기](<https://toolpony.com/ko/tools/random-number-generator/>)







## 참고 사항



브라우저에서 처리합니다. 단위를 일관되게 사용하세요.







## 계산 방법



임의의 값은 Web Crypto에서 제공됩니다. 거절 샘플링은 모듈로 편향을 피합니다. 범위에서 최대 1,000개의 값을 생성합니다 −1,000,000,000 내지 1,000,000,000.

[문서](https://docs.toolpony.com/ko/guides/random-number-generator/)
