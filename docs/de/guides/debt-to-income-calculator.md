# Rechner für das Schulden-Einkommens-Verhältnis



Vergleichen Sie Ihre wiederkehrenden monatlichen Schuldenzahlungen mit monatlichen Bruttoeinkommen.





## Erste Schritte



1. Verwenden Sie das Beispiel oder geben Sie eigene Werte ein.
2. Berechnen Sie das Ergebnis und kopieren oder laden Sie die Details herunter.







## Beispiel



### Eingabe



```
Einkommen 5.000, Schuldenzahlungen 1.500
```



### Erwartetes Ergebnis



```
30%
```







## Ausprobieren



[Vollständiges Werkzeug öffnen](<https://toolpony.com/de/tools/debt-to-income-calculator/>)







## Hinweise



Die Verarbeitung erfolgt im Browser. Verwenden Sie einheitliche Einheiten.







## Berechnungsmethode



Schulden-Einkommen-Verhältnis = monatliche Schuldenzahlungen ÷ monatliches Bruttoeinkommen. Verwenden Sie für alle Beträge die gleiche Währung und eine monatliche Periode.
