# 単利計算機



他の入力から、元金利または用語の単純な金利計算または解決計算。





## 使い方



1. 例を使うか、任意の値を入力します。
2. 計算後、結果をコピーするか詳細をダウンロードできます。







## 例



### 入力



```
元金 1,000、年利 5%、期間 2 年
```



### 期待される結果



```
100件の利息;合計1,100件
```







## 試してみる



[ツール全体を開く](<https://toolpony.com/ja/tools/simple-interest-calculator/>)







## 注意点



処理はブラウザ内で実行されます。単位をそろえて入力してください。







## 計算方法



利息は元本×定期的レート×期間数に等しい。 乗算前に、その用語をレートと同じ単位に変換してください。 期末残高は元本に利益を加える。



$$
I=Prt,\qquad A=P+I
$$



期間を利率と同じ単位に換算します。たとえば年利 5% を 24 か月に適用する場合は 2 年として計算します。



エンドバランスがわかっている場合は、逆モードを使用してください。 ゼロレートまたはゼロ語は、逆問題を非統一的にすることができる。







## 計算モード
