# Grundumsatz- und Kalorienrechner



Schätzung der Ruheenergie und des täglichen Energieverbrauchs in metrischen oder US-Einheiten mit drei Gleichungen.





## Erste Schritte



1. Verwenden Sie das Beispiel oder geben Sie eigene Werte ein.
2. Berechnen Sie das Ergebnis und kopieren oder laden Sie die Details herunter.







## Beispiel



### Eingabe



```
Männliche Gleichung, 30 Jahre, 70 kg, 175 cm, Mifflin-St Jeor
```



### Erwartetes Ergebnis



```
1.648,75 kcal/Tag in Ruhe
```







## Ausprobieren



[Vollständiges Werkzeug öffnen](<https://toolpony.com/de/tools/bmr-calculator/>)







## Hinweise



Die Verarbeitung erfolgt im Browser. Verwenden Sie einheitliche Einheiten.







## Berechnungsmethode



Ruheenergie wird mit Mifflin-St Jeor, revidiertem Harris-Benedict oder Katch-McArdle geschätzt. Tägliche Ausgaben multiplizieren die Schätzung mit Ihrem Aktivitätsfaktor.







## Berechnungsmodus



**Metrisch**

- Alter
- Gleichungsgruppe · männlich / Weiblich
- Gewicht · kg
- Höhe · cm
- Gleichung · Mifflin–St. Jeor / Überarbeitet Harris-Benedict / Katch-McArdle
- Körperfett für Katch-McArdle · %
- Aktivitätsfaktor
- Energieeinheit · kcal/day / kJ/day





**US-Einheiten**

- Alter
- Gleichungsgruppe · männlich / Weiblich
- Gewicht · lb
- Höhe in Fuß · ft
- Zusätzliche Zoll · in
- Gleichung · Mifflin–St. Jeor / Überarbeitet Harris-Benedict / Katch-McArdle
- Körperfett für Katch-McArdle · %
- Aktivitätsfaktor
- Energieeinheit · kcal/day / kJ/day
