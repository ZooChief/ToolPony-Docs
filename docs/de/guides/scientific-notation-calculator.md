# Rechner für wissenschaftliche Schreibweise



Konvertieren Sie zwischen wissenschaftlicher, technischer, E- und Dezimalnotation oder berechnen Sie mit skalierten Werten.





## Erste Schritte



1. Verwenden Sie das Beispiel oder geben Sie eigene Werte ein.
2. Berechnen Sie das Ergebnis und kopieren oder laden Sie die Details herunter.







## Beispiel



### Eingabe



```
1568938
```



### Erwartetes Ergebnis



```
1.568938 × 10^6
```

## Berechnungsmethode



Die wissenschaftliche Notation verwendet eine führende Ziffer. Die technische Notation verwendet einen durch drei teilbaren Exponenten. Addition, Subtraktion und Multiplikation verwenden exakte Dezimalkoeffizienten, bevor sie auf die gewählte Präzision gerundet werden.



$$
x=a\times10^n,\qquad 1\le |a|<10\quad(x\ne0)
$$



Geben Sie 1568938, 1.568938e6 oder 1.568938 × 10^6 ein. Sie repräsentieren den gleichen Wert. Die technische Notation verwendet eine Potenz von zehn, die durch drei teilbar ist.



Der arithmetische Modus hält exakte Dezimalkoeffizienten für Addition, Subtraktion und Multiplikation.
