# Wurzelrechner



Berechnen Sie die reelle Quadrat-, Würfel- oder n-te Wurzel.





## Erste Schritte



1. Verwenden Sie das Beispiel oder geben Sie eigene Werte ein.
2. Berechnen Sie das Ergebnis und kopieren oder laden Sie die Details herunter.







## Beispiel



### Eingabe



```
Quadratwurzel von 144
```



### Erwartetes Ergebnis



```
12
```







## Ausprobieren

## Hinweise



Die Verarbeitung erfolgt im Browser. Verwenden Sie einheitliche Einheiten.







## Berechnungsmethode



Die n-te Wurzel ist x auf 1/n erhöht. Ungerade ganzzahlige Grade akzeptieren negative Radicanden. Ein negativer Grad nimmt den Kehrwert.



$$
\sqrt[n]{x}=x^{1/n},\qquad n\ne0
$$

**Kubikwurzel**

**n-te Wurzel**

- Höhe
