# 이익률과 원가 가산율



비용 및 가격에서 총 마진 및 마크 업을 찾거나 목표 마진으로 제품의 가격을 책정하십시오.





## 시작하기



1. 예제 값을 사용하거나 원하는 값을 입력하세요.
2. 계산한 결과를 복사하거나 세부 정보를 내려받을 수 있습니다.







## 예시



### 입력



```
비용 60, 가격 100
```



### 예상 결과



```
40% 마진; 66.67% 마크업
```







## 직접 사용해 보기



[전체 도구 열기](<https://toolpony.com/ko/tools/margin-calculator/>)







## 참고 사항



브라우저에서 처리합니다. 단위를 일관되게 사용하세요.







## 계산 방법



마진 = 이익 ÷ 판매 가격. 마크업 = 이익 ÷ 비용. 목표 마진은 판매 가격 = 비용 ÷ (1−margin)이 필요합니다.







## 계산 모드



**비용 및 가격**

- 비용
- 판매 가격





**목표 마진의 가격**

- 비용
- 목표 마진 · %
