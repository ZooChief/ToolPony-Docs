# 体積計算機



タンクの容量や立体の体積を寸法から求めます。中空管は内半径と外半径から管壁の体積を計算できます。出力はリットルまたは立方単位を選べます。





## 例



### 入力



```
半径2mの球体
```



### 期待される結果



```
≈33.5103 m³
```





<a id="case-study"></a>



## 水位線までの円筒タンクの容量を見積もる



1. タンクの内径と水位線までの深さを測ります。内径 1 m、深さ 1.2 m の例を実行すると、円柱モードで半径が 0.5 m、出力単位が L に設定されます。
2. 容量は π × 0.5² × 1.2 m³ で、約 942.48 L です。直径を半径欄に入れると二乗の項により結果が 4 倍になります。
3. 水位線を 0.2 m 下げ、深さを 1 m として再計算します。約 785.40 L となり、差の約 157.08 L が 2 本の水位線の間の容量です。

## 計算方法



プリズムの体積は、その基部面積が垂直な高さのときである。 円錐形またはピラミッド型は、その製品を3つに分ける。 中空管が内円筒を引き算する。 球形キャップは任意の2次元を許容する。



$$
V_{\mathrm{cone}}=\tfrac13\pi r^2h,\qquad V_{\mathrm{sphere}}=\tfrac43\pi r^3
$$
