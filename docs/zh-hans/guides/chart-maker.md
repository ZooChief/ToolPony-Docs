# 图表生成器



粘贴包含表头、标签列与数值列的 CSV。选择柱状图或折线图，更新预览并下载 SVG。





## 开始使用



1. 输入 CSV 表头，第一列写类别标签，后面各列写数值系列。
2. 选择柱状图或折线图并更新预览。
3. 下载 SVG 图表。







## 示例



### 输入



```
月份,访问量
一月,24
二月,38
```



### 预期结果



```
从左到右绘制一月 24、二月 38。
```

## 使用提示



标签内的逗号需要用双引号包住。小数点用句点，负值与正值使用同一坐标尺度。







## 适用范围



最多 120 行数据和六列数值。双引号内可包含逗号，单元格不跨行。按输入顺序绘制。
