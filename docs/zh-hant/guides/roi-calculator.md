# 投資回報率計算器使用指南



計入費用，計算淨收益、總投資回報率和年化回報率。





## 示例



### 輸入



```
投入 1,000，兩年後收到 1,210
```



### 預期結果



```
總回報率 21%，年化 10%
```







## 試一試

[打開完整工具 · 投資回報率計算器](<https://toolpony.com/zh-hant/tools/roi-calculator/>)





## 計算方法



總回報率爲（淨回收金額 − 總投入）÷ 總投入。年化回報率把該比例按期限折算爲複合年收益。
