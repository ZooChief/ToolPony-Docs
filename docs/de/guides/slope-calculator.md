# Steigungsrechner



Finden Sie eine Steigung und Schnittpunkte von zwei Punkten oder finden Sie beide Endpunkte in einer bestimmten Entfernung.





## Erste Schritte



1. Verwenden Sie das Beispiel oder geben Sie eigene Werte ein.
2. Berechnen Sie das Ergebnis und kopieren oder laden Sie die Details herunter.







## Beispiel



### Eingabe



```
(0, 0) bis (3, 4)
```



### Erwartetes Ergebnis



```
Steigung 4/3 und Entfernung 5
```

## Berechnungsmethode



Eine vertikale Linie hat eine undefinierte Steigung, wobei ein bekannter Abstand und eine bekannte Richtung zwei Endpunkte auf gegenüberliegenden Seiten des Startpunktes bestimmen.



$$
m=\frac{y_2-y_1}{x_2-x_1},\qquad \theta=\arctan(m),\qquad y=mx+b
$$



Der Zwei-Punkte-Modus meldet vertikale und horizontale Änderungen separat; das Vorzeichen jeder Änderung verwenden, um zu erkennen, in welche Richtung sich der Punkt bewegt hat; eine vertikale Linie hat eine konstante x-Koordinate.



Eine Linie und eine Entfernung bestimmen einen Punkt auf jeder Seite des Startpunktes. Verwenden Sie die Endpunkttabelle, um beide Lösungen zu behalten.
