# Rechner für große Zahlen



Berechnen Sie mit genauen großen Ganzzahlen und Dezimalkoeffizienten, mit wählbarer Rundung für Division und Wurzeln.





## Erste Schritte



1. Verwenden Sie das Beispiel oder geben Sie eigene Werte ein.
2. Berechnen Sie das Ergebnis und kopieren oder laden Sie die Details herunter.







## Beispiel



### Eingabe



```
9,007,199,254,740,993 + 7
```



### Erwartetes Ergebnis



```
9007199254741000
```

Die Verarbeitung erfolgt im Browser. Verwenden Sie einheitliche Einheiten.







## Berechnungsmethode



Addition, Subtraktion, Multiplikation, ganzzahlige Potenzen und ganzzahlige Operationen verwenden BigInt-Koeffizienten. Divisionsrunden auf die ausgewählten Dezimalstellen. Quadratwurzeln können auf den nächsten gekürzt oder gerundet werden. Positive und negative ganzzahlige Exponenten werden innerhalb der Ergebnisgrenze unterstützt.



$$
x=m\cdot 10^e,\quad x_1x_2=(m_1m_2)\cdot 10^{e_1+e_2}
$$
