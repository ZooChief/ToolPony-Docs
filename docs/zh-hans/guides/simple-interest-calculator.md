# 单利计算器



计算单利与到期金额，或反推本金、利率与期限。





## 开始使用



1. 按示例填写数值，或输入你自己的测量值。
2. 计算后可复制结果或下载明细。







## 示例



### 输入



```
1,000 按年利率 5%，2 年
```



### 预期结果



```
利息 100，到期金额 1,100
```

## 使用提示



计算在浏览器内完成。无单位标记的字段请使用一致单位。







## 计算方法



单利等于本金乘以每期利率与期数。先将期限换成和利率一致的单位，再相乘。到期金额等于本金加利息。



$$
I=Prt,\qquad A=P+I
$$



期限要换算成报价利率的周期。例如年利率 5%、期限 24 个月，按两个年度周期计算。



已知到期金额时可使用反推模式。零利率或零期限会让部分反推问题失去唯一解。







## 计算模式



**单利与到期金额**

- 本金
- 利率 · %
- 利率周期 · 每年 / 每月
- 年
- 月





**求本金**

- 到期金额
- 利率 · %
- 利率周期 · 每年 / 每月
- 期限
- 期限单位 · 年 / 月





**求利率**

- 本金
- 到期金额
- 期限
- 期限单位 · 年 / 月
- 利率周期 · 每年 / 每月





**求期限**

- 本金
- 到期金额
- 利率 · %
- 利率周期 · 每年 / 每月
- 期限单位 · 年 / 月
