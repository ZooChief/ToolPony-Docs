# 電阻色環與串並聯計算器



讀 3 至 6 道色環，計算串並聯等效電阻與圓線電阻。





## 開始使用



1. 選擇色環數或電路連接方式。容差環通常和其他色環有較大間距。
2. 圓形導體填寫直徑和長度。材料預設會填入可編輯的電導率。







## 示例



### 輸入



```
4 色環：綠、紅、紅、金
```



### 預期結果



```
5,200 Ω ±5%
```

## 使用提示



計算在瀏覽器內完成。無單位標記的字段請使用一致單位。







## 計算方法



依次讀有效數字、倍率、容差和可選溫度係數。三環電阻按 20% 容差。均勻圓形導體用 R = L/(σA)。特殊標記請覈對器件資料。



$$
R_{\rm series}=\sum_i R_i,\quad R_{\rm parallel}=\left(\sum_i 1/R_i\right)^{-1},\quad R_{\rm wire}=\frac{L}{\sigma\pi(d/2)^2}
$$



$$
R_{\rm band}=D\,10^m,\qquad R_{\min,\max}=R_{\rm band}(1\mp t/100)
$$
