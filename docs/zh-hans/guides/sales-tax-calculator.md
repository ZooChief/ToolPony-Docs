# 销售税与增值税计算器



按自定义税率计算含税价、未税价与税额。





## 示例



### 输入



```
未税价 100，增值税 20%
```



### 预期结果



```
含税价 120，税额 20
```







## 试一试

[打开完整工具 · 销售税与增值税计算器](<https://toolpony.com/zh-hans/tools/sales-tax-calculator/>)





## 计算方法



含税价 = 未税价 ×（1 + 税率）。税率由用户填写。
