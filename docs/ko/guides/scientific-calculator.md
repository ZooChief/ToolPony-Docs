# 공학용 계산기



능력, 요인, 삼각법, 삼각법, 뿌리 및 로그를 가진 수학 식을 평가합니다.





## 시작하기



1. 예제 값을 사용하거나 원하는 값을 입력하세요.
2. 계산한 결과를 복사하거나 세부 정보를 내려받을 수 있습니다.







## 예시



### 입력



```
sqrt(81) + 2^3 × sin(30), 도
```



### 예상 결과



```
13
```

## 참고 사항



브라우저에서 처리합니다. 단위를 일관되게 사용하세요.







## 계산 방법



연산자는 괄호, postfix, exponent, 곱셈 및 덧셈 우선 순위를 따릅니다. 권한은 오른쪽에서 연관됩니다. 퍼센트는 100으로 나뉩니다. 결과는 부동 소수점 산술을 사용합니다.
