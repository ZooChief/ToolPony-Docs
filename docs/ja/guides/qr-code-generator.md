# QR コード生成



読み取り時に開く種類を選び、リンクやテキスト、必要項目を入力します。 生成した内容を確認し、共有用 PNG または印刷用 SVG を保存します。 必要に応じて外観で濃い6桁のHEX色を指定します。どちらの出力も白い余白を保ちます。





## 使い方



1. 読み取り時に開く種類を選び、リンクやテキスト、必要項目を入力します。
2. 生成した内容を確認し、共有用 PNG または印刷用 SVG を保存します。
3. 必要に応じて外観で濃い6桁のHEX色を指定します。どちらの出力も白い余白を保ちます。







## 例



### 入力



```
https://example.com/
```



### 期待される結果



```
https://example.com/
```

## 制限



静的 QR は入力した内容を直接格納します。UTF-8 で最大 2,048 バイトで、高い誤り訂正では容量が減ります。白い余白は 4 モジュールです。Wi-Fi QR には入力したパスワードが含まれます。
