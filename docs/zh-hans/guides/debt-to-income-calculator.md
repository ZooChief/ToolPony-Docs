# 债务收入比计算器



比较每月固定债务还款与税前月收入。





## 示例



### 输入



```
税前月收入 5,000，月债务还款 1,500
```



### 预期结果



```
30%
```







## 试一试



[打开完整工具](<https://toolpony.com/zh-hans/tools/debt-to-income-calculator/>)







## 计算方法



债务收入比 = 月债务还款额 ÷ 税前月收入。所有金额请用同一币种和月度口径。
