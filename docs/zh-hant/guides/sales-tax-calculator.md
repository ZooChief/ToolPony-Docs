# 銷售稅與增值稅計算器



按自定義稅率計算含稅價、未稅價與稅額。





## 開始使用



1. 按示例填寫數值，或輸入你自己的測量值。
2. 計算後可複製結果或下載明細。







## 示例



### 輸入



```
未稅價 100，增值稅 20%
```



### 預期結果



```
含稅價 120，稅額 20
```







## 試一試

## 使用提示



計算在瀏覽器內完成。無單位標記的字段請使用一致單位。







## 計算方法



含稅價 = 未稅價 ×（1 + 稅率）。稅率由用戶填寫。
