# 债务收入比计算器



比较每月固定债务还款与税前月收入。





## 开始使用



1. 按示例填写数值，或输入你自己的测量值。
2. 计算后可复制结果或下载明细。







## 示例



### 输入



```
税前月收入 5,000，月债务还款 1,500
```



### 预期结果



```
30%
```







## 试一试

## 使用提示



计算在浏览器内完成。无单位标记的字段请使用一致单位。







## 计算方法



债务收入比 = 月债务还款额 ÷ 税前月收入。所有金额请用同一币种和月度口径。
