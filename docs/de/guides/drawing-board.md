# Zeichenfläche



Zeichnen Sie mit einem Pinsel oder Radiergummi auf die Leinwand. Legen Sie die Farbe und Größe fest, machen Sie die Striche rückgängig oder wiederholen Sie sie, und laden Sie dann einen transparenten PNG herunter.





## Erste Schritte



1. Wählen Sie den Pinsel oder Radiergummi und legen Sie seine Größe fest.
2. Zeichne auf der Leinwand mit Maus, Finger oder Stift.
3. Wiederholen oder wiederholen Sie einen Strich und exportieren Sie einen transparenten PNG.







## Ausprobieren



[Vollständiges Werkzeug öffnen](<https://toolpony.com/de/tools/drawing-board/>)







## Hinweise



Das Löschen der Leinwand kann innerhalb der verfügbaren Historie rückgängig gemacht werden.







## Grenzen



Die Leinwand hat 1080 × 640 Pixel. Die Zeichnung bleibt in dieser Registerkarte.
