# 関数電卓



力、因子、三角法、根、対数を用いて数学的表現を評価する。





## 使い方



1. 例を使うか、任意の値を入力します。
2. 計算後、結果をコピーするか詳細をダウンロードできます。







## 例



### 入力



```
sqrt(81)+ 2^3 × 罪(30)、学位
```



### 期待される結果



```
13
```







## 試してみる



[ツール全体を開く](<https://toolpony.com/ja/tools/scientific-calculator/>)







## 注意点



処理はブラウザ内で実行されます。単位をそろえて入力してください。







## 計算方法



オペレーターは括弧、ポストフィックス、付入、乗算、加算の優先順位に従います。 権力は右から関連付ける。 パーセントは100を分ける。 結果は浮動小数点演算を使用します。
