# 半減期計算機



3つの測定値から指数関数的な減衰を解き、半減期、つまり寿命、および減衰定数を変換する。





## 使い方



1. 例を使うか、任意の値を入力します。
2. 計算後、結果をコピーするか詳細をダウンロードできます。







## 例



### 入力



```
50単位で100～10個
```



### 期待される結果



```
半身 ≈ 15.0515
```







## 試してみる



[ツール全体を開く](<https://toolpony.com/ja/tools/half-life-calculator/>)







## 注意点



処理はブラウザ内で実行されます。単位をそろえて入力してください。







## 計算方法



指数減衰は N(t) = N₀ · 2^(−t/T) で表します。T は半減期、平均寿命は T/ln(2)、減衰定数は ln(2)/T です。変換では ln(2) を小数第 10 位まで丸めます。時間の単位を統一してください。



$$
N(t)=N_0\,2^{-t/T},\qquad \lambda=\frac{\ln 2}{T},\qquad \tau=\frac1\lambda
$$



最初に求める値を選び、残りの 3 項目は時間の単位をそろえます。初期量 100、半減期 10 なら、時間 20 の時点で残りは 25 です。







## 計算モード



**半減期を探す**

- 残り量
- 初期数量
- 時間の失速





**残りの数量を探す**

- 初期数量
- 時間の失速
- 半身生活





**初期数量を探す**

- 残り量
- 時間の失速
- 半身生活





**使用時間を確認してください**

- 残り量
- 初期数量
- 半身生活





**変換の減衰対策**

- 既知の測定 · 半身生活 / 平均寿命 / デカイ定数
- 値
