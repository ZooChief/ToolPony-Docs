# Exponent calculator guide



Solve for a power, the base, or the exponent from the other two values.





## Example



### Input



```
Base 2, exponent 5
```



### Expected result



```
32
```







## Try it

[Open full tool · Exponent calculator](<https://toolpony.com/en/tools/exponent-calculator/>)





## Calculation method



For y = bⁿ, solve the exponent with logarithms when b and y are positive and b ≠ 1. Solving for a real base with a nonzero even integer exponent can produce two roots.



$$
y=b^p,\qquad p=\frac{\ln y}{\ln b},\qquad b=\sqrt[p]{y}
$$
