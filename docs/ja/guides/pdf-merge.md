# PDF を結合



端末内で複数の PDF を指定した順に結合します。





## 使い方



1. PDF を 2 件以上選択します。
2. 上下ボタンで順序を変更し、結合した PDF を保存します。







## 例



### 入力



```
A.pdf（2 ページ）、B.pdf（3 ページ）
```



### 期待される結果



```
A1、A2、B1、B2、B3 の順で 1 件の PDF
```







## 試してみる



[ツール全体を開く](<https://toolpony.com/ja/tools/pdf-merge/>)







## 制限



入力は合計 30 MB・300 ページまで。暗号化 PDF には対応しません。フォーム、しおり、電子署名は保持されない場合があります。

[ドキュメント](https://docs.toolpony.com/ja/guides/pdf-merge/)
