# Générateur d’adresses fictives



Générez des adresses de test pour 18 pays et territoires, avec région, format local et export par lot.





## Prise en main



1. Choisissez le pays et la région, puis le nombre et les coordonnées facultatives.
2. Réutilisez la graine et les mêmes réglages pour reproduire un lot. Copiez un champ ou exportez en TXT, CSV ou JSON.
3. Les adresses enregistrées restent dans ce navigateur. Vous pouvez les supprimer dans l’outil.







## Exemple



### Entrée



```
Allemagne · Berlin · Graine pony-demo
```



### Résultat attendu



```
Testperson 001
Beispielstraße 4957
10115 Berlin
Deutschland
```

## Notes



Le traitement se fait dans le navigateur. Utilisez des unités cohérentes.







## Méthode de calcul



Jusqu’à 100 exemples par lot. Localité et code postal illustrent le format. La voie et le destinataire sont fictifs. Les téléphones utilisent des numéros réservés ou masqués. Pour les tests de formulaires et de logiciels.
