# 字幕変換と時間調整



SRTとWebVTTを変換し、時間を移動・拡縮して、保存前に字幕の重複を確認します。





## 使い方



1. 字幕を貼り付けるかSRT・VTTを読み込み、出力形式を選びます。
2. 正のずれで字幕が遅くなります。基準時刻との差に倍率を掛けてからずれを足します。切り詰めや重複を確認して保存します。







## 例



### 入力



```
1
00:00:00,120 --> 00:00:01,400
A line
Second line

2
00:00:01,350 --> 00:00:02,700
Overlap 50 ms
```



### 期待される結果



```
WEBVTT

00:00:00.120 --> 00:00:01.400
A line
Second line

00:00:01.350 --> 00:00:02.700
Overlap 50 ms
```

## 制限



最大1 MiB、字幕10,000件。0秒より前に終わる字幕は削除し、0秒をまたぐ字幕は0秒から始めます。SRTではWebVTTの位置、スタイル、識別子をすべて表現できません。
