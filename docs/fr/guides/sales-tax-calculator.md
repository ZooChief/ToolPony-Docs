# Calculatrice de taxe de vente et de TVA



Ajouter ou supprimer la taxe de vente et la TVA en utilisant votre propre taux.





## Prise en main



1. Utilisez l’exemple ou saisissez vos propres valeurs.
2. Calculez, puis copiez le résultat ou téléchargez les détails.







## Exemple



### Entrée



```
Prix net 100, TVA 20%
```



### Résultat attendu



```
Montant brut 120, taxe 20
```







## Essayer



[Ouvrir l’outil complet](<https://toolpony.com/fr/tools/sales-tax-calculator/>)







## Notes



Le traitement se fait dans le navigateur. Utilisez des unités cohérentes.







## Méthode de calcul



Prix brut = prix net × (1 + taux). Les taux d'imposition sont fournis par l'utilisateur.
