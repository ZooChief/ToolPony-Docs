# 로그 계산기



로그, 기본 또는 인수를 찾습니다. 기본은 숫자 또는 e가 될 수 있습니다.





## 시작하기



1. 예제 값을 사용하거나 원하는 값을 입력하세요.
2. 계산한 결과를 복사하거나 세부 정보를 내려받을 수 있습니다.







## 예시



### 입력



```
Base 3, 인수 81
```



### 예상 결과



```
4
```

## 계산 방법



로그 로그(b)(x)는 지수 y 만족스러운 = x입니다. 기본 변경 공식은 ln(x)을 ln(b)로 나눕니다.



$$
\log_b(x)=\frac{\ln x}{\ln b},\qquad b>0,\quad b\ne1,\quad x>0
$$
