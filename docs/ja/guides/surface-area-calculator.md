# 表面積計算機



球体、円錐形、タンク、カプセル、キャップ、楕円体、ピラミッド、および混合寸法の中空チューブを解く。





## 使い方



1. 例を使うか、任意の値を入力します。
2. 計算後、結果をコピーするか詳細をダウンロードできます。







## 例



### 入力



```
半径2mの球体
```



### 期待される結果



```
≈50.2655 m²
```







## 試してみる



[ツール全体を開く](<https://toolpony.com/ja/tools/surface-area-calculator/>)







## 注意点



処理はブラウザ内で実行されます。単位をそろえて入力してください。







## 計算方法



表面面積全体にはエンドフェイスが含まれます。 該当する場合、ラテラルエリアとエンドフェイスエリアは別にリストされています。 楕円領域は概算です。



$$
A_{\mathrm{cylinder}}=2\pi r^2+2\pi rh,\qquad A_{\mathrm{sphere}}=4\pi r^2
$$
