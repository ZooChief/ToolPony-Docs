# BMI-Rechner für Erwachsene



Berechnen Sie den BMI für Erwachsene in metrischen oder US-amerikanischen Einheiten, vergleichen Sie Referenzbereiche und sehen Sie den BMI Prime und den Ponderal-Index.





## Erste Schritte



1. Verwenden Sie das Beispiel oder geben Sie eigene Werte ein.
2. Berechnen Sie das Ergebnis und kopieren oder laden Sie die Details herunter.







## Beispiel



### Eingabe



```
70 kg, 175 cm
```



### Erwartetes Ergebnis



```
BMI ≈ 22,86 kg/m2
```

## Hinweise



Die Verarbeitung erfolgt im Browser. Verwenden Sie einheitliche Einheiten.







## Berechnungsmethode



BMI = Gewicht (kg) ÷ Größe (m)². Die Referenzbereiche entsprechen den CDC-Kategorien für Erwachsene ab 20 Jahren. BMI Prime = BMI ÷ 25. Ponderal-Index = Gewicht (kg) ÷ Größe (m)³.



$$
\operatorname{BMI}=\frac{m_{\mathrm{kg}}}{h_{\mathrm{m}}^2}
$$







## Berechnungsmodus



**Metrisch**

- Alter
- Gewicht · kg
- Höhe · cm





**US-Einheiten**

- Alter
- Gewicht · lb
- Höhe in Fuß · ft
- Zusätzliche Zoll · in
