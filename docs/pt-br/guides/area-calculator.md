# Calculadora de áreas



Encontre a área de formas planas em onze modos com unidades de entrada mistas e uma unidade de saída selecionável.





## Primeiros passos



1. Use o exemplo ou insira seus próprios valores.
2. Calcule, copie o resultado ou baixe os detalhes disponíveis.







## Exemplo



### Entrada



```
Um retângulo de 4 m por 3 m
```



### Resultado esperado



```
12 m²
```

## Notas de uso



O cálculo é feito no seu navegador. Use unidades consistentes.







## Método de cálculo



Dimensões convertem-se em metros antes do cálculo. O triângulo de três lados usa a fórmula de Heron. Um setor usa metade do raio quadrado vezes o seu ângulo em radianos.



$$
A_{\mathrm{rectangle}}=lw,\qquad A_{\mathrm{sector}}=\tfrac12 r^2\theta
$$



$$
A_{\mathrm{triangle}}=\sqrt{s(s-a)(s-b)(s-c)},\quad s=\tfrac12(a+b+c)
$$







## Modo de cálculo



**Rectângulo**

- Comprimento
- Unidade de comprimento
- Largura
- Unidade da largura
- Unidade de área





**Quadrado**

- Comprimento da borda
- Unidade de comprimento da borda
- Unidade de área





**Triângulo · três lados**

- Primeiro lado
- Unidade do primeiro lado
- Segundo lado
- Unidade do segundo lado
- Terceiro lado
- Unidade do terceiro lado
- Unidade de área





**Triângulo · base e altura**

- Primeiro lado paralelo
- Primeira unidade lateral paralela
- Altura perpendicular
- Unidade de altura perpendicular
- Unidade de área





**Trapézio**

- Primeiro lado paralelo
- Primeira unidade lateral paralela
- Segundo lado paralelo
- Segunda unidade lateral paralela
- Altura perpendicular
- Unidade de altura perpendicular
- Unidade de área





**Círculo**

- Raio
- Unidade de raios
- Unidade de área





**Sector circular**

- Raio
- Unidade de raios
- Ângulo central
- Unidade de ângulo · Graus / Radianos
- Unidade de área





**Elipse**

- Primeiro semieixo
- Primeira unidade de semieixo
- Segundo semieixo
- Segunda unidade de semieixo
- Unidade de área





**Paralelograma**

- Primeiro lado paralelo
- Primeira unidade lateral paralela
- Altura perpendicular
- Unidade de altura perpendicular
- Unidade de área





**Coroa circular**

- Raio exterior
- Unidade de raio exterior
- Raio interno
- Unidade de raio interno
- Unidade de área





**Polígono regular**

- Comprimento da borda
- Unidade de comprimento da borda
- Número de lados
- Unidade de área
