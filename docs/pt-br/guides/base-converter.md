# Conversor e calculadora de bases



Converta inteiros assinados entre as bases 2–36 e execute operações aritméticas exatas, remanescentes ou bitwise.





## Primeiros passos



1. Use o exemplo ou insira seus próprios valores.
2. Calcule, copie o resultado ou baixe os detalhes disponíveis.







## Exemplo



### Entrada



```
FF, base 16 à base 10
```



### Resultado esperado



```
255
```

## Notas de uso



O cálculo é feito no seu navegador. Use unidades consistentes.







## Método de cálculo



O BigInt preserva a precisão inteira. A divisão trunca para zero. As operações Bitwise usam a semântica do BigInt assinada. Cada operando é limitado a 256 dígitos.
