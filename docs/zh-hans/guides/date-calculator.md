# 日期计算器



统计日历天数与工作日，或按年月周日、工作日增减日期。





## 开始使用



1. 统计时填两个日期，选择是否包含较晚日期。节假日在更多选项填写。
2. 要向前移日期，输入负数。按工作日增减时跳过周六、周日和填写的节假日。







## 示例



### 输入



```
2020-01-01 至 2020-02-01
```



### 预期结果



```
31 个日历日、23 个工作日
```

## 使用提示



计算在浏览器内完成。无单位标记的字段请使用一致单位。







## 计算方法



工作日为周一至周五，并排除你填写的日期。YYYY-MM-DD 仅一次，MM-DD 每年重复。按工作日增减时计入较早日期、排除较晚日期，结果可落在周末或节假日。月份增减遇短月取月末。







## 计算模式



**日期间隔**

- 起始日期
- 结束日期
- 包含结束日期
- 节假日（YYYY-MM-DD 或 MM-DD）





**日期加减**

- 起始日期
- 年
- 月
- 周数
- 天





**按工作日增减**

- 起始日期
- 工作日
- 节假日（YYYY-MM-DD 或 MM-DD）
