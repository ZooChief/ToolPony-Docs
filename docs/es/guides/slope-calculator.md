# Calculadora de pendiente



Encuentra una pendiente e intercepta desde dos puntos, o encuentra ambos puntos finales a una distancia determinada.





## Primeros pasos



1. Usa el ejemplo o introduce tus propios valores.
2. Calcula, copia el resultado o descarga los detalles disponibles.







## Ejemplo



### Entrada



```
(0, 0) a (3, 4)
```



### Resultado esperado



```
Pendiente 4/3 y distancia 5
```

## Método de cálculo



La pendiente es el ascenso dividido por la carrera. Una línea vertical tiene una pendiente indefinida. Una distancia y dirección conocida determinan dos puntos finales en los lados opuestos del punto de partida.



$$
m=\frac{y_2-y_1}{x_2-x_1},\qquad \theta=\arctan(m),\qquad y=mx+b
$$



El modo de dos puntos reporta cambios verticales y horizontales por separado. Utilice el signo de cada cambio para saber qué dirección se movió el punto. Una línea vertical tiene una constante x-coordinado.



Una línea y una distancia determinan un punto en cada lado del punto de partida. Utilice la tabla de punto final para mantener ambas soluciones.
