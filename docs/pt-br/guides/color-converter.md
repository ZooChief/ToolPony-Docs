# Conversor de cores



Converta HEX, RGB e HSL, preserve a transparência e visualize a cor.





## Primeiros passos



1. Use o exemplo ou insira seus próprios valores.
2. Calcule, copie o resultado ou baixe os detalhes disponíveis.







## Exemplo



### Entrada



```
rgb(102, 51, 153)
```



### Resultado esperado



```
#663399, hsl(270 50% 40%)
```







## Experimente



[Abrir ferramenta completa](<https://toolpony.com/pt-br/tools/color-converter/>)







## Notas de uso



O cálculo é feito no seu navegador. Use unidades consistentes.







## Método de cálculo



HEX usa canais de 8 bits. RGB aceita números ou porcentagens. HSL usa graus no matiz e porcentagens na saturação e na luminosidade. A saída HEX arredonda cada canal ao byte mais próximo.
