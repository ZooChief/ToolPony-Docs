# Documento a texto



Elige un archivo DOCX, ODT o PDF de tu dispositivo, o abre el DOCX de ejemplo.





## Primeros pasos



1. Elige un archivo DOCX, ODT o PDF de tu dispositivo, o abre el DOCX de ejemplo.
2. Cada párrafo comienza en una línea nueva. Las celdas se separan con tabulaciones. Copia el resultado o descarga un archivo UTF-8.







## Ejemplo



### Entrada



```
DOCX con un título, dos fragmentos de texto y una tabulación
```



### Resultado esperado



```
ToolPony
ABC	123
```







## Pruébalo



[Abrir herramienta completa](<https://toolpony.com/es/tools/document-to-text/>)







## Límites



En DOCX y ODT se lee el cuerpo, con hasta 20 MiB por archivo y 1 MiB de texto UTF-8 extraído. El PDF necesita texto seleccionable. Se excluyen las imágenes, la maquetación y los archivos con contraseña.

[Documentación](https://docs.toolpony.com/es/guides/document-to-text/)
