# JSON 整形



JSONを貼り付け、インデントを選択してフォーマットするか、または最小にしてください。 結果をコピーするか、JSONファイルをダウンロードしてください。 Cmd/Ctrl + Enter はフォーマッターを実行します。





## 使い方



1. JSONドキュメントを貼り付けます。
2. 2つまたは4つのスペースを選択し、フォーマットします。コンパクトな結果にはMinifyを使用してください。
3. 結果をコピーするか、JSONファイルをダウンロードしてください。







## 例



### 入力



```
{"name":"ToolPony","ready":true}
```



### 期待される結果



```
{
  "name": "ToolPony",
  "ready": true
}
```







## 試してみる



[ツール全体を開く](<https://toolpony.com/ja/tools/json-formatter/>)







## 注意点



キーと文字列には二重引用符が必要です。 コメントや後れを取ったコンマはJSONではありません。 安全な精度以外の数値は、値を黙って変更しないように拒否されます。







## 制限



最大1MBまで。 無効なJSONおよび安全でない数値精度は拒否されます。 フォーマットはアプリケーションスキーマに対して認証されません。
