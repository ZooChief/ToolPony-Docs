# Bilder komprimieren



Wählen Sie ein bis zwölf Bilder und das Ausgabeformat JPEG oder WebP. Legen Sie Qualität oder Zielgröße je Datei fest. Geben Sie bei Bedarf eine maximale Seitenlänge ein. Vergleichen Sie jedes Bild und laden Sie Dateien einzeln oder als ZIP herunter.





## Erste Schritte



1. Wählen Sie ein bis zwölf Bilder und das Ausgabeformat JPEG oder WebP.
2. Legen Sie Qualität oder Zielgröße je Datei fest. Geben Sie bei Bedarf eine maximale Seitenlänge ein.
3. Vergleichen Sie jedes Bild und laden Sie Dateien einzeln oder als ZIP herunter.







## Beispiel



### Eingabe



```
Zwei Fotos, WebP, je 100 KB, maximale Seite 1200 px, Verkleinerung erlaubt
```



### Erwartetes Ergebnis



```
Erreichbare Ergebnisse sind WebP-Dateien mit je höchstens 100.000 Byte im ZIP.
```

## Grenzen



Je Bild maximal 20 MB und 24 Megapixel, je Stapel 64 MiB für Ein- und Ausgabe. Die maximale Seitenlänge vergrößert keine Bilder. JPEG und WebP werden verlustbehaftet kodiert. Animationen werden Standbilder und ursprüngliche Metadaten werden entfernt.
