# Age calculator



Find calendar age, elapsed time and the next birthday.





## Get started



1. Enter the date of birth and a reference date. A blank reference uses today on your device.







## Example



### Input



```
Birth 2000-01-01, reference 2025-02-03
```



### Expected result



```
25 years · 1 month · 2 days
```







## Try it



[Open full tool](<https://toolpony.com/en/tools/age-calculator/>)







## Good to know



The calculation runs in your browser. Use consistent units in fields with no explicit unit.







## Calculation method



Months align to the same day or to month-end. For a February 29 birthday, choose February 28 or March 1 in common years. Elapsed time uses 24-hour days.
