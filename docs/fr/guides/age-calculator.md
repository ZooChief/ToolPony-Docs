# Calculateur d’âge



Calculez l’âge, le temps écoulé et le prochain anniversaire.





## Prise en main



1. Saisissez la date de naissance et la date de référence. Sans référence, la date de l’appareil est utilisée.







## Exemple



### Entrée



```
Naissance le 2000-01-01, référence le 2025-02-03
```



### Résultat attendu



```
25 ans · 1 mois · 2 jours
```







## Essayer



[Ouvrir l’outil complet](<https://toolpony.com/fr/tools/age-calculator/>)







## Notes



Le traitement se fait dans le navigateur. Utilisez des unités cohérentes.







## Méthode de calcul



Les mois se terminent au même quantième ou en fin de mois. Pour une naissance le 29 février, choisissez le 28 février ou le 1er mars les années ordinaires. Les jours durent 24 heures dans ce calcul.
