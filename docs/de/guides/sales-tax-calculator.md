# Umsatz- und Mehrwertsteuerrechner



Fügen Sie Umsatzsteuer und Mehrwertsteuer mit Ihrem eigenen Satz hinzu oder entfernen.





## Erste Schritte



1. Verwenden Sie das Beispiel oder geben Sie eigene Werte ein.
2. Berechnen Sie das Ergebnis und kopieren oder laden Sie die Details herunter.







## Beispiel



### Eingabe



```
Nettopreis 100, Mehrwertsteuer 20%
```



### Erwartetes Ergebnis



```
Brutto 120, Steuer 20
```







## Ausprobieren



[Vollständiges Werkzeug öffnen](<https://toolpony.com/de/tools/sales-tax-calculator/>)







## Hinweise



Die Verarbeitung erfolgt im Browser. Verwenden Sie einheitliche Einheiten.







## Berechnungsmethode



Bruttopreis = Nettopreis × (1 + Satz) Steuersätze werden vom Benutzer angegeben.
