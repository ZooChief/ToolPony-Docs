# 옴의 법칙 계산기



두 값으로 전압, 전류, 저항, 전력을 구합니다.





## 시작하기



1. 양수 두 개를 입력하고 각 단위를 선택하세요. 나머지 값은 비워 두세요.







## 예시



### 입력



```
12 V와 6 Ω
```



### 예상 결과



```
2 A, 24 W
```







## 직접 사용해 보기



[전체 도구 열기](<https://toolpony.com/ko/tools/ohms-law-calculator/>)







## 참고 사항



브라우저에서 처리합니다. 단위를 일관되게 사용하세요.







## 계산 방법



저항성 회로에서 V = IR, P = VI입니다. 입력을 SI 단위로 변환하고 1 hp를 746 W로 계산합니다. 결과는 V, A, Ω, W입니다.



$$
V=IR,\qquad P=IV
$$
