# 확률 계산기



이벤트 확률을 계산하거나, 알려진 두 값에서 독립적인 확률을 복구하거나, 정상적인 간격을 사용합니다.





## 시작하기



1. 예제 값을 사용하거나 원하는 값을 입력하세요.
2. 계산한 결과를 복사하거나 세부 정보를 내려받을 수 있습니다.







## 예시



### 입력



```
독립 이벤트 A = 0.31, B = 0.56
```



### 예상 결과



```
한 번 이상일 확률 0.6964
```

## 계산 방법



독립적 인 이벤트는 P (A∩B) = P (A) P (B)를 만족시킵니다. 종속 이벤트의 경우 교차로에 직접 들어갑니다. 반복 된 시험은 확률에 곱하고 적어도 하나의 성공 확률은 보완을 사용합니다.



$$
P(A\cup B)=P(A)+P(B)-P(A\cap B)
$$



$$
P(A\cap B)=P(A)P(B)\quad\text{(independent)}
$$







## 계산 모드



**두 개의 독립적인 이벤트**

- A의 확률
- B의 확률





**알려진 교차로**

- A의 확률
- B의 확률
- 두 이벤트 모두





**독립적 인 이벤트 복구**

- 처음 알려진 수량 · A의 확률 / B의 확률 / A가 아닌 / B가 아닙니다 / 두 이벤트 모두 / 적어도 하나의 이벤트 / 정확히 하나의 이벤트 / 이벤트 없음
- 첫 번째 확률
- 두 번째로 알려진 수량 · A의 확률 / B의 확률 / A가 아닌 / B가 아닙니다 / 두 이벤트 모두 / 적어도 하나의 이벤트 / 정확히 하나의 이벤트 / 이벤트 없음
- 두 번째 확률





**반복되는 독립적인 재판**

- A의 확률
- A의 재판
- B의 확률
- B의 재판
