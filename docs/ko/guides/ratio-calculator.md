# 비율 계산기



누락 된 용어를 비율로 해결하거나, 비율을 단순화하거나, 두 용어를 모두 확장하십시오.





## 시작하기



1. 예제 값을 사용하거나 원하는 값을 입력하세요.
2. 계산한 결과를 복사하거나 세부 정보를 내려받을 수 있습니다.







## 예시



### 입력



```
3:4 = x:20
```



### 예상 결과



```
x=15
```







## 직접 사용해 보기



[전체 도구 열기](<https://toolpony.com/ko/tools/ratio-calculator/>)







## 참고 사항



브라우저에서 처리합니다. 단위를 일관되게 사용하세요.







## 계산 방법



A:B = C:D는 A×D = B×C를, nonzero 분모와 함께 의미합니다. 단순화는 소수 및 소수 자릿수를 허용합니다.







## 계산 모드



**비율 해결**

- A
- B
- C
- D





**단순화 또는 규모**

- 첫째 항
- 두 번째 임기
- 스케일 팩터





**비율을 확대하거나 줄이기**

- 첫째 항
- 두 번째 임기
- 방향 · 줄이기 / 확장
- 인수
