# Calculadora de descuentos



Descuentos en estadio, restar un cupón fijo y aplicar impuestos de ventas al precio rebajado.





## Primeros pasos



1. Usa el ejemplo o introduce tus propios valores.
2. Calcula, copia el resultado o descarga los detalles disponibles.







## Ejemplo



### Entrada



```
100 con 20% y 10% de descuento
```



### Resultado esperado



```
72; descuento combinado 28%
```

## Notas de uso



El cálculo se ejecuta en tu navegador. Usa unidades coherentes.







## Método de cálculo



Aplicar descuentos porcentuales en orden, luego el cupón fijo, luego impuestos. Hasta 10 tarifas de 0% a 100%.



Dos descuentos sucesivos de 20% y 10% de licencia 0.8 × 0.9 del precio original. Introduzca ambas tarifas en orden, a continuación, añadir un cupón o impuesto si es aplicable.



Utilice un modo inverso cuando sepa el precio de venta o la cantidad guardada. Modos inversos manejan un descuento antes del impuesto.







## Modo de cálculo



**Aplicar descuentos**

- Precio original
- Porcentajes de descuento
- Golpe fijo
- Tasa impositiva · %





**Encontrar precio original**

- Precio tras descuento
- Tipo de descuento · Porcentaje / Cantidad fija
- Descuento





**Buscar tarifas y ahorros**

- Precio original
- Cantidad conocida · Precio con descuento / Ahorros
- Monto





**Encuentre precios de ahorros**

- Cuantía salvada
- Tasa de descuento · %
