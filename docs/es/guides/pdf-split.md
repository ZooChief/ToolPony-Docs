# Dividir PDF



Selecciona páginas y guárdalas en un PDF o ZIP nuevo.





## Primeros pasos



1. Selecciona un PDF sin cifrar.
2. Selecciona miniaturas o escribe páginas y rangos como 5, 1-3.
3. Elige un PDF, un archivo por rango o un archivo por página.
4. También puedes dividir por número de páginas o tamaño de archivo. El límite se aplica al PDF generado, sin volver a comprimirlo.







## Ejemplo



### Entrada



```
PDF de 5 páginas, selección 5, 1-3
```



### Resultado esperado



```
Un PDF con las páginas 5, 1, 2 y 3 en ese orden
```







## Pruébalo



[Abrir herramienta completa](<https://toolpony.com/es/tools/pdf-split/>)







## Límites



Hasta 30 MB y 300 páginas. No se pueden repetir páginas. Los PDF dentro del ZIP tienen un límite de 64 MB en total. Los formularios, marcadores y firmas pueden perderse.
