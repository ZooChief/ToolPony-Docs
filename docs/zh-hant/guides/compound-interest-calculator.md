# 複利計算器



估算含定期投入和通脹的複利餘額，或在不同計息頻率間換算。





## 開始使用



1. 按示例填寫數值，或輸入你自己的測量值。
2. 計算後可複製結果或下載明細。







## 示例



### 輸入



```
10,000 按 5% 年複利，10 年
```



### 預期結果



```
16,288.95
```

## 計算方法



實際年增長率爲 (1+r/m)^m−1，連續複利爲 exp(r)−1。定期投入按選定的期初或期末開始計息。



$$
A=P(1+r/m)^{mt},\qquad \mathrm{APY}=(1+r/m)^m-1
$$
