# Conversor y calculadora de bases



Convertir números enteros firmados entre las bases 2–36 y realizar operaciones aritméticas exactas, continuas o bitwise.





## Primeros pasos



1. Usa el ejemplo o introduce tus propios valores.
2. Calcula, copia el resultado o descarga los detalles disponibles.







## Ejemplo



### Entrada



```
FF, base 16 a base 10
```



### Resultado esperado



```
255
```

## Notas de uso



El cálculo se ejecuta en tu navegador. Usa unidades coherentes.







## Método de cálculo



BigInt mantiene la precisión del entero. División se mueve hacia cero. Las operaciones Bitwise usan semántica BigInt firmada. Cada operando se limita a 256 dígitos.
