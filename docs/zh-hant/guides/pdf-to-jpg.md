# PDF 轉 JPG 或 PNG



選擇 PDF，設定頁碼和分辨率。可下載單張圖片，也可按選頁順序打包 ZIP。





## 開始使用



1. 選擇未加密的 PDF。
2. 在縮略圖選頁或輸入頁碼，再選擇 JPG 或 PNG 及分辨率。
3. 轉換後下載一張圖片，或按選頁順序下載 ZIP。







## 示例



### 輸入



```
一頁 612 × 792 pt，PNG，144 DPI
```



### 預期結果



```
一張 1224 × 1584 像素的 PNG
```

## 使用提示



PDF 每英寸爲 72 點。144 DPI 時每點對應兩個像素。帶旋轉設置的頁面按其原有方向輸出。







## 適用範圍



輸入最大 30 MB、300 頁。每次最多導出 40 頁、總計 6000 萬像素，每頁最大 2400 萬像素、每邊最多 8,192 像素。ZIP 內圖片合計最多 64 MB。以白底渲染，不支持加密 PDF。
