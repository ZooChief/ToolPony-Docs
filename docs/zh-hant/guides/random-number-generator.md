# 隨機數生成器



在閉區間內生成隨機整數，支持去重和排序。





## 開始使用



1. 按示例填寫數值，或輸入你自己的測量值。
2. 計算後可複製結果或下載明細。







## 示例



### 輸入



```
最小 1，最大 10，生成 5 個
```



### 預期結果



```
5 個 1 至 10 的隨機整數
```

## 使用提示



計算在瀏覽器內完成。無單位標記的字段請使用一致單位。







## 計算方法



隨機值來自 Web Crypto，採用拒絕採樣避免取模偏差。最多生成 1,000 個數，區間範圍爲 −10 億至 10 億。
