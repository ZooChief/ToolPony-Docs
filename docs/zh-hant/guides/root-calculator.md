# 方根計算器



計算平方根、立方根或任意次方根的實數主值。





## 開始使用



1. 按示例填寫數值，或輸入你自己的測量值。
2. 計算後可複製結果或下載明細。







## 示例



### 輸入



```
144 的平方根
```



### 預期結果



```
12
```

計算在瀏覽器內完成。無單位標記的字段請使用一致單位。







## 計算方法



n 次方根爲 x 的 1/n 次冪。奇數次可處理負數，負次數表示取倒數。



$$
\sqrt[n]{x}=x^{1/n},\qquad n\ne0
$$







## 計算模式



**平方根**

- 被開方數





**立方根**

- 被開方數





**任意次方根**

- 被開方數
- 次數
