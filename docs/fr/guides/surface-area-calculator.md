# Calculatrice d’aire de surface



Résolvez les sphères, cônes, réservoirs, capsules, capsules, ellipsoïdes, pyramides et tubes creux aux dimensions mélangées.





## Prise en main



1. Utilisez l’exemple ou saisissez vos propres valeurs.
2. Calculez, puis copiez le résultat ou téléchargez les détails.







## Exemple



### Entrée



```
Sphère avec rayon 2 m
```



### Résultat attendu



```
≈50.2655 m²
```

## Notes



Le traitement se fait dans le navigateur. Utilisez des unités cohérentes.







## Méthode de calcul



La superficie totale comprend les faces terminales. Le cas échéant, les surfaces latérales et terminales sont énumérées séparément.



$$
A_{\mathrm{cylinder}}=2\pi r^2+2\pi rh,\qquad A_{\mathrm{sphere}}=4\pi r^2
$$
