# PDF 병합



여러 PDF를 선택한 순서대로 기기에서 합칩니다.





## 시작하기



1. PDF를 두 개 이상 선택합니다.
2. 위아래 버튼으로 순서를 정하고 합친 PDF를 저장합니다.







## 예시



### 입력



```
A.pdf(2페이지), B.pdf(3페이지)
```



### 예상 결과



```
A1, A2, B1, B2, B3 순서의 PDF 한 개
```







## 직접 사용해 보기



[전체 도구 열기](<https://toolpony.com/ko/tools/pdf-merge/>)







## 제한 사항



입력은 총 30 MB, 300페이지까지 가능합니다. 암호화된 PDF는 지원하지 않습니다. 양식, 북마크, 전자 서명이 유지되지 않을 수 있습니다.

[문서](https://docs.toolpony.com/ko/guides/pdf-merge/)
