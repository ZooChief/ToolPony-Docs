# 帯域幅計算機



ファイルサイズ、リンク速度、プロトコル効率から転送時間を推定します。





## 使い方



1. 例を使うか、任意の値を入力します。
2. 計算後、結果をコピーするか詳細をダウンロードできます。







## 例



### 入力



```
100Mbpsで1GB、高効率100%
```



### 期待される結果



```
80秒
```







## 試してみる



[ツール全体を開く](<https://toolpony.com/ja/tools/bandwidth-calculator/>)







## 注意点



処理はブラウザ内で実行されます。単位をそろえて入力してください。







## 計算方法



所要時間 (秒) = ファイルのバイト数 × 8 ÷ 実効速度 (bit/s)。通信速度の接頭辞は 10 進です。ファイルサイズは 10 進と 2 進の接頭辞に対応します。
