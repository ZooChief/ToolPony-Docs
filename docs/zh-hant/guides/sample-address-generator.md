# 虛擬地址生成器



生成 18 個國家和地區的地址測試數據，支持行政區選擇、本地地址格式及批量導出。





## 開始使用



1. 選擇國家或地區和行政區，設置條數及聯繫信息。
2. 使用相同的隨機種子和設置即可復現同一批。可複製單個字段或導出 TXT、CSV、JSON。
3. 選擇「保存到本機」後，地址樣例保存在當前瀏覽器，可在工具內移除。







## 示例



### 輸入



```
德國 · 柏林 · 隨機種子 pony-demo
```



### 預期結果



```
Testperson 001
Beispielstraße 4957
10115 Berlin
Deutschland
```

## 使用提示



計算在瀏覽器內完成。無單位標記的字段請使用一致單位。







## 計算方法



每批最多 100 條。城市與郵編用於展示格式，街道與收件人由工具合成。電話使用保留示例號或佔位符。適用於表單及軟件測試。
