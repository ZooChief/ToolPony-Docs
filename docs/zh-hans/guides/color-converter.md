# 颜色转换器



在 HEX、RGB 和 HSL 间转换，保留透明度并预览颜色。





## 开始使用



1. 按示例填写数值，或输入你自己的测量值。
2. 计算后可复制结果或下载明细。







## 示例



### 输入



```
rgb(102, 51, 153)
```



### 预期结果



```
#663399，hsl(270 50% 40%)
```

## 使用提示



计算在浏览器内完成。无单位标记的字段请使用一致单位。







## 计算方法



HEX 表示 8 位通道。RGB 可输入数值或百分比。HSL 色相用度，饱和度与亮度用百分比。HEX 输出将各通道舍入到最接近的字节值。
