# Image conversion

[简体中文](image-conversion.zh-CN.md) · [Open Image Converter](https://toolpony.com/en/tools/image-converter/)

1. Add up to 12 images. The converter detects the format of each file.
2. Choose an output format for the batch or set the format, quality and background for each image.
3. Convert, then download individual files or a ZIP.

| Choose | When you need it |
|---|---|
| PNG | Keep transparent areas in logos or screenshots. |
| JPEG | Prepare photos or use an upload form that requires JPG. The selected background fills transparent areas. |
| WebP | Adjust the file size while keeping transparency when needed. |
| AVIF | Select it when your browser offers AVIF encoding. |

For example, a transparent WebP logo can become a transparent PNG. For a JPEG-only upload form, convert a PNG with a white background. When converting JPEG to PNG, the visible detail comes from the existing JPEG.

Each input can be up to 20 MiB and 24 megapixels. A batch can total up to 64 MiB. The browser handles conversion locally. Animated files export one frame, and conversion removes original metadata.
