# 문서 텍스트 추출



기기에서 DOCX, ODT, PDF를 선택하거나 DOCX 예제를 여세요.





## 시작하기



1. 기기에서 DOCX, ODT, PDF를 선택하거나 DOCX 예제를 여세요.
2. 문단은 줄바꿈하고 표의 셀은 탭으로 구분합니다. 결과를 복사하거나 UTF-8 텍스트를 받으세요.







## 예시



### 입력



```
제목, 텍스트 두 개, 탭이 있는 DOCX
```



### 예상 결과



```
ToolPony
ABC	123
```







## 직접 사용해 보기



[전체 도구 열기](<https://toolpony.com/ko/tools/document-to-text/>)







## 제한 사항



DOCX와 ODT는 본문만 읽습니다. 파일은 20 MiB, 추출한 UTF-8은 1 MiB까지입니다. PDF에는 선택 가능한 텍스트가 필요합니다. 이미지, 페이지 서식, 암호 파일은 지원 범위에서 제외됩니다.

[문서](https://docs.toolpony.com/ko/guides/document-to-text/)
