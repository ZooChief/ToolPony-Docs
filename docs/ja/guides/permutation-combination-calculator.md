# 順列・組み合わせ計算機



繰り返しの有無にかかわらず、注文済みおよび未順序の選択を正確に計算します。





## 使い方



1. 例を使うか、任意の値を入力します。
2. 計算後、結果をコピーするか詳細をダウンロードできます。







## 例



### 入力



```
n=10、r=3、繰り返しなし
```



### 期待される結果



```
720回の変数;120個の組み合わせ
```







## 試してみる



[ツール全体を開く](<https://toolpony.com/ja/tools/permutation-combination-calculator/>)







## 注意点



処理はブラウザ内で実行されます。単位をそろえて入力してください。







## 計算方法



繰り返しなしでは、nPr = n!/(n−r)! および nCr = nPr/r! を繰り返しない。 繰り返しの場合、順序選択はnrであり、順序のない選択は C(n+r−1,r である。
