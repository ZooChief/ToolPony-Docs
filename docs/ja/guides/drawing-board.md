# お絵描きボード



キャンバスにブラシや消しゴムを塗ってください。 色とサイズを設定し、ストロークを元に戻したりやりやすったりしてから、透明なPNGをダウンロードしてください。





## 使い方



1. ブラシまたは消しゴムを選び、サイズを設定します。
2. キャンバスにマウス、指、またはペンで描き出す。
3. ストロークを解除またはやり、透明なPNGをエクスポートします。







## 試してみる



[ツール全体を開く](<https://toolpony.com/ja/tools/drawing-board/>)







## 注意点



キャンバスのクリアリングは、利用可能な履歴内で取り消せる。 タブを閉じる前にPNGをエクスポートしてください。







## 制限



キャンバスは1080×640ピクセルです。 図面はこのタブに残ります。 Ctrl/Cmd+Z と Ctrl/Cmd+Shift+Z を使用して、やります。
