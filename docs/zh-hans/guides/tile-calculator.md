# 瓷砖用量计算器



根据瓷砖尺寸、留缝和铺贴面积估算片数、箱数与费用。





## 开始使用



1. 填写砖长、砖宽和缝隙。负缝宽表示相邻砖有搭接。
2. 输入已知面积，或输入区域的长和宽。填每箱片数可估算整箱数。
3. 需要预留切割和破损时，在「更多选项」填写损耗率。片数按面积覆盖估算。







## 示例



### 输入



```
180 平方英尺、12 × 12 英寸瓷砖、¼ 英寸缝、每箱 12 片
```



### 预期结果



```
173 片，15 箱
```

## 计算方法



面积除以（砖长 + 缝宽）×（砖宽 + 缝宽）后向上取整。负缝宽表示搭接。按需加损耗，再换算成整箱。



$$
N=\left\lceil\frac{A}{(l+g)(w+g)}\right\rceil,\quad N_{\rm order}=\left\lceil N(1+a/100)\right\rceil
$$



180 平方英尺使用 12 英寸方砖并留 ¼ 英寸缝，估算需 173 片。预留 10% 后为 191 片，每箱 12 片时向上取整为 16 箱。



覆盖模型用每片砖的有效长度和宽度。损耗率可预留切割、拼花和破损。最终排版请用实际房间和砖尺寸核对。
