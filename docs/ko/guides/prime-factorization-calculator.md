# 소인수분해 계산기



양수, 지수 양식 및 양수 정수의 구분자 수를 찾습니다.





## 예시



### 입력



```
360
```



### 예상 결과



```
2³ × 3² × 5, 약수 24개
```







## 직접 사용해 보기

[전체 도구 열기 · 소인수분해 계산기](<https://toolpony.com/ko/tools/prime-factorization-calculator/>)





## 계산 방법



시험 분할은 나머지 정수의 제곱근까지 요소를 제거합니다. 입력 범위: 2 ~ 1 조.
