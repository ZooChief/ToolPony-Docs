# 팁 계산기



세금 전후 금액에 따라 팁과 함께 사람들 사이에 청구서와 팁을 나눕니다.





## 예시



### 입력



```
80 청구서, 20% 끝, 4 사람들
```



### 예상 결과



```
합계 96, 1인당 24
```







## 직접 사용해 보기

[전체 도구 열기 · 팁 계산기](<https://toolpony.com/ko/tools/tip-calculator/>)





## 계산 방법



팁 = 선택한 청구서 금액 × 팁 비율. 1 인당 총 청구서, 세금 및 팁은 사람들의 수로 나뉩니다.
