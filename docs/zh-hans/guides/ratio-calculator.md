# 比例计算器



求比例中的未知项、化简比例，或按倍数缩放两项。





## 开始使用



1. 按示例填写数值，或输入你自己的测量值。
2. 计算后可复制结果或下载明细。







## 示例



### 输入



```
3:4 = x:20
```



### 预期结果



```
x=15
```







## 试一试

## 使用提示



计算在浏览器内完成。无单位标记的字段请使用一致单位。







## 计算方法



A:B = C:D 等价于 A×D = B×C，分母应非零。化简支持小数和分数。







## 计算模式



**求未知项**

- A
- B
- C
- D





**化简或缩放**

- 第一项
- 第二项
- 缩放倍数





**按倍数放大或缩小**

- 第一项
- 第二项
- 方向 · 缩小 / 放大
- 倍数
