# Conversor de números romanos



Convertir números romanos e números enteros en cualquier dirección, incluyendo fechas o listas delimitadas.





## Primeros pasos



1. Usa el ejemplo o introduce tus propios valores.
2. Calcula, copia el resultado o descarga los detalles disponibles.







## Ejemplo



### Entrada



```
MCMXCIX
```



### Resultado esperado



```
1999
```

## Notas de uso



El cálculo se ejecuta en tu navegador. Usa unidades coherentes.







## Método de cálculo



El convertidor utiliza pares subtráctiles estándar como IV y CM. Un overline multiplica un grupo por 1.000. Ingrese un subrayado antes de cada letra overlined, o pega el overline en sí mismo. Los valores se limitan a 1–3,999,999. El modo de fecha convierte cada campo y preserva separadores.







## Modo de cálculo



**Valor único**

- Número entero o romano





**Fecha o lista**

- Valores o fecha
