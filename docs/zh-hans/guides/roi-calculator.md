# 投资回报率计算器



计入费用，计算净收益、总投资回报率和年化回报率。





## 开始使用



1. 按示例填写数值，或输入你自己的测量值。
2. 计算后可复制结果或下载明细。







## 示例



### 输入



```
投入 1,000，两年后收到 1,210
```



### 预期结果



```
总回报率 21%，年化 10%
```

## 使用提示



计算在浏览器内完成。无单位标记的字段请使用一致单位。







## 计算方法



总回报率为（净回收金额 − 总投入）÷ 总投入。年化回报率把该比例按期限折算为复合年收益。
