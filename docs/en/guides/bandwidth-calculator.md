# Bandwidth calculator



Estimate transfer time from file size, link speed and protocol efficiency.





## Get started



1. Use the example values or enter your own measurements.
2. Calculate, then copy the result or download the available details.







## Example



### Input



```
1 GB at 100 Mbps, efficiency 100%
```



### Expected result



```
80 seconds
```







## Try it



[Open full tool](<https://toolpony.com/en/tools/bandwidth-calculator/>)







## Good to know



The calculation runs in your browser. Use consistent units in fields with no explicit unit.







## Calculation method



Time in seconds = file bytes × 8 ÷ effective bits per second. Network prefixes are decimal. File size supports decimal and binary prefixes.
