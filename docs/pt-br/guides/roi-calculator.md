# Calculadora de retorno sobre investimento



Calcular lucro líquido, retorno total e retorno anualizado com taxas.





## Primeiros passos



1. Use o exemplo ou insira seus próprios valores.
2. Calcule, copie o resultado ou baixe os detalhes disponíveis.







## Exemplo



### Entrada



```
Investir 1.000 e receber 1.210 após 2 anos
```



### Resultado esperado



```
21% total; 10% anualizado
```







## Experimente



[Abrir ferramenta completa](<https://toolpony.com/pt-br/tools/roi-calculator/>)







## Notas de uso



O cálculo é feito no seu navegador. Use unidades consistentes.







## Método de cálculo



O retorno total é (rendimentos líquidos - custo total) □ custo total. Compostos de retorno anualizados a mesma proporção ao longo dos anos especificados.
