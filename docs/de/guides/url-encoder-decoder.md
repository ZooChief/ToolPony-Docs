# URL kodieren und dekodieren



Verschlüsseln oder dekodieren Sie vollständige URLs, URI-Komponenten und Formularwerte.





## Erste Schritte



1. Verwenden Sie das Beispiel oder geben Sie eigene Werte ein.
2. Berechnen Sie das Ergebnis und kopieren oder laden Sie die Details herunter.







## Beispiel



### Eingabe



```
Kodierungskomponente: a+b & c
```



### Erwartetes Ergebnis



```
a%2Bb%20%26%20c
```







## Ausprobieren



[Vollständiges Werkzeug öffnen](<https://toolpony.com/de/tools/url-encoder-decoder/>)







## Hinweise



Die Verarbeitung erfolgt im Browser. Verwenden Sie einheitliche Einheiten.







## Berechnungsmethode



Die Komponentenkodierung entgeht reservierten Trennzeichen. Die vollständige URL-Kodierung bewahrt Trennzeichen. Die Formularkodierung verwendet plus für Leerzeichen.

[Dokumentation](https://docs.toolpony.com/de/guides/url-encoder-decoder/)
