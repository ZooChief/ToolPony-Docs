# 수열 계산기



등차수열, 등비수열, 피보나치 수열의 항과 부분합을 계산하고 목록을 내려받습니다.





## 시작하기



1. 예제 값을 사용하거나 원하는 값을 입력하세요.
2. 계산한 결과를 복사하거나 세부 정보를 내려받을 수 있습니다.







## 예시



### 입력



```
등차수열, 첫째 항 7, 공차 −3, 제8항
```



### 예상 결과



```
−14, 합 −28
```

브라우저에서 처리합니다. 단위를 일관되게 사용하세요.







## 계산 방법



등차수열과 등비수열의 인덱스는 1부터 시작합니다. 피보나치 수열은 F₀ = 0부터 시작하고 정확한 정수로 계산합니다.



$$
a_n=a_1+(n-1)d,\quad g_n=g_1r^{n-1},\quad F_n=F_{n-1}+F_{n-2}
$$







## 계산 모드



**등차수열**

- 첫째 항
- 공차
- 인덱스





**등비수열**

- 첫째 항
- 공비
- 인덱스





**피보나치 수열**

- 인덱스
