# 面積計算器



提供 11 種平面面積計算模式，尺寸單位可混用，並可選擇結果單位。





## 開始使用



1. 按示例填寫數值，或輸入你自己的測量值。
2. 計算後可複製結果或下載明細。







## 示例



### 輸入



```
長方形長 4 米，寬 3 米
```



### 預期結果



```
12 平方米
```

## 使用提示



計算在瀏覽器內完成。無單位標記的字段請使用一致單位。







## 計算方法



各尺寸先換算爲米。三邊求三角形面積採用海倫公式。扇形面積等於半徑平方乘以弧度角再除以二。



$$
A_{\mathrm{rectangle}}=lw,\qquad A_{\mathrm{sector}}=\tfrac12 r^2\theta
$$



$$
A_{\mathrm{triangle}}=\sqrt{s(s-a)(s-b)(s-c)},\quad s=\tfrac12(a+b+c)
$$
