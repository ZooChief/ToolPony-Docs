# 图片压缩



选择最多 12 张图，设置 JPEG 或 WebP、画质或单文件目标体积，以及可选的最长边。逐张对比，单独下载或打包 ZIP。





## 开始使用



1. 选择最多 12 张图，设置 JPEG 或 WebP。
2. 选择画质或每张图的目标大小。可设最长边，等比例缩小较大的图。目标模式可允许进一步缩小。
3. 逐张对比原图和结果。可以单独下载，也可将处理成功的图片打包。







## 示例



### 输入



```
两张照片，WebP，每张 100 KB，最长边 1200 px，允许缩小
```



### 预期结果



```
将达到目标的 WebP 打包成 ZIP，每张不超过 100,000 字节。
```

## 使用提示



这里 1 KB = 1,000 字节。目标为大小上限，不是精确字节数。JPEG/WebP 是有损编码，透明 PNG 可选 WebP 保留透明度。较小的原文件也可能越压越大，结果会如实提示。







## 适用范围



每张最多 20 MB、2400 万像素；批次输入和输出各限 64 MiB。最长边仅缩小较大图片。JPEG 和 WebP 为有损编码。动图转为单帧并移除原始元数据。
