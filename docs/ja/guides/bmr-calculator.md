# 基礎代謝量・消費カロリー計算機



メートル法または米国単位における安静エネルギーおよび日次エネルギー消費量を、3つの方程式で推定する。





## 使い方



1. 例を使うか、任意の値を入力します。
2. 計算後、結果をコピーするか詳細をダウンロードできます。







## 例



### 入力



```
雄の方程式、30年、70kg、175cm、ミフリン=シュト・ジェオール
```



### 期待される結果



```
静息時は 1,648.75 kcal/日
```







## 試してみる



[ツール全体を開く](<https://toolpony.com/ja/tools/bmr-calculator/>)







## 注意点



処理はブラウザ内で実行されます。単位をそろえて入力してください。







## 計算方法



休息エネルギーは、改訂版のハリス・ベネディクト、またはカッチ=マカードルによるミフリン=セント・ジェオールの推定値である。 日々の支出は、活動要因によって推定値を複数上回る。







## 計算モード



**メートル法**

- 年齢
- 方程式群 · 男性 / 女性
- 重さ · kg
- 高さ · cm
- 方程式 · ミフリン=シュト・ジェオル / 改訂版ハリス・ベネディクト / カッチ・マカードル
- カッチ・マカードルの体脂肪 · %
- 活動係数
- エネルギーユニット · kcal/day / kJ/day





**米国慣用単位**

- 年齢
- 方程式群 · 男性 / 女性
- 重さ · lb
- 足の高さ · ft
- 追加インチ · in
- 方程式 · ミフリン=シュト・ジェオル / 改訂版ハリス・ベネディクト / カッチ・マカードル
- カッチ・マカードルの体脂肪 · %
- 活動係数
- エネルギーユニット · kcal/day / kJ/day
