# 색상 변환기



HEX, RGB, HSL을 상호 변환하고 투명도를 유지한 채 색상을 확인합니다.





## 시작하기



1. 예제 값을 사용하거나 원하는 값을 입력하세요.
2. 계산한 결과를 복사하거나 세부 정보를 내려받을 수 있습니다.







## 예시



### 입력



```
rgb(102, 51, 153)
```



### 예상 결과



```
#663399, hsl (270 50% 40%)
```

브라우저에서 처리합니다. 단위를 일관되게 사용하세요.







## 계산 방법



HEX는 8비트 채널을 표현합니다. RGB는 숫자 또는 백분율을 받습니다. HSL은 색상각을 도로, 채도와 밝기를 백분율로 입력합니다. HEX 출력은 채널을 가장 가까운 바이트 값으로 반올림합니다.
