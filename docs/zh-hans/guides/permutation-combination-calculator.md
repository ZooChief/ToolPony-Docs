# 排列组合计算器



精确计算有序与无序选择，支持可重复和不重复两种方式。





## 开始使用



1. 按示例填写数值，或输入你自己的测量值。
2. 计算后可复制结果或下载明细。







## 示例



### 输入



```
n=10，r=3，不重复
```



### 预期结果



```
排列 720，组合 120
```

## 使用提示



计算在浏览器内完成。无单位标记的字段请使用一致单位。







## 计算方法



不重复时 nPr = n!/(n−r)!，nCr = nPr/r!。可重复时有序方案为 nʳ，无序方案为 C(n+r−1,r)。
