# 三大营养素计算器使用指南



把热量目标和营养比例换算成克数，或由克数计算热量和比例。





## 示例



### 输入



```
2,000 kcal，蛋白质 25%、碳水 45%、脂肪 30%
```



### 预期结果



```
蛋白质 125 g、碳水 225 g、脂肪约 66.67 g
```





<a id="case-study"></a>



## 一份食谱分成三份



1. 整份食谱含蛋白质 30 克、碳水 60 克、脂肪 10 克。按通用的 4/4/9 系数计算，总热量为 450 千卡。平均分成三份，每份 150 千卡，含蛋白质 10 克、碳水 20 克、脂肪约 3.33 克。
2. 包装食品标签可能为膳食纤维或糖醇采用专门的能量系数，相同总克数也可能算出不同的能量。

## 计算方法



通用食物能量系数为蛋白质和碳水每克 4 千卡、脂肪每克 9 千卡。留空一个比例会补足到 100%。等量分份时，各营养素和总能量都除以同一份数。







## 计算模式





### 目标换算克数



- 总热量 · kcal
- 蛋白质 · %
- 碳水化合物 · %
- 脂肪 · %
- 用此项补足 · 按空白项判断 / 手动 / 蛋白质 / 碳水化合物 / 脂肪
- 份数







### 克数换算热量



- 蛋白质 · g
- 碳水化合物 · g
- 脂肪 · g
- 份数
