# 單位換算



換算長度、質量、面積、體積、溫度、速度、能量、數字存儲等單位。





## 開始使用



1. 按示例填寫數值，或輸入你自己的測量值。
2. 計算後可複製結果或下載明細。







## 示例



### 輸入



```
1 米轉英尺
```



### 預期結果



```
約 3.28084 英尺
```

## 使用提示



計算在瀏覽器內完成。無單位標記的字段請使用一致單位。







## 計算方法



每組先換算到標準基準單位。美製和英制體積分開，十進制與二進制存儲單位採用各自基數。
