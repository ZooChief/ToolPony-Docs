# GPA 绩点计算器



按课程学分加权计算绩点，计入既往成绩或按学期统计，也可倒算目标绩点。





## 开始使用



1. 按示例填写数值，或输入你自己的测量值。
2. 计算后可复制结果或下载明细。

### 输入



```
数学 3 学分 A，英语 3 学分 B
```

## 计算方法



GPA 是课程绩点乘学分之和除以总学分。字母采用 4.3 分制。百分制模式直接计算加权百分数。其他校规可直接输入绩点。



$$
\operatorname{GPA}=\frac{\sum_i g_i c_i}{\sum_i c_i}
$$



每行填写一门课。第四列可指定学期，第五列可为该课程的每学分绩点加分。计入既往成绩时同时填写既往绩点和学分。



A+ 至 F 采用 4.3 分制。P、NP、I、W 不计入加权总和。学校另有分制时选择绩点数值模式。







## 计算模式



**课程成绩**

- 每行：课程、学分、成绩，可选学期与加分
- 成绩格式 · 字母 / 百分制 / 绩点数值
- 此前绩点
- 此前学分





**规划目标绩点**

- 当前绩点
- 目标绩点
- 已修学分
- 待修学分
