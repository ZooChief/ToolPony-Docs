# 图片尺寸调整



设置输出宽度或高度，开启保持宽高比以避免拉伸。调整后的图片以 PNG 格式导出。





## 开始使用



1. 选择图片。
2. 输入宽度或高度，开启保持宽高比以避免拉伸。
3. 调整尺寸并下载 PNG 结果。







## 示例



### 输入



```
1600 × 1200 → 宽度设为 800，保持宽高比
```



### 预期结果



```
800 × 600 PNG
```

## 使用提示



改变像素尺寸与无损压缩不同。放大图片无法找回原图中不存在的细节。







## 适用范围



输入最大 20 MB，像素总数最多 2400 万，输出每边最多 8,192 像素。放大图片不能恢复原本缺失的细节。
