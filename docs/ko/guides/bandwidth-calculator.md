# 대역폭 계산기 사용 가이드



파일 크기, 링크 속도 및 프로토콜 효율성에서 전송 시간을 추정합니다.





## 예시



### 입력



```
100 Mbps에 1개 GB, 효율성 100%년
```



### 예상 결과



```
80 초
```







## 직접 사용해 보기

[전체 도구 열기 · 대역폭 계산기](<https://toolpony.com/ko/tools/bandwidth-calculator/>)





## 계산 방법



전송 시간(초)은 파일 바이트 수 × 8 ÷ 초당 유효 비트 수입니다. 1 MB/s는 초당 1,000,000바이트, 1 MiB/s는 초당 1,048,576바이트입니다. 입력한 효율을 속도에 반영합니다.





**계산 및 처리 방식의 출처** [NIST · Binary prefixes](<https://physics.nist.gov/cuu/Units/binary.html>)
