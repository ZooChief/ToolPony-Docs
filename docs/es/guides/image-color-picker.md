# Selector de colores de imagen



Haga clic en el ejemplo o elija una imagen. Haga clic en un punto o introduzca sus coordenadas pixel para leer HEX y RGBA. Copiar un color o exportar la paleta muestreada como CSV.





## Primeros pasos



1. Pruebe el ejemplo incorporado o elija una imagen.
2. Haga clic en un punto, o introduzca X y Y y muestre ese pixel original.
3. Copiar HEX o exportar hasta dieciséis coordenadas y filas RGBA como CSV.







## Ejemplo



### Entrada



```
Muestra incorporada, X = 32 y Y = 32
```



### Resultado esperado



```
#285eaa · RGBA 40, 94, 170, 255
```

## Notas de uso



La vista previa puede ser reducida mientras el muestreo todavía lee el pixel original correspondiente. El navegador puede convertir los perfiles de color de la imagen durante la decodificación.







## Límites



JPG, PNG, WebP, AVIF o GIF hasta 20 MB y 24 megapíxeles. Lee los píxeles decodificados del navegador. Las coordenadas comienzan en (0, 0) a la izquierda. Una paleta tiene hasta 16 puntos.

[Documentación](https://docs.toolpony.com/es/guides/image-color-picker/)
