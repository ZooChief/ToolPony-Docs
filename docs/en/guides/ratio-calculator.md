# Ratio calculator



Solve a missing term in a proportion, simplify a ratio, or scale both terms.





## Get started



1. Use the example values or enter your own measurements.
2. Calculate, then copy the result or download the available details.







## Example



### Input



```
3:4 = x:20
```



### Expected result



```
x=15
```







## Try it



[Open full tool](<https://toolpony.com/en/tools/ratio-calculator/>)







## Good to know



The calculation runs in your browser. Use consistent units in fields with no explicit unit.







## Calculation method



A:B = C:D implies A×D = B×C, with nonzero denominators. Simplification accepts decimal and fractional quantities.







## Calculation mode



**Solve a proportion**

- A
- B
- C
- D





**Simplify or scale**

- First term
- Second term
- Scale factor





**Enlarge or reduce a ratio**

- First term
- Second term
- Direction · Reduce / Enlarge
- Factor
