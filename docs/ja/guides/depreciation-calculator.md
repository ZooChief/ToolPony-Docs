# 減価償却計算機



年間の直線、リダナスバランス、または年単位の桁数スケジュールを構築。





## 使い方



1. 例を使うか、任意の値を入力します。
2. 計算後、結果をコピーするか詳細をダウンロードできます。







## 例



### 入力



```
取得原価 17,500、残存価額 2,500、耐用年数 6 年、定額法
```



### 期待される結果



```
年間2,500件
```







## 試してみる



[ツール全体を開く](<https://toolpony.com/ja/tools/depreciation-calculator/>)







## 注意点



処理はブラウザ内で実行されます。単位をそろえて入力してください。







## 計算方法



直線的に見れば、減価償却費は耐用年数によって分ける。 バランスの低下は、帳簿価額の開放に要因と生命を適用し、救済措置で停止する。 年数の合計は、残りの年数の重みによって算出される。 金額は年間四捨五回です。



$$
D_{\mathrm{SL}}=\frac{C-S}{n},\quad D_{k,\mathrm{SYD}}=(C-S)\frac{n-k+1}{n(n+1)/2}
$$







## 計算モード



**直線**

- 資産コスト
- サルバッジ値
- 役立つ人生
- 丸め · 小数点以下2桁のポイント / 総額





**バランスの低下**

- 資産コスト
- サルバッジ値
- 役立つ人生
- 減価償却係数
- 丸め · 小数点以下2桁のポイント / 総額





**年単位の数字**

- 資産コスト
- サルバッジ値
- 役立つ人生
- 丸め · 小数点以下2桁のポイント / 総額
