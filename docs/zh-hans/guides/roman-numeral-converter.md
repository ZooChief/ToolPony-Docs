# 罗马数字转换器



双向转换罗马数字和整数，也可转换日期或带分隔符的列表。





## 开始使用



1. 按示例填写数值，或输入你自己的测量值。
2. 计算后可复制结果或下载明细。







## 示例



### 输入



```
MCMXCIX
```



### 预期结果



```
1999
```

## 使用提示



计算在浏览器内完成。无单位标记的字段请使用一致单位。







## 计算方法



使用 IV、CM 等标准减法组合，上划线将该组数值乘以 1,000。输入时可在每个带线字符前加下划线，或直接粘贴上划线。支持 1 至 3,999,999，日期模式逐项转换并保留分隔符。







## 计算模式

- 整数或罗马数字





**日期或列表**

- 列表或日期
