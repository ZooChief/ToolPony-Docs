# 文書をテキストに変換



端末の DOCX、ODT、PDF を選ぶか、サンプル DOCX を開きます。





## 使い方



1. 端末の DOCX、ODT、PDF を選ぶか、サンプル DOCX を開きます。
2. 段落は改行し、表のセルはタブで区切ります。結果のコピーや UTF-8 テキストの保存ができます。







## 例



### 入力



```
タイトル、二つのテキスト、タブを含む DOCX
```



### 期待される結果



```
ToolPony
ABC	123
```







## 試してみる



[ツール全体を開く](<https://toolpony.com/ja/tools/document-to-text/>)







## 制限



DOCX と ODT は本文を読み取り、ファイルは 20 MiB、抽出後の UTF-8 テキストは 1 MiB までです。PDF には選択可能な文字が必要です。画像、ページの書式、パスワード付きファイルは対象外です。

[ドキュメント](https://docs.toolpony.com/ja/guides/document-to-text/)
