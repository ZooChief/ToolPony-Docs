# 表面積計算機の使い方



立体の表面積を計算します。タンクや管など底面がある立体では、覆う面を選んで面積を比較できます。





## 例



### 入力



```
半径2mの球体
```



### 期待される結果



```
≈50.2655 m²
```





<a id="case-study"></a>



## ふたのない水槽の内張り



1. 内寸は長さ120 cm、幅0.8 m、深さ450 mmです。側面と底面1つを選ぶと、四つの壁と床を覆います。
2. 壁は1.80 m²、底は0.96 m²、継ぎ目や端材を除く合計は2.76 m²です。すべての面を選ぶと、ふたを含む3.72 m²になります。



[入力例を実行](<https://toolpony.com/ja/tools/surface-area-calculator/#example-open-tank>)

## 計算方法



閉じた表面にはすべての底面を含みます。各底面積は寸法から直接計算し、楕円体の表面積は対称楕円積分で数値計算します。



$$
A_{\mathrm{cylinder}}=2\pi r^2+2\pi rh,\qquad A_{\mathrm{sphere}}=4\pi r^2
$$
