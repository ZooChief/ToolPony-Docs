# 文档转纯文本



从设备选择 DOCX、ODT 或 PDF，或打开 DOCX 示例。





## 开始使用



1. 从设备选择 DOCX、ODT 或 PDF，或打开 DOCX 示例。
2. 段落另起一行，表格单元格用制表符分隔。可复制结果或下载 UTF-8 文本。







## 示例



### 输入



```
含标题、两段行内文字和一个制表符的 DOCX
```



### 预期结果



```
ToolPony
ABC	123
```

## 适用范围



DOCX 和 ODT 仅读取正文，文件最多 20 MiB，提取的 UTF-8 文本最多 1 MiB。PDF 须含可选文字。图片、页面排版和受密码保护的文件不在处理范围内。
