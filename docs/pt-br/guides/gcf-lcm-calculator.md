# Calculadora de MDC e MMC



Encontre o maior fator comum e o menor múltiplo comum para uma lista de inteiros grandes.





## Primeiros passos



1. Use o exemplo ou insira seus próprios valores.
2. Calcule, copie o resultado ou baixe os detalhes disponíveis.







## Exemplo



### Entrada



```
12, 18, 24
```



### Resultado esperado



```
GCF 6; LCM 72
```







## Experimente



[Abrir ferramenta completa](<https://toolpony.com/pt-br/tools/gcf-lcm-calculator/>)







## Notas de uso



O cálculo é feito no seu navegador. Use unidades consistentes.







## Método de cálculo



O algoritmo de Euclides calcula o MDC. Quando ambos os números são diferentes de zero, MMC(a,b) = |a·b| ÷ MDC(a,b). São aceitos até 100 inteiros de até 50 dígitos cada.
