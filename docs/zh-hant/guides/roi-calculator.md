# 投資回報率計算器



計入費用，計算淨收益、總投資回報率和年化回報率。





## 開始使用



1. 按示例填寫數值，或輸入你自己的測量值。
2. 計算後可複製結果或下載明細。







## 示例



### 輸入



```
投入 1,000，兩年後收到 1,210
```



### 預期結果



```
總回報率 21%，年化 10%
```

## 使用提示



計算在瀏覽器內完成。無單位標記的字段請使用一致單位。







## 計算方法



總回報率爲（淨回收金額 − 總投入）÷ 總投入。年化回報率把該比例按期限折算爲複合年收益。
