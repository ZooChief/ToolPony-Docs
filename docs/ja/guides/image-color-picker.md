# 画像から色を抽出



例をクリックするか、画像を選択してください。 ポイントをクリックするか、ピクセル座標を入力してHEXとRGBAを読み取ります。 色をコピーするか、サンプルパレットをCSVとしてエクスポートしてください。





## 使い方



1. 組み込みの例を試すか、画像を選択してください。
2. ポイントをクリックするか、XとYを入力してその元のピクセルをサンプリングしてください。
3. HEXをコピーするか、最大16行の座標とRGBA行をCSVとしてエクスポートしてください。







## 例



### 入力



```
内蔵サンプル、X = 32 および Y = 32
```



### 期待される結果



```
#285eaa · RGBA 40, 94, 170, 255
```







## 試してみる



[ツール全体を開く](<https://toolpony.com/ja/tools/image-color-picker/>)







## 注意点



プレビューは、サンプリングが対応する元のピクセルを読み取りながら、縮小できます。 ブラウザはデコード中に画像のカラープロファイルを変換できます。







## 制限



JPG、PNG、WebP、AVIF、GIFは最大20MBおよび24メガピクセルまで。 ブラウザのデコードされたピクセルを読み取りました。 座標は左上から(0、0)から開始されます。 パレットは最大16ポイントまで保持されます。
