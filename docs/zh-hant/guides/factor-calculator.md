# 因數計算器



列出全部正因數、因數對與質因數分解。





## 開始使用



1. 按示例填寫數值，或輸入你自己的測量值。
2. 計算後可複製結果或下載明細。







## 示例



### 輸入



```
120
```



### 預期結果



```
共有 16 個正因數，包括 1 和 120
```

## 計算方法



因數能將原數整除。每個較小的因數 d 對應 n/d，因此查到 √n 即可找全。



$$
d\mid n\iff n\bmod d=0,\qquad n=d\cdot(n/d)
$$
