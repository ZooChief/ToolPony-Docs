# 密度计算器



任填两项求质量、体积或密度。





## 示例



### 输入



```
8 kg，0.001 m³
```



### 预期结果



```
8,000 kg/m³
```







## 试一试

[打开完整工具 · 密度计算器](<https://toolpony.com/zh-hans/tools/density-calculator/>)





## 计算方法



密度 = 质量 ÷ 体积，采用 kg、m³ 和 kg/m³。



$$
\rho=\frac{m}{V}
$$
