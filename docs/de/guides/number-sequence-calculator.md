# Folgenrechner



Glieder, Partialsummen und Listen arithmetischer, geometrischer oder Fibonacci-Folgen berechnen und herunterladen.





## Erste Schritte



1. Verwenden Sie das Beispiel oder geben Sie eigene Werte ein.
2. Berechnen Sie das Ergebnis und kopieren oder laden Sie die Details herunter.







## Beispiel



### Eingabe



```
Arithmetische Folge, Startwert 7, Differenz −3, Index 8
```



### Erwartetes Ergebnis



```
−14, Summe −28
```

## Berechnungsmethode



Arithmetische und geometrische Folgen beginnen beim Index 1. Die Fibonacci-Folge beginnt mit F₀ = 0 und verwendet exakte ganze Zahlen.



$$
a_n=a_1+(n-1)d,\quad g_n=g_1r^{n-1},\quad F_n=F_{n-1}+F_{n-2}
$$







## Berechnungsmodus



**Arithmetisch**

- Erstes Glied
- Differenz
- Index





**Geometrisch**

- Erstes Glied
- Quotient
- Index





**Fibonacci**

- Index
