# Calculatrice de masse volumique



Résolvez pour la masse, le volume ou la densité en entrant deux valeurs.





## Prise en main



1. Utilisez l’exemple ou saisissez vos propres valeurs.
2. Calculez, puis copiez le résultat ou téléchargez les détails.







## Exemple



### Entrée



```
8 kg, 0,001 m3
```



### Résultat attendu



```
8 000 kg/m3
```







## Essayer



[Ouvrir l’outil complet](<https://toolpony.com/fr/tools/density-calculator/>)







## Notes



Le traitement se fait dans le navigateur. Utilisez des unités cohérentes.







## Méthode de calcul



Densité = masse ÷ volume. L'interface utilise kg, m3 et kg/m3.



$$
\rho=\frac{m}{V}
$$
