# 小费计算器



分摊账单与小费，可按税前或含税金额计算小费。





## 开始使用



1. 按示例填写数值，或输入你自己的测量值。
2. 计算后可复制结果或下载明细。







## 示例



### 输入



```
账单 80，小费 20%，4 人
```



### 预期结果



```
合计 96，每人 24
```

## 使用提示



计算在浏览器内完成。无单位标记的字段请使用一致单位。







## 计算方法



小费 = 所选金额 × 小费比例。每人金额为账单、税费与小费之和除以人数。
