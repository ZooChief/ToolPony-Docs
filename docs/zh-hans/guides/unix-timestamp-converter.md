# Unix 时间戳转换



将秒或毫秒时间戳换算为 UTC，或将带时区偏移的 ISO 时间转回 Unix 时间。





## 开始使用



1. 按示例填写数值，或输入你自己的测量值。
2. 计算后可复制结果或下载明细。







## 示例



### 输入



```
0 秒
```



### 预期结果



```
1970-01-01T00:00:00.000Z
```

## 使用提示



计算在浏览器内完成。无单位标记的字段请使用一致单位。







## 计算方法



Unix 时间以 1970-01-01T00:00:00Z 为起点，支持 1900–9999 年，精确到毫秒。







## 计算模式



**时间戳转日期**

- Unix 时间戳
- 单位 · 秒 / 毫秒





**日期转时间戳**

- 带时区偏移的 ISO 8601
