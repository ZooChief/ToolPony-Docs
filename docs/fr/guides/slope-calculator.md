# Calculatrice de pente



Trouver une pente et intercepter à partir de deux points, ou trouver les deux paramètres à une distance donnée.





## Prise en main



1. Utilisez l’exemple ou saisissez vos propres valeurs.
2. Calculez, puis copiez le résultat ou téléchargez les détails.







## Exemple



### Entrée



```
(0, 0) à (3, 4)
```



### Résultat attendu



```
Pente 4/3 et distance 5
```

Le traitement se fait dans le navigateur. Utilisez des unités cohérentes.







## Méthode de calcul



La pente est la montée divisée par la course. Une ligne verticale a une pente non définie. Une distance et une direction connues déterminent deux paramètres sur les côtés opposés du point de départ.



$$
m=\frac{y_2-y_1}{x_2-x_1},\qquad \theta=\arctan(m),\qquad y=mx+b
$$



Le mode à deux points signale les changements verticaux et horizontaux séparément. Utilisez le signe de chaque changement pour indiquer la direction du point déplacé. Une ligne verticale a une coordination x constante.



Une ligne et une distance déterminent un point de chaque côté du point de départ. Utilisez le tableau de pointage pour conserver les deux solutions.
