# 確率計算機



イベント確率を計算する、2つの既知の値から独立した確率を回復する、または通常の間隔を使用する。





## 使い方



1. 例を使うか、任意の値を入力します。
2. 計算後、結果をコピーするか詳細をダウンロードできます。







## 例



### 入力



```
独立種事象A = 0.31、B = 0.56
```



### 期待される結果



```
少なくとも 1 回は 0.6964
```







## 試してみる



[ツール全体を開く](<https://toolpony.com/ja/tools/probability-calculator/>)







## 注意点



処理はブラウザ内で実行されます。単位をそろえて入力してください。







## 計算方法



独立したイベントはP(A∩B)=P(A)P(B)を満たす。 依存イベントの場合は、交差点に直接進入します。 繰り返された試行は確率を倍増させ、少なくとも1つの成功確率は補算を用いる。



$$
P(A\cup B)=P(A)+P(B)-P(A\cap B)
$$



$$
P(A\cap B)=P(A)P(B)\quad\text{(independent)}
$$







## 計算モード



**2つの独立したイベント**

- Aの確率
- Bの確率





**既知の交差点**

- Aの確率
- Bの確率
- 両方のイベント





**独立したイベントを復旧**

- 最初に確認した量 · Aの確率 / Bの確率 / いいえA / Bではない / 両方のイベント / 少なくとも1つのイベント / まさに一つの出来事 / どちらの出来事も
- 第一確率
- 第二既知の量 · Aの確率 / Bの確率 / いいえA / Bではない / 両方のイベント / 少なくとも1つのイベント / まさに一つの出来事 / どちらの出来事も
- 第二確率





**繰り返される独立した試験**

- Aの確率
- Aの試練
- Bの確率
- Bの試練





**通常の分布間隔**

- 平均
- 標準偏差
- 下限
- 上限
