# Calculadora de custo e consumo de combustível



Converter unidades de economia de combustível, estimar o custo de combustível de uma viagem, ou calcular a economia de combustível medido.





## Primeiros passos



1. Use o exemplo ou insira seus próprios valores.
2. Calcule, copie o resultado ou baixe os detalhes disponíveis.







## Exemplo



### Entrada



```
300 km, 7 L/100 km, preço 1,5 por litro
```



### Resultado esperado



```
21 L; custo do combustível 31.50
```

[Abrir ferramenta completa](<https://toolpony.com/pt-br/tools/fuel-cost-calculator/>)







## Notas de uso



O cálculo é feito no seu navegador. Use unidades consistentes.







## Método de cálculo



Combustível utilizado = distância × L/100 km 100. EUA e milhas imperiais por galão usar diferentes volumes de galões. Os preços de combustível são fornecidos pelo usuário.







## Modo de cálculo



**Custo da viagem**

- Distância · km
- Economia de combustível
- Unidade de economia de combustível · L/100 km / km/L / mpg (EUA) / mpg (imperial)
- Preço por litro





**Converter economia de combustível**

- Economia de combustível
- Unidade de entrada · L/100 km / km/L / mpg (EUA) / mpg (imperial)





**Milhagem medida**

- Distância · km
- Combustível utilizado · L
