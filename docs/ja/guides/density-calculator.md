# 密度計算機の使い方



質量、体積、密度をそれぞれ2つの値に入力することで解決します。





## 例



### 入力



```
8kg、0.001m3
```



### 期待される結果



```
8,000 kg/m3
```







## 試してみる

[ツール全体を開く · 密度計算機](<https://toolpony.com/ja/tools/density-calculator/>)





## 計算方法



密度は質量を体積で割った値です。計算ではキログラムと立方メートルにそろえ、結果を選択した単位に換算します。



$$
\rho=\frac{m}{V}
$$
