# 返済負担率計算機



毎月の返済額と総月収を比較してください。





## 使い方



1. 例を使うか、任意の値を入力します。
2. 計算後、結果をコピーするか詳細をダウンロードできます。







## 例



### 入力



```
収入5,000、債務支払い額1,500
```



### 期待される結果



```
30%
```







## 試してみる



[ツール全体を開く](<https://toolpony.com/ja/tools/debt-to-income-calculator/>)







## 注意点



処理はブラウザ内で実行されます。単位をそろえて入力してください。







## 計算方法



債務対所得比率=月次債務支払い ÷ 月次総収入。 すべての金額に対して、同じ通貨と月次期間を使用してください。
