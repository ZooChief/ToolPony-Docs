# 砂利計算機



砂利や砂の体積、質量、袋数、費用を見積もります。





## 使い方



1. 面積、長方形、円形のいずれかを選び、厚さを入力します。
2. 材料を選びます。詳細オプションで密度や袋の容量を指定できます。







## 例



### 入力



```
200 ft²、厚さ 3 in、砂利 1,680 kg/m³。
```



### 期待される結果



```
50 ft³（1.42 m³）、約 2,379 kg。
```

[ツール全体を開く](<https://toolpony.com/ja/tools/gravel-calculator/>)







## 注意点



処理はブラウザ内で実行されます。単位をそろえて入力してください。







## 計算方法



面積に厚さを掛けて予備率を加えます。質量は体積と見かけ密度の積です。袋単価を使う場合は袋数を切り上げます。入手できる場合は供給元の密度を使ってください。



$$
V=Ad(1+w/100),\qquad m=\rho V,\qquad N=\left\lceil\frac{m}{m_{\rm bag}}\right\rceil\ \text{or}\ \left\lceil\frac{V}{V_{\rm bag}}\right\rceil
$$
