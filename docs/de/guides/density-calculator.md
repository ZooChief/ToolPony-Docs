# Dichterechner



Lösen Sie Masse, Volumen oder Dichte, indem Sie zwei beliebige Werte eingeben.





## Beispiel



### Eingabe



```
8 kg, 0,001 m3
```



### Erwartetes Ergebnis



```
8.000 kg/m3
```







## Ausprobieren

[Vollständiges Werkzeug öffnen · Dichterechner](<https://toolpony.com/de/tools/density-calculator/>)





## Berechnungsmethode



Dichte = Masse ÷ Volumen. Die Schnittstelle verwendet kg, m3 und kg/m3.



$$
\rho=\frac{m}{V}
$$
