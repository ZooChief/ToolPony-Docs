# Bildgröße ändern



Wählen Sie ein Bild. Geben Sie Breite oder Höhe ein. Behalten Sie bei Bedarf die Proportionen bei. Ändern Sie die Größe und laden Sie das PNG herunter.





## Erste Schritte



1. Wählen Sie ein Bild.
2. Geben Sie Breite oder Höhe ein. Behalten Sie bei Bedarf die Proportionen bei.
3. Ändern Sie die Größe und laden Sie das PNG herunter.







## Beispiel



### Eingabe



```
1600 × 1200, Breite 800, Seitenverhältnis beibehalten
```



### Erwartetes Ergebnis



```
800 × 600 PNG
```

## Grenzen



Bis zu 20 MB, 24 Megapixel und 8.192 Pixel je Seite. Eine Vergrößerung stellt keine fehlenden Details wieder her.
