# Calculadora de imposto sobre vendas e IVA



Adicione ou remova o imposto de vendas e o IVA usando sua própria taxa.





## Primeiros passos



1. Use o exemplo ou insira seus próprios valores.
2. Calcule, copie o resultado ou baixe os detalhes disponíveis.







## Exemplo



### Entrada



```
Preço líquido 100, IVA 20%
```



### Resultado esperado



```
Total 120, imposto 20
```







## Experimente



[Abrir ferramenta completa](<https://toolpony.com/pt-br/tools/sales-tax-calculator/>)







## Notas de uso



O cálculo é feito no seu navegador. Use unidades consistentes.







## Método de cálculo



Preço bruto = preço líquido × (1 + taxa). As taxas de imposto são fornecidas pelo usuário.
