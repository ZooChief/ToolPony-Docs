# Criador de gráficos



Colar CSV com um cabeçalho, uma coluna de etiquetas e séries numéricas. Escolha barras ou linhas, atualize o gráfico e baixe SVG.





## Primeiros passos



1. Digite um cabeçalho CSV. Coloque as legendas de categoria na primeira coluna e séries numéricas nas colunas restantes.
2. Escolha barras ou linhas e atualize a visualização.
3. Baixe o gráfico como um SVG.







## Exemplo



### Entrada



```
Month,Visits
Jan,24
Feb,38
```



### Resultado esperado



```
Dois valores em Jan e Fev, traçados da esquerda para a direita.
```

## Notas de uso



Rótulos de citações contendo vírgulas. Use um período como separador decimal. Os valores negativos usam a mesma escala que os valores positivos.







## Limites



Até 120 linhas e seis séries numéricas. Uma célula citada pode conter uma vírgula. Cada linha permanece numa linha. Os valores são plotados na ordem indicada.
