# Diviser un PDF



Sélectionnez des pages et enregistrez-les dans un PDF ou un ZIP.





## Prise en main



1. Sélectionnez un PDF non chiffré.
2. Cliquez sur les miniatures ou saisissez des pages, par exemple 5, 1-3.
3. Choisissez un PDF unique, un fichier par plage ou un fichier par page.
4. Vous pouvez aussi fractionner par nombre de pages ou par taille de fichier. La limite porte sur les PDF générés, sans recompression.







## Exemple



### Entrée



```
PDF de 5 pages, sélection 5, 1-3
```



### Résultat attendu



```
Un PDF avec les pages 5, 1, 2 et 3 dans cet ordre
```







## Essayer



[Ouvrir l’outil complet](<https://toolpony.com/fr/tools/pdf-split/>)







## Limites



30 Mo et 300 pages maximum. Chaque page ne peut apparaître qu’une fois. Les PDF du ZIP sont limités à 64 Mo. Les formulaires, signets et signatures peuvent être perdus.
