# Descomposición en factores primos



Encontrar los factores principales, la forma exponente y el recuento de divisor de un entero positivo.





## Primeros pasos



1. Usa el ejemplo o introduce tus propios valores.
2. Calcula, copia el resultado o descarga los detalles disponibles.







## Ejemplo



### Entrada



```
360
```



### Resultado esperado



```
2³ × 3² × 5, 24 divisores
```
