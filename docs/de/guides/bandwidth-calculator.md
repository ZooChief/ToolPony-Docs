# Bandbreitenrechner



Schätzen Sie die Übertragungszeit von der Dateigröße, der Verbindungsgeschwindigkeit und der Protokolleffizienz.





## Erste Schritte



1. Verwenden Sie das Beispiel oder geben Sie eigene Werte ein.
2. Berechnen Sie das Ergebnis und kopieren oder laden Sie die Details herunter.







## Beispiel



### Eingabe



```
1 GB bei 100 Mbps, Effizienz 100%
```



### Erwartetes Ergebnis



```
80 Sekunden
```







## Ausprobieren



[Vollständiges Werkzeug öffnen](<https://toolpony.com/de/tools/bandwidth-calculator/>)







## Hinweise



Die Verarbeitung erfolgt im Browser. Verwenden Sie einheitliche Einheiten.







## Berechnungsmethode



Zeit in Sekunden = Dateibytes × 8 ÷ effektive Bits pro Sekunde. Netzwerkpräfixe sind dezimal. Dateigröße unterstützt dezimale und binäre Präfixe.
