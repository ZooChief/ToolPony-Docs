# Codificar y decodificar Base64



codificar texto UTF-8 como estándar o seguro de URL Base64 y validar texto decodificado.





## Ejemplo



### Entrada



```
Codificar hello
```



### Resultado esperado



```
aGVsbG8=
```







## Pruébalo

[Abrir herramienta completa · Codificar y decodificar Base64](<https://toolpony.com/es/tools/base64-encoder-decoder/>)





## Método de cálculo



El texto se convierte como UTF-8. El modo URL-safe utiliza "-" y "\_" y omite el relleno en salida. Hasta 500.000 caracteres de entrada.





**Fuentes del método** [IETF · RFC 4648 (Base64)](<https://www.rfc-editor.org/rfc/rfc4648>)
