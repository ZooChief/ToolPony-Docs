# 비밀번호 생성기



문자 집합, 사용자 지정 제외 및 선택적 고유 문자로 로컬로 암호를 생성합니다.





## 시작하기



1. 예제 값을 사용하거나 원하는 값을 입력하세요.
2. 계산한 결과를 복사하거나 세부 정보를 내려받을 수 있습니다.







## 예시



### 입력



```
20자, 문자 그룹 4개
```



### 예상 결과



```
신선한 무작위 비밀번호
```







## 직접 사용해 보기



[전체 도구 열기](<https://toolpony.com/ko/tools/password-generator/>)







## 참고 사항



브라우저에서 처리합니다. 단위를 일관되게 사용하세요.







## 계산 방법



Web Crypto는 무작위성을 제공합니다. 필요한 그룹이 활성화되면 각 그룹에서 한 개의 문자가 선택되고 위치는 셔플됩니다. 비밀번호는 현재 페이지에 남기거나 지울 때까지 현재 페이지에 있습니다.
