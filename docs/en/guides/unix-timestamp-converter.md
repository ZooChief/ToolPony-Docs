# Unix timestamp converter



Convert seconds and milliseconds to UTC, and convert an ISO time with an explicit offset back to Unix time.





## Get started



1. Use the example values or enter your own measurements.
2. Calculate, then copy the result or download the available details.







## Example



### Input



```
0 seconds
```



### Expected result



```
1970-01-01T00:00:00.000Z
```







## Try it



[Open full tool](<https://toolpony.com/en/tools/unix-timestamp-converter/>)







## Good to know



The calculation runs in your browser. Use consistent units in fields with no explicit unit.







## Calculation method



Unix time is elapsed time since 1970-01-01T00:00:00Z. Conversions support dates from 1900 to 9999 at millisecond precision.







## Calculation mode



**Timestamp to date**

- Unix timestamp
- Unit · Seconds / Milliseconds





**Date to timestamp**

- ISO 8601 with offset
