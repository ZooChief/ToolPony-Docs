# Calculadora de raíces



Calcular el cuadrado real principal, cubo, o raíz nth.





## Primeros pasos



1. Usa el ejemplo o introduce tus propios valores.
2. Calcula, copia el resultado o descarga los detalles disponibles.







## Ejemplo



### Entrada



```
raíz cuadrada de 144
```



### Resultado esperado



```
12
```

## Notas de uso



El cálculo se ejecuta en tu navegador. Usa unidades coherentes.







## Método de cálculo



La raíz nth es x elevada a 1/n. Los grados de enteros Odd aceptan radicands negativos. Un grado negativo toma el recíproco.



$$
\sqrt[n]{x}=x^{1/n},\qquad n\ne0
$$

**Raíz cúbica**

**Raíz enésima**
