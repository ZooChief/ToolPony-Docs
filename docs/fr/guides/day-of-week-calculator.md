# Calculateur du jour de la semaine



Trouvez le jour de la semaine, le rang dans l’année, la semaine ISO et les occurrences.





## Prise en main



1. Utilisez l’exemple ou saisissez vos propres valeurs.
2. Calculez, puis copiez le résultat ou téléchargez les détails.







## Exemple



### Entrée



```
2000-01-01
```



### Résultat attendu



```
samedi
```







## Essayer



[Ouvrir l’outil complet](<https://toolpony.com/fr/tools/day-of-week-calculator/>)







## Notes



Le traitement se fait dans le navigateur. Utilisez des unités cohérentes.







## Méthode de calcul



Le calendrier est grégorien. Les semaines ISO commencent le lundi. La semaine 1 contient le 4 janvier. Le début de janvier peut appartenir à la dernière semaine ISO de l’année précédente.
