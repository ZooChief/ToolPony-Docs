# Wochentagsrechner



Ermitteln Sie Wochentag, Jahrestag, ISO-Woche und Häufigkeit des Wochentags.





## Erste Schritte



1. Verwenden Sie das Beispiel oder geben Sie eigene Werte ein.
2. Berechnen Sie das Ergebnis und kopieren oder laden Sie die Details herunter.







## Beispiel



### Eingabe



```
2000-01-01
```



### Erwartetes Ergebnis



```
Samstag
```

## Hinweise



Die Verarbeitung erfolgt im Browser. Verwenden Sie einheitliche Einheiten.







## Berechnungsmethode



Es gilt der gregorianische Kalender. ISO-Wochen beginnen am Montag. Woche 1 enthält den 4. Januar. Frühe Januartage können zur letzten ISO-Woche des Vorjahres gehören.
