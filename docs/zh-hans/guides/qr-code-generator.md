# 二维码生成器



选择扫描后要打开的类型，再填写链接、文本或相应字段。 生成后可核对编码内容。分享可用 PNG，印刷可用 SVG。 需要时在外观中填入深色六位 HEX。两种导出都保留白色留边。





## 开始使用



1. 选择扫描后要打开的类型，再填写链接、文本或相应字段。
2. 生成后可核对编码内容。分享可用 PNG，印刷可用 SVG。
3. 需要时在外观中填入深色六位 HEX。两种导出都保留白色留边。
