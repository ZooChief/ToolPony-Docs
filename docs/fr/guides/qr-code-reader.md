# Lecteur de code QR



Choisissez, déposez ou collez une image. La caméra est aussi disponible dans l’outil autonome. Vérifiez le texte avant de le copier ou le télécharger. Contrôlez l’adresse avant d’ouvrir un lien web.





## Prise en main



1. Choisissez, déposez ou collez une image. La caméra est aussi disponible dans l’outil autonome.
2. Vérifiez le texte avant de le copier ou le télécharger. Contrôlez l’adresse avant d’ouvrir un lien web.

### Entrée



```
Lire l’exemple
```


## Essayer



[Ouvrir l’outil complet](<https://toolpony.com/fr/tools/qr-code-reader/>)







## Limites



Un code QR par lecture. Images jusqu’à 20 Mio et 24 mégapixels, dont PNG, JPEG, WebP et SVG pris en charge. La caméra nécessite une autorisation et s’arrête après lecture. Les images restent sur votre appareil.

[Documentation](https://docs.toolpony.com/fr/guides/qr-code-reader/)
