# 자막 변환 및 시간 조정



SRT와 WebVTT를 변환하고 시간을 이동하거나 조정한 뒤 겹치는 자막을 확인합니다.





## 시작하기



1. 자막을 붙여넣거나 SRT 또는 VTT를 가져온 후 출력 형식을 고르세요.
2. 양수 오프셋은 자막을 늦춥니다. 기준에서 잰 시간에 배율을 곱한 뒤 오프셋을 더합니다. 잘림과 겹침을 확인하고 저장하세요.







## 예시



### 입력



```
1
00:00:00,120 --> 00:00:01,400
A line
Second line

2
00:00:01,350 --> 00:00:02,700
Overlap 50 ms
```



### 예상 결과



```
WEBVTT

00:00:00.120 --> 00:00:01.400
A line
Second line

00:00:01.350 --> 00:00:02.700
Overlap 50 ms
```

## 제한 사항



텍스트 1 MiB, 자막 10,000개까지 지원합니다. 0초 전에 끝나는 자막은 제거하며 0초를 넘는 자막은 0초에서 시작합니다. SRT는 모든 WebVTT 위치, 스타일 및 식별자를 담을 수 없습니다.
