# 密碼生成器



在本地生成密碼，支持字符集、自定義排除與字符不重複。





## 開始使用



1. 按示例填寫數值，或輸入你自己的測量值。
2. 計算後可複製結果或下載明細。







## 示例



### 輸入



```
20 位，啓用四個字符組
```



### 預期結果



```
生成一條隨機密碼
```

## 使用提示



計算在瀏覽器內完成。無單位標記的字段請使用一致單位。







## 計算方法



使用 Web Crypto 隨機取樣。要求包含每個啓用的字符組時，先分別抽取，再隨機打亂位置。密碼僅顯示在當前頁面。
