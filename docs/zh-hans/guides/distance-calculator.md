# 距离计算器



计算二维或三维两点距离，或估算两组地理坐标的地表距离。





## 开始使用



1. 按示例填写数值，或输入你自己的测量值。
2. 计算后可复制结果或下载明细。







## 示例



### 输入



```
二维：从（0, 0）到（3, 4）
```



### 预期结果



```
距离 5
```

## 使用提示



计算在浏览器内完成。无单位标记的字段请使用一致单位。







## 计算方法



直角坐标使用欧氏距离。经纬度模式使用 WGS 84 椭球和 Lambert 近似，近对跖点使用球面近似。结果为地表距离估算。



$$
d=\sqrt{(x_2-x_1)^2+(y_2-y_1)^2+(z_2-z_1)^2}
$$



坐标采用同一线性尺度时使用二维或三维模式。先把两点坐标换成一致单位。



地理坐标中，北纬和东经为正。测绘数据分开给出度、分、秒时选择对应模式，结果是沿椭球面的距离估算。
