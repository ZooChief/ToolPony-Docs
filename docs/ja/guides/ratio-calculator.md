# 比の計算機



不足した用語を一定の割合で解決し、比率を簡素化するか、または両方の用語をスケーリングする。





## 使い方



1. 例を使うか、任意の値を入力します。
2. 計算後、結果をコピーするか詳細をダウンロードできます。







## 例



### 入力



```
3:4 = x:20
```



### 期待される結果



```
x=15
```







## 試してみる



[ツール全体を開く](<https://toolpony.com/ja/tools/ratio-calculator/>)







## 注意点



処理はブラウザ内で実行されます。単位をそろえて入力してください。







## 計算方法



A:B = C:D は、非非非項を持つA×D = B×Cを意味する。 簡素化は小数点および小数点の数量を受け入れます。







## 計算モード



**割合を解く**

- A
- B
- C
- D





**簡素化またはスケーリング**

- 初項
- 第二期
- スケールファクター





**比率を拡大または縮小する**

- 初項
- 第二期
- 方向 · 削減 / 拡大
- 係数
