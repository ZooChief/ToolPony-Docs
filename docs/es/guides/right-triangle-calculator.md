# Calculadora de triángulos rectángulos



Calcula catetos, hipotenusa y ángulos a partir de dos medidas, entre ellas altura, área o perímetro.





## Primeros pasos



1. Introduce dos medidas, incluida una longitud, área o perímetro.
2. Las dos soluciones intercambian las etiquetas de los catetos y los ángulos agudos.







## Ejemplo



### Entrada



```
c = 5, h = 2,4
```



### Resultado esperado



```
Catetos 3 y 4, área 6, perímetro 12. Cualquiera puede ser a.
```

## Notas de uso



El cálculo se ejecuta en tu navegador. Usa unidades coherentes.







## Método de cálculo



c es la hipotenusa y h su altura perpendicular. Usa una unidad de longitud y la unidad cuadrada correspondiente para el área.



$$
c^2=a^2+b^2,\quad h=ab/c,\quad S=ab/2,\quad P=a+b+c
$$



$$
a,b=\frac{\sqrt{c^2+2ch}\;\pm\;\sqrt{c^2-2ch}}{2}
$$
