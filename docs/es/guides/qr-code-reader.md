# Lector de códigos QR



Elige, arrastra o pega una imagen. También puedes activar la cámara en la herramienta independiente. Revisa el texto y luego cópialo o descárgalo. Comprueba la dirección antes de abrir un enlace.





## Primeros pasos



1. Elige, arrastra o pega una imagen. También puedes activar la cámara en la herramienta independiente.
2. Revisa el texto y luego cópialo o descárgalo. Comprueba la dirección antes de abrir un enlace.







## Ejemplo



### Entrada



```
Leer ejemplo
```



### Resultado esperado




## Límites



Un QR por lectura. Imágenes de hasta 20 MiB y 24 megapíxeles, incluidos PNG, JPEG, WebP y SVG compatibles. La cámara requiere permiso y se detiene al leer. Las imágenes se quedan en tu dispositivo.
