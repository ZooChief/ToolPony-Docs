# チップ計算機



税金の前後金額をもとに、請求書とチップを人間で分割する。





## 例



### 入力



```
80件、20%のチップ、4名
```



### 期待される結果



```
合計 96、1 人あたり 24
```







## 試してみる

[ツール全体を開く · チップ計算機](<https://toolpony.com/ja/tools/tip-calculator/>)





## 計算方法



ヒント = 選択された請求額 × チップパーセンテージ。 一人当たりの合計は、請求額、税金、およびチップを人数で割る。
