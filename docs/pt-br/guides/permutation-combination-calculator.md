# Calculadora de permutações e combinações



Calcular seleções ordenadas e não ordenadas com ou sem repetição.





## Primeiros passos



1. Use o exemplo ou insira seus próprios valores.
2. Calcule, copie o resultado ou baixe os detalhes disponíveis.







## Exemplo



### Entrada



```
n=10, r=3, sem repetição
```



### Resultado esperado



```
720 permutações; 120 combinações
```







## Experimente



[Abrir ferramenta completa](<https://toolpony.com/pt-br/tools/permutation-combination-calculator/>)







## Notas de uso



O cálculo é feito no seu navegador. Use unidades consistentes.







## Método de cálculo



Sem repetição, nPr = n!/(n−r)! e nCr = nPr/r!. Com repetição, as escolhas ordenadas são nr e as escolhas não ordenadas são C(n+r−1,r).
