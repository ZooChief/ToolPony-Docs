# 利益率と値入率



コストと価格から粗利益率とマークアップを見つけ、ターゲットマージンで製品の価格を算出してください。





## 例



### 入力



```
料金60、価格100
```



### 期待される結果



```
40%のマージン;66.67%のマークアップ
```







## 試してみる

[ツール全体を開く · 利益率と値入率](<https://toolpony.com/ja/tools/margin-calculator/>)





## 計算方法



利益率=利益 ÷ 販売価格。 マークアップ=利益 ÷ コスト。 目標マージンには販売価格=原価(1−マージン)が必要である。







## 計算モード



**コストと価格**

- コスト
- 販売価格





**目標マージンでの価格**

- コスト
- 目標マージン · %
