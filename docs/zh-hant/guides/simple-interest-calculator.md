# 單利計算器



計算單利與到期金額，或反推本金、利率與期限。





## 開始使用



1. 按示例填寫數值，或輸入你自己的測量值。
2. 計算後可複製結果或下載明細。







## 示例



### 輸入



```
1,000 按年利率 5%，2 年
```



### 預期結果



```
利息 100，到期金額 1,100
```

## 使用提示



計算在瀏覽器內完成。無單位標記的字段請使用一致單位。







## 計算方法



單利等於本金乘以每期利率與期數。先將期限換成和利率一致的單位，再相乘。到期金額等於本金加利息。



$$
I=Prt,\qquad A=P+I
$$



期限要換算成報價利率的週期。例如年利率 5%、期限 24 個月，按兩個年度週期計算。



已知到期金額時可使用反推模式。零利率或零期限會讓部分反推問題失去唯一解。







## 計算模式



**單利與到期金額**

- 本金
- 利率 · %
- 利率週期 · 每年 / 每月
- 年
- 月





**求本金**

- 到期金額
- 利率 · %
- 利率週期 · 每年 / 每月
- 期限
- 期限單位 · 年 / 月





**求利率**

- 本金
- 到期金額
- 期限
- 期限單位 · 年 / 月
- 利率週期 · 每年 / 每月





**求期限**

- 本金
- 到期金額
- 利率 · %
- 利率週期 · 每年 / 每月
- 期限單位 · 年 / 月
