# 二次方程式の解の公式



ax2 + bx + c = 0 を、実数または複雑な根(分数係数を含む)で解く。





## 使い方



1. 例を使うか、任意の値を入力します。
2. 計算後、結果をコピーするか詳細をダウンロードできます。







## 例



### 入力



```
a=1, b=−5, c=6
```



### 期待される結果



```
x₁=2, x₂=3
```







## 試してみる



[ツール全体を開く](<https://toolpony.com/ja/tools/quadratic-calculator/>)







## 注意点



処理はブラウザ内で実行されます。単位をそろえて入力してください。







## 計算方法



差別的b2−4acを使用してください。 ゼロ二次係数は、式を線形方程式に低減する。



$$
ax^2+bx+c=0,\qquad x=\frac{-b\pm\sqrt{b^2-4ac}}{2a},\quad a\ne0
$$
