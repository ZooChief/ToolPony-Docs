# Depreciation calculator



Build an annual straight-line, declining-balance, or sum-of-years’ digits schedule.





## Get started



1. Use the example values or enter your own measurements.
2. Calculate, then copy the result or download the available details.







## Example



### Input



```
17,500 cost, 2,500 salvage, 6 years, straight-line
```



### Expected result



```
2,500 per year
```







## Try it



[Open full tool](<https://toolpony.com/en/tools/depreciation-calculator/>)







## Good to know



The calculation runs in your browser. Use consistent units in fields with no explicit unit.







## Calculation method



Straight-line divides depreciable cost by useful life. Declining balance applies factor/life to opening book value and stops at salvage. Sum-of-years’ digits allocates by the remaining years’ weights. Amounts are rounded per year.



$$
D_{\mathrm{SL}}=\frac{C-S}{n},\quad D_{k,\mathrm{SYD}}=(C-S)\frac{n-k+1}{n(n+1)/2}
$$







## Calculation mode



**Straight-line**

- Asset cost
- Salvage value
- Useful life
- Rounding · Two decimal places / Whole amount





**Declining balance**

- Asset cost
- Salvage value
- Useful life
- Depreciation factor
- Rounding · Two decimal places / Whole amount





**Sum-of-years’ digits**

- Asset cost
- Salvage value
- Useful life
- Rounding · Two decimal places / Whole amount
