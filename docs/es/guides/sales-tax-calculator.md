# Calculadora de impuesto sobre ventas e IVA



Agregue o retire el impuesto de ventas y el IVA utilizando su propia tarifa.





## Primeros pasos



1. Usa el ejemplo o introduce tus propios valores.
2. Calcula, copia el resultado o descarga los detalles disponibles.







## Ejemplo



### Entrada



```
Precio neto 100, IVA 20%
```



### Resultado esperado



```
Bruto 120, impuesto 20
```

## Notas de uso



El cálculo se ejecuta en tu navegador. Usa unidades coherentes.







## Método de cálculo



Precio bruto = precio neto × (1 + tasa). Las tasas de impuestos son suministradas por el usuario.
