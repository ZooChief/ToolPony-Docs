# 行列計算機



ランクと決定要因を追加、乗算、転位、反転、解き、または見つけ出す。 結果をTSVとしてコピーするか、CSVをダウンロードしてください。





## 使い方



1. 例を使うか、任意の値を入力します。
2. 計算後、結果をコピーするか詳細をダウンロードできます。







## 例



### 入力



```
A = [2, 4; 1, 3], B = [1, −2; 4, 5]
```



### 期待される結果



```
A + B = [3, 2; 5, 8]
```







## 試してみる



[ツール全体を開く](<https://toolpony.com/ja/tools/matrix-calculator/>)







## 注意点



処理はブラウザ内で実行されます。単位をそろえて入力してください。







## 計算方法



各行を新しい列またはセミコロンで区切ってください。 値はスペースまたはカンマで区切ることができます。 ネストされたJSON配列が受け入れられます。 平方線方式では、ガウス型除去法とスケーリングされたピボット法を用いる。



$$
(AB)_{ij}=\sum_{k=1}^{n}A_{ik}B_{kj},\qquad A^{-1}A=I
$$



$$
[A\mid B]\longrightarrow[I\mid X]\quad\Rightarrow\quad AX=B
$$
