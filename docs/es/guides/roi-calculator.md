# Calculadora de retorno de inversión



Calcular el beneficio neto, el rendimiento total y el rendimiento anualizado con honorarios.





## Primeros pasos



1. Usa el ejemplo o introduce tus propios valores.
2. Calcula, copia el resultado o descarga los detalles disponibles.







## Ejemplo



### Entrada



```
Invertir 1.000 y recibir 1.210 al cabo de 2 años
```



### Resultado esperado



```
21% total; 10% anualizado
```







## Pruébalo



[Abrir herramienta completa](<https://toolpony.com/es/tools/roi-calculator/>)







## Notas de uso



El cálculo se ejecuta en tu navegador. Usa unidades coherentes.







## Método de cálculo



El rendimiento total es (procedimientos netos - costo total) ÷ costo total. Compuestos anuales de retorno la misma relación con los años especificados.
