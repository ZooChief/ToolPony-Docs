# Calculadora de cascalho



Estime volume, massa, quantidade de sacos e custo de cascalho ou areia.





## Primeiros passos



1. Escolha área conhecida, retângulo ou círculo e informe a espessura.
2. Escolha o material. Informe a densidade ou a capacidade em Mais opções.







## Exemplo



### Entrada



```
200 ft², espessura de 3 in, cascalho de 1.680 kg/m³.
```



### Resultado esperado



```
50 ft³ (1,42 m³), cerca de 2.379 kg.
```

## Notas de uso



O cálculo é feito no seu navegador. Use unidades consistentes.







## Método de cálculo



Multiplique a área pela espessura e some a margem. A massa é o volume vezes a densidade aparente. Para preço por saco, arredonde para cima. Use a densidade do fornecedor quando disponível.



$$
V=Ad(1+w/100),\qquad m=\rho V,\qquad N=\left\lceil\frac{m}{m_{\rm bag}}\right\rceil\ \text{or}\ \left\lceil\frac{V}{V_{\rm bag}}\right\rceil
$$
