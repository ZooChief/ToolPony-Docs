# Verhältnisrechner



Lösen Sie einen fehlenden Begriff in einer Proportion, vereinfachen Sie ein Verhältnis oder skalieren Sie beide Begriffe.





## Beispiel



### Eingabe



```
3:4 = x:20
```



### Erwartetes Ergebnis



```
x=15
```







## Ausprobieren

[Vollständiges Werkzeug öffnen · Verhältnisrechner](<https://toolpony.com/de/tools/ratio-calculator/>)





## Berechnungsmethode



A:B = C:D impliziert A × D = B × C, mit ungleichen Nennern.







## Berechnungsmodus



**Einen Anteil lösen**

- A
- B
- C
- D





**Vereinfachen oder Skalieren**

- Erstes Glied
- Zweite Amtszeit
- Skalierungsfaktor





**Vergrößern oder Verkleinern eines Verhältnisses**

- Erstes Glied
- Zweite Amtszeit
- Richtung · Reduzieren / Erweiterung
- Faktor
