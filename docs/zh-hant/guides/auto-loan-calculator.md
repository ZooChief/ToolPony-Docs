# 車貸計算器



計入舊車折抵、未償欠款、返現和稅費，計算車貸月供或可承受車價。





## 開始使用



1. 輸入車價，或切換到目標月供。填寫首付、舊車折抵價和欠款，以及返現。
2. 輸入稅率和費用，選定稅基抵扣與是否隨貸，再導出還款表。







## 示例



### 輸入



```
車價 30,000，首付 5,000，60 個月，年利率 5%
```



### 預期結果



```
稅費爲零時月供 471.78
```

## 計算方法



稅率和抵扣規則由你輸入。選擇隨貸時，稅費計入本金。舊車淨值爲折抵價減去未償債務。使用固定月利率。



$$
P=V-D-(T-O)-R+F,\quad M=\frac{Pr}{1-(1+r)^{-n}},\quad M=\frac Pn\; (r=0)
$$



V 爲車價，D 爲首付，T 爲舊車折抵價，O 爲舊車欠款，R 爲返現，F 爲隨貸稅費。P 爲貸款本金，M 爲月供，r 爲月利率，n 爲月數。
