# Redimensionar imágenes



Elige una imagen. Introduce el ancho o el alto. Mantén la proporción para evitar deformaciones. Cambia el tamaño y descarga el PNG.





## Primeros pasos



1. Elige una imagen.
2. Introduce el ancho o el alto. Mantén la proporción para evitar deformaciones.
3. Cambia el tamaño y descarga el PNG.







## Ejemplo



### Entrada



```
1600 × 1200, ancho 800, mantener proporción
```



### Resultado esperado



```
PNG de 800 × 600
```







## Pruébalo



[Abrir herramienta completa](<https://toolpony.com/es/tools/image-resizer/>)







## Límites



Hasta 20 MB, 24 megapíxeles y 8.192 píxeles por lado. Ampliar la imagen no recupera los detalles ausentes.

[Documentación](https://docs.toolpony.com/es/guides/image-resizer/)
