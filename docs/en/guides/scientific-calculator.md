# Scientific calculator



Evaluate mathematical expressions with powers, factorials, trigonometry, roots and logarithms.





## Get started



1. Use the example values or enter your own measurements.
2. Calculate, then copy the result or download the available details.







## Example



### Input



```
sqrt(81) + 2^3 × sin(30), degrees
```



### Expected result



```
13
```







## Try it



[Open full tool](<https://toolpony.com/en/tools/scientific-calculator/>)







## Good to know



The calculation runs in your browser. Use consistent units in fields with no explicit unit.







## Calculation method



Operators follow parentheses, postfix, exponent, multiplication and addition precedence. Powers associate from the right. Percent divides by 100. Results use floating-point arithmetic.
