# 混凝土用量計算器



估算板、基礎、圓管、路緣溝和臺階所需的混凝土體積、重量和整袋數。





## 開始使用



1. 選擇實際形狀，併爲各尺寸設置單位。圓管模式使用內外直徑。
2. 樓梯模式分別輸入臺階級數和頂部平臺進深。其餘模式填寫相同構件的數量。
3. 已知包裝上的材料密度時可替換默認值。採購時看整袋數表。







## 示例



### 輸入



```
7 英尺 × 3 英尺 × 5 英寸的板，數量 2
```



### 預期結果



```
17.5 立方英尺，按 133 磅/立方英尺計爲 2,327.50 磅
```

## 計算方法



體積爲截面積乘長度。默認按 133 磅/立方英尺算磅數，按 2,130 公斤/立方米算公斤數。自定義密度時兩項結果按同一密度換算。採購先加損耗預留，再向上取整。



$$
V_{\rm slab}=lwhq,\quad V_{\rm tube}=\pi hq(d_o^2-d_i^2)/4
$$



$$
V_{\rm stairs}=brn\left[p+u(n-1)/2\right],\qquad m=V\rho
$$



樓梯公式中，b 爲寬度，r 爲每級高度，u 爲每級水平進深，n 爲臺階級數，p 爲頂部平臺進深。實體體積包含 n−1 段踏步和頂層平臺。



兩塊 7 英尺 × 3 英尺 × 5 英寸的板，按 133 磅/立方英尺計需 2327.50 磅，摺合 38.79 袋 60 磅裝。未預留損耗時，採購表向上取整爲 39 袋。
