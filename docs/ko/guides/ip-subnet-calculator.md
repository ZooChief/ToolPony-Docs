# IP 서브넷 계산기



IPv4 및 IPv6 네트워크, 마스크, 범위 및 주소 수를 검사하거나 IP가 CIDR 블록에 속하는지 테스트합니다.





## 시작하기



1. 예제 값을 사용하거나 원하는 값을 입력하세요.
2. 계산한 결과를 복사하거나 세부 정보를 내려받을 수 있습니다.







## 예시



### 입력



```
192.0.2.129 /27
```



### 예상 결과



```
네트워크 192.0.2.128/27, 30 사용 가능한 호스트
```

## 계산 방법



그리고 첫 번째 주소를 찾기 위해 접두사 마스크가 있는 주소입니다. 호스트 부분에는 2^(address bits − prefix) 가능성이 있습니다. IPv4 /31은 RFC 3021 포인트-투-포인트 옵션과 함께 기본적으로 레거시 호스트 카운팅을 사용합니다. 인라인 CIDR 접두사가 우선합니다.



$$
\text{Addresses}=2^{w-p},\qquad w\in\{32,128\}
$$



IPv4는 접두사 길이나 연속된 비트로 이루어진 점 표기 마스크를 받습니다. 예를 들어 192.0.2.129와 255.255.255.224는 192.0.2.129/27과 같은 네트워크를 나타냅니다.



접두사 크기의 범주는 비교 도구의 A/B/C 규칙을 따릅니다. 역사적 주소 클래스는 별도로 나타납니다. CIDR 멤버십의 주소 범위를 사용합니다. 옵션 포인트 투 포인트 설정은 /31 호스트 계산 만 변경됩니다.







## 계산 모드



**IPv4는**

- IPv4 주소 또는 CIDR
- 접두사 또는 서브넷 마스크
- /31 포인트-투-포인트 링크에서 두 주소 모두 사용





**IPv6는**

- IPv6 주소 또는 CIDR
- 접두사





**주소 회원 확인**

- CIDR 네트워크
- 확인해야 할 주소
