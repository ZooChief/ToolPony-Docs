# Pace calculator



Solve pace, elapsed time and distance. Compare split paces, convert units, and estimate a finish time.





## Get started



1. Use the example values or enter your own measurements.
2. Calculate, then copy the result or download the available details.







## Example



### Input



```
10 km in 00:50:00
```



### Expected result



```
05:00 per km, 12 km/h
```







## Try it



[Open full tool](<https://toolpony.com/en/tools/pace-calculator/>)







## Good to know



The calculation runs in your browser. Use consistent units in fields with no explicit unit.







## Calculation method



Pace is elapsed time divided by distance. Finish time extrapolates constant pace. Split rows use the selected distance unit and accept up to 100 rows.



$$
p=\frac{t}{d},\qquad v=\frac{d}{t}
$$
