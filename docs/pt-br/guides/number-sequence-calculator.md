# Calculadora de sequências



Encontre um termo, soma parcial e uma lista para download para sequências aritméticas, geométricas ou Fibonacci.





## Primeiros passos



1. Use o exemplo ou insira seus próprios valores.
2. Calcule, copie o resultado ou baixe os detalhes disponíveis.







## Exemplo



### Entrada



```
Sequência aritmética, primeiro 7, diferença −3, índice 8
```



### Resultado esperado



```
−14, soma −28
```

## Notas de uso



O cálculo é feito no seu navegador. Use unidades consistentes.







## Método de cálculo



Os índices aritméticos e geométricos começam em 1. Fibonacci começa em F0 = 0. A lista Fibonacci usa números inteiros exatos.



$$
a_n=a_1+(n-1)d,\quad g_n=g_1r^{n-1},\quad F_n=F_{n-1}+F_{n-2}
$$







## Modo de cálculo



**Aritmética**

- Primeiro período
- Diferença comum
- Índice





**Geométrico**

- Primeiro período
- Rácio comum
- Índice





**Fibonacci**
