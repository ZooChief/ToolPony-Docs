# 单位换算使用指南



换算长度、质量、面积、体积、温度、速度、能量、数字存储等单位。





## 示例



### 输入



```
1 米转英尺
```



### 预期结果



```
约 3.28084 英尺
```

## 核对一次降温



1. 温度从 20 °C 降到 10 °C。选择「温差」并输入 −10 °C，变化量为 −18 °F。切回「温度」，10 °C 的读数对应 50 °F。





## 1 TB 硬盘有多少 GiB



标称 1 TB 的硬盘有 1,000,000,000,000 字节。每 GiB 有 1,073,741,824 字节，格式化前容量约为 931.32 GiB。页面和导出的 CSV 保留完整小数。



[运行示例](<https://toolpony.com/zh-hans/tools/unit-converter/#example-drive-capacity>)







## 3/8 英寸的接头



在英寸栏输入 3/8，读数是 9.525 mm。也可以输入带分数，例如 1 3/8 in 等于 34.925 mm。



[运行示例](<https://toolpony.com/zh-hans/tools/unit-converter/#example-fractional-inch>)

## 计算方法



已定义的换算比例按精确分数计算。遇到循环小数，同时显示近似读数与原分数。弧度与其他角度单位互转时使用 π 的近似值。
