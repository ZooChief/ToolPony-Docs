# 원 계산기



알려진 측정에서 반경, 직경, 둘레 및 면적을 찾으십시오. 아크, 섹터 및 코드를 계산합니다.





## 시작하기



1. 예제 값을 사용하거나 원하는 값을 입력하세요.
2. 계산한 결과를 복사하거나 세부 정보를 내려받을 수 있습니다.







## 예시



### 입력



```
반경 2; 중앙 각 90°
```



### 예상 결과



```
둘레 ≈12.5664; 아크 ≈3.1416
```

## 참고 사항



브라우저에서 처리합니다. 단위를 일관되게 사용하세요.







## 계산 방법



둘레 = 2πr. 면적 = πr2. 아크 길이 및 중앙 각을 가진 분야 면적 가늠자는 360°에 의해 분할됩니다.



$$
A=\pi r^2,\qquad C=2\pi r
$$
