# Dice roller



Roll one or more dice with custom sides, compare totals and see each roll.





## Get started



1. Use the example values or enter your own measurements.
2. Calculate, then copy the result or download the available details.







## Example



### Input



```
3 dice, 6 sides
```



### Expected result



```
Three faces and their sum
```







## Try it



[Open full tool](<https://toolpony.com/en/tools/dice-roller/>)







## Good to know



The calculation runs in your browser. Use consistent units in fields with no explicit unit.







## Calculation method



Each die uses an independent uniform Web Crypto draw. Roll up to 100 dice, with 2 to 1,000 sides each.

[Documentation](https://docs.toolpony.com/en/guides/dice-roller/)
