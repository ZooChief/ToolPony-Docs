# 羅馬數字轉換器



雙向轉換羅馬數字和整數，也可轉換日期或帶分隔符的列表。





## 開始使用



1. 按示例填寫數值，或輸入你自己的測量值。
2. 計算後可複製結果或下載明細。







## 示例



### 輸入



```
MCMXCIX
```



### 預期結果



```
1999
```

## 使用提示



計算在瀏覽器內完成。無單位標記的字段請使用一致單位。







## 計算方法



使用 IV、CM 等標準減法組合，上劃線將該組數值乘以 1,000。輸入時可在每個帶線字符前加下劃線，或直接粘貼上劃線。支持 1 至 3,999,999，日期模式逐項轉換並保留分隔符。







## 計算模式



**單個數值**

- 整數或羅馬數字





**日期或列表**

- 列表或日期
