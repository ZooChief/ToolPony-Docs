# 概率計算器



計算事件概率，按兩個已知量反求獨立事件概率，或計算正態區間概率。





## 開始使用



1. 按示例填寫數值，或輸入你自己的測量值。
2. 計算後可複製結果或下載明細。







## 示例



### 輸入



```
獨立事件 A = 0.31，B = 0.56
```



### 預期結果



```
至少一個發生：0.6964
```

## 計算方法



獨立事件滿足 P(A∩B)=P(A)P(B)。相關事件需直接輸入交集。重複試驗的全部成功概率爲各次概率之積，至少一次成功使用補集計算。



$$
P(A\cup B)=P(A)+P(B)-P(A\cap B)
$$



$$
P(A\cap B)=P(A)P(B)\quad\text{(independent)}
$$







## 計算模式



**兩個獨立事件**

- A 的概率
- B 的概率





**已知交集**

- A 的概率
- B 的概率
- 兩個事件均發生





**反求獨立事件**

- 第一已知量 · A 的概率 / B 的概率 / A 不發生 / B 不發生 / 兩個事件均發生 / 至少一個事件發生 / 恰好一個事件發生 / 兩個事件均不發生
- 第一概率
- 第二已知量 · A 的概率 / B 的概率 / A 不發生 / B 不發生 / 兩個事件均發生 / 至少一個事件發生 / 恰好一個事件發生 / 兩個事件均不發生
- 第二概率





**重複獨立試驗**

- A 的概率
- A 的試驗次數
- B 的概率
- B 的試驗次數





**正態分佈區間**

- 均值
- 標準差
- 下界
- 上界
