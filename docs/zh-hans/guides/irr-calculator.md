# 内部收益率计算器



根据不规则年度现金流，或到期金额和定期存取，计算年有效内部收益率。





## 开始使用



1. 按示例填写数值，或输入你自己的测量值。
2. 计算后可复制结果或下载明细。







## 示例



### 输入



```
初始投入 55,000，之后流入 14,000、18,000、22,000、26,000
```



### 预期结果



```
内部收益率约 15.093%
```

## 计算方法



IRR 是使净现值为零的收益率。固定模式按选定的频率与期初或期末计入现金流。可选择期初模式是否在终点边界再计入一笔存取。搜索收益率范围为 −99.9999% 至 10,000%。



$$
0=\sum_{i=0}^n\frac{F_i}{(1+r)^{t_i}}
$$







## 计算模式



**不规则年度现金流**

- 初始投入
- 以后各年现金流





**固定存取与期末余额**

- 初始投入
- 完整年数
- 额外月数
- 期末余额
- 单次存取金额
- 存取方向 · 取出 / 存入
- 每年次数 · 1 / 2 / 4 / 12 / 24 / 26 / 52
- 存取时点 · 期末 / 期初
- 期初模式包含终点存取
