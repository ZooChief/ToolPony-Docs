# Diagramme erstellen



Fügen Sie CSV mit einer Kopfzeile, einer Etikettenspalte und numerischen Reihen ein. Wählen Sie Balken oder Linien, aktualisieren Sie das Diagramm und laden Sie SVG herunter.





## Erste Schritte



1. Geben Sie einen CSV-Header ein, setzen Sie Kategorie-Etiketten in die erste Spalte und numerische Reihen in die restlichen Spalten.
2. Wählen Sie Balken oder Linien und aktualisieren Sie die Vorschau.
3. Laden Sie das Diagramm als SVG herunter.







## Beispiel



### Eingabe



```
Month,Visits
Jan,24
Feb,38
```



### Erwartetes Ergebnis



```
Zwei Werte bei Jan und Feb, von links nach rechts aufgetragen.
```







## Ausprobieren



[Vollständiges Werkzeug öffnen](<https://toolpony.com/de/tools/chart-maker/>)







## Hinweise



Anführungszeichen mit Kommas; eine Periode als Dezimaltrennzeichen verwenden; negative Werte verwenden die gleiche Skala wie positive Werte.







## Grenzen



Bis zu 120 Zeilen und sechs numerische Reihen; eine zitierte Zelle kann ein Komma enthalten; jede Zeile bleibt in einer Zeile; die Werte werden in der eingegebenen Reihenfolge aufgetragen.
