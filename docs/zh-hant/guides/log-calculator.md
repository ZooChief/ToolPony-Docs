# 對數計算器



計算對數值、底數或真數，底數可爲數值或 e。





## 開始使用



1. 按示例填寫數值，或輸入你自己的測量值。
2. 計算後可複製結果或下載明細。







## 示例



### 輸入



```
底數 3，真數 81
```



### 預期結果



```
4
```

## 使用提示



計算在瀏覽器內完成。無單位標記的字段請使用一致單位。







## 計算方法



log₍b₎(x) 是滿足 bʸ = x 的指數 y。換底公式爲 ln(x) 除以 ln(b)。



$$
\log_b(x)=\frac{\ln x}{\ln b},\qquad b>0,\quad b\ne1,\quad x>0
$$







## 計算模式



**求對數**

- 底數（數值或 e）
- 真數





**求底數**

- 真數
- 對數值





**求真數**

- 底數（數值或 e）
- 對數值
