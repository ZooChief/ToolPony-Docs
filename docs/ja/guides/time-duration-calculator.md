# 時間間隔計算機



時刻の間隔と加減算を行い、日時を移動します。





## 使い方



1. 1 シフトは時刻、複数日は日時、加減算は時間の式を選びます。







## 例



### 入力



```
22:30 から翌日の 06:15
```



### 期待される結果



```
07:45:00
```







## 試してみる



[ツール全体を開く](<https://toolpony.com/ja/tools/time-duration-calculator/>)







## 注意点



処理はブラウザ内で実行されます。単位をそろえて入力してください。







## 計算方法



時刻の間隔は日付をまたげます。日付を指定する場合は 1 日を 24 時間とします。式の d、h、m、s は日、時、分、秒です。負号は次の時間項の組全体に適用します。



$$
T=86400d+3600h+60m+s
$$
