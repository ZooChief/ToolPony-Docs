# 在線畫板



用畫筆或橡皮擦在畫布上繪製，調整顏色與粗細，撤銷或重做筆畫，最後下載透明 PNG。





## 開始使用



1. 選擇畫筆或橡皮擦，設置粗細。
2. 使用鼠標、手指或觸控筆繪製。
3. 撤銷或重做筆畫，然後導出透明 PNG。







## 試一試

## 使用提示



在可用的歷史記錄內可以撤銷清空。關閉標籤頁前請導出 PNG。







## 適用範圍



畫布爲 1080 × 640 像素，內容保留在當前標籤頁。使用 Ctrl/Cmd+Z 撤銷，Ctrl/Cmd+Shift+Z 重做。
