# PDF 合併



添加兩個或更多 PDF，調整文件順序後合併爲一個文檔。每份文件的頁面按你選定的順序依次複製。





## 開始使用



1. 選擇至少兩個 PDF 文件。
2. 使用上移、下移按鈕調整文件順序。
3. 合併並下載文檔。







## 示例



### 輸入



```
A.pdf（2 頁）+ B.pdf（3 頁）
```



### 預期結果



```
5 頁 PDF，順序爲 A1、A2、B1、B2、B3
```

## 使用提示



頁面按文件順序複製。不支持加密文件；表單、書籤、數字簽名等文檔級功能可能無法在頁面複製後保留。







## 適用範圍



輸入總計最多 30 MB、300 頁。不支持加密 PDF；數字簽名、表單、書籤等文檔級功能可能無法在頁面複製後保留。
