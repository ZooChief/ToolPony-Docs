# 関数電卓の使い方



累乗、階乗、三角関数、根号、対数を含む数式を計算します。





## 例



### 入力



```
sqrt(81)+ 2^3 × 罪(30)、学位
```



### 期待される結果



```
13
```





<a id="case-study"></a>



## 対角線を求める



1. 12 × 5 cm の板で √(12² + 5²) を貼り付けると対角線は 13 cm です。式の一部を選択して x² を押すと、その部分だけを二乗できます。
2. 対角線を求めた直後に DEG で asin(5/Ans) を計算すると、5 cm の辺の対角は約 22.62° です。



[入力例を実行](<https://toolpony.com/ja/tools/scientific-calculator/#example-panel-diagonal>)

## 計算方法



括弧、後置演算、累乗、乗除、加減の順で計算します。累乗は右から結合し、% は 100 で割ります。計算には浮動小数点を使います。
