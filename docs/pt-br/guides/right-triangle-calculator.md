# Calculadora de triângulos retângulos



Calcule catetos, hipotenusa e ângulos a partir de duas medidas, incluindo altura, área ou perímetro.





## Primeiros passos



1. Insira duas medidas, incluindo um comprimento, uma área ou o perímetro.
2. As duas soluções trocam os rótulos dos catetos e dos ângulos agudos.







## Exemplo



### Entrada



```
c = 5, h = 2,4
```



### Resultado esperado



```
Catetos 3 e 4, área 6, perímetro 12. Qualquer cateto pode ser a.
```

## Notas de uso



O cálculo é feito no seu navegador. Use unidades consistentes.







## Método de cálculo



c é a hipotenusa e h é a altura perpendicular a ela. Use a mesma unidade de comprimento e seu quadrado para a área.



$$
c^2=a^2+b^2,\quad h=ab/c,\quad S=ab/2,\quad P=a+b+c
$$



$$
a,b=\frac{\sqrt{c^2+2ch}\;\pm\;\sqrt{c^2-2ch}}{2}
$$
