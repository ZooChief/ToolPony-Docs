# 円の計算機



既知の測定から半径、直径、周囲および面積を検索します。 アーク、セクタ、コードを計算する。





## 使い方



1. 例を使うか、任意の値を入力します。
2. 計算後、結果をコピーするか詳細をダウンロードできます。







## 例



### 入力



```
半径2;中央角90度
```



### 期待される結果



```
円周量 ≈12.5664;アーク ≈3.1416
```







## 試してみる



[ツール全体を開く](<https://toolpony.com/ja/tools/circle-calculator/>)







## 注意点



処理はブラウザ内で実行されます。単位をそろえて入力してください。







## 計算方法



円周 = 2πr。 面積 = πr2。 円弧の長さと面積は中央角度を360°で割った状態でスケーリングします。



$$
A=\pi r^2,\qquad C=2\pi r
$$
