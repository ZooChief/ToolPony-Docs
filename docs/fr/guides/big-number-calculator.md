# Calculatrice de grands nombres



Calculer avec des nombres entiers et des coefficients décimal exacts, avec des arrondis sélectionnables pour la division et les racines.





## Prise en main



1. Utilisez l’exemple ou saisissez vos propres valeurs.
2. Calculez, puis copiez le résultat ou téléchargez les détails.







## Exemple



### Entrée



```
9,007,199,254,740,993 + 7
```



### Résultat attendu



```
9007199254741000
```

## Notes



Le traitement se fait dans le navigateur. Utilisez des unités cohérentes.







## Méthode de calcul



L'addition, la soustraction, la multiplication, les puissances d'entier et les opérations d'entier utilisent les coefficients de BigInt. Les rounds de division aux décimales sélectionnées. Les racines carrées peuvent tronquer ou arrondir à la plus proche.



$$
x=m\cdot 10^e,\quad x_1x_2=(m_1m_2)\cdot 10^{e_1+e_2}
$$
