# 科学的記数法の計算機



科学、工学、E、および小数点の数値を変換するか、またはスケール値で計算します。





## 使い方



1. 例を使うか、任意の値を入力します。
2. 計算後、結果をコピーするか詳細をダウンロードできます。







## 例



### 入力



```
1568938
```



### 期待される結果



```
1.568938 × 10^6
```

[ツール全体を開く](<https://toolpony.com/ja/tools/scientific-notation-calculator/>)







## 注意点



処理はブラウザ内で実行されます。単位をそろえて入力してください。







## 計算方法



科学的表示は1つのリード数値を使用します。 工学的表示は、3つで割り切れる説明を使用します。 加算、減算および乗算は、選択した精度に丸める前に正確な十数係数を使用します。



$$
x=a\times10^n,\qquad 1\le |a|<10\quad(x\ne0)
$$



1568938、1.568938e6、1.568938 × 10^6 は同じ値です。工学表記では 10 の指数を 3 の倍数にします。



算術モードは、加算、引算、および乗算の正確な10進係数を保持します。 非整数電位と平方根は浮動小数点近似を使用します。
