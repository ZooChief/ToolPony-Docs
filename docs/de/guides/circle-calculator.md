# Kreisrechner



Radius, Durchmesser, Umfang und Fläche aus einer beliebigen bekannten Messung ermitteln, Bögen, Sektoren und Akkorde berechnen.





## Erste Schritte



1. Verwenden Sie das Beispiel oder geben Sie eigene Werte ein.
2. Berechnen Sie das Ergebnis und kopieren oder laden Sie die Details herunter.







## Beispiel



### Eingabe



```
Radius 2; Mittelwinkel 90°
```



### Erwartetes Ergebnis



```
Umfang ≈ 12,5664; Bogen ≈ 3,1416
```

## Hinweise



Die Verarbeitung erfolgt im Browser. Verwenden Sie einheitliche Einheiten.







## Berechnungsmethode



Umfang = 2πr. Fläche = πr2. Bogenlänge und Sektorflächenskala mit dem Mittelwinkel geteilt durch 360°.



$$
A=\pi r^2,\qquad C=2\pi r
$$
