# Rechner für quadratische Gleichungen



Lösen Sie ax2 + bx + c = 0 mit reellen oder komplexen Wurzeln, einschließlich Bruchkoeffizienten.





## Erste Schritte



1. Verwenden Sie das Beispiel oder geben Sie eigene Werte ein.
2. Berechnen Sie das Ergebnis und kopieren oder laden Sie die Details herunter.







## Beispiel



### Eingabe



```
a=1, b=−5, c=6
```



### Erwartetes Ergebnis



```
x₁=2, x₂=3
```

Die Verarbeitung erfolgt im Browser. Verwenden Sie einheitliche Einheiten.







## Berechnungsmethode



Verwenden Sie den diskriminanten b2-4ac. Ein nullquadratischer Koeffizient reduziert den Ausdruck auf eine lineare Gleichung.



$$
ax^2+bx+c=0,\qquad x=\frac{-b\pm\sqrt{b^2-4ac}}{2a},\quad a\ne0
$$
