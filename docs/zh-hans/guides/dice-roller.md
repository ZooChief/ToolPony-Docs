# 掷骰子



自定义骰子面数和颗数，查看每次掷骰及合计。





## 开始使用



1. 按示例填写数值，或输入你自己的测量值。
2. 计算后可复制结果或下载明细。







## 示例



### 输入



```
3 颗六面骰
```



### 预期结果



```
三个点数与总和
```







## 试一试



[打开完整工具](<https://toolpony.com/zh-hans/tools/dice-roller/>)







## 使用提示



计算在浏览器内完成。无单位标记的字段请使用一致单位。







## 计算方法



每颗骰子独立使用 Web Crypto 均匀抽取。最多 100 颗，每颗可选 2 至 1,000 面。

[文档站](https://docs.toolpony.com/zh-hans/guides/dice-roller/)
