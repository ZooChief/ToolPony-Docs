# Calculatrice de moyenne GPA



Calculer le GPA pondéré par cours, inclure les crédits antérieurs et les semestres de groupe, ou calculer le GPA nécessaire pour atteindre une cible.





## Prise en main



1. Utilisez l’exemple ou saisissez vos propres valeurs.
2. Calculez, puis copiez le résultat ou téléchargez les détails.







## Exemple



### Entrée



```
Mathématiques, 3, A et anglais, 3, B
```



### Résultat attendu



```
GPA 3.5
```

## Méthode de calcul



Les notes de lettre utilisent l'échelle de 4,3 points affichée. Le mode de pourcentage représente les pourcentages moyens directement. Utilisez des points explicites pour les autres échelles scolaires.



$$
\operatorname{GPA}=\frac{\sum_i g_i c_i}{\sum_i c_i}
$$



Entrez un cours par ligne. La quatrième colonne peut regrouper les cours par terme. La cinquième ajoute un bonus par crédit explicite pour un cours. Entrez GPA antérieur et crédits ensemble lors de l'ajout d'un enregistrement existant.



A+ à F utilisent la cartographie en 4,3 points. P, NP, I et W sont omis de la somme pondérée. Utilisez le mode points pour suivre une échelle numérique spécifique à l'école.
