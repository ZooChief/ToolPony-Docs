# Calculatrice de ratio d’endettement



Comparez vos versements mensuels récurrents avec votre revenu mensuel brut.





## Prise en main



1. Utilisez l’exemple ou saisissez vos propres valeurs.
2. Calculez, puis copiez le résultat ou téléchargez les détails.







## Exemple



### Entrée



```
Recettes 5 000, paiements de la dette 1 500
```



### Résultat attendu



```
30%
```







## Essayer



[Ouvrir l’outil complet](<https://toolpony.com/fr/tools/debt-to-income-calculator/>)







## Notes



Le traitement se fait dans le navigateur. Utilisez des unités cohérentes.







## Méthode de calcul



Ratio de la dette au revenu = paiements mensuels de la dette ÷ revenu mensuel brut. Utilisez la même devise et une période mensuelle pour tous les montants.
