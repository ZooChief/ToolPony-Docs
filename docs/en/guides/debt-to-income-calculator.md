# Debt-to-income calculator



Compare your recurring monthly debt payments with gross monthly income.





## Example



### Input



```
Income 5,000, debt payments 1,500
```



### Expected result



```
30%
```







## Try it

[Open full tool · Debt-to-income calculator](<https://toolpony.com/en/tools/debt-to-income-calculator/>)





## Calculation method



Debt-to-income ratio = monthly debt payments ÷ gross monthly income. Use the same currency and a monthly period for all amounts.





**Method references** [CFPB · Debt-to-Income Ratio](<https://www.consumerfinance.gov/ask-cfpb/what-is-a-debt-to-income-ratio-en-1791/>)
