# Calculadora de propinas



Dividir una factura y una propina entre las personas, con la propina basada en la cantidad antes o después del impuesto.





## Primeros pasos



1. Usa el ejemplo o introduce tus propios valores.
2. Calcula, copia el resultado o descarga los detalles disponibles.







## Ejemplo



### Entrada



```
80 billetes, 20% propina, 4 personas
```



### Resultado esperado



```
96 en total, 24 por persona
```

## Notas de uso



El cálculo se ejecuta en tu navegador. Usa unidades coherentes.







## Método de cálculo



Sugerencia = cantidad de factura seleccionada × porcentaje de propina. El total por persona equivale a factura, impuesto y propina dividida por el número de personas.
