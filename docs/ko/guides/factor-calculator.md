# 약수 계산기



모든 긍정적 인 쌍, 모든 요인 쌍 및 주요 인자를 나열합니다.





## 시작하기



1. 예제 값을 사용하거나 원하는 값을 입력하세요.
2. 계산한 결과를 복사하거나 세부 정보를 내려받을 수 있습니다.







## 예시



### 입력



```
120
```



### 예상 결과



```
1 및 120을 포함한 16 개의 긍정적 인 분열자
```

## 계산 방법



분배자는 나머지 0으로 입력을 나눕니다. 각 작은 divisor d 쌍은 n/d, 그래서 √n에 검색은 각 쌍을 찾습니다.



$$
d\mid n\iff n\bmod d=0,\qquad n=d\cdot(n/d)
$$
