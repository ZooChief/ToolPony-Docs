# Calculatrice scientifique



Évaluer les expressions mathématiques avec pouvoirs, factoriels, trigonométrie, racines et logarithmes.





## Prise en main



1. Utilisez l’exemple ou saisissez vos propres valeurs.
2. Calculez, puis copiez le résultat ou téléchargez les détails.







## Exemple



### Entrée



```
sqrt(81) + 2^3 × sin(30), degrés
```



### Résultat attendu



```
13
```

## Notes



Le traitement se fait dans le navigateur. Utilisez des unités cohérentes.







## Méthode de calcul



Les opérateurs suivent les parenthèses, postfix, exposant, multiplication et l'ajout de priorité. Les puissances associent de la droite. Pourcentage divise par 100. Les résultats utilisent l'arithmétique en point flottant.
