# Calculadora da relação dívida-renda



Compare seus pagamentos de dívida mensais recorrentes com o rendimento mensal bruto.





## Exemplo



### Entrada



```
Rendimento 5.000, pagamentos da dívida 1.500
```



### Resultado esperado



```
30%
```







## Experimente

[Abrir ferramenta completa · Calculadora da relação dívida-renda](<https://toolpony.com/pt-br/tools/debt-to-income-calculator/>)





## Método de cálculo



Razão dívida/rendimento = pagamentos mensais da dívida □ Rendimento mensal bruto. Use a mesma moeda e um período mensal para todos os montantes.





**Referências do método** [CFPB · Debt-to-Income Ratio](<https://www.consumerfinance.gov/ask-cfpb/what-is-a-debt-to-income-ratio-en-1791/>)
