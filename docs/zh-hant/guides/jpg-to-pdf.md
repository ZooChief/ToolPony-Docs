# 圖片轉 PDF



添加最多 20 張圖片，調整順序、紙張、方向和邊距。每張圖片生成一頁，再下載合成的 PDF。





## 開始使用



1. 從設備添加圖片。
2. 用箭頭調整頁面順序，選擇 A4、US Letter 或圖片尺寸。
3. 生成並下載 PDF。







## 示例



### 輸入



```
一張橫向 JPG，再添加一張縱向 PNG → A4，自動方向
```



### 預期結果



```
按順序生成兩頁 PDF，第一頁橫向，第二頁縱向。
```

## 使用提示



每張圖片居中佔一頁，保持比例，不拉伸；透明區域爲白色。瀏覽器解碼時處理圖片方向，JPEG 會重新編碼。圖片尺寸模式按每個像素對應一個 PDF 點生成頁面，忽略方向和邊距。文件不上傳。







## 適用範圍



輸入總計 30 MB，每張最大 20 MB、2400 萬像素，總像素最多 6000 萬；編碼後的圖片總計最多 64 MB。支持瀏覽器可解碼的 JPG、PNG、WebP、AVIF 和 GIF，動圖只保留單幀。透明區域變爲白色，JPEG 會重新編碼，不保留元數據。
