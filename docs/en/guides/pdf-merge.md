# Merge PDF



Add two or more PDFs, adjust their order, then merge them into one document. Every page is copied in the order you choose.





## Get started



1. Choose at least two PDF files.
2. Use the up/down controls to place files in the desired order.
3. Merge and download the combined document.







## Example



### Input



```
A.pdf (2 pages) + B.pdf (3 pages)
```



### Expected result



```
A single PDF with 5 pages: A1, A2, B1, B2, B3
```







## Try it



[Open full tool](<https://toolpony.com/en/tools/pdf-merge/>)







## Good to know



The tool copies pages in order. Encrypted documents are rejected. Forms, bookmarks, signatures and other document-level features may not survive copying.







## Limits



Up to 30 MB combined input and 300 pages. Encrypted PDFs are not supported. Digital signatures, forms, bookmarks, and document-level features may not survive page copying.
