计算正态分布的左尾、右尾和双尾 P 值，或由概率反求 Z 分数。

1. 按示例填写数值，或输入你自己的测量值。
2. 计算后可复制结果或下载明细。


## 计算方法



正态检验统计量的双尾 P 值是 |z| 处右尾概率的两倍。尾部的选取应与备择假设一致。



$$
p_{\mathrm{two\ tails}}=2[1-\Phi(|z|)]
$$
