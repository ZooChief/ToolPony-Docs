# 三大栄養素計算機



カロリー目標と栄養比をグラムに変換するか、またはグラムからエネルギーと比率を計算する。





## 使い方



1. 例を使うか、任意の値を入力します。
2. 計算後、結果をコピーするか詳細をダウンロードできます。







## 例



### 入力



```
2,000kcal:タンパク質25%、炭水化物45%、脂肪30%
```



### 期待される結果



```
たんぱく質125g、炭水化物225g、脂質66.67g
```







## 試してみる



[ツール全体を開く](<https://toolpony.com/ja/tools/macro-calculator/>)







## 注意点



処理はブラウザ内で実行されます。単位をそろえて入力してください。







## 計算方法



たんぱく質と炭水化物は 4 kcal/g、脂質は 9 kcal/g で換算します。目標から計算する場合、割合の合計は 100% です。







## 計算モード



**グラム単位でターゲット**

- 総エネルギー · kcal
- たんぱく質 · %
- 炭水化物 · %
- 脂質 · %





**グラムからエネルギーへ**

- たんぱく質 · g
- 炭水化物 · g
- 脂質 · g
