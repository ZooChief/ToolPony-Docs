# Gerador de números aleatórios



Gerar inteiros aleatórios em uma faixa inclusiva, com unicidade opcional e ordenação.





## Primeiros passos



1. Use o exemplo ou insira seus próprios valores.
2. Calcule, copie o resultado ou baixe os detalhes disponíveis.







## Exemplo



### Entrada



```
Mínimo 1, máximo 10, quantidade 5
```



### Resultado esperado



```
Cinco inteiros aleatórios de 1 a 10
```







## Experimente



[Abrir ferramenta completa](<https://toolpony.com/pt-br/tools/random-number-generator/>)







## Notas de uso



O cálculo é feito no seu navegador. Use unidades consistentes.







## Método de cálculo



Valores aleatórios vêm da Web Crypto. Amostragem de rejeição evita viés modulo. Gerar até 1.000 valores na faixa -1.000.000.000 a 1.000.000.000.
