# Margen de beneficio y recargo



Encontrar margen bruto y marcado de coste y precio, o precio un producto a un margen de destino.





## Primeros pasos



1. Usa el ejemplo o introduce tus propios valores.
2. Calcula, copia el resultado o descarga los detalles disponibles.







## Ejemplo



### Entrada



```
Costo 60, precio 100
```



### Resultado esperado



```
40% de margen; 66.67% de marcado
```







## Pruébalo



[Abrir herramienta completa](<https://toolpony.com/es/tools/margin-calculator/>)







## Notas de uso



El cálculo se ejecuta en tu navegador. Usa unidades coherentes.







## Método de cálculo



Margin = ganancia ÷ precio de venta. Markup = beneficio ÷ costo. Un margen de destino requiere el precio de venta = costo ÷ (1−margin).







## Modo de cálculo



**Costo y precio**

- Costo
- Precio de venta





**Precio a un margen de destino**

- Costo
- Nivel de destino · %
