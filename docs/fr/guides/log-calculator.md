# Calculatrice de logarithmes



Trouvez le logarithme, la base ou l'argument. La base peut être un nombre ou e.





## Exemple



### Entrée



```
Base 3, argument 81
```



### Résultat attendu



```
4
```







## Essayer

[Ouvrir l’outil complet · Calculatrice de logarithmes](<https://toolpony.com/fr/tools/log-calculator/>)





## Méthode de calcul



Le logarithme log(b)(x) est l'exposant y satisfaisant par = x. La formule de changement de base divise ln(x) par ln(b).



$$
\log_b(x)=\frac{\ln x}{\ln b},\qquad b>0,\quad b\ne1,\quad x>0
$$
