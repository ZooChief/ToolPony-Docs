# 小费计算器使用指南



分摊账单与小费，可按税前或含税金额计算小费。





## 示例



### 输入



```
账单 80，小费 20%，4 人
```



### 预期结果



```
合计 96，每人 24
```







## 试一试

[打开完整工具 · 小费计算器](<https://toolpony.com/zh-hans/tools/tip-calculator/>)





## 计算方法



小费 = 所选金额 × 小费比例。每人金额为账单、税费与小费之和除以人数。
