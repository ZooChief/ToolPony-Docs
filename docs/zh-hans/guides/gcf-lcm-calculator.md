# 最大公因数与最小公倍数



计算多组大整数的最大公因数和最小公倍数。





## 开始使用



1. 按示例填写数值，或输入你自己的测量值。
2. 计算后可复制结果或下载明细。







## 示例



### 输入



```
12、18、24
```



### 预期结果



```
最大公因数 6，最小公倍数 72
```

## 使用提示



计算在浏览器内完成。无单位标记的字段请使用一致单位。







## 计算方法



最大公因数使用欧几里得算法。两个非零数的最小公倍数为乘积的绝对值除以最大公因数。最多支持 100 个 50 位整数。
