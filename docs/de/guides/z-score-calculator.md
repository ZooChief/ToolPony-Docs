# Z-Wert-Rechner



Einen Wert standardisieren und zwischen Z-Werten, Normalwahrscheinlichkeiten und Intervallen umrechnen.





## Erste Schritte



1. Verwenden Sie das Beispiel oder geben Sie eigene Werte ein.
2. Berechnen Sie das Ergebnis und kopieren oder laden Sie die Details herunter.







## Beispiel



### Eingabe



```
Wert 18, Mittelwert 23, Standardabweichung 4
```



### Erwartetes Ergebnis



```
z = −1.25
```

## Berechnungsmethode



Der Standardwert ist (x − μ)/σ. Die linke Randwahrscheinlichkeit ist die Normalverteilungsfunktion bei z. Für symmetrische Bereiche liefert die Umkehrung die nichtnegative Grenze.



$$
z=\frac{x-\mu}{\sigma},\qquad P(a<Z<b)=\Phi(b)-\Phi(a)
$$
