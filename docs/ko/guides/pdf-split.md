# PDF 분할



선택한 페이지를 새 PDF 또는 ZIP으로 저장합니다.





## 시작하기



1. 암호화되지 않은 PDF를 선택합니다.
2. 미리 보기에서 고르거나 5, 1-3처럼 페이지 범위를 입력합니다.
3. PDF 한 개, 범위별, 페이지별 중에서 선택합니다.
4. 고정 페이지 수 또는 파일 크기 제한으로도 나눌 수 있습니다. 생성한 PDF의 크기로 판단하며 다시 압축하지 않습니다.







## 예시



### 입력



```
5페이지 PDF, 선택 5, 1-3
```



### 예상 결과



```
5, 1, 2, 3 순서의 PDF 한 개
```







## 직접 사용해 보기



[전체 도구 열기](<https://toolpony.com/ko/tools/pdf-split/>)







## 제한 사항



최대 30 MB, 300페이지입니다. 페이지는 중복할 수 없습니다. ZIP에 담는 PDF는 총 64 MB까지입니다. 양식, 북마크, 전자 서명이 유지되지 않을 수 있습니다.
