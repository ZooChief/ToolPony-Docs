# 科學計算器



計算包含冪、階乘、三角函數、根式和對數的數學表達式。





## 開始使用



1. 按示例填寫數值，或輸入你自己的測量值。
2. 計算後可複製結果或下載明細。







## 示例



### 輸入



```
sqrt(81) + 2^3 × sin(30)，角度制
```



### 預期結果



```
13
```

計算在瀏覽器內完成。無單位標記的字段請使用一致單位。







## 計算方法



按括號、後綴、乘方、乘除、加減的優先級計算。乘方從右結合，百分號表示除以 100。結果採用浮點運算。
