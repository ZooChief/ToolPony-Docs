# 素因数分解



正の整数の素因、非定量、および除算数を見つける。





## 使い方



1. 例を使うか、任意の値を入力します。
2. 計算後、結果をコピーするか詳細をダウンロードできます。







## 例



### 入力



```
360
```



### 期待される結果



```
2³ × 3² × 5、約数は 24 個
```







## 試してみる



[ツール全体を開く](<https://toolpony.com/ja/tools/prime-factorization-calculator/>)







## 注意点



処理はブラウザ内で実行されます。単位をそろえて入力してください。







## 計算方法



試行分割は、残りの整数の平方根までの要因を除去します。 入力範囲:2〜1兆。
