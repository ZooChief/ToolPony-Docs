# 勾股定理計算器



輸入任意兩邊的長度或平方，解出 a² + b² = c²。





## 開始使用



1. 請輸入兩條不同邊的長度或平方。







## 示例



### 輸入



```
a² = 7，c² = 32
```



### 預期結果



```
b² = 32 − 7 = 25，因此 b = 5。
```

## 計算方法



求斜邊時將兩直角邊的平方相加。求直角邊時用斜邊平方減去另一條直角邊平方。邊長鬚爲正。



$$
c=\sqrt{a^2+b^2},\quad a=\sqrt{c^2-b^2},\quad b=\sqrt{c^2-a^2}
$$
