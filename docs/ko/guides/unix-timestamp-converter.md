# Unix 타임스탬프 변환기



seconds와 밀리초를 UTC로 변환하고, 명시적 오프셋이 있는 ISO 시간을 Unix 시간으로 다시 변환합니다.





## 시작하기



1. 예제 값을 사용하거나 원하는 값을 입력하세요.
2. 계산한 결과를 복사하거나 세부 정보를 내려받을 수 있습니다.







## 예시



### 입력



```
0 초
```



### 예상 결과



```
1970-01-01T00:00:00.000Z
```

## 계산 방법



Unix 시간은 1970-01-01T00:00:00Z 이후 경과 시간입니다. 변환 지원은 밀리초 정밀도에 1900년에서 9999까지입니다.







## 계산 모드



**현재까지 타임스탬프**

- Unix 타임스탬프
- 단위 · 초 / 밀리세컨즈





**타임스탬프 날짜**

- 오프셋을 가진 ISO 8601
