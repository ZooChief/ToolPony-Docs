# 기울기 계산기



기울기를 찾고 두 지점에서 가로채거나 주어진 거리에서 두 끝점을 모두 찾으십시오.





## 시작하기



1. 예제 값을 사용하거나 원하는 값을 입력하세요.
2. 계산한 결과를 복사하거나 세부 정보를 내려받을 수 있습니다.







## 예시



### 입력



```
(0, 0) ~ (3, 4)
```



### 예상 결과



```
사면 4/3 및 거리 5
```







## 직접 사용해 보기



[전체 도구 열기](<https://toolpony.com/ko/tools/slope-calculator/>)







## 참고 사항



브라우저에서 처리합니다. 단위를 일관되게 사용하세요.







## 계산 방법



경사는 달리기로 나눈 상승입니다. 수직 선은 정의되지 않은 기울기를 가지고 있습니다. 알려진 거리와 방향은 시작점의 반대쪽에 두 개의 끝점을 결정합니다.



$$
m=\frac{y_2-y_1}{x_2-x_1},\qquad \theta=\arctan(m),\qquad y=mx+b
$$



2 점 모드는 세로 및 수평 변경 사항을 별도로보고합니다. 각 변경의 기호를 사용하여 포인트가 이동한 방향을 알려줍니다. 수직 선은 일정한 x 좌표를 가지고 있습니다.



선 및 거리는 시작점의 각 측면에 있는 점을 결정합니다. 엔드포인트 테이블을 사용하여 두 솔루션을 모두 유지합니다.







## 계산 모드



**2 점**

- X1
- Y1
- X2
- Y2





**포인트 및 방향**

- X1
- Y1
- 거리
- 방향 지정 방식 · 기울기 / 각도 in degrees
- 방향 값
