# Bruchrechner



Verwenden Sie genaue Arithmetik, um Brüche und gemischte Zahlen zu addieren, zu subtrahieren, zu multiplizieren, zu teilen oder zu vereinfachen.





## Erste Schritte



1. Verwenden Sie das Beispiel oder geben Sie eigene Werte ein.
2. Berechnen Sie das Ergebnis und kopieren oder laden Sie die Details herunter.







## Beispiel



### Eingabe



```
1 1/2 + 2/3
```



### Erwartetes Ergebnis



```
13/6
```

## Hinweise



Die Verarbeitung erfolgt im Browser. Verwenden Sie einheitliche Einheiten.







## Berechnungsmethode



Die Dezimalzahlen werden als exakte Brüche gelesen. Arithmetik verwendet BigInt und reduziert um den größten gemeinsamen Teiler. Das Dezimalergebnis ist ungefähr.



$$
\frac{a}{b}+\frac{c}{d}=\frac{ad+bc}{bd},\qquad b,d\ne0
$$







## Berechnungsmodus



**Arithmetisch**

- Erste Nummer
- Rechenoperation · Additiv / Subtraktion / Multiplikation / Teilung
- Zweite Nummer





**Vereinfachen oder Konvertieren**

- Nummer





**Bruch bis Dezimalzahl**

- Fraktion oder gemischte Zahl
