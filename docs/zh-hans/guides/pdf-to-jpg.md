# PDF 转 JPG 或 PNG



选择 PDF，设定页码和分辨率。可下载单张图片，也可按选页顺序打包 ZIP。





## 开始使用



1. 选择未加密的 PDF。
2. 在缩略图选页或输入页码，再选择 JPG 或 PNG 及分辨率。
3. 转换后下载一张图片，或按选页顺序下载 ZIP。







## 示例



### 输入



```
一页 612 × 792 pt，PNG，144 DPI
```



### 预期结果



```
一张 1224 × 1584 像素的 PNG
```

## 使用提示



PDF 每英寸为 72 点。144 DPI 时每点对应两个像素。带旋转设置的页面按其原有方向输出。







## 适用范围



输入最大 30 MB、300 页。每次最多导出 40 页、总计 6000 万像素，每页最大 2400 万像素、每边最多 8,192 像素。ZIP 内图片合计最多 64 MB。以白底渲染，不支持加密 PDF。
