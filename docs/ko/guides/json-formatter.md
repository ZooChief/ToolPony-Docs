# JSON 포매터



JSON을 붙여넣고, 들여쓰기를 선택하고, 포맷하거나 축소하십시오. 결과를 복사하거나 JSON 파일을 다운로드합니다. Cmd/Ctrl + Enter는 포맷터를 실행합니다.





## 시작하기



1. JSON 문서를 붙여넣습니다.
2. 두 개 또는 네 개의 공백을 선택한 다음 포맷하십시오. 컴팩트 한 결과에 Miniify를 사용하십시오.
3. 결과를 복사하거나 JSON 파일을 다운로드합니다.







## 예시



### 입력



```
{"name":"ToolPony","ready":true}
```



### 예상 결과



```
{
  "name": "ToolPony",
  "ready": true
}
```







## 직접 사용해 보기



[전체 도구 열기](<https://toolpony.com/ko/tools/json-formatter/>)







## 참고 사항



키와 문자열은 두 개의 따옴표가 필요합니다. 주석 및 후행 쉼표는 JSON이 아닙니다. 안전한 정밀도 외부의 숫자는 조용히 가치를 변경하지 않도록 거부됩니다.







## 제한 사항



최대 1 MB. 유효하지 않은 JSON 및 안전하지 않은 숫자 정밀도는 거부됩니다. 포맷은 애플리케이션 스키마에 대해 유효성을 검사하지 않습니다.
