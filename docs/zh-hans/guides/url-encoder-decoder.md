# URL 编码与解码



编码或解码完整 URL、URI 组件和表单值。





## 开始使用



1. 按示例填写数值，或输入你自己的测量值。
2. 计算后可复制结果或下载明细。







## 示例



### 输入



```
编码组件：a+b & c
```



### 预期结果



```
a%2Bb%20%26%20c
```

## 使用提示



计算在浏览器内完成。无单位标记的字段请使用一致单位。







## 计算方法



组件编码转义保留分隔符。完整 URL 模式保留分隔符。表单模式用加号表示空格。
