# 二維碼識別



選擇、拖入或粘貼圖片。獨立工具頁也可以開啓相機。 覈對識別結果後複製或下載。確認地址後再打開網頁鏈接。





## 開始使用



1. 選擇、拖入或粘貼圖片。獨立工具頁也可以開啓相機。
2. 覈對識別結果後複製或下載。確認地址後再打開網頁鏈接。

每次讀一個二維碼。圖片最大 20 MiB、2400 萬像素，支持瀏覽器可讀的 PNG、JPEG、WebP 和 SVG。相機需瀏覽器授權，識別成功後關閉。圖片和幀留在本機。
