# 날짜 계산기



날짜와 영업일을 세고 달력 단위나 영업일로 날짜를 이동합니다.





## 시작하기



1. 날짜를 세려면 두 날짜를 입력하고 늦은 날짜 포함 여부를 선택하세요. 추가 옵션에서 휴일을 입력하세요.
2. 이전 날짜로 이동하려면 음수를 입력하세요. 영업일 이동은 토요일, 일요일, 지정한 휴일을 건너뜁니다.







## 예시



### 입력



```
2020-01-01부터 2020-02-01까지
```



### 예상 결과



```
31일, 영업일 23일
```







## 직접 사용해 보기



[전체 도구 열기](<https://toolpony.com/ko/tools/date-calculator/>)







## 참고 사항



브라우저에서 처리합니다. 단위를 일관되게 사용하세요.







## 계산 방법



영업일은 월~금에서 지정한 휴일을 뺍니다. YYYY-MM-DD는 한 번, MM-DD는 매년 적용됩니다. 영업일 이동은 이른 날짜를 포함하고 늦은 날짜는 제외합니다. 결과가 주말이나 휴일일 수 있습니다. 짧은 달은 말일로 맞춥니다.







## 계산 모드



**날짜 간격**

- 시작 날짜
- 종료 날짜
- 종료 날짜 포함
- 휴일(YYYY-MM-DD 또는 MM-DD)





**날짜 더하기 또는 빼기**

- 시작 날짜
- 년
- 개월
- 주
- 일





**영업일로 이동**

- 시작 날짜
- 영업일
- 휴일(YYYY-MM-DD 또는 MM-DD)
