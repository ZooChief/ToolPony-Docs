# 利潤率與加價率



由成本與售價計算毛利率和加價率，或按目標毛利率定價。





## 示例



### 輸入



```
成本 60，售價 100
```



### 預期結果



```
毛利率 40%，加價率約 66.67%
```







## 試一試

[打開完整工具 · 利潤率與加價率](<https://toolpony.com/zh-hant/tools/margin-calculator/>)





## 計算方法



毛利率 = 毛利 ÷ 售價，加價率 = 毛利 ÷ 成本。按目標毛利率定價時，售價 = 成本 ÷（1−毛利率）。







## 計算模式



**成本與售價**

- 成本
- 售價





**按目標毛利率定價**

- 成本
- 目標毛利率 · %
