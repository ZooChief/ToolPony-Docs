# Verhältnisrechner



Lösen Sie einen fehlenden Begriff in einer Proportion, vereinfachen Sie ein Verhältnis oder skalieren Sie beide Begriffe.





## Erste Schritte



1. Verwenden Sie das Beispiel oder geben Sie eigene Werte ein.
2. Berechnen Sie das Ergebnis und kopieren oder laden Sie die Details herunter.







## Beispiel



### Eingabe



```
3:4 = x:20
```



### Erwartetes Ergebnis



```
x=15
```







## Ausprobieren



[Vollständiges Werkzeug öffnen](<https://toolpony.com/de/tools/ratio-calculator/>)







## Hinweise



Die Verarbeitung erfolgt im Browser. Verwenden Sie einheitliche Einheiten.







## Berechnungsmethode



A:B = C:D impliziert A × D = B × C, mit ungleichen Nennern.







## Berechnungsmodus



**Einen Anteil lösen**

- A
- B
- C
- D





**Vereinfachen oder Skalieren**

- Erstes Glied
- Zweite Amtszeit
- Skalierungsfaktor





**Vergrößern oder Verkleinern eines Verhältnisses**

- Erstes Glied
- Zweite Amtszeit
- Richtung · Reduzieren / Erweiterung
- Faktor
