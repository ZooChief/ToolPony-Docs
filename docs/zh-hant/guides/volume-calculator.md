# 體積計算器



支持球、圓錐、圓柱、長方體、膠囊體、球冠、橢球、棱錐和空心管等，可混用尺寸單位。





## 開始使用



1. 按示例填寫數值，或輸入你自己的測量值。
2. 計算後可複製結果或下載明細。







## 示例



### 輸入



```
球半徑 2 米
```



### 預期結果



```
約 33.5103 立方米
```

## 使用提示



計算在瀏覽器內完成。無單位標記的字段請使用一致單位。







## 計算方法



棱柱體積等於底面積乘垂直高度，圓錐和棱錐再除以三。空心管扣除內圓柱。球冠可填寫任意兩個尺寸。



$$
V_{\mathrm{cone}}=\tfrac13\pi r^2h,\qquad V_{\mathrm{sphere}}=\tfrac43\pi r^3
$$
