# CSV 비교



이전 표와 새 표를 붙여넣거나 가져오세요. 첫 행은 머리글로 두고 구분자와 키 열을 고르세요. 표를 비교하고 변경을 필터링하세요. 스프레드시트에는 CSV, 원문을 보존하는 전체 보고서에는 JSON을 사용합니다.





## 시작하기



1. 이전 표와 새 표를 붙여넣거나 가져오세요. 첫 행은 머리글로 두고 구분자와 키 열을 고르세요.
2. 표를 비교하고 변경을 필터링하세요. 스프레드시트에는 CSV, 원문을 보존하는 전체 보고서에는 JSON을 사용합니다.







## 예시



### 입력



```
ID,Name,Qty
001,Oak,2
002,Pine,1
004,Ash,3

Qty,ID,Name
4,001,Oak
1,003,Fir
3,004,Ash
```



### 예상 결과



```
추가 1 · 누락 1 · 변경 1
```







## 직접 사용해 보기



[전체 도구 열기](<https://toolpony.com/ko/tools/csv-compare/>)







## 제한 사항



표당 UTF-8 1 MiB, 데이터 행 5,000개 및 열 80개까지 지원합니다. 앞자리 0을 포함해 텍스트를 그대로 비교합니다. 중복 키와 빈 키는 따로 표시하며 머리글부터 레코드 번호를 셉니다.
