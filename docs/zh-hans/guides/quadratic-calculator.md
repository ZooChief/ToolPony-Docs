# 二次方程计算器



求 ax² + bx + c = 0 的实根或复根，支持分数系数。





## 开始使用



1. 按示例填写数值，或输入你自己的测量值。
2. 计算后可复制结果或下载明细。







## 示例



### 输入



```
a=1，b=−5，c=6
```



### 预期结果



```
x₁=2，x₂=3
```

## 使用提示



计算在浏览器内完成。无单位标记的字段请使用一致单位。







## 计算方法



判别式为 b²−4ac。二次项系数为零时按一次方程处理。



$$
ax^2+bx+c=0,\qquad x=\frac{-b\pm\sqrt{b^2-4ac}}{2a},\quad a\ne0
$$
