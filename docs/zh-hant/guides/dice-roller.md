# 擲骰子



自定義骰子面數和顆數，查看每次擲骰及合計。





## 開始使用



1. 按示例填寫數值，或輸入你自己的測量值。
2. 計算後可複製結果或下載明細。







## 示例



### 輸入



```
3 顆六面骰
```



### 預期結果



```
三個點數與總和
```

## 使用提示



計算在瀏覽器內完成。無單位標記的字段請使用一致單位。







## 計算方法



每顆骰子獨立使用 Web Crypto 均勻抽取。最多 100 顆，每顆可選 2 至 1,000 面。
