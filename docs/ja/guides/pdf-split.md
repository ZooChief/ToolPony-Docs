# PDF を分割



ページを選択し、新しい PDF または ZIP に保存します。





## 使い方



1. 暗号化されていない PDF を選択します。
2. サムネイルを選ぶか、5, 1-3 のようにページ番号を入力します。
3. 1 件の PDF、範囲ごと、ページごとのいずれかを選択します。
4. 固定ページ数やファイルサイズ上限でも分割できます。サイズは生成された PDF で判定し、再圧縮しません。







## 例



### 入力



```
5 ページの PDF、選択 5, 1-3
```



### 期待される結果



```
5、1、2、3 ページの順で 1 件の PDF
```







## 試してみる



[ツール全体を開く](<https://toolpony.com/ja/tools/pdf-split/>)







## 制限



30 MB・300 ページまで。重複ページは指定できません。ZIP 内の PDF は合計 64 MB まで。フォーム、しおり、電子署名は保持されない場合があります。

[ドキュメント](https://docs.toolpony.com/ja/guides/pdf-split/)
