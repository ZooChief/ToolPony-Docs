# 最大公約数・最小公倍数の計算の使い方



大きな整数のリストに対して、最も一般的な要素と最小の倍数を見つけましょう。





## 例



### 入力



```
12, 18, 24
```



### 期待される結果



```
GCF 6;LCM 72
```







## 試してみる

[ツール全体を開く · 最大公約数・最小公倍数の計算](<https://toolpony.com/ja/tools/gcf-lcm-calculator/>)





## 計算方法



ユークリッドのアルゴリズムはGCFを発見する。 LCM(a,b) = |a·b| ÷ GCF(a,b) がいずれもゼロでない場合。 それぞれ50桁の最大100個の整数。
