# Document en texte



Choisissez un fichier DOCX, ODT ou PDF sur votre appareil ou ouvrez l’exemple DOCX.





## Prise en main



1. Choisissez un fichier DOCX, ODT ou PDF sur votre appareil ou ouvrez l’exemple DOCX.
2. Chaque paragraphe commence sur une nouvelle ligne. Les tabulations séparent les cellules. Copiez le résultat ou téléchargez le fichier UTF-8.







## Exemple



### Entrée



```
DOCX avec un titre, deux fragments de texte et une tabulation
```



### Résultat attendu



```
ToolPony
ABC	123
```







## Essayer



[Ouvrir l’outil complet](<https://toolpony.com/fr/tools/document-to-text/>)







## Limites



DOCX et ODT sont lus dans le corps du document, jusqu’à 20 Mio par fichier et 1 Mio de texte UTF-8 extrait. Le PDF doit contenir du texte sélectionnable. Images, mise en page et fichiers protégés sont exclus.

[Documentation](https://docs.toolpony.com/fr/guides/document-to-text/)
