# Profit margin and markup



Find gross margin and markup from cost and price, or price a product at a target margin.





## Get started



1. Use the example values or enter your own measurements.
2. Calculate, then copy the result or download the available details.







## Example



### Input



```
Cost 60, price 100
```



### Expected result



```
40% margin; 66.67% markup
```







## Try it



[Open full tool](<https://toolpony.com/en/tools/margin-calculator/>)







## Good to know



The calculation runs in your browser. Use consistent units in fields with no explicit unit.







## Calculation method



Margin = profit ÷ selling price. Markup = profit ÷ cost. A target margin requires selling price = cost ÷ (1−margin).







## Calculation mode



**Cost and price**

- Cost
- Selling price





**Price at a target margin**

- Cost
- Target margin · %
