# Calculadora del teorema de Pitágoras



Resuelve a² + b² = c² a partir de longitudes o cuadrados de dos lados.





## Primeros pasos



1. Introduce las longitudes o cuadrados de dos lados distintos.







## Ejemplo



### Entrada



```
a² = 7, c² = 32
```



### Resultado esperado



```
b² = 32 − 7 = 25, de modo que b = 5.
```

## Método de cálculo



Suma los cuadrados de los catetos para la hipotenusa. Para un cateto, resta del cuadrado de la hipotenusa el del otro cateto. Las longitudes son positivas.



$$
c=\sqrt{a^2+b^2},\quad a=\sqrt{c^2-b^2},\quad b=\sqrt{c^2-a^2}
$$
