# 乱数生成



任意の一意と並べ替えで、包括的な範囲でランダムな整数を生成します。





## 使い方



1. 例を使うか、任意の値を入力します。
2. 計算後、結果をコピーするか詳細をダウンロードできます。







## 例



### 入力



```
最小 1、最大 10、個数 5
```



### 期待される結果



```
1～10 の乱数（整数）を 5 個
```







## 試してみる



[ツール全体を開く](<https://toolpony.com/ja/tools/random-number-generator/>)







## 注意点



処理はブラウザ内で実行されます。単位をそろえて入力してください。







## 計算方法



Web Crypto の乱数を使います。棄却サンプリングで剰余の偏りを避けます。−1,000,000,000 から 1,000,000,000 までの整数を最大 1,000 個生成します。

[ドキュメント](https://docs.toolpony.com/ja/guides/random-number-generator/)
