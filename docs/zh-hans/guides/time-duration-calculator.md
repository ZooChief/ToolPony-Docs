# 时长计算器



计算时刻或日期时间的间隔、加减时长，也可移动日期时间。





## 开始使用



1. 单班用时刻间隔，多天用日期时间间隔，混合加减可用表达式。







## 示例



### 输入



```
22:30 至 06:15，跨日
```



### 预期结果



```
07:45:00
```

## 使用提示



计算在浏览器内完成。无单位标记的字段请使用一致单位。







## 计算方法



时刻间隔可以跨午夜。填写日期时，每日按 24 小时。表达式用 d、h、m、s 表示天、小时、分钟和秒，减号作用于后面一整组时间量。



$$
T=86400d+3600h+60m+s
$$
